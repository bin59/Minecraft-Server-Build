### 📌 插件概述

AntiLitematica 是一款专为 **Paper/Spigot** 服务器设计的插件，旨在从服务端检测并阻止玩家使用 **Litematica**、**Schematica** 等投影模组的作弊功能，尤其是其“**打印机 (Printer)**”和“**快速放置 (EasyPlace)**”。

它完全在服务端运行，**无需客户端安装任何模组**，非常适合用于维护建筑比赛的公平性。

---

### ✨ 核心功能特点

- **多层检测机制**：
  - **网络频道检测**：监控 `servux:litematics`（Litematica）和 `schematica`（Schematica）等频道注册。
  - **ProtocolLib 深度检测**：捕获异常数据包，即使玩家关闭同步功能也能检测。
  - **反打印机引擎**：通过强制光线追踪、放置速率限制等分析方块放置行为，识别非人类模式。
  - **命令防护**：阻止 `/setblock` 等可能用于快速粘贴的命令。
- **渐进式惩罚系统**：支持 **警告 → 临时封禁 → 永久封禁** 的递进式处罚，并可集成 LiteBans、AdvancedBan 等主流封禁插件。
- **智能兼容与适配**：
  - **Geyser 兼容**：自动豁免基岩版玩家，防止协议转换导致的误报。
  - **动态阈值**：根据服务器 TPS 自动调整检测灵敏度，降低对性能的影响。
  - **反作弊集成**：支持可选的 GrimAC 集成。
- **便捷管理**：提供**游戏内 GUI 配置**界面，支持热重载，并可通过 Discord Webhook 发送违规通知。

### ⚙️ 安装步骤

1.  **检查前置要求**：
    - **服务端**：Paper、Spigot 或 Bukkit。
    - **必需前置**：**ProtocolLib** 插件。（注意：务必下载与你的服务端版本兼容的 ProtocolLib 版本）
    - **可选前置**：PlaceholderAPI、Geyser、LiteBans、AdvancedBan、EssentialsX 等。

2.  **下载插件**：从 MCBBS、SpigotMC 等可信来源下载最新版 AntiLitematica 的 `.jar` 文件。

3.  **安装插件**：
    - 将下载的 `AntiLitematica.jar` 文件放入服务端的 `plugins` 文件夹。
    - 确保 `ProtocolLib.jar` 也已在 `plugins` 文件夹中。

4.  **重启服务器**：完全重启你的服务器，或使用 `/reload` 命令（不推荐）来加载插件。首次启动会自动生成配置文件。

---

### 🛠️ 配置详解

所有配置存储在 `plugins/AntiLitematica/` 目录下的 `config.yml` 和 `messages.yml` 文件中。`config.yml` 的主要配置部分如下：

| 配置部分                   | 作用                                                                                                                              |
| :------------------------- | :-------------------------------------------------------------------------------------------------------------------------------- |
| **`detection`**            | **检测设置**：配置要监控的频道列表，以及检测到违规时的动作（如仅记录日志 `LOG`、踢出 `KICK`、封禁 `BAN` 或执行命令 `COMMANDS`）。 |
| **`anti_printer`**         | **反打印机引擎**：核心设置！调整光线追踪、放置速率限制、连续相同方块检测等阈值，灵敏度越高，误报风险也可能增加。                  |
| **`command_guard`**        | **命令防护**：设置需要阻止的命令列表（如 `/setblock`）以及命令执行的频率限制。                                                    |
| **`graduated_punishment`** | **渐进式惩罚**：定义惩罚的等级（如第几次违规）和对应的持续时间（如 1h, 1d, 7d）。                                                 |
| **`geyser_compat`**        | **Geyser 兼容**：启用或禁用对基岩版玩家的自动豁免。                                                                               |
| **`discord`**              | **Discord 通知**：配置 Webhook URL，以便在检测到违规时发送通知到你的 Discord 频道。                                               |

完整配置：[config.yml](./config.yml)

> **💡 配置建议**：
>
> - 对于建筑比赛等严格场景，可以保持较高的检测灵敏度，并设置“踢出”或“封禁”等严厉的处罚动作。
> - 对于允许一定辅助的生存服务器，可以适当放宽 `anti_printer` 中的阈值，并将处罚动作设为“警告”或“仅记录日志”，避免误伤。

### ⌨️ 命令与权限

- **主要命令**：
  - `/aal reload`：重新加载插件配置文件。
  - `/aal test <玩家名>`：手动扫描指定玩家。
- **权限节点**：
  - `antilitematica.admin`：允许使用所有管理命令。
  - `antilitematica.bypass`：拥有此权限的玩家将**免受检测**，适合用于管理员或建筑比赛裁判。

---

### 🧠 工作原理简析

插件的检测流程如下：

1.  **频道监控**：玩家加入时，检查其是否注册了 Litematica 或 Schematica 的专用网络频道。
2.  **数据包拦截**：通过 ProtocolLib 拦截并分析可疑数据包，如异常的点击向量或 NBT 查询请求。
3.  **行为分析**：由“反打印机引擎”分析玩家的方块放置行为，判断是否存在“非人类”模式（如放置速度过快、无需视线瞄准等）。
4.  **执行处罚**：一旦确认违规，根据配置执行相应的处罚动作。

### ❓ 常见问题与解决方案

- **Q：安装后玩家反馈被误判怎么办？**
  - **A**：首先，检查 `config.yml` 中的 `anti_printer` 阈值是否过于严格。其次，可以给予特定玩家 `antilitematica.bypass` 权限以豁免检测。最后，建议在服务器规则中说明插件存在，并为玩家提供申诉渠道。
- **Q：插件会影响服务器性能吗？**
  - **A**：插件本身设计有“动态阈值”功能，会根据服务器 TPS 自动调整检测强度以减轻负担。但在线玩家数量很多时，建议关注服务器性能表现。
- **Q：为什么基岩版玩家总被误报？**
  - **A**：确保在 `config.yml` 中正确启用了 `geyser_compat` 选项。如果问题依旧，请检查 Geyser 插件版本是否兼容。
- **Q：插件无法正常工作或报错怎么办？**
  - **A**：首先检查 `ProtocolLib` 是否为最新版本且与你的服务端版本兼容。然后查看服务端控制台日志中的具体报错信息，这通常是解决问题的关键。
