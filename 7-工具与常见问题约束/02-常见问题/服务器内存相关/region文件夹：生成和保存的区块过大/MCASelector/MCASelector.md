# MCA Selector的详细使用

MCA Selector 是一款专为 Minecraft Java版设计的强大区块管理工具，能帮你可视化地查看、选择、删除或导出世界中的区块，非常适合用来优化存档体积或清理服务器里跑图产生的冗余区块。

以下是它的详细使用指南：

### 📥 1. 获取与安装

- **官方下载**：建议直接前往官方 GitHub 仓库（`github.com/Querz/mcaselector`）的 Releases 页面下载。根据你的系统选择 Windows 安装包、macOS 版本或通用的 `.jar` 文件。
- **环境要求**：需要安装 Java 8 或更高版本的运行环境。
- **⚠️ 核心警告**：在进行任何操作前，**务必备份你的世界存档**！虽然工具自带备份机制，但手动备份是防止数据丢失的最安全底线。

### 🧹 2. 清理服务器跑图产生的冗余区块

对于面向国际服的服务器，定期清理玩家跑图产生的无用区块是控制存档体积和降低 I/O 负载的关键。

**常规可视化清理：**

1.  **停服备份**：操作前务必停服，并对 `world`、`world_nether`、`world_the_end` 进行完整备份。
2.  **智能筛选**：打开 MCA Selector，点击 `Filter`。推荐使用以下组合条件来精准定位“鬼区”：
    - `InhabitedTime < 1m`（玩家停留时间小于1分钟，通常是跑图误加载）
    - `LastUpdate > 30d`（最后更新时间在30天前）
    - `DistanceFromSpawn > 5000`（距离出生点大于5000格，保护主城和核心基地）
3.  **执行删除**：确认预览无误后，按下 `Ctrl + D` 批量删除。

**💡 运维进阶：命令行自动化**
既然你有插件开发经验，完全可以把这个清理动作写成 Shell 脚本，结合 `cron` 定时任务，在服务器低峰期（比如每周四凌晨）自动执行，省去手动操作：

```bash
# 示例：自动清理主世界中距离出生点5000格外，且玩家停留时间小于1分钟的区块
java -jar mcaselector.jar --world /path/to/server/world --delete --filter "DistanceFromSpawn>5000 && InhabitedTime<1m"
```

### 📦 3. 跨存档迁移建筑

**方案 A：使用 MCA Selector（适合大型建筑群/完整地形）**

1.  **导出**：在源存档中框选建筑区域，点击 `File` > `Export Selection` 保存为 `.mca` 文件。
2.  **导入**：打开目标存档，点击 `File` > `Import Selection`，拖动绿色预览框到目标坐标，按下 `Ctrl + V` 覆盖。

- **⚠️ 注意**：跨存档迁移时，尽量保证两个存档的游戏版本和 Mod 环境一致。如果是国际服跨版本迁移，极易导致自定义方块或实体 NBT 数据丢失报错。

**方案 B：使用结构方块（适合纯建筑/小型搬迁）**
如果你只是想把一个纯建筑（不带周边复杂地形）搬过去，用游戏内的结构方块会更安全：

1.  在源存档用结构方块（Save 模式）框选并保存建筑。
2.  去存档目录的 `structures` 文件夹，把生成的 `.nbt` 文件复制到目标存档的同名文件夹下。
3.  在目标存档用结构方块（Load 模式）读取并放置。

**💡 进阶思路：插件化迁移**
既然你平时会自己写服务器插件，其实完全可以开发一个基于 Bukkit/Spigot API 的轻量级迁移插件。通过读取源存档的区块 NBT 数据，直接在内存中实例化到目标世界。这样不仅能完美规避 MCA Selector 跨版本带来的格式兼容问题，还能在后台异步执行，连停服都不需要。

你可以先评估一下这次要迁移的建筑规模，如果数据量不大，直接用 MCA Selector 或结构方块就能快速搞定。

### 📦 4.进阶功能：导出与导入（区块迁移）

如果你想在不同的存档之间转移建筑，或者把服务器里的某个基地搬到单机存档，这个功能非常实用：

1.  **导出**：在源世界中框选目标区域，点击 `File` > `Export Selection`，将其保存为 `.mca` 文件。
2.  **导入**：在目标世界中，点击 `File` > `Import Selection`，选择刚才的文件，拖动绿色预览框到目标坐标，按下 `Ctrl + V` 并确认覆盖即可。

- **注意**：跨存档复制时，尽量保证两个存档的游戏版本和 Mod 环境一致，否则可能导致方块丢失或实体报错。

### 5.高级技巧：批量修改属性

点击 `Edit` > `Change Fields`，可以批量修改选中区块的 NBT 数据。例如，批量更改某片区域的生物群系（Biome），或者重置区块的 `LastUpdate` 时间戳，这在地图制作和服务器运维中非常高效。

**💡 运维小建议**：如果是用来维护服务器，操作前一定要先停服，避免文件被占用导致数据损坏或读写冲突。
