# ✅ 报错解析

```
Failed to validate message acknowledgements from PumpkinVegetable: Checksum mismatch on last seen update: the client and server must have desynced
PumpkinVegetable lost connection: Chat message validation failure
```

**这是MC原版安全聊天（Chat Signing）的原生BUG（MC-309298）**，不是VoiceChat模组本身问题，只是VoiceChat跟着一起断开连接。

> 现象：客户端和服务端的「聊天消息确认校验和」不同步，发送聊天消息时直接踢人，**间歇性触发**，刚好符合你说的「有时候打字发送就闪退/被踢」。 触发条件：

1. 玩家客户端开启了**聊天延迟（Chat Delay）**
2. 快速连续发消息、网络抖动、数据包丢包
3. 开启了 `enforce-secure-profile=true`，强制开启聊天签名校验
4. 聊天预览 enable-chat-preview=true 会加剧这个问题

------

# 🚀 南瓜生存服 Fabric 解决步骤（按顺序操作）

## 1. 修改 server.properties（最重要）

打开服务端 `server.properties`，修改这两项：

```
enforce-secure-profile=false
enable-chat-preview=false
```

- `enforce-secure-profile=false`：关闭强制安全聊天签名（根治这个校验和踢人）
- `enable-chat-preview=false`：关闭聊天预览，预览功能极易破坏聊天同步

修改完**重启服务器**。

## 2. 安装 Fabric 模组 No Chat Reports（强烈推荐）

对应你服务器版本的 NoChatReports，**服务端+客户端都装** 作用：完全禁用MC的聊天签名、消息校验链，直接杜绝 `Checksum mismatch` 踢人问题，很多Fabric生存服都用这个方案。

> 注意：玩家客户端也必须装上这个mod，否则会提示聊天不安全警告。

## 3. 让玩家客户端这边做2个设置（可以发群公告）

1. 游戏内设置 → 聊天，

   把【聊天延迟 Chat Delay】设置为「无」

   > Mojang官方确认：只要Chat Delay不为无，就会有概率触发这个踢人BUG

2. 不要短时间疯狂连续刷屏发消息，容易触发同步错位

## 4. 额外排查点（Fabric特有）

- 检查有没有其他修改聊天数据包的mod：聊天美化、自定义聊天格式、中文输入mod（CaramelChat），这类mod会修改聊天包，**加重聊天签名不同步**
- VoiceChat只是附带断开，不是元凶，不用删voicechat，上面改完语音不会因为这个报错掉线

## 5. 临时应急方案（不改配置）

玩家被踢后**退出重进服务器**，聊天同步状态重置，暂时恢复正常，但还会复发，只能临时救急。

# 简单一句话总结

这个是MC原版聊天签名校验的BUG，`enforce-secure-profile=true` + 聊天延迟/网络波动 → 校验和错位踢人。 优先：`server.properties`关闭强制安全聊天 + 安装NoChatReports，同时让玩家把聊天延迟改成**无**。
