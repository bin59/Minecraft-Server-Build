# 综合RPG框架（数据包部署说明）

> 目标服务器：Leaf 1.21.11（Paper 分支）Java/基岩互通服
> 部署位置：`world\datapacks\rpg_framework`（143 个文件）
> 适配版本：Minecraft Java 1.21.11，数据包格式 94

## 一、部署与加载

1. 把 `rpg_framework` 文件夹放入主世界 `world/datapacks/`。
2. 重启服务器，或游戏内执行 `/reload`（OP）。
3. 数据包挂载点：`data/minecraft/tags/function/load.json`（启动执行 `rpg:load`）、`tick.json`（每刻执行 `rpg:tick`）。
4. 卸载（清空全部 RPG 数据）：执行函数 `rpg:uninstall`，会删除血条、标签、属性修饰符、全部计分板、传送点存储。

数据包是纯服务端逻辑（计分板 + 函数 + 指令），基岩玩家经 Geyser 接入后同样执行；玩家交互统一走 `/trigger` 指令（非 OP 可用，基岩玩家可手动输入）。

## 二、双端入口（怎么打开菜单）

| 端 | 打开方式 |
|---|---|
| Java 版 | 按 ESC 暂停菜单 / 快捷动作键 / 右键「冒险指南」道具 → 图形弹窗（Dialog） |
| 基岩版 | 右键「冒险指南」道具 / 聊天栏按钮 → 聊天菜单（tellraw 按钮可点） |
| 通用兜底 | `/trigger rpg.gui` → 弹出主菜单 |

- **技能魔杖** = 胡萝卜钓竿（`rpg.stick` 计分板），右键释放职业技能。
- **冒险指南** = 诡异菌钓竿（`rpg.guide` 计分板），右键打开主菜单。
- 新手进服自动发放这两件道具 + 面包×16。旧存档玩家没有指南道具时补发：`/give <玩家> minecraft:warped_fungus_on_a_stick`，或直接按 ESC 打开。

## 三、模块清单

### 1. 职业系统
四职业，新手引导选择，触发器 `trigger rpg.pick set 1~4`：

| 职业 | 被动加成 |
|---|---|
| 战士 | 攻击+3、生命+4 |
| 弓箭手 | 移速+15% |
| 法师 | 技能冷却-30% |
| 牧师 | 持续回血（每 20 tick 挂 2 秒再生） |

管理员可用 `rpg:admin/reset_player` 重置玩家职业与进度。

### 2. 等级与经验
- 每杀 1 只怪 +1 经验 +1 金币。
- 升级所需经验公式：`20 + (等级-1) × 12`。
- 升级奖励：+50 金、回血特效、全服广播；支持连升多级。
- 10 级起每 2 级 +1 最大生命（上限 +10），用 attribute modifier 实现，可精确移除。

### 3. 技能系统
右键技能魔杖（胡萝卜钓竿）或 `/trigger rpg.skill`，统一走冷却判断。四职业技能：

| 职业 | 技能效果 |
|---|---|
| 战士 | 冲锋怒吼：8 秒力量+1、抗性+1，周围敌人短暂悬浮震飞 |
| 弓箭手 | 箭雨：头顶召唤 6 支不可拾取的箭 |
| 法师 | 圣火流星：视线前方 3 个火球垂直坠落（不破坏地形） |
| 牧师 | 圣光普照：治疗 8 格内所有玩家 |

### 4. 任务系统
- **3 条可重复普通任务**（杀僵尸 / 拾铁锭 / 杀骷髅）+ **3 条每日任务**（杀 15 怪 / 采 20 石头 / 拾 5 绿宝石）。
- 状态机：`0 未接取 → 1 进行中 → 2 已达标待交付 → 0`；每日任务多一态 `3 = 今日已完成`（跨天自动归零）。
- 接取时记录统计基准值，进度 = 当前统计 − 基准，避免历史数据污染。

### 5. 经济系统
- **金币商店**：10 种商品，余额检查 → 扣款 → 发货 → 提示。药水用 1.21 物品组件语法。
- **玩家转账**：转给 16 格内最近的玩家（规避基岩版无法解析玩家名）。
- **每日签到**：按游戏内天数限制每天一次。

### 6. 传送系统
- 坐标存 `storage rpg:warps`（w1/w2/w3，每点含 x/y/z/dim）。
- 管理员站在目标位置执行设置函数，自动写入坐标与维度。
- 传送用函数宏 `$execute in $(dim) run tp @s $(x) $(y) $(z)`，一行解决跨维度。

### 7. BOSS 战
- 门槛：等级 ≥ 5 且金币 ≥ 300。
- 全服仅一只（全局锁）；200 血强化僵尸，抗火+迅捷永久效果，全套下界合金装备且掉落率归零。
- 击杀奖励：全服 +500 金 +300 经验。
- 弹窗 `boss_confirm` 为确认型，防误触浪费 300 金。

### 8. 精英入侵
- 门槛：3 级 + 100 金。
- 召唤精英僵尸/骷髅/苦力怕（各 60 血，防火，禁拾装备，防消失）。
- 每刻用专属血条显示剩余精英数；全部击败 → 全服 +300 金 +200 经验 + 胜利演出。
- 管理员强制移除：`rpg:admin/elite_remove`（不发奖励）。

### 9. 幸运抽奖
- 花费 50 金一次，`random value` 出随机数，概率公示在弹窗正文：

| 奖项 | 概率 |
|---|---|
| 100 金 | 50% |
| 200 金 | 25% |
| 500 金 | 10% |
| 附魔金苹果 | 5% |
| 谢谢惠顾 | 10% |

### 10. 等级里程碑奖励
接入升级函数末尾：

| 等级 | 奖励 |
|---|---|
| 5 级 | 200 金 + 金苹果×2 |
| 10 级 | 500 金 + 钻石剑 |
| 20 级 | 1000 金 + 附魔金苹果 + 钻石×8 |
| 30 级 | 2000 金 + 下界合金锭×2 |
| 50 级 | 5000 金 + 附魔下界合金剑（锋利5+火焰附加2） |

### 11. 成就系统
11 个成就，全部用 `impossible` 准则（由函数手动授予），分主线链（选职业 → 5/10/20/30/50 级）与支线（首次技能 / 累计 5 任务 / 击败 BOSS / 平息入侵 / 攒 10000 金）。

## 四、管理员指令速查

| 函数 / 指令 | 作用 |
|---|---|
| `rpg:uninstall` | 卸载数据包，清空全部 RPG 数据 |
| `rpg:admin/reset_player` | 重置玩家职业、等级、每日任务状态 |
| `rpg:admin/elite_remove` | 强制清除在场精英怪（不发奖励） |
| `/trigger rpg.gui` | 打开主菜单（玩家兜底入口） |
| `/trigger rpg.stats` | 查看角色信息（聊天面板） |
| `/trigger rpg.quest` | 查看任务进度（聊天面板） |

## 五、已知限制

1. **图形弹窗不显示动态数据**：角色金币、任务进度等实时数值只能在聊天面板（`/trigger rpg.stats`、`/trigger rpg.quest`）查看，这是 Dialog 系统的固有限制（不支持 score/selector/NBT 组件）。
2. **基岩版无图形弹窗**：Geyser 不转发 Dialog，基岩玩家走聊天按钮通道，功能一致、仅交互形式不同。
3. **界面文字为纯中文无 emoji**：游戏默认字体渲染不了 emoji，会显示方块。
