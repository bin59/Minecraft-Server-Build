# 末影龙重生与破坏保护

> 需求：控制末影龙重生（但不刷新黑曜石柱子）+ 战斗时不能破坏旁边建筑。
> 方案：**dragon-block-plugin**（拦截龙的一切方块破坏）+ **DragonManager**（自研，命令重生龙、绕过原版柱子重置仪式）。
> 2026-09-25 部署，待重启生效。

## 一、为什么不能直接"放水晶重生"

原版机制：在末地返回传送门四角放 4 个末影水晶 → 触发完整重生仪式 → **重置全部黑曜石柱**、清掉柱子上玩家放的方块（Mojira MC-279520 确认）、生成新水晶塔 → 龙在 (0,128,0) 出现。
只要走原版仪式，柱子就必然被刷新，无法保留玩家改造过的柱子/建筑。所以要绕过仪式，直接生成龙实体。

## 二、DragonManager（自研插件，plugins/DragonManager.jar）

`com.hh.dragon.DragonManager` v1.0.0，Java 21 字节码，api-version 1.20（对 Leaf 1.21.11 向下兼容，与 AdvZone 同一套编译链：本机 .m2 的 spigot-api-1.20.1 + JDK21）。

### 命令
| 命令 | 权限 | 说明 |
|---|---|---|
| `/dragon respawn [世界名]` | `dragon.admin`（默认 op） | 在指定世界（缺省 world_the_end）的 (0,128,0) 生成末影龙。**不刷新黑曜石柱、不重置祭坛**。已存在龙时拒绝重复生成 |

### 拦截逻辑
- 监听 `EntityPlaceEvent`：**禁止在末地返回传送门四角（(±4,75,0) / (0,75,±4) 附近）放置末影水晶** → 取消 + 提示改用 `/dragon respawn`。柱子顶部、其他位置放水晶不受影响（战斗回血机制保留）。
- 目的：杜绝玩家用原版仪式把柱子刷掉。

### 重生方式的差异（重要，已如实说明）
`/dragon respawn` 生成的是"普通龙实体"，和原版战斗龙有差异：

| 项 | 原版水晶重生 | /dragon respawn |
|---|---|---|
| 黑曜石柱 | 全部重置 | **保持原样** |
| BossBar 血条 | 有 | 无（普通实体） |
| 击杀龙蛋 | 掉（仅首次） | 不掉（不经战斗逻辑） |
| 出口传送门/传送门 | 重置/激活 | 不动 |
| 掉落经验 | 有 | 有 |

- 如果玩家还没打过首次末影龙战斗（没拿过蛋），建议先正常打完一次再启用命令重生，避免错过龙蛋。
- 需要 BossBar 的话可以后续给插件加（生成龙时挂一条 BossBar），当前未做。

## 三、dragon-block-plugin（plugins/dragon-block-plugin-1.0-SNAPSHOT.jar）

来源：Modrinth `dragon-block-plugin`（MIT，Paper/Folia 1.21.x，官方版本列表含 1.21.11）。
下载：`https://cdn.modrinth.com/data/5FihdWbN/versions/hqlMrsj0/dragon-block-plugin-1.0-SNAPSHOT.jar`

### 功能
拦截龙破坏方块的两条路径：
1. `EntityChangeBlockEvent` —— 龙本体飞行撞碎方块
2. `EntityExplodeEvent` —— 龙火球 / 爆炸破坏

### 配置（plugins/dragon-block-plugin/config.yml）
```yaml
# Material 枚举名（不区分大小写）。空列表 = 龙不能破坏任何方块
whitelisted-blocks: []
```
当前为空白名单 = 龙不能破坏任何方块（黑曜石柱、建筑、地形全保护）。如需放开某些方块（如黑曜石柱可被打），把 Material 名加进去，然后 `/dragonblock reload`。

### 命令 / 权限
| 命令 | 权限 | 说明 |
|---|---|---|
| `/dragonblock reload` | `dragonblock.admin`（op 默认） | 重载配置，无需重启 |

## 四、与现有保护的衔接

- **EssentialsX** `protect.disable.enderdragon-blockdamage: true`（服务器实际已开）—— 拦龙本体飞行破坏，但**不拦**龙火球与末地水晶爆炸（`ender-crystal-explosion: false`）。
- **dragon-block-plugin** 补齐火球/爆炸路径，与 Essentials 不冲突（重复拦截无害）。
- 需要拦截水晶爆炸破坏时，把 config.yml 的 `ender-crystal-explosion` 也开成 true 可作双保险（当前由 dragon-block-plugin 统一兜底）。

## 五、使用流程（重启后）

1. `/dragon respawn` —— 生成龙（广播提示），柱子保持原样
2. 玩家正常打龙：龙不会破坏任何方块（本体/火球/爆炸都挡）
3. 击杀后：掉经验、不掉蛋、柱子无损
4. 想再打：再次 `/dragon respawn`
