# 空间传送阵 SpacePortal 使用说明

适用于 **Java / 基岩互通服**（Paper/Spigot + Geyser/Floodgate）。所有粒子与音效均走 Bukkit 标准通道，Java 与基岩玩家均可正常看到特效。本文档说明该插件的安装方法、建阵与双向连接玩法、/csz 指令与权限配置、可调参数及卡顿调优建议，供服主部署和日常管理参考。

## 一、安装

1. 服务器要求：Java 17+，Paper 或 Spigot 1.20.x（1.19~1.21 大部分版本可用）。
2. 把 `SpacePortal-1.0.0.jar` 放入服务器 `plugins/` 目录，重启服务器。
3. 互通服需已安装 Geyser + Floodgate（基岩玩家进服、粒子显示由它们负责，本插件无需额外配置）。

## 二、玩法流程

1. **建阵**：站到想放阵法的位置，执行：
   ```
   /csz create 主城
   /csz create 矿区
   ```
   - **管理员**（`spaceportal.admin`）建阵不占额度，记为公共阵法，所有人可见可用。
   - **普通玩家**（`spaceportal.create`）也能建阵，每人默认限 1 个，记为私人阵法并绑定归属者；上限由管理员通过 `/csz setlimit` 或界面控制。
2. **双向连接**（两点互通）：
   ```
   /csz link2way 主城 矿区
   ```
3. **使用**：玩家走进任意一个阵法范围，自动开始充能（动作栏显示进度），期间站在原地不动；充能完成后消耗 **20 颗钻石**（实际值，见 `plugins/SpacePortal/config.yml` 第 6 行 `cost-diamonds: 20`），伴随爆发特效传送到对面阵法，落地后播放约 2.5 秒的"时光穿梭"彩虹螺旋特效。移动离开阵法会取消充能。
4. **图形界面**：输入 `/csz gui` 打开箱子界面。Java 版直接显示为箱子 GUI；基岩版经 Geyser 自动转换为原生箱子界面，双端同一套界面通用。

   - **主界面**（54 格）：0~44 列出你可见的阵法（自己的 + 公共的，管理员可见全部），45 创建阵法，48~50 管理员增减玩家建阵上限，52 费用信息，53 关闭。
   - **管理界面**（27 格）：在主界面**点击任意一个阵法图标**进入，可对该阵法单独操作 —— 4「连接到…」（聊天栏输入目标名，建立双向连接）、11「传送到该阵法」、13 阵法信息、15「删除该阵法」（需二次确认）、22「返回列表」。
   - **删除权限**：管理员可删除任意阵法（含公共阵法）；普通玩家只能删除自己名下的阵法。删除前按钮会变成红色「再次点击确认删除」，点其他按钮或关闭界面即取消。

   界面传送与走进阵法充能传送**使用同一套费用规则**：都按 `cost-diamonds` 扣钻石，免费权限（`spaceportal.free`）和创造/旁观免费同样生效。钻石不足时不会关闭界面、也不会传送，阵法图标上会直接标注本次消耗数量。

## 三、指令一览

| 指令 | 说明 | 权限 |
|---|---|---|
| `/csz gui` | 打开传送阵箱子界面（双端通用） | 所有人 |
| `/csz create <名字> [颜色]` | 在脚下创建阵法 | 玩家/管理员 |
| `/csz list` | 查看所有阵法 | 所有人 |
| `/csz remove <名字>` | 删除阵法 | 管理员 |
| `/csz link <A> <B>` | 单向连接 A→B | 管理员 |
| `/csz link2way <A> <B>` | 双向连接 | 管理员 |
| `/csz sethue <名字> <颜色>` | 改阵法颜色 | 管理员 |
| `/csz setcost <钻石数>` | 游戏内改传送费用，立即生效 | 管理员 |
| `/csz setlimit <数量>` | 游戏内改玩家建阵上限，立即生效（0=禁止，-1=不限制） | 管理员 |
| `/csz tp <名字>` | 管理员直达阵法 | 管理员 |
| `/csz reload` | 重载配置 | 管理员 |

颜色可选：cyan、blue、purple、pink、red、orange、yellow、green、white。

## 四、权限

| 权限 | 默认 | 说明 |
|---|---|---|
| `spaceportal.use` | 所有人 | 使用传送阵 |
| `spaceportal.free` | 无 | 免费传送（免钻石） |
| `spaceportal.create` | 所有人 | 玩家自建传送阵（受数量上限约束） |
| `spaceportal.admin` | OP | 创建/管理阵法、调整费用与上限 |

## 五、可调参数（plugins/SpacePortal/config.yml）

| 参数 | 文档默认 | 本服实际值 | 说明 |
|---|---|---|---|
| `cost-diamonds` | 5 | **20**（config.yml 第 6 行） | 每次传送消耗钻石（也可用 `/csz setcost` 在游戏内修改，存于 override.yml） |
| `player-portal-limit` | 1 | **config.yml 未含此键**（使用代码内默认值） | 每个玩家最多可创建的阵法数量，0=禁止自建，-1=不限制（也可用 `/csz setlimit` 在游戏内修改） |
| `free-in-creative` | true | true（config.yml 第 9 行） | 创造/旁观免费（方便测试） |
| `portal-radius` | 3.0 | 3.0（config.yml 第 12 行） | 地面阵法半径 |
| `activate-radius` | 2.2 | 2.2（config.yml 第 15 行） | 触发传送的感应半径 |
| `charge-ticks` | 60 | 60（config.yml 第 18 行） | 充能时长（20=1秒） |
| `tunnel-ticks` | 50 | 50（config.yml 第 21 行） | 落地时光穿梭特效时长 |
| `cooldown-seconds` | 5 | 5（config.yml 第 24 行） | 传送后冷却，防止立刻重复触发 |
| `render-distance` | 24 | **40.0**（config.yml 第 27 行） | 范围内有玩家才发送粒子包（超过客户端可见距离的包是白发的） |
| `particle-interval-ticks` | 4 | **config.yml 未含此键**（使用代码内默认值） | **粒子性能主开关**：阵法刷新间隔，2=每秒10帧（华丽吃性能），4=每秒5帧（推荐），6/10 更省 |

> 📌 **本服实际阵法**（见 `plugins/SpacePortal/portals.yml`）：`主城 ↔ 矿区` 双向连接，均位于 `world` 世界，hue=185.0（青色）。`override.yml` 当前为空（0 字节），表示游戏内尚未通过 `/csz setcost` / `/csz setlimit` 改过默认值。

改完执行 `/csz reload` 即可生效。游戏内用 `/csz setcost`、`/csz setlimit` 改过的值会保存在 `override.yml`，优先级高于 `config.yml`，重载后依然保留。

## 六、特效说明

- **地面阵法**：旋转外环 + 反向内环 + 六芒星 + 稀疏上升光柱（简洁版，去掉了原先的双层外环、符文弧与上升微光）；玩家充能时追加能量向内汇聚的螺旋，充能满时爆发闪光。
- **传送瞬间**：起点收缩漩涡 + 终点爆发粒子 + 末影传送音效。
- **时光穿梭**：落地后环绕玩家身体的双螺旋彩虹粒子流 + 头顶流光圆盘，结束时水晶音效收尾。

## 七、卡顿调优

粒子卡顿的本质是**网络包数量**：每一次 `spawnParticle` 调用都是一个独立数据包，发给附近所有玩家。按优先级依次调：

1. 调大 `particle-interval-ticks`（默认 4）：4 → 6 立刻省 1/3，→ 10 帧率再降一半。
2. 调小 `render-distance`（文档默认 24，本服实际 40.0）：客户端粒子渲染距离有限，设太大只是白发包。
3. 调小 `portal-radius`：半径不影响粒子点数，但影响客户端的粒子绘制面积。

已内置的三项优化：同位置点多颗粒用 `count` 参数一次发出（1 个包渲染多颗粒子，视觉密度不降反增）；色相→RGB 结果全局缓存，每帧不再反复新建 `Color`；玩家可见性判定改用 `world.getPlayers()`，不再扫描全部实体。

## 八、常见问题

- **基岩玩家看不到粒子**：确认服务器装了 Geyser 且版本较新；本插件只使用标准粒子，无 NMS。
- **钻石被扣但没传送**：不会发生——费用在传送执行前一刻才扣除，余额不足会直接提示。
- **跨世界传送**：支持，两个阵法可以在不同世界，目的地世界需已加载。
- **源码**：完整 Maven 工程在 `SpacePortal/` 目录，可二次开发（颜色、图案都在 `EffectController.java`）。
