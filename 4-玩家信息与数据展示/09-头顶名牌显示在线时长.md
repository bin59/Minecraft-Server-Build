# 头顶名牌显示在线时长

**采用方案**：TAB v6.2.1 + Plan + PAPI Math，头顶名牌后缀显示**历史总在线分钟数**。

## 配置

`plugins/TAB/groups.yml` → `default:` 组：

```yaml
default:
  tabprefix: '&7[&f玩家&7] '
  tagsuffix: ' &f总在线&b%math_0:_{plan_player_time_total_raw}/60000%&f分'
```

- 头顶名牌由 `scoreboard-teams` 渲染，值只认 `groups.yml` / `users.yml` 的 `tagsuffix`；`config.yml` 的 `tablist-name-formatting` 段只放 `enabled` / `disable-condition`。
- **不要写 `\n`**：TAB v6 名牌是单行，`\n` 只会显示成字面字符。
- 组里显式写了 `tagsuffix` 就覆盖 `_DEFAULT_`：当前 `Admin:` 与 `default:` 都写了同一行；`VIP:` 未写，继承 `_DEFAULT_` 的 `%luckperms-suffix%`（本服未设 suffix，为空）。要让所有组都显示，逐个补同一行。查来源用 `/tab dump <玩家>`。

## 时长占位符

| 占位符 | 输出 | 用途 |
| --- | --- | --- |
| `%plan_player_time_total_raw%` | 毫秒原始值 | 换算用 |
| `%math_0:_{plan_player_time_total_raw}/60000%` | `9267` | **头顶采用**（总在线分钟） |
| `%plan_player_time_total%` | `6d  10h 26m 43s` | 侧边栏 |
| `%plan_player_current_session_length%` | 格式化时长 | 侧边栏（本次会话，非总时长） |
| `%ptop_<N>_time%` | `11963分` | PlanTop 榜单第 N 名 |

- 换算：`毫秒 ÷ 60000 = 分钟`；`math_0:_` 为 0 位小数四舍五入，与 PlanTop `PlaytimeCache#fmt()` 口径一致。
- Math 是 PAPI 扩展：`/papi ecloud download Math` → `/papi reload`。
- 口径是**历史全部会话累计**，不是本次进服时长。

## 生效与验证

```
/papi parse me %math_0:_{plan_player_time_total_raw}/60000%   → 9264（分）
/papi parse me %plan_player_time_total%                       → 6d  10h 26m 43s
/tab reload
```

`9264 × 60000 = 555,840,000 ms ≈ 6 天 10 小时 24 分`；格式化值 `6d 10h 26m 43s = 9266.72 分`，差 3 分钟是两条命令间玩家仍在线所致。

## 注意

- 本地 26.3 主服 `PlaceholderAPI/expansions/` 为空，本地要显示需先装 Math 扩展；云服已能解析说明已装。
- TAB 占位符默认 500ms 刷新；首次不显示按 `01-Plan使用文档.md:77` 替换两次或加进 `Load_these_placeholders_on_join`。
