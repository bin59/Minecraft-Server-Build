# 头顶名牌显示在线时长

> 用 **TAB（头顶名牌）+ Plan 占位符** 在玩家名字正下方显示在线时长，无需新插件。数据源是 Plan 自带的两个 PAPI 占位符，显示位置由 TAB 的 `tablist-name-formatting` 提供第二行。

## 依赖

- **TAB**（头顶名牌渲染，本服已装）
- **Plan**（在线时长统计，本服已装，提供占位符）
- **PlaceholderAPI**（占位符解析中间层，本服已装 2.12.3）

## 数据源：两个现成占位符

| 占位符 | 含义 | 说明 |
| --- | --- | --- |
| `%plan_player_current_session_length%` | 本次在线时长 | 本次进服到现在，随 TAB 刷新周期实时累加 |
| `%plan_player_time_total%` | 总在线时长 | 历史全部在线时长总和（含 AFK） |

> 这两个占位符在 `03-TAB信息展示.md` 的侧边栏已经在用，属于已验证可用的占位符，头顶名牌直接调用即可。

## 方案一（推荐）：启用 `tablist-name-formatting` 加第二行

改 `plugins/TAB/config.yml`：

```yaml
tablist-name-formatting:
  enabled: true
  default:
    tabprefix: '%luckperms_prefix%'
    tagname: '&f%player_name%'
    tagsuffix: '\n&7在线 &b%plan_player_current_session_length%'
```

头顶效果：

```
  玩家名
在线 2小时13分
```

显示**总时长**则把最后一行换成：

```yaml
    tagsuffix: '\n&7总在线 &b%plan_player_time_total%'
```

生效：`/tab reload`。

## 方案二：不动现有称号配置（改 scoreboard-teams）

本服头顶前缀当前由 `scoreboard-teams` 渲染（`tablist-name-formatting.enabled` 为 `false`），若不想切换渲染来源，可在 `scoreboard-teams` 的玩家名牌名/后缀里同样用 `\n` 拼上在线时长。具体键名以运行服 `plugins/TAB/config.yml` 实际结构为准。

## 生效步骤

1. 备份 `plugins/TAB/config.yml`
2. 按方案一/二改对应段
3. `/tab reload`
4. 进游戏看自己头顶：名字正下方出现时长即成功

## 注意事项

1. **切换渲染来源**：启用 `tablist-name-formatting` 后，头顶前缀改由它接管（会读 `%luckperms_prefix%`）。开启前先记下现状，开启后进游戏确认头顶称号没乱；乱了就回滚或改用方案二。
2. **刷新频率**：TAB nametag 占位符有刷新周期，本次在线时长会随刷新跳动（几秒~几十秒一次），属正常现象。
3. **多行叠加**：若玩家的 LuckPerms 前缀本身是多行称号（`\n`），再叠加时长行可能显得高；普通玩家单行前缀不受影响。
4. **性能**：TAB nametag 本身开销极低；两个占位符均为 Plan 读取，无需额外开 Plan 扩展。
5. **时长口径**：Plan 对在线会话每几分钟续写，本次时长显示有最多几分钟延迟。
