# LuckPerms + TAB + PlaceholderAPI 实现炫彩多层称号效果

在 Minecraft 服务器中，使用 **LuckPerms + TAB + PlaceholderAPI** 实现炫彩多层称号效果。

---

### 前置条件

确保已安装以下插件：

- **TAB**（TAB列表 + 头顶名牌管理）
- **LuckPerms**（权限组 + 前缀管理）
- **PlaceholderAPI**（占位符解析）
- **LuckPerms 的 PAPI 扩展**：`/papi ecloud download LuckPerms` → `/papi reload`

---

### 第一步：LuckPerms 设置多行前缀

TAB 插件支持用 `\n` 实现多行显示。在 LuckPerms 中为不同权限组设置前缀：

```bash
# 管理员 - 三行炫彩称号
/lp group admin meta setprefix "&4&l✦ 管理员 ✦\n&c&lSERVER\n&7"

# 普通玩家 - 单行
/lp group default meta setprefix "&7"
```

> **注意**：`\n` 是换行符，LuckPerms 的前缀支持这个语法，TAB 插件会正确解析为多行显示。

---

### 第二步：TAB 配置头顶多行显示

编辑 TAB 的 `config.yml`，配置 `tagprefix`（头顶前缀）：

```yaml
tablist-name-formatting:
  default:
    tabprefix: '%luckperms_prefix%'
    tabname: '&f%player_name%'
    tabsuffix: ''
    tagprefix: '%luckperms_prefix%'
    tagname: '&f%player_name%'
    tagsuffix: ''
```

这样玩家头顶会显示为：

```
    ✦ 管理员 ✦
    SERVER
  Steve
```

---

### 第三步：炫彩渐变效果（1.16+）

服务器版本 **1.16 及以上** 时，TAB 支持十六进制颜色（`&#RRGGBB`），可实现渐变：

```bash
# 管理员 - 渐变红色称号
/lp group admin meta setprefix "&#FF0000&l✦ &#FF4400管 &#FF8800理 &#FFAA00员 &#FF0000&l✦ &#FF6600&lSERVER &7"
```

效果类似：

```
  ✦ 管 理 员 ✦    ← 每个字颜色不同，形成渐变
    SERVER
  Steve
```

---

### 第四步：动态彩虹效果

TAB 内置动态彩虹占位符，可实现**实时流动**的彩虹称号。在 LuckPerms 中使用：

```bash
/lp group admin meta setprefix "&4&l✦ &c&l管理员 &4&l✦\n&c&lSERVER\n&7"
```

---

### 第五步：TAB 列表中也显示多行

TAB 列表（按 Tab 键弹出的玩家列表）也显示多行称号，修改配置：

```yaml
tablist-name-formatting:
  default:
    tabprefix: '%luckperms_prefix%'
    tabname: '&f%player_name%'
    tabsuffix: ' &7| &f%player_health%&c❤'
    tagprefix: '%luckperms_prefix%'
    tagname: '&f%player_name%'
    tagsuffix: ''
```

---

### 最终效果预览

```
TAB 列表中：
┌──────────────────────────┐
│ ✦ 管理员 ✦  Steve  20❤  │
│ SERVER                   │
│                          │
│ Player1           15❤    │
└──────────────────────────┘

玩家头顶：

    SERVER
  Steve
```

### 常用命令速查

| 命令                                    | 作用                 |
| --------------------------------------- | -------------------- |
| `/lp group <组> meta setprefix <前缀>`  | 设置权限组前缀       |
| `/lp user <玩家> meta setprefix <前缀>` | 单独给某玩家设置前缀 |
| `/lp user <玩家> parent add <组>`       | 将玩家加入权限组     |
| `/tab reload`                           | 重载 TAB 配置        |

---

### 前缀设置示例

默认组彩色前缀：

```
/lp group default meta setprefix "[&d玩家&f] &6"
```

基岩版玩家（Floodgate）按 UUID 设置前缀：

```
/lp user 00000000-0000-0000-0009-01f42087bd04 meta setprefix &a[青蛙🐸]
```

指定 Java 玩家前缀：

```
/lp user PumpkinVegetable meta setprefix "[&4南瓜🎃&f] &6"
```

---

### 注意事项

- 多行前缀中，**最后一行**应该是玩家名字的颜色前缀（如 `&7`），否则名字会继承上一行的颜色
- `\n` 换行在头顶名牌（tag）中有效，但在 TAB 列表中可能只显示第一行
- 十六进制颜色 `&#RRGGBB` 仅在 **1.16+** 版本生效，低版本会自动降级为最近的颜色代码
- 如果前缀不生效，执行 `/papi parse me %luckperms_prefix%` 测试占位符是否正常返回

## 配置文件模板

### 📄 `animations.yml`

每个动画只支持 `change-interval` 和 `texts` 两个键（不要写 `type`、`speed`、`colors` 等无效键），`texts` 列表不能为空。

```yaml
rainbow:
  change-interval: 200
  texts:
    - '&cR'
    - '&6a'
    - '&ei'
    - '&an'
    - '&bb'
    - '&9o'
    - '&5w'

gradient:
  change-interval: 300
  texts:
    - '&cG'
    - '&6r'
    - '&ea'
    - '&ad'
    - '&bi'
    - '&9e'
    - '&5n'
    - '&dt'

breathing:
  change-interval: 500
  texts:
    - '&fB'
    - '&7r'
    - '&fB'
    - '&7r'
```

> **说明**：`change-interval` 单位为毫秒，数值越小动画越快。`texts` 列表中的每一行就是一帧，插件按顺序循环播放。在 `config.yml` 中通过 `%animation:rainbow%` 引用动画名。

---

### 📄 `config.yml`（`tablist-name-formatting` 部分）

```yaml
tablist-name-formatting:
  enabled: true
  disable-condition: '%world%=disabledworld'
```

> **说明**：`disable-condition` 用于指定在哪些世界/条件下禁用 TAB 列表名称格式化。不需要禁用任何世界时设为空字符串 `""`。
>
> **本服实际值**：`tablist-name-formatting.enabled: false`——本服未启用该组件，头顶/TAB 列表前缀实际由 `scoreboard-teams`（`enabled: true`）读取 LuckPerms 前缀渲染，而非本组件。若要按上文方案启用多行炫彩称号，需先把此处 `enabled` 改为 `true` 并 `/tab reload`。

---

### 📄 `groups.yml`（`Admin` 组部分）

```yaml
Admin:
  tabprefix: '&4[Admin] &f'
  tagsuffix: ''
  customtabname: '%player%'
  tabsuffix: ''
```

> **说明**：
>
> - `tabprefix`：TAB 列表中玩家名字前面的前缀
> - `tagsuffix`：TAB 列表中玩家名字后面的后缀
> - `customtabname`：TAB 列表中显示的名称（默认 `%player%` 即玩家名）
> - `tabsuffix`：TAB 列表后缀
> - 如果使用 LuckPerms 管理权限组，前缀后缀也可直接在 LuckPerms 中设置，TAB 会自动读取。

---

修改完成后，在游戏内或控制台执行 `/tab reload` 即可生效。
