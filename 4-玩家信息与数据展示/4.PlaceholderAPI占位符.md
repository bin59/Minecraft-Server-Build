# 4. PlaceholderAPI 占位符桥接

本文介绍 PlaceholderAPI（PAPI）这款占位符解析中间层：它本身不提供数据，而是让 TAB、DecentHolograms、聊天等插件通过 %占位符% 引用其他插件的数据。文档列出本服已装的 player、server、vault 三个扩展、config.yml 实测键值、/papi 系列命令权限，以及与本服 TAB、称号、全息等插件的挂钩关系。

> **一句话**：PlaceholderAPI（PAPI）是服务端的**占位符解析中间层**，让 TAB、DecentHolograms、Chat 等插件能引用其他插件的数据（玩家名、余额、在线人数、TPS 等），用 `%placeholder%` 语法动态渲染文本。
>
> **本服版本**：2.12.3（jar：`PlaceholderAPI-2.12.3.jar`）

---

## 一、简介

PlaceholderAPI 本身**不提供任何占位符**，它只是一个"字典"：各插件把自己的数据注册成占位符，其他插件通过 PAPI 查询。

- **位置**：`plugins/PlaceholderAPI/`
- **配置**：`config.yml`
- **扩展目录**：`expansions/`（每个 `.jar` 是一个扩展，注册一组占位符）
- **依赖**：无（软依赖，被 TAB / DecentHolograms / LuckPerms 等调用）

---

## 二、安装

1. 下载 `PlaceholderAPI-2.12.3.jar` 放入 `plugins/` 目录。
2. 重启服务器，自动生成 `plugins/PlaceholderAPI/config.yml` 与 `expansions/` 目录。
3. 按需通过 `/papi ecloud download <名称>` 下载扩展，或手动把扩展 jar 放进 `expansions/` 后 `/papi reload`。

---

## 三、本服已装扩展（expansions/ 目录实测）

| 扩展 jar               | 注册的占位符前缀 | 数据来源                                 |
| ---------------------- | ---------------- | ---------------------------------------- |
| `Expansion-player.jar` | `%player_*%`     | 玩家自身（ping、方向、名称等）           |
| `Expansion-server.jar` | `%server_*%`     | 服务器（TPS、在线人数、时间、MOTD）      |
| `Expansion-vault.jar`  | `%vault_*%`      | 经济余额、组（依赖 Vault + EssentialsX） |

> 其他插件（LuckPerms、TAB、SimplePets 等）**自带** PAPI 扩展，无需额外下载；它们在自身 config.yml 里直接暴露 `%luckperms_*%`、`%tab_*%` 等。

---

## 四、配置要点（plugins/PlaceholderAPI/config.yml 实际值）

| 键                                             | 实际值               | 说明                                              |
| ---------------------------------------------- | -------------------- | ------------------------------------------------- |
| `check_updates`                                | `true`               | 启动时检查新版本                                  |
| `cloud_enabled`                                | `true`               | 允许 `/papi ecloud` 在线下载扩展                  |
| `cloud_sorting`                                | `name`               | ecloud 列表按名称排序                             |
| `boolean.true` / `boolean.false`               | `yes` / `no`         | 布尔占位符的显示文本                              |
| `date_format`                                  | `MM/dd/yy HH:mm:ss`  | `%date%` 默认格式                                 |
| `detect_malicious_expansions`                  | `true`               | 拒绝含恶意代码的扩展                              |
| `use_adventure_provided_replacer`              | `false`              | 使用 PAPI 自带的组件替换器；若显示乱码可改 `true` |
| `debug`                                        | `false`              | 调试模式（开后控制台输出占位符解析过程）          |
| `expansions.player.ping_value.high/medium`     | 100 / 50             | ping 高/中阈值（ms）                              |
| `expansions.player.ping_color.low/medium/high` | `&a` / `&e` / `&c`   | ping 三色                                         |
| `expansions.server.time.locale`                | `zh-CN`              | 时间本地化（中文）                                |
| `expansions.server.time.zone`                  | `Asia/Shanghai`      | 时区，与服务器一致                                |
| `expansions.server.server_name`                | `A Minecraft Server` | **默认未改**，如需自定义可在此改                  |
| `expansions.vault.formatting`                  | k / M / B / T / Q    | 金额缩写单位（千/百万/十亿/万亿/千兆）            |

## 五、命令与权限

| 命令                           | 作用                                      | 权限                             |
| ------------------------------ | ----------------------------------------- | -------------------------------- |
| `/papi list`                   | 列出已安装扩展及其版本                    | `placeholderapi.list`（默认 OP） |
| `/papi info <占位符>`          | 查看某占位符的注册插件与示例              | `placeholderapi.info`            |
| `/papi parse <玩家> <文本>`    | 手动解析一段含 `%...%` 的文本（调试利器） | `placeholderapi.parse`           |
| `/papi parse me <文本>`        | 以自己为上下文解析                        | 同上                             |
| `/papi ecloud`                 | 打开在线扩展浏览器                        | `placeholderapi.ecloud`          |
| `/papi ecloud download <名称>` | 下载并安装扩展                            | 同上                             |
| `/papi ecloud list`            | 列出 ecloud 上可下载的扩展                | 同上                             |
| `/papi reload`                 | 重载 config.yml 与 expansions             | `placeholderapi.reload`          |
| `/papi bcparse <玩家> <文本>`  | 解析并广播                                | `placeholderapi.broadcast`       |

> 普通玩家**无需任何权限**，他们只是"被占位符渲染的文本"的读者；所有管理命令默认仅 OP 可用。

## 七、常见问题

- **占位符显示为字面量 `%xxx_yyy%`**：说明对应扩展未装。`/papi list` 查看；缺则 `/papi ecloud download xxx`。
- **`%vault_*%` 无值**：确认 Vault 与经济插件（EssentialsX）已装且 `Expansion-vault.jar` 在 `expansions/` 目录。
- **中文时间乱码**：`expansions.server.time.locale` 保持 `zh-CN`，`zone` 保持 `Asia/Shanghai`。
- **扩展装了不生效**：手动放入 `expansions/` 后必须 `/papi reload`。
