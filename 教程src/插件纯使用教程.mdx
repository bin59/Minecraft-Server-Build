## Floodgate

### 玩家命令

无玩家可直接使用的命令。Floodgate 是纯服务端认证组件，玩家全程无感知地受益于以下功能：

- <Mark bold>绕过 Java 版正版验证</Mark>：基岩版玩家凭 Xbox Live 账号即可直接加入 online-mode=true 的服务器，无需购买 Java 版账号。
- <Mark bold>玩家名前缀识别</Mark>：基岩版玩家进入服务器后，用户名会自动带 `.` 前缀（例如基岩玩家 Steve 在服务器内显示为 `.Steve`），据此可区分 Java 版与基岩版玩家。

### 管理员命令

无独立的管理员命令（Floodgate 没有注册 Bukkit 命令）。其联动的基岩连接状态可通过 Geyser 的 `/geyser` 系列命令查看；账号关联（player-link）相关功能由 Floodgate 自身的配置与表单驱动，管理员无需输入命令维护。

### 权限节点

Floodgate 本身不提供独立命令，因此无专属权限节点。其生效完全依赖与 Geyser 共享的加密密钥（key.pem），只要密钥匹配，经 Geyser 代理的基岩连接即被放行。

### 典型工作流

<Mark bold>玩家视角（基岩版）：</Mark>
1. 与 Geyser 流程一致，在基岩客户端填好服务器地址与端口后加入。
2. 登录后服务器内名字显示带 `.` 前缀，正常游戏即可，无需任何额外操作。

<Mark bold>管理员视角：</Mark>
1. 确认 Geyser 配置中 java.auth-type: floodgate 已启用。
2. 确保 plugins/floodgate/key.pem 与 Geyser 指向的密钥文件一致。
3. 在游戏内或后台通过 `.` 前缀区分基岩玩家。
4. 如需将基岩账号与 Java 账号关联，由玩家侧在基岩客户端内通过 Floodgate 弹出的表单完成。

### 版本信息

最新版本：Floodgate Build #141（floodgate-spigot.jar，对应版本线 2.2.x），发布于 2026-09-17 / 查证日期 2026-11-13 / 来源 https://geysermc.org/download

## Leaf

### 玩家命令

无。Leaf 是服务端核心（Paper/Gale 链路的高性能分支），普通玩家在游戏内没有任何专属命令，玩家感知不到它的存在，只会在整体服务器流畅度上间接受益。

### 管理员命令

- `/leaf reload` — 热重载 Leaf 的全局配置（Leaf 特有生成的配置文件，如 leaf-global.yml 等），无需完整重启即可生效配置改动。

### 权限节点

- `/leaf reload` 通常由 OP 或控制台执行；Leaf 未对外公开细粒度的玩家级权限节点。

### 典型工作流

- <Mark bold>玩家视角</Mark>：正常进入游戏即可，无需任何操作。
- <Mark bold>管理员视角</Mark>：将 Leaf 作为 Paper 的即插即用替代品部署后，日常运维时若调整了 Leaf 全局配置，可在控制台执行 `/leaf reload` 热重载。

### 版本信息

最新版本：Leaf 26.3（构建 #22，2026-11-08，Java 25+）/ 查证日期 2026-11-13 / 来源 https://www.leafmc.one/zh/download

## Velocity + Multiverse

### Velocity（代理端）

Velocity 是独立的代理服务器（独立进程），玩家从 Velocity 一个地址进出，可在多个后端子服间无缝切换。

<Mark bold>玩家命令</Mark>
- `/server [子服名]` — 切换到指定子服，或省略参数列出可前往的子服。
- `/glist` — 查看整个网络中在线的玩家总数与各子服分布。

<Mark bold>管理员命令</Mark>
- `/velocity list` — 列出网络内所有子服及在线玩家。
- `/velocity send &lt;玩家|all|current&gt; &lt;子服名&gt;` — 将玩家（或全体/all、当前服/current）传送到指定子服。
- `/velocity reload` — 重载代理配置。
- `/velocity plugins` — 查看代理端已加载的插件列表。

<Mark bold>权限节点</Mark>
- `velocity.command.server` —— 允许使用 `/server`
- `velocity.command.list` —— 允许查看网络玩家列表
- `velocity.command.send` —— 允许使用 `/velocity send`
- `velocity.command.reload` —— 允许重载代理配置

<Mark bold>典型工作流</Mark>
- 玩家：用正式地址进入服务器 → 默认落到首个子服 → 想换服时 `/server minigames` 无缝切换；用 `/glist` 看大家在哪个服。
- 管理员：日常用 `/velocity list` 监控各服在线；活动结束用 `/velocity send all lobby` 把玩家集中回大厅。

### Multiverse-Core（后端多世界）

## BGM 资源包

> 本服 BGM 方案由「服务器资源包 + 自定义音效 + 循环播放数据包」组成，并非独立插件。玩家进服时若同意下载资源包，进入主城、矿区、出生点等区域会<Mark bold>被动自动听到</Mark>对应 BGM；基岩版玩家经 Geyser 转译同样能听到。

### 玩家命令

无专属命令。玩家进服弹窗选择下载音乐资源包（选"是"即可收听），走进对应区域自动响起背景音乐，无需任何权限或操作。

若想手动测试某段 BGM（通常由管理员执行）：
- `/playsound &lt;音效事件&gt; &lt;类别&gt; &lt;目标&gt; &lt;x&gt; &lt;y&gt; &lt;z&gt; &lt;音量&gt; &lt;音高&gt;` — 播放自定义音效事件。
  - 示例：`/playsound bgm.lobby music @a ~ ~ ~ 1 1`（向全体玩家播放主城 BGM）
  - 可用事件：`bgm.lobby`（主城）、`bgm.mines`（矿区）、`bgm.spawn`（出生点）

### 管理员命令

- `/reload` — 重载数据包（修改或首次放入循环 BGM 数据包后）。
- `/function bgm:start` — 启动常驻 BGM 循环。
- `/function bgm:stop` — 停止 BGM 循环。

### 权限节点

- 玩家侧：无需任何权限，`/playsound` 由服务端对玩家播放，玩家被动收听。
- 管理员侧：`/function bgm:start|stop` 与 `/reload` 需 OP 或控制台权限。

### 典型工作流

<Mark bold>玩家视角</Mark>：进服弹窗选择下载音乐资源包 → 走进主城/矿区/出生点区域自动响起对应背景音乐 → 无需任何输入。

<Mark bold>管理员视角</Mark>：准备好 OGG 音乐并打包为资源包托管到 HTTPS → 把循环 BGM 数据包放入 world/datapacks/ → 控制台执行 `/reload` → 执行 `/function bgm:start` 开启常驻循环 → 日后维护用 `/function bgm:stop` 暂停。

### 版本信息

自研方案，无独立插件版本号（基于 Minecraft 原版资源包 + 数据包机制，适用 MC 26.3）/ 查证日期 2026-11-13

- <Mark bold>启动 / 停止实例</Mark>：进入实例 → 终端/控制台页面 → 点击开启实例/启动 或停止按钮。

3. <Mark bold>跨机管理</Mark>：电脑 A 运行 Daemon（端口 24444）并记下 key；电脑 B 运行 Panel，在节点管理中添加电脑 A 的 Daemon 节点，即可远程启停。

## VexBot（PvP 机器人）

### 玩家命令

VexBot 没有玩家专属命令——机器人由操作员生成后，玩家直接在游戏内与机器人对战/陪练即可。玩家可感知的功能：陪练 PvP（近战/远程/水晶/鞘翅+锤等多种风格）、FFA 混战、难度梯度（EASY→PERFECT）、机动与补给。

### 管理员命令（默认需权限等级 2 / gamemaster，OP 即可）

命令前缀均为 `/vexbot`，支持 Tab 补全。

<Mark bold>召唤 / 管理</Mark>
- `/vexbot` — 打开主 GUI，点选类型/kit 在脚下生成（主推方式）
- `/vexbot spawn [&lt;name&gt;] [&lt;pos&gt;] [&lt;kit&gt;]` — 一条指令带名字/坐标/kit 召唤
- `/vexbot mass_spawn &lt;count&gt; [&lt;pos&gt;]` — 一次生成多个机器人
- `/vexbot kill [&lt;name&gt;]` — 移除指定（或所有）机器人
- `/vexbot list` — 列出当前机器人

<Mark bold>战斗 / 难度</Mark>
- `/vexbot attack (stop &lt;bot&gt;|&lt;player&gt; &lt;bot&gt;)` — 让机器人攻击玩家
- `/vexbot follow &lt;bot&gt; (stop|&lt;player&gt;)` — 让机器人跟随玩家
- `/vexbot ffa (start|stop|config ...)` — 开启/关闭 FFA 混战
- `/vexbot difficulty preset &lt;level&gt;` — 设全局难度档（EASY..PERFECT）
- `/vexbot playstyle (list|&lt;style&gt; (all|&lt;targets&gt;))` — 指定战斗风格

<Mark bold>Kit 系统</Mark>
- `/vexbot createkit &lt;name&gt;` — 把当前背包+护甲+副手+末影箱存为 kit
- `/vexbot updatekit &lt;name&gt;` / `deletekit [list|&lt;kit&gt;]` / `renamekit &lt;kit&gt; &lt;newName&gt;` — 管理 kit
- `/vexbot givekit [list|&lt;kit&gt; [&lt;player&gt;]]` — 把 kit 发给玩家

> 套用 kit 召唤的前置：需 `/vexbot settings advancedspawn on`（默认 OFF）。参数顺序为 名字 → 坐标 → kit；省略坐标时写 `/vexbot spawn &lt;名字&gt; &lt;kit名&gt;`。

### 权限节点

官方未定义细粒度权限节点；默认执行命令需<Mark bold>权限等级 2（gamemaster）</Mark>，即 OP 可执行。若安装 LuckPerms，可按权限组分配谁能使用 /vexbot。

### 典型工作流

<Mark bold>管理员（生成机器人陪练）</Mark>：手持/身穿好装备 → `/vexbot createkit &lt;kit名&gt;` 存 kit → `/vexbot settings advancedspawn on` → `/vexbot spawn &lt;名字&gt; &lt;kit名&gt;` → `/vexbot difficulty preset PERFECT` → 练完 `/vexbot kill &lt;名字&gt;` 清空。

<Mark bold>管理员（开启 FFA 混战）</Mark>：`/vexbot ffa config randomdifficulties` → `/vexbot ffa start` 自动生成一批机器人开混战 → `/vexbot ffa stop`。

### 版本信息

最新版本 3.1.15+paper-mc26.3（发布 2026-10-25，支持 MC 1.21–26.3）/ 查证日期 2026-11-13 / 来源 https://mcreference.com/mods/vexbot

## CoreProtect（方块记录与回滚）

### 玩家命令

普通玩家<Mark bold>无</Mark>可直接使用的查询/回滚命令——但玩家的行为会被自动记录（无需任何操作）。玩家能感知到的功能是：管理员可查到"谁动了我的箱子/谁挖了我的方块"，以及破坏可被回滚恢复。

### 管理员命令

主命令 `/co`（等价 /coreprotect）；常用别名：`/co i`=inspect、`/co l`=lookup、`/co rb`=rollback、`/co rs`=restore、`/co near`、`/co undo`。

<Mark bold>核心区别</Mark>：lookup 只查不改；rollback 真正改动世界；restore 把 rollback 反悔；回滚默认半径 10（以自己为中心）。

<Mark bold>检查员模式（inspect）</Mark>
```
/co inspect          # 开启（手持物品右键方块/箱子/告示牌查记录）
/co inspect          # 再敲一次关闭
/co i                # 简写
```

- 用法：把要附魔的装备放进<Mark bold>上方中间输入格</Mark> → 下方列出全部已启用的自定义附魔（标注类型与价格，单位为经验等级）→ 点击一个附魔即购买：输入格没放装备 → 提示先放装备；装备类型不符 → 提示不可用；经验不够 → 提示需要几级；装备已有该附魔 → 提示不重复扣；通过 → 扣经验等级，把附魔打在输入格装备上。关闭菜单时输入格的装备自动回到背包。
