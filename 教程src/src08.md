# 八、自研插件

## 空间传送阵（SpacePortal）

> 自研插件，版本 1.0.0（1.0.0-r2）。Java / 基岩互通服通用，阵法默认用特殊物品静态标记，特效默认关闭。命令为 `/csz`、`/spportal`、`/spaceportal`；`/portal` 属于 Advanced Portals，别用它打开传送阵。

### 玩家命令

| 命令 | 语法 | 说明 |
|---|---|---|
| 打开界面 | `/csz gui` | 打开传送阵箱子界面（双端通用） |
| 创建阵法 | `/csz create <名字> [颜色]` | 在脚下创建一座阵法，绑定归属者；每人默认限 1 个 |
| 查看阵法 | `/csz list` | 列出所有可见阵法（自己的 + 公共的） |
| 使用阵法 | 走进阵法范围自动充能 | 站定不动读条，完成后自动传送并扣钻石；移动离开取消 |

- 颜色参数可选：cyan、blue、purple、pink、red、orange、yellow、green、white。
- 坐骑与本人已驯服宠物（检测半径内）会随行，每个随行实体额外消耗钻石。
- 界面传送与走进充能传送用同一套费用规则（按 cost-diamonds 扣钻石，免费权限与创造/旁观免费同样生效）。

### 管理员命令

| 命令 | 语法 | 说明 |
|---|---|---|
| 创建公共阵法 | `/csz create <名字> [颜色]` | 持 spaceportal.admin 建阵不占额度，记为公共阵法 |
| 单向连接 | `/csz link <A> <B>` | 建立 A→B 单向连接 |
| 双向连接 | `/csz link2way <A> <B>` | 建立 A↔B 双向连接 |
| 删除阵法 | `/csz remove <名字>` | 删除任意阵法（含公共阵法） |
| 改颜色 | `/csz sethue <名字> <颜色>` | 修改阵法颜色 |
| 改费用 | `/csz setcost <钻石数>` | 游戏内改传送费用，立即生效并存 override.yml |
| 改上限 | `/csz setlimit <数量>` | 改玩家建阵上限（0=禁止，-1=不限制） |
| 直达阵法 | `/csz tp <名字>` | 管理员直接传送到阵法 |
| 设置标记 | `/csz item set` | 把主手物品设为全局阵法标记 |
| 发放标记 | `/csz item give` | 给自己发一份当前标记物品 |
| 重置标记 | `/csz item reset` | 恢复默认标记物品 |
| 重载 | `/csz reload` | 重载配置 |

### 权限节点

| 权限 | 默认 | 说明 |
|---|---|---|
| `spaceportal.use` | 所有人 | 使用传送阵 |
| `spaceportal.free` | 无 | 免费传送（免钻石） |
| `spaceportal.create` | 所有人 | 玩家自建传送阵（受数量上限约束） |
| `spaceportal.admin` | OP | 创建/管理阵法、调整费用与上限、管理标记物品 |

### 版本信息

自研插件，版本 1.0.0（产物 SpacePortal-1.0.0.jar）

## 南瓜账本（MoneyLedger）

> 自研插件，版本 1.1.0（2026-11-12）。自动记录全服南瓜币变动流水，并对账。

### 玩家命令

玩家**无直接可用命令**。插件通过监听 Essentials 的 UserBalanceUpdateEvent **实时**记录每一笔南瓜币收支，并可由南瓜账本按来源名追溯。

### 管理员命令

主命令 `/moneyledger`，所有子命令均需权限 `moneyledger.admin`。

| 命令 | 语法 | 说明 |
|---|---|---|
| 回填 | `/moneyledger backfill [full]` | 解析 Essentials/trade.log 幂等回填历史流水（加 full 全量） |
| 校验 | `/moneyledger verify` | 报告对账缺口、余额衔接不连续等异常 |
| 统计 | `/moneyledger stats` | 按来源分计数展示流水统计 |
| 导出 | `/moneyledger export` | 导出 CSV（含 uuid / origin / 精确金额列） |

### 权限节点

- `moneyledger.admin` — OP，执行全部子命令

### 版本信息

自研插件，版本 1.1.0（2026-11-12，产物 MoneyLedger-1.1.0.jar）

## 南瓜飞（PumpkinFly）

> 自研插件，版本 1.0.0（最新修订 r6）。按飞行时长扣秒的付费飞行；开飞无需命令，插件判定通过后自动允许飞行，玩家**双击空格**即可起飞。

### 玩家命令

主命令 `/pfly`，别名 /pumpkinfly、/pf。

| 命令 | 语法 | 说明 |
|---|---|---|
| 购买 | `/pfly buy <时长|perm>` | 购买时长或永久；时长累加到余额。格式 30m/2h/3d/45s/1天2小时30分，纯数字按分钟 |
| 领取体验 | `/pfly claim` | 领取限时体验奖励（默认每人一次 30 分钟） |
| 开关飞行 | `/pfly on` / `off` / `toggle` | 手动开关飞行能力（不消耗余额） |
| 界面显示 | `/pfly hud [on|off|toggle]` | 开关自己的飞行 HUD 显示 |
| 查看状态 | `/pfly status [玩家]` | 查看凭证来源、体验/余额剩余等 |
| 查看记录 | `/pfly records [玩家] [buy|session]` | 最近 10 条记录 |

### 管理员命令（均需 pumpkinfly.admin）

| 命令 | 语法 | 说明 |
|---|---|---|
| 发体验 | `/pfly trial <玩家|online|all> <时长|clear|status>` | 发放限时体验 |
| 全服总开关 | `/pfly global <on|off|toggle|status>` | 全服开关；off 时所有人立即安全落地 |
| 全服免费 | `/pfly global free <on|off|toggle>` | 全服免费飞行 |
| 全服体验 | `/pfly global trial <时长|clear>` | 全服限时体验 |
| 单人管理 | `/pfly player <玩家> <status|on|off|ban|unban|trial <时长>|cleartrial|give|take|setperm>` | 单人管理 |
| 重载 | `/pfly reload` | 重载配置并重建定时任务 |

### 权限节点

| 权限 | 默认 | 说明 |
|---|---|---|
| `pumpkinfly.use` | 所有人 | 开关飞行、领取体验、查看状态、HUD |
| `pumpkinfly.buy` | 所有人 | 购买飞行时长/永久 |
| `pumpkinfly.records` | 所有人 | 查看自己的记录 |
| `pumpkinfly.admin` | OP | 全部管理命令 |
| `pumpkinfly.bypass` | OP | 完全跳过区域/余额门禁（调试用） |

### 版本信息

自研插件，版本 1.0.0（最新修订 r6，产物 PumpkinFly-1.0.0.jar）

## 快捷菜单系统（QuickMenu）

> 自研插件，版本 1.0.0。玩家右键触发物品（时钟）弹出菜单：Java 端箱子 GUI，基岩端原生表单，一套配置驱动两端。已整合全服 33 套菜单（279 个菜单项，含 2026-11-15 新增的世界切换 worldmenu）。r5 起基岩端按钮带图标与两行说明，说明项与需要参数的项都改成原生表单按钮。

### 玩家命令

| 命令 | 语法 | 说明 |
|---|---|---|
| 打开默认菜单 | `/qm` | 打开主菜单（等同于右键触发物品） |
| 打开指定菜单 | `/qm open <菜单id>` | 打开指定 id 的菜单 |
| 查看信息 | `/qm info` | 显示客户端类型与设备信息（调试用） |

- 默认触发物品为**时钟（CLOCK）**，拿在快捷栏右键即开主菜单；进服自动发放，丢失用 `/qm` 或 `/qm give` 补发。
- 基岩端自动走原生表单：按钮带图标、两行说明；点说明项弹说明页，点需要参数的项弹输入表单，全程不用打字。

### 管理员命令（均需 quickmenu.admin）

| 命令 | 语法 | 说明 |
|---|---|---|
| 发放触发物品 | `/qm give [玩家]` | 给玩家发触发物品 |
| 热重载 | `/qm reload` | 热重载菜单配置，即时生效 |
| 列出菜单 | `/qm list` | 列出已加载的菜单 |

### 权限节点

- `quickmenu.use` — 所有人，打开/使用菜单
- `quickmenu.admin` — OP，管理面板入口、发放物品、热重载

> 管理面板靠权限门控：主菜单「管理面板」项配 quickmenu.admin，普通玩家界面里不出现；管理面板内每个按钮还各自配了底层插件权限（如 essentials.ban、coreprotect.rollback）。

### 版本信息

自研插件，版本 1.0.0（产物 QuickMenu-1.0.0.jar）

## 每日随机收购（DailySell）

> 自研插件，版本 1.2.4。每天从 110 种物品池随机抽 8 种作为全服候选，每位玩家自选 5 种后出售；单价当日浮动、每种额度随机，单人每日总收益封顶 900 南瓜币。基岩玩家 /ds 直接弹原生表单。

### 玩家命令

主命令 `/ds`，权限 `dailysell.use`（默认全体玩家）。

| 命令 | 语法 | 说明 |
|---|---|---|
| 打开界面 | `/ds` / `/ds gui` / `/ds menu` | 未选满 5 种时打开自选界面，选满后打开收购界面 |
| 自选 | `/ds choose [1-8|clear]` | 不带参打开自选界面；带序号选/取消第 N 种；clear 清空当天选择 |
| 查看候选 | `/ds today` | 列出 8 种候选、序号、单价、额度、已选标记、已卖数量与今日已赚金额 |
| 卖 1 个 | `/ds sell` | 手持物品卖 1 个（须是已选中的 5 种之一） |
| 批量卖 | `/ds sellall` | 手持那一组物品卖到「剩余额度 / 剩余预算」上限 |
| 帮助 | `/ds help` | 用法提示 |

- 每天零点自动重抽 8 种候选；选择按日期持久化，重登/重启不变，**跨天失效需重选**；未选满 5 种不能出售。

### 管理员命令（均需 dailysell.admin）

| 命令 | 语法 | 说明 |
|---|---|---|
| 重载 | `/ds reload` | 重载 config.yml（今日清单不变） |
| 重抽 | `/ds reroll` | 重新生成今日清单（清空当天所有玩家自选） |

### 权限节点

- `dailysell.use` — 所有人，打开/自选/出售
- `dailysell.admin` — OP，重载配置、重抽今日清单

### 版本信息

自研插件，版本 1.2.4（产物 DailySell-1.2.4.jar）

## 建筑评分（BuildRate）

> 自研插件，活动制打分评审。一场活动多座建筑，玩家给每座建筑打 1~10 分（可反复改分记最新、打分公开、统计去最高/最低分），玩家自主报名。Java / 基岩双端可用。

### 玩家命令

| 命令 | 语法 | 说明 |
|---|---|---|
| 报名 | `/br join <建筑名>` | 报名参评（再报名=改名） |
| 打开打分 | `/br open` | 打开打分面板：点建筑 → 选 1~10 分 |
| 命令打分 | `/br score <编号> <分数>` | 命令直接打分（基岩兜底） |
| 参评列表 | `/br list` | 查看参评列表（含当前均分/票数） |
| 排名 | `/br result` | 查看排名（均分降序，去最高最低后） |
| 历史 | `/br history` | 查看历史活动列表 |

- 每人可给每座建筑打分一次，**可反复改分**记最新；默认不能给自己的建筑打分；打分公开可见。

### 管理员命令（均需 buildrate.admin，推荐 /br admin 打开管理箱子菜单）

| 命令 | 语法 | 说明 |
|---|---|---|
| 创建活动 | `/br create <名称>` | 创建活动并设为进行中 |
| 代报名 | `/br add <玩家> <建筑名>` | 管理员代玩家报名 |
| 移除参评 | `/br remove <编号>` | 移除参评（含其评分） |
| 开始/截止 | `/br start` / `/br stop` | 开启评分 / 截止并自动结算发奖 |

> `/br stop` 截止时按名次自动结算：所有奖励（南瓜币、物品、自定义命令）入队玩家南瓜邮箱，由玩家 /mailbox 领取。

### 权限节点

- `buildrate.admin` — OP，创建活动、报名管理、开启/截止结算
- 玩家操作（join/open/score/list/result/history）无需额外权限

### 版本信息

自研插件（版本见 CHANGELOG / 构建产物）

## 附魔商店（EnchantShop）

> 自研插件，让玩家用经验等级在箱子 GUI 里给手持装备购买 ExcellentEnchants 自定义附魔，绕过物理铁砧（解决基岩端铁砧取物/改名框问题）。依赖 ExcellentEnchants（EE 未加载则本插件不启用）。

### 玩家命令

| 命令 | 语法 | 说明 |
|---|---|---|
| 打开商店 | `/eshop` | 打开附魔商店箱子 GUI（也可从快捷菜单主菜单「附魔商店」进入） |

- 用法：把要附魔的装备放进**上方中间输入格** → 下方列出全部已启用的自定义附魔（标注类型与价格，单位为经验等级）→ 点击一个附魔即购买：输入格没放装备 → 提示先放装备；装备类型不符 → 提示不可用；经验不够 → 提示需要几级；装备已有该附魔 → 提示不重复扣；通过 → 扣经验等级，把附魔打在输入格装备上。关闭菜单时输入格的装备自动回到背包。
- 价格读该附魔在 plugins/ExcellentEnchants/enchants/<id>.yml 的 AnvilCost（未配置时用本插件默认 3 级）。在 EE 中启用新附魔后重启即自动出现在商店。

### 管理员命令

无独立管理命令；附魔列表与价格完全由 ExcellentEnchants 的启用状态与 AnvilCost 决定。

### 版本信息

自研插件（版本见 CHANGELOG / 构建产物 EnchantShop.jar）
