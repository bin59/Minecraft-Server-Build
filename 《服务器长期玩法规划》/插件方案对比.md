# 插件方案对比（服务器长期玩法规划 · 选型参考）

> 配套文档：`README.md`（八条进度线总规划）。
> 本文把"每个 RPG 子系统用什么插件实现"拆开对比，给出推荐结论与避坑点。
> 适用环境：**Leaf 1.21.11（Paper 分支，实现 Bukkit API）+ Geyser 基岩互通**，已用 Residence 做领地。

---

## ⚠️ 重要前提：关于 neOmega

**本规划不把 neOmega 当作通用 RPG 脚本平台来依赖。**

- 用户环境中的 neOmega 为**网易（NetEase）版**，并非可自由编写任意 Lua 逻辑的开源 neOmega 框架；不能假设能用它来手写"每日任务脚本 / Boss 定时刷新 / 城镇统计 / 成就核验"等 RPG 逻辑。
- 因此下面所有对比里，**不再把 neOmega 列为"你已有、可直接用"的组件**。
- 原有的签到计分板、信任传送、群服互通等既成功能仍由网易 neOmega 承担，**但新增 RPG 系统一律改用成熟插件实现**，不依赖 neOmega 脚本能力。

> 结论：选型时把"可自由脚本"这一项从我们的资产里划掉，按"只能用现成插件"来规划。

---

## 选型总原则（契合现有运维习惯）

1. **轻量优先**：能用现有插件栈（LuckPerms + TAB + QuickMenu + Residence + VexBot）解决的，不新增插件。
2. **基岩友好**：所选插件不能在基岩端出现"看不到/用不了"的硬伤（避开需要资源包的插件）。
3. **不冲突**：**绝不引入第二套领地系统**（Towny / Lands / Factions 都会和 Residence 冲突）。
4. **可回退**：所有规则配置化，删组/卸插件即恢复。
5. **免费优先**：同等能力下优先免费插件，付费仅在上限明显更高时考虑。

## 1. 技能 / 职业成长

| 插件 | 价格 | 1.21.11 | 特点 | 适合 |
|---|---|---|---|---|
| **AuraSkills**（原 Aurelium Skills） | 免费 | ✅ Paper 1.21+/Folia | 15 技能 + 属性面板（力/血/韧），现代 GUI，Modrinth | 想要"升级涨属性"的 RPG 养成感 |
| **mcMMO Classic** | 免费 | ✅ 1.21+ | 14 技能，老牌，聊天栏提示，配置偏旧 | 经典"挖矿给熟练度"体验 |
| **MMOCore** | 付费套件 | ✅ | 职业/属性/技能框架，需配 MythicMobs | 想做"一转二转职业树" |
| *（现有）LuckPerms 组* | 免费 | ✅ | 用组前缀做 5 职业身份标签（`[战士]`/`[农夫]`…），零新插件 | 轻量、只想要"身份+前缀" |

**推荐**：
- 只想给玩家一个"身份 + 前缀 + 轻量增益" → **继续用 LuckPerms 组方案**（已在 README §2 给出完整命令，零新插件）。
- 想要"刷怪/挖矿真的涨属性、有技能树" → 上 **AuraSkills**（免费、现代、基岩无碍）。

## 2. 任务 / 剧情（每日钩子 + 长线叙事）

| 插件 | 价格 | 特点 | 学习曲线 |
|---|---|---|---|
| **BetonQuest** | 免费（有付费扩展） | YAML 脚本，分支对话/条件/持久状态，47 个插件集成（LuckPerms/DecentHolograms/MythicMobs） | 高（像写代码） |
| **Quests (PikaMug)** | 免费 | 游戏内问答式编辑器，杀怪/收集/对话，线性任务 | 低 |
| **BeautyQuests** | 免费 | GUI 建任务，1.17–1.21 | 中低 |

**推荐**：
- 只做"每日 / 周常任务 + 连签奖励"这种简单钩子 → **Quests**（轻、GUI 建，不用写脚本）。
- 想做有分支、跨章节的主线剧情 → **BetonQuest**（配 Citizens NPC + DecentHolograms 做对话石碑）。
- ❌ 不再用"neOmega 签到脚本"承担此职责（网易版不可自由脚本）。

## 3. Boss / 副本

| 插件 | 价格 | 特点 |
|---|---|---|
| **MythicMobs** | 免费核心 | 自定义血量/技能/阶段/掉落，**RPG 服做 Boss 的事实标准**，社区资源多，学习曲线中 |
| **EliteMobs** | 免费+付费内容 | **一体包**：Boss+地牢+任务+装备+战利品全有，约 50% 内容免费，近期支持基岩看模型 |
| *（现有）VexBot 改 Boss* | 免费 | 已会 `/vexbot spawn <名> <kit>` + `advancedspawn`，能做训练假人 / 简易 Boss |

**推荐**：
- 认真做副本 Boss（多阶段、专属技能、定制掉落）→ **MythicMobs**（可控、社区资源最多）。
- 想要"开箱即用的地牢内容"、不愿拼装 → **EliteMobs** 一体包。
- 只是想要几个训练靶 / 演示 Boss → 继续用 **VexBot**（零新插件）。
- **定时刷新 Boss**：用计划任务类插件（如 ScheduledCommands）或手动/活动触发，**不依赖 neOmega 脚本**。

## 4. 经济 / 商店

| 插件 | 价格 | 模式 | 基岩 |
|---|---|---|---|
| **EconomyShopGUI** | 免费 | 管理员 GUI 商店，Vault 经济，多货币 | ✅ 官方称"为基岩设计" |
| **QuickShop-Hikari** | 免费 | **玩家摆摊**（箱子商店），Residence 集成防乱放 | 一般 |
| **ShopGUIPlus** | ~$15 | 付费，UI 最精致，动态定价 | 一般 |
| **ChestShop** | 免费 | 牌子商店，最轻量，近零开销 | 一般 |

**推荐**：
- "玩家之间真流通" → **QuickShop-Hikari**（免费、玩家市场、Residence 集成）。
- "服务器统一定价商店" → **EconomyShopGUI**（免费、基岩友好）。
- 两者可共存。南瓜币真源仍是 Essentials `money`，交易流水走 `import-trade-history.mjs` 回填。

## 5. 城镇 / 阵营 RP ⚠️

| 插件 | 说明 | 与本服冲突 |
|---|---|---|
| **Towny** | 城镇+国家+税收，SMP/RP 首选 | ❌ 自带领地系统，与 **Residence 冲突** |
| **Lands** | GUI 领地+国家+战争，基岩有表单 | ❌ 同上，另一套领地 |
| **Factions / Saber** | 阵营 PvP 抢地 | ❌ 也是领地系统 |
| *（现有）Residence + LuckPerms 组* | 大领地+子领地 + 阵营组前缀 | ✅ 已就位，零冲突 |

**推荐**：**维护 Residence + LuckPerms，不引入任何新领地插件**。
- 城镇 = Residence 大领地 + 子领地（`/res subzone`）。
- 阵营 = LuckPerms 组（`faction_a`/`faction_b`）+ TAB 前缀色（复用职业/新人前缀机制）。
- 阵营战 / 城镇等级统计 → 用经济、领地数据估算或手动维护，**不依赖 neOmega 脚本**。

## 6. 成就 / 收集

| 插件 | 价格 | 特点 |
|---|---|---|
| **AdvancedAchievements** | 免费 | 55 类成就、GUI、排行、奖励（含 Vault 经济 / PAPI），1.18–26.2，Java 21 |
| *（现有）DecentHolograms 成就墙* | 免费 | 手动展示，无自动追踪 |

**推荐**：想要"自动追踪 + 排行 + 奖励" → **AdvancedAchievements**（免费，与 EssentialsX / PAPI 集成好）。
- 成就核验由插件原生完成，**不再用 Plan 数据 + neOmega 脚本**手动核验。

---

## 7. 自定义物品 / 外观（可选增强）

| 插件 | 说明 | 基岩风险 |
|---|---|---|
| **ItemsAdder / Oraxen** | 自定义物品/方块/家具 | ⚠️ **需要资源包**，基岩玩家不装包看不到贴图 |
| *（现有）/give 命令* | 用 `/give` 输出自定义附魔物品（如 `netherite_spear` + `minecraft:lunge`） | ✅ 无资源包，基岩可读 |

**推荐**：**避开 ItemsAdder / Oraxen / ModelEngine**（资源包对基岩互通是额外负担）。自定义物品继续用 `/give` + 数据包/指令生成。

## 三类"一系列包"对比

| 路线 | 组成 | 重量 | 适合 |
|---|---|---|---|
| **A. 模块化自组（推荐）** | AuraSkills + Quests/BetonQuest + MythicMobs/VexBot + EconomyShopGUI + QuickShop-Hikari + AdvancedAchievements + Residence | 中 | 灵活、可控、基岩友好 |
| **B. 一体包 EliteMobs** | 单插件搞定 Boss+地牢+任务+装备 | 中（黑盒） | 想快速有 RPG 内容、不愿拼装 |
| **C. MMO 全家桶** | MMOCore + MythicMobs + ModelEngine + ItemsAdder | 重（需资源包） | 硬核 RPG、不在乎基岩贴图缺失 |
| **D. 轻量自研（README 主线）** | LuckPerms 组 + QuickMenu + VexBot + DecentHolograms（**无 neOmega 依赖**） | 最轻 | 坚持"少上新插件"原则 |

## 针对本服的落地建议（修正版，无 neOmega 依赖）

1. **城镇 / 阵营**：维持 Residence + LuckPerms，不动 Towny/Lands/Factions。
2. **技能**：先上 **AuraSkills**（免费、基岩无碍），或继续 LuckPerms 职业组。
3. **任务**：每日/周常用 **Quests**；要做剧情再上 **BetonQuest**（配 Citizens）。
4. **Boss**：继续 **VexBot**，认真做副本再上 **MythicMobs**；定时刷新用计划任务插件。
5. **商店**：**EconomyShopGUI**（统一定价）+ **QuickShop-Hikari**（玩家市场）双开，免费且基岩友好。
6. **成就**：上 **AdvancedAchievements**（免费，原生追踪）。
7. **避开**：ItemsAdder/Oraxen/ModelEngine（资源包对基岩不友好）；Towny/Lands/Factions（领地冲突）。

## 避坑清单

- ✅ 所有"实体类型名"用 Bukkit `EntityType` 枚举常量（服务端是 Leaf/Paper，实现 Bukkit API，故配置里写 Bukkit 名正确）。
- ✅ 1.21.11 船已逐木头拆分（`OAK_BOAT`…`PALE_OAK_BOAT` + `BAMBOO_RAFT`），无统一 `BOAT`；杨木船（`POPLAR_*`）属 26.3+，本服暂不可写。
- ✅ 新增玩法实体（Boss、宠物、展示物）确认已加入 ClearLag `excluded-entities`，防误清。
- ❌ 不要为 RPG 引入第二套领地系统。
- ❌ 不要把网易 neOmega 当通用脚本平台来规划新功能。
- ❌ 基岩互通服慎用"需要资源包"的自定义物品插件。
