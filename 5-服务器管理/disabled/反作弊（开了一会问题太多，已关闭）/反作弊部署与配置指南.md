## 三、基岩（Bedrock）检测配置建议

### 前置要求（已确认满足）

- **Floodgate（Bukkit 版）**已安装于本服 ✅ —— Themis 需要它识别基岩玩家
- **Geyser config** 需开启 `forward-player-ping: true`（否则 Themis 无法测基岩玩家 ping）
- 确认 Floodgate 的 `send-floodgate-data` 生效（本服非 Bungee，直连无需额外配置）

### Themis 基岩配置要点（config.yml 生成后修改）

Themis 安装后首次启动会生成 `plugins/Themis/config.yml`。基岩相关建议：

```yaml
default:
  enable: true # 启用检测
  block: true # 命中后回拖/拦截（基岩侧建议先观察再开 block）
  block-threshold: 10.0 # 触发拦截的分数
  max-ping: -1.0 # 不因高 ping 跳过检测（基岩玩家 ping 较高，但建议先保留检测）
  min-tps: -1.0
  violation-expiration: 900.0

# 关键：基岩玩家误报风险主要在 Geyser 自身 bug
# 建议刚部署时先只开 notify（通知），确认无误报后再开 block

# 载具/鞘翅检测（对基岩玩家的船/鞘翅加速有效）
boat_movement: {}
elytra_flight: {}

# 若只想测基岩、不测 Java（一般不需要，保持 false 即可）
# bedrock-only: false
```

> **重要建议**：Themis 官方明确提示"支持基岩比 Java 更难，Geyser 有 bug 会导致随机异常行为，会有误报"。**部署初期务必先只开告警（notify）、不开自动惩罚（block）**，运行 1-2 周观察误报率后再启用拦截。

### GrimAC 基岩处理说明

GrimAC 对基岩玩家**完全豁免**（这是设计行为，避免误报），它只负责 Java 玩家。**不要试图开启 GrimAC 的基岩检测**——这是官方为防误报刻意为之，强行开启会导致基岩玩家大量误报。

## 四、各插件常用命令

### GrimAC

```
/grim help                 # 帮助
/grim verbose [on|off]     # 检测明细输出
/grim reload               # 重载配置
/grim alerts               # 告警开关
/grim perf                 # 性能诊断
/grim stats                # 统计
```

### Themis

```
/themis                    # 检查是否运行
/themis info <玩家名>       # 查看玩家违规分数（可用 /themis info <基岩玩家> 确认是否被识别为基岩）
/themis reload             # 重载配置
/themis notifications [on|off]
/themis notify <消息>       # 发送反作弊通知
```

### 权限

```
# Themis 关键权限（默认值）
themis.bypass              默认 false（所有玩家不可绕过）
themis.bypass.<checkName>  默认 false（按检查项绕过）
themis.silent              默认 false
themis.notifications       默认 op（接收检测通知）
themis.command.info        默认 op
```

## 五、NovaAC 手动安装指引（❌ 此部分已不适用，仅留档 —— NovaAC 已停用，2026-09-30）

NovaAC 发布在 SpigotMC 资源站（id: 134592），下载受登录保护，**自动化无法下载**，请手动完成：

1. 用浏览器打开：`https://www.spigotmc.org/resources/nova-sub-anticheat.134592/`
2. 登录 SpigotMC 账号，点击 **Download Now** 下载 `NovaAC.jar`（最新 1.24.10）
3. 将 `NovaAC.jar` 放入服务器 `plugins/` 目录
4. 重启服务器（PacketEvents 2.14.0 已装好，满足其"需 2.7+"要求）

**NovaAC 使用要点：**

- 强制要求 **Java 21+**（本机 21.0.1 ✅）
- **强烈建议搭配 PacketEvents 2.7+**（已装 2.14.0 ✅）
- 官方定位为 **sub-anticheat（副反作弊）**，与 GrimAC 搭配使用
- **部署初期务必只开告警、不开自动惩罚**（项目很新，需先调参观察）

## 六、部署后验证清单

1. 重启服务器，确认四个插件均正常加载（`/pl` 无红色报错）
2. `/themis` 确认 Themis 运行
3. 让一个基岩玩家上线，执行 `/themis info <该玩家>`，确认 Themis 正确识别其为 **Bedrock player**（否则 Floodgate 配置有问题）
4. 让 Java 玩家正常游戏，确认 GrimAC 无误报
5. 观察 1-2 周误报情况，再决定是否开启自动拦截

---

## 七、注意事项

- ⚠️ **误报优先**：所有反作弊插件部署初期都应"先告警后拦截"，尤其 Themis（基岩）和 NovaAC（新项目）
- ⚠️ 更新前**备份** `plugins/GrimAC/config.yml`、`plugins/Themis/config.yml`
- ⚠️ 反作弊插件会读取移动数据包，与 Geyser/ViaVersion/ProtocolLib 协同需留意兼容（本服已有这些插件）
- 📌 若遇误报，Themis 可在 Discord 上报；GrimAC 走 GitHub issues
