# AdvancedSensitiveWords — 敏感词过滤

> 服务器聊天、告示牌、铁砧、书等内容的敏感词过滤插件。

## 基本信息

| 项目 | 内容 |
|---|---|
| 插件名 | AdvancedSensitiveWords |
| 版本 | 2.3.0 |
| 数据目录 | `plugins/AdvancedSensitiveWords/` |
| 配置文件 | `config.yml` |
| 默认替换字符 | `喵` |

---

## 一、词表文件

| 文件 | 说明 | 数量 |
|---|---|---|
| `敏感词库-中文.txt` | 内置中文敏感词库 | 56,665 个 |

| `白名单-内置.txt` | 内置白名单（不过滤） | 11 个 |

## 五、相关命令

| 命令 | 说明 |
|---|---|
| `/asw reload` | 重载配置 |
| `/asw words` | 查看所有词 |
| `/asw list` | 查看列表 |
| `/asw player <玩家>` | 查看玩家违规记录 |
