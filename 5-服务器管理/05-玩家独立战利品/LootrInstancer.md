# Lootr Instancer 插件文档（南瓜服 · 1.21.11 Leaf/Paper）

存放路径：`F:\game\pc\MC\开服\Minecraft-Server-Build\5-服务器管理\05-玩家独立战利品\LootrInstancer.md`

> 插件来源：Modrinth，项目名 Lootr Instancer，Paper插件，**非Fabric Lootr模组**
> 适用版本：1.21.11，兼容 Paper / Leaf / Purpur；**客户端无需装mod，Geyser基岩玩家可用**
> 核心定位：实现【每个玩家独立战利品宝箱】，复刻Fabric Lootr核心机制，同箱子A开完B仍能拿到自己的战利品

## 一、基础信息

- 插件名称：Lootr Instancer
- 加载类型：服务端插件（Jar放入plugins文件夹，重启加载）
- 数据存储：YAML 文件，路径 `plugins/LootrInstancer/data/`
- 自动保存：默认5分钟自动落盘
- 许可证：ARR（保留所有权利，仅服务器自用，禁止二次分发/修改插件本体）
- 冲突提示：自定义战利品、自定义结构插件有概率冲突；**建议插件加载顺序放在末尾**

### 支持容器（自动实例化原版loot_table宝箱）

- 普通箱子、陷阱箱、木桶、矿车箱子
  > 潜影盒默认不生效，可在配置按需开启

## 二、核心特性

1. 虚拟战利品实例：不修改世界方块本身，每个玩家独立roll战利品表，互不干扰
2. 自带箱子保护
   - 防爆：TNT、苦力怕、床炸、重生锚爆炸保护
   - 漏斗禁止抽取、活塞无法推动箱子
   - 玩家破坏箱子：需要短时间连续点击2次，防止误拆
3. 粒子视觉标记（替代Fabric Lootr方块变色效果）
   - 未开启箱子显示粒子；玩家开过之后粒子消失
   - 可开关粒子、更换粒子类型；支持开箱音效开关
4. 支持手动创建自定义独立战利品箱（新手礼包、副本奖励箱）

## 三、OP指令列表

```
/lootr help          # 查看全部指令
/lootr reload        # 重载配置 + 加载数据
/lootr info          # 看向箱子，查看该箱子实例信息
/lootr stats         # 统计：箱子数量、玩家记录、插件运行时长
/lootr reset <玩家>  # 重置【单个玩家】全部宝箱开启记录
/lootr resetall      # 清空全部实例记录 ⚠️高危，慎用！
/lootr create        # 将当前站立位置普通箱子转为自定义独立战利品箱
```

## 四、权限节点

| 权限节点    | 作用                                 |
| ----------- | ------------------------------------ |
| lootr.\*    | 全部权限（OP默认自带）               |
| lootr.admin | 管理员权限：创建箱子、重置、重载配置 |
| lootr.use   | 玩家基础使用权限（默认全体玩家拥有） |

## 五、部署步骤

1. 将下载的 LootrInstancer.jar 放入服务器 `plugins` 文件夹
2. 启动服务器一次，自动生成配置文件夹与config.yml
3. 停止服务器，替换为上方优化配置，重启服务端
4. 测试：找一个自然生成宝箱，A玩家开启，换B玩家打开同箱子验证独立战利品
5. 备份规则：定期备份 `plugins/LootrInstancer/data` 目录（玩家开箱记录）

## 六、已知坑点&运维注意事项

1. ❗**不支持MySQL**，全部记录存在YAML文件；大量玩家+大量宝箱时文件数量会增多，必须纳入定时备份
2. 无方块材质变色：方块变色是Fabric客户端mod渲染效果，插件只能用粒子做视觉标记
3. 与自定义loot、结构生成插件存在冲突风险，加载顺序后置
4. resetall 会清除**所有人所有箱子记录**，生产环境严禁随意执行
5. Geyser基岩版玩家完全兼容，无特殊客户端需求

## 七、运维检查命令

```
/lootr stats    # 快速查看插件运行状态、箱子计数
/lootr info     # 定点检测单个箱子是否正常实例化
```

## 八、故障排查

### 1. 粒子不显示

- 检查配置 `particles.enabled: true` 是否开启
- 确认玩家客户端粒子设置没有调至最低
- 确认箱子属于原版loot_table容器，自定义方块箱子不会生成粒子

### 2. 战利品没有独立（A开完B拿不到）

- 确认插件正常加载，`/lootr stats` 查看插件状态
- 检查该世界是否被加入 `world-blacklist`
- 部分自定义结构生成的箱子不携带原版loot_table，无法实例化

### 3. 指令提示无权限

- OP检查是否拥有 `lootr.admin` 权限节点
- 权限插件（LuckPerms）是否覆盖了插件权限

### 4. 大量YAML文件占用磁盘

- 增加备份频率；定期清理离线很久玩家的开箱记录
- 不要随意执行`/lootr resetall`，会清空所有玩家进度
