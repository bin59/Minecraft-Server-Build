# 03. 方块记录与回滚 — CoreProtect 操作手册

**适用版本**：CoreProtect 23.x+（MC 1.21.11 推荐 23.0 及以上；方块级 `purge` 需 v23+，DuckDB/ClickHouse 迁移需 v25+）
**主命令**：`/co`（等价 `/coreprotect`）
**常用别名**：`/co i` = inspect，`/co l` = lookup，`/co rb` = rollback，`/co rs` = restore，`/co near`，`/co undo`

> CoreProtect 是轻量的方块/容器/聊天记录与回滚插件，直接发包、无前置依赖。南瓜生存服用它做** grief 回滚、被盗物品追回、破坏定位、聊天/命令审计**。所有记录落在数据库（默认 SQLite，可换 MySQL/DuckDB/ClickHouse）。

---

## 一、命令总览

| 命令 | 别名 | 作用 |
| --- | --- | --- |
| `/co help` | — | 列出全部命令 |
| `/co inspect` | `/co i` | 开关“检查员模式”（手持物品右键方块查记录） |
| `/co lookup <参数>` | `/co l` | 查询记录（不改动世界） |
| `/co rollback <参数>` | `/co rb` | 回滚（撤销玩家/实体造成的改变） |
| `/co restore <参数>` | `/co rs` | 还原（撤销回滚，或恢复玩家行为） |
| `/co purge <参数>` | — | 删除旧记录、释放磁盘 |
| `/co reload` | — | 重载配置文件 |
| `/co status` | — | 查看插件状态/版本 |
| `/co consumer` | — | 控制台命令：暂停/恢复写入队列 |
| `/co migrate-db <后端>` | — | 控制台命令：迁移数据库后端 |
| `/co near` | — | 以半径 5 做查询（lookup 快捷方式） |
| `/co undo` | — | 用相反动作撤销上一次 rollback/restore |

> **关键区别**：`lookup` **只查不改**；`rollback` 真正改动世界；`restore` 把 rollback 反过来（相当于“反悔”）。查询默认**全局**，回滚默认半径 **10**（以你自己为中心）。

## 二、参数速查（lookup / rollback / restore 通用）

| 参数 | 含义 | 示例 |
| --- | --- | --- |
| `u:<用户>` | 指定玩家/实体（可多个，逗号分隔） | `u:Notch`、`u:Notch,Intelli`、`u:#fire,#tnt,#creeper,#explosion` |
| `t:<时间>` | 时间范围（可组合、可小数） | `t:1h`、`t:5d2h`、`t:2w,5d,7h`、`t:1h-2h`（1~2 小时间）、`t:2.50h` |
| `r:<半径>` | 以你为中心的半径；或全局/世界/WorldEdit 选区 | `r:20`、`r:#global`、`r:#world_nether`、`r:#worldedit`（或 `r:#we`） |
| `a:<动作>` | 限定动作类型（见下方动作表） | `a:-block`、`a:container`、`a:chat` |
| `i:<包含>` | 仅包含某些方块/物品/实体 | `i:stone`、`i:stone,oak_wood,bedrock` |
| `e:<排除>` | 排除某些方块/物品/实体/用户 | `e:tnt`、`e:stone,dirt` |
| `f:<过滤>` | 按前缀过滤聊天/命令/告示文本 | `a:command f:/ban`、`a:chat f:-hello` |
| `#<标签>` | 附加动作（见下方哈希标签） | `#preview`、`#count`、`#summary` |

> **时间单位**：`s` 秒 / `m` 分 / `h` 时 / `d` 天 / `w` 周 / `y` 年。可连写如 `t:5d2h`。
> **半径说明**：`r:#global` 全服；`r:#world_xxx` 指定世界（世界名带下划线，如 `world_the_end`）；`r:#worldedit` 需装 WorldEdit 并先选区。

### 动作类型 `a:<action>` 完整表

| 参数 | 含义 |
| --- | --- |
| `a:block` | 放置/破坏的方块 |
| `a:+block` | 仅放置的方块 |
| `a:-block` | 仅破坏的方块 |
| `a:chat` | 聊天消息 |
| `a:click` | 玩家交互（如按按钮、拉拉杆） |
| `a:command` | 执行的命令 |
| `a:container` | 从容器存入/取出物品 |
| `a:+container` | 仅存入容器 |
| `a:-container` | 仅从容器取出 |
| `a:inventory` | 玩家背包增减 |
| `a:+inventory` | 仅背包新增 |
| `a:-inventory` | 仅背包减少 |
| `a:item` | 玩家丢弃/拾取/投掷/存取物品 |
| `a:+item` | 仅拾取/取出 |
| `a:-item` | 仅丢弃/存入 |
| `a:kill` | 击杀的生物/动物 |
| `a:spawn` | 玩家放置/生成的实体 |
| `a:session` | 登录/登出 |
| `a:+session` | 仅登录 |
| `a:-session` | 仅登出 |
| `a:sign` | 写在告示牌上的文字 |
| `a:username` | 用户名变更记录 |

### 哈希标签 `#<hashtag>`

| 标签 | 效果 |
| --- | --- |
| `#preview` | 回滚/还原**预览**（不真正改动，先看清影响） |
| `#count` | 返回查询命中的行数 |
| `#summary` | 返回行数 + 各玩家/材质的统计汇总 |
| `#verbose` | 回滚/还原时显示额外信息 |
| `#silent` | 回滚/还原时只显示最少信息 |
| `#optimize` | purge 时一并优化数据库表、回收空间（MySQL/ClickHouse 有效） |

## 三、检查员模式（inspect）

手持任意物品，开启检查员后**右键**方块/容器即可在聊天框看到该位置的修改记录。

```
/co inspect          # 开启
/co inspect          # 再敲一次关闭
/co i                # 简写
```

- 右键**方块**：显示谁在何时放置/破坏、材质。
- 右键**容器（箱子/熔炉/漏斗等）**：显示谁取放过什么物品。
- 右键**告示牌**：显示牌面文字历史。
- 适合现场核查“这块被谁挖了”“这箱子谁动过”。

## 四、查询（lookup）— 只查不改

```
/co lookup u:Notch t:30m a:chat          # Notch 近 30 分钟聊天
/co lookup u:Notch t:3d a:inventory      # Notch 近 3 天背包变动
/co lookup u:Notch a:login               # Notch 全部登录记录
/co lookup u:Notch a:username            # Notch 用过的旧名
/co lookup i:diamond_ore t:1h a:-block   # 近 1 小时被挖的钻石矿
/co lookup r:50 t:7d a:block #summary    # 周围 50 格、7 天内方块变动汇总
```

**分页**：命中多页时，`/co lookup <页码>` 翻页；`/co lookup <页>:<行数>` 调整每页行数，如 `/co l 1:10` 显示第 1 页 10 行。

**文本过滤** `f:`（仅配合 `a:chat` / `a:command` / `a:sign`）：

```
/co lookup a:command f:/ban          # 以 /ban 开头的命令
/co lookup a:command f:/ban,/kick    # /ban 或 /kick 开头
/co lookup a:command f:/ban,-/banlist# 含 /ban 但排除 /banlist
/co lookup a:chat f:-hello            # 排除以 hello 开头的消息
```

**爆炸 / 放置人员 常用速查**（现场排查最直接；记住 `lookup` 默认全局，加 `r:` 才限定“附近”）：

```
/co lookup u:#explosion r:#global                  # 全服所有爆炸造成的方块变动
/co lookup u:#tnt,#creeper,#fire,#explosion r:#global   # 全服各类爆炸源（TNT/苦力怕/火焰）
/co lookup u:#explosion r:30                       # 周围 30 格内所有爆炸
/co lookup u:#tnt,#creeper,#fire,#explosion r:30 t:2h   # 周围 30 格、近 2 小时各类爆炸
/co inspect                                       # 手持物品右键某方块，直接看是谁放置/破坏
/co lookup a:+block r:10                          # 周围 10 格内所有“放置”记录
/co lookup a:+block r:10 t:1h                     # 近 1 小时放置
/co lookup i:stone a:+block r:10                  # 周围 10 格内谁放了石头
/co lookup u:玩家名 a:+block r:20                 # 某玩家在周围 20 格放了什么
```

> `#explosion` 是爆炸类总标识；`#tnt`/`#creeper`/`#fire` 可单独细查某一种爆炸源。`a:+block` = 仅放置，`a:-block` = 仅破坏。

## 五、回滚（rollback）— 真正撤销

默认半径 10（以你为中心），需全服请加 `r:#global`。**建议先用 `#preview` 预览再正式执行。**

```
/co rollback u:Notch t:1h                       # 回滚 Notch 近 1 小时（半径 10）
/co rollback u:Notch,Intelli t:1h #preview      # 预览两人近 1 小时回滚
/co rollback u:Notch t:1h i:stone              # 仅回滚 Notch 放的/挖的石头
/co rollback u:Notch t:1h i:stone a:-block     # 仅回滚 Notch 挖掉的石头
/co rollback u:Notch t:1h r:#global e:stone,dirt  # 全服回滚 Notch，但保留石头泥土
/co rollback u:Notch t:1h r:20                 # 仅你周围 20 格内
/co rollback u:Notch t:1h r:#world_nether      # 仅下界
/co rollback u:Notch t:5m a:inventory          # 回滚 Notch 近 5 分钟背包
/co rollback t:15m r:30                        # 近 15 分钟、周围 30 格内所有人
/co rollback t:15m r:#worldedit                 # WorldEdit 选区内近 15 分钟
/co rollback u:#creeper t:1h r:#global         # 全服回滚 1 小时内所有苦力怕破坏
/co rollback u:#tnt,#fire t:2h r:#global       # 全服回滚 TNT/火焰造成的破坏
```

**常见实体/自然源用户标识**（用于 `u:`）：
- `#creeper` 苦力怕、`#tnt` TNT、`#fire` 火焰、`#explosion` 爆炸、`#entity` 实体、`#player` 玩家、`#water` 水、`#lava` 岩浆（部分版本支持）。

## 六、还原 / 撤销（restore / undo）

`restore` 与 `rollback` 参数完全一致，只是方向相反——把被回滚的内容**恢复回来**，或主动“恢复”某玩家的行为。

```
/co restore u:Notch t:1h            # 把 Notch 近 1 小时的回滚反悔（恢复）
/co restore t:1h r:#global          # 全服恢复近 1 小时（反悔一次全服回滚）
```

`/co undo` 是快捷方式，对**上一次** rollback/restore 执行相反动作，无需重填参数：

```
/co undo                            # 撤销上一次回滚/还原
```

> 回滚前不确定影响范围？先 `/co rollback ... #preview`，确认无误后去掉 `#preview` 正式执行；若执行错了立刻 `/co undo`。

## 七、数据清理（purge）— 释放磁盘

```
/co purge t:30d                     # 删除 30 天前的所有记录（游戏内仅可删>30天）
/co purge t:30d #optimize           # 删除并优化数据库表、回收空间
/co purge t:30d r:#world_nether     # 仅删下界 30 天前记录（v19+）
/co purge t:30d i:stone,dirt        # 仅删石头/泥土 30 天前记录（v23+）
```

> **限制**：游戏内执行只能清理 **30 天以前**的数据；控制台可清理 **24 小时以前**。`#optimize` 对 MySQL/ClickHouse 有效（SQLite 无需，DuckDB 无额外效果）。

---

## 八、状态 / 重载 / 数据库 / 队列

```
/co status            # 查看版本、数据库类型、记录条数
/co reload            # 改了 config.yml 后重载
```

**数据库迁移**（仅控制台，v23+ 支持 SQLite↔MySQL，v25+ 支持 DuckDB/ClickHouse）：

```
co migrate-db sqlite
co migrate-db mysql
co migrate-db duckdb
co migrate-db clickhouse
```

> 目标后端必须**无 CoreProtect 数据**；DuckDB 目标须用新库文件且保持 `database-lock` 开启。迁移成功后插件自动更新 `config.yml` 的 `database-type`。

**消费者队列**（仅控制台）：CoreProtect 用队列异步写库，`consumer` 可暂停/恢复排大队时的写入。

```
co consumer           # 暂停/恢复切换
```

## 九、实战场景速查表

| 场景 | 命令 |
| --- | --- |
| 某玩家在身边搞破坏，10 分钟内 | `/co rollback u:玩家 t:10m #preview` |
| 全服 grief，来回滚 | `/co rollback u:玩家 t:2h r:#global #preview` |
| 只找回被偷的物品 | `/co rollback u:小偷 t:1h a:-container` 或 `a:inventory` |
| 找回被挖的钻石矿 | `/co lookup i:diamond_ore t:1h a:-block` 然后回滚 |
| 服务器被 TNT/苦力怕炸 | `/co rollback u:#tnt,#creeper t:1h r:#global` |
| 岩浆/水淹了房子 | `/co rollback u:#lava,#water t:1h r:#global`（版本支持时） |
| 查全服所有爆炸 | `/co lookup u:#explosion r:#global` |
| 查周围 30 格爆炸 | `/co lookup u:#explosion r:30` |
| 查某方块是谁放置的 | `/co inspect` 后右键方块（或 `/co lookup a:+block r:10`） |
| 查某玩家在附近放了什么 | `/co lookup u:玩家 a:+block r:20` |
| 查谁动了某个箱子 | `/co inspect` 后右键箱子 |
| 查命令记录（谁开过 /op） | `/co lookup a:command f:/op` |
| 查聊天记录 | `/co lookup a:chat f:关键词` |
| 清一个月前的旧数据 | `/co purge t:30d #optimize` |
| 回滚执行错了 | `/co undo` |

## 十、权限节点（LuckPerms）

| 节点 | 说明 |
| --- | --- |
| `coreprotect.use` | 可使用全部 CoreProtect 命令 |
| `coreprotect.inspect` | 检查员模式 |
| `coreprotect.lookup` | 查询 |
| `coreprotect.rollback` | 回滚 |
| `coreprotect.purge` | 清理数据 |
| `coreprotect.reload` | 重载配置 |
| `coreprotect.status` | 查看状态 |

> 服主/管理组给 `coreprotect.use`；普通玩家无需任何节点即可被记录，但不能查询/回滚。建议只把 `rollback` 给可信管理，避免误回滚。

## 十一、排错与注意事项

- **回滚范围过大卡服**：先用 `r:#global` 全服回滚会瞬间处理大量方块；大范围建议在低峰期执行，或先用 `#preview` 估算行数（`#count`）。
- **回滚后世界没变**：确认时间 `t:` 是否够长、半径 `r:` 是否覆盖、用户 `u:` 拼写是否正确；用 `lookup` 先验证能查到记录。
- **玩家离线也能回滚**：CoreProtect 按 UUID 记录，改名/离线不影响回滚。
- **容器物品追回**：`a:container` 回滚会把被取出的物品放回、把放入的取出；若只想追“被盗”，用 `a:-container`（仅取出）更精准。
- **数据库体积**：长期运行靠 `purge` 定期清理；MySQL 用户可加 `#optimize`。
- **WorldEdit 选区回滚**：需先 `/wand` 选区，再用 `r:#worldedit`；未选区会报错。
- **不要和 `/reload` 混用**：CoreProtect 自身用 `/co reload`；服务端 `/reload` 可能中断写入队列，建议完整重启更稳妥。
