|---|---|---|
| `easybot.command` | 命令基类 | 🔧 |
| `easybot.command.bind` | `/bind <验证码>` | 绑定 QQ ✅ |
| `easybot.command.esay` | — | 衍生命令 |
| `easybot.command.reload` ⚠️ | `/ebot reload` | 重载重连 Bridge 🔧 |
| `easybot.admin` ⚠️ | — | 管理 🔧 |
| `easybot.*` ⚠️ | — | 全部 服主 |

**实测方法**：`/lp user <玩家> permission check easybot.command.bind`

## 依赖库与面板

- **CMILib** — `plugin.yml` 无 `permissions:` 段，无独立节点（被其他插件依赖）。
- **bStats** — 统计库，无节点。
- **opanel** (`opanel-bukkit`) — `plugin.yml` 无 `permissions:` 段；管理通过面板 Web 完成，无 LuckPerms 节点。
- **MCSM** — 面板系统（非插件权限），通过面板账号控制，无 LuckPerms 节点。

## 原版与 Bukkit 命令

| 节点 | 说明 |
|---|---|
| `minecraft.command.<命令>` | 单个原版命令，如 `minecraft.command.gamemode` |
| `minecraft.command.*` | 全部原版命令 🔧 |
| `bukkit.command.*` | Bukkit 内置命令（`/pl` `/version` 等）🔧 |

常用原版命令节点：

```
minecraft.command.gamemode      minecraft.command.teleport
minecraft.command.give          minecraft.command.effect
minecraft.command.time          minecraft.command.weather
minecraft.command.summon        minecraft.command.kill
minecraft.command.setblock      minecraft.command.fill
minecraft.command.clone         minecraft.command.tp
minecraft.command.op            minecraft.command.deop        ☠️
minecraft.command.stop          ☠️
minecraft.command.datapack      ☠️
```

> ☠️ `minecraft.command.op` / `deop` / `stop` **绝不给任何玩家组，包括 admin**。

## 通用排错命令

```bash
# 检查某玩家是否拥有某权限
/lp user <玩家> permission check <节点>

# 查看某玩家完整权限信息（含继承来源）
/lp user <玩家> info

# 查看某组完整信息
/lp group <组名> info

# 实时追踪某权限判定过程（排查神器）
/lp verbose on <玩家|me> <权限关键字>
/lp verbose off

# 查看某插件注册了哪些节点（写本文档的主要依据）
/lp tree <关键字>

# 列出所有组
/lp listgroups
```

> 所有 `⚠️` 标记的节点建议先用 `/lp tree <关键字>` 在测试服导出实际注册清单再精确授权；版本升级后 plugin.yml 可能增减节点。
