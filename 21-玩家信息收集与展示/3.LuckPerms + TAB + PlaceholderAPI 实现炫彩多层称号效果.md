在 Minecraft 服务器中，使用 **LuckPerms + TAB + PlaceholderAPI** 实现炫彩多层称号效果，以下是完整配置方案：

---

### 前置条件

确保已安装以下插件：

- **TAB**（TAB列表 + 头顶名牌管理）
- **LuckPerms**（权限组 + 前缀管理）
- **PlaceholderAPI**（占位符解析）
- **LuckPerms 的 PAPI 扩展**：`/papi ecloud download LuckPerms` → `/papi reload`

---

### 第一步：LuckPerms 设置多行前缀

TAB 插件支持用 `\n` 实现多行显示。在 LuckPerms 中为不同权限组设置前缀：

```bash
# 管理员 - 三行炫彩称号
/lp group admin meta setprefix "&4&l✦ 管理员 ✦\n&c&lSERVER\n&7"

# VIP - 两行称号
/lp group vip meta setprefix "&6&l★ VIP ★\n&e"

# MVP - 两行称号
/lp group mvp meta setprefix "&b&l◆ MVP ◆\n&3"

# 普通玩家 - 单行
/lp group default meta setprefix "&7"
```

> **注意**：`\n` 是换行符，LuckPerms 的前缀支持这个语法，TAB 插件会正确解析为多行显示。

---

### 第二步：TAB 配置头顶多行显示

编辑 TAB 的 `config.yml`，配置 `tagprefix`（头顶前缀）：

```yaml
tablist-name-formatting:
  default:
    tabprefix: '%luckperms_prefix%'
    tabname: '&f%player_name%'
    tabsuffix: ''
    tagprefix: '%luckperms_prefix%'
    tagname: '&f%player_name%'
    tagsuffix: ''
```

这样玩家头顶会显示为：

```
    ✦ 管理员 ✦
    SERVER
  Steve
```

---

### 第三步：炫彩渐变效果（1.16+）

如果你的服务器版本是 **1.16 及以上**，TAB 插件支持十六进制颜色（`&#RRGGBB`），可以实现渐变效果：

```bash
# 管理员 - 渐变红色称号
/lp group admin meta setprefix "&#FF0000&l✦ &#FF4400管 &#FF8800理 &#FFAA00员 &#FF0000&l✦ &#FF6600&lSERVER &7&#FFD700&l★ &#FFCC00V &#FFBB00I &#FFAA00P &#FFD700&l★ &#FFD700&#00FFFF&l◆ &#00DDDDМ &#00BBBBV &#009999P &#00FFFF&l◆"




# VIP - 渐变金色称号
/lp group vip meta setprefix "&#FFD700&l★ &#FFCC00V &#FFBB00I &#FFAA00P &#FFD700&l★\n&#FFD700"

# MVP - 渐变青色称号
/lp group mvp meta setprefix "&#00FFFF&l◆ &#00DDDDМ &#00BBBBV &#009999P &#00FFFF&l◆\n&#00DDDD"
```

效果类似：

```
  ✦ 管 理 员 ✦    ← 每个字颜色不同，形成渐变
    SERVER
  Steve
```

---

### 第四步：动态彩虹效果

TAB 插件内置了动态彩虹占位符，可以实现**实时流动**的彩虹称号：

在 TAB `config.yml` 中配置：

```yaml
tablist-name-formatting:
  default:
    tabprefix: '%luckperms_prefix%'
    tabname: '&f%player_name%'
    tabsuffix: ''
    tagprefix: '%luckperms_prefix%'
    tagname: '&f%player_name%'
    tagsuffix: ''
```

然后在 LuckPerms 中使用 TAB 提供的彩虹占位符：

```bash
# 使用 TAB 的渐变占位符（需要 TAB 4.0+）
/lp group admin meta setprefix "&4&l✦ &c&l管理员 &4&l✦\n&c&lSERVER\n&7"
```

---

### 第五步：TAB 列表中也显示多行

如果你希望 TAB 列表（按 Tab 键弹出的玩家列表）也显示多行称号，修改配置：

```yaml
tablist-name-formatting:
  default:
    tabprefix: '%luckperms_prefix%'
    tabname: '&f%player_name%'
    tabsuffix: ' &7| &f%player_health%&c❤'
    tagprefix: '%luckperms_prefix%'
    tagname: '&f%player_name%'
    tagsuffix: ''
```

### 常用命令速查

| 命令                                    | 作用                 |
| --------------------------------------- | -------------------- |
| `/lp group <组> meta setprefix <前缀>`  | 设置权限组前缀       |
| `/lp user <玩家> meta setprefix <前缀>` | 单独给某玩家设置前缀 |
| `/lp user <玩家> parent add <组>`       | 将玩家加入权限组     |
| `/tab reload`                           | 重载 TAB 配置        |

---

### 注意事项

- 多行前缀中，**最后一行**应该是玩家名字的颜色前缀（如 `&7`），否则名字会继承上一行的颜色
- `\n` 换行在头顶名牌（tag）中有效，但在 TAB 列表中可能只显示第一行（取决于 TAB 版本）
- 十六进制颜色 `&#RRGGBB` 仅在 **1.16+** 版本生效，低版本会自动降级为最近的颜色代码
- 如果前缀不生效，执行 `/papi parse me %luckperms_prefix%` 测试占位符是否正常返回

# 以下是三个配置文件的正确模板，你可以直接参考修改：

---

### 📄 `animations.yml`

当前版本每个动画**只支持 `change-interval` 和 `texts` 两个键**，需要删除 `type`、`speed`、`colors` 等旧版无效键，并确保 `texts` 列表不为空。

```yaml
rainbow:
  change-interval: 200
  texts:
    - '&cR'
    - '&6a'
    - '&ei'
    - '&an'
    - '&bb'
    - '&9o'
    - '&5w'

gradient:
  change-interval: 300
  texts:
    - '&cG'
    - '&6r'
    - '&ea'
    - '&ad'
    - '&bi'
    - '&9e'
    - '&5n'
    - '&dt'

breathing:
  change-interval: 500
  texts:
    - '&fB'
    - '&7r'
    - '&fB'
    - '&7r'
```

> **说明**：`change-interval` 单位为毫秒，数值越小动画越快。`texts` 列表中的每一行就是一帧，插件会按顺序循环播放。你可以自由增减帧数和内容。在 `config.yml` 中通过 `%animation:rainbow%` 这样的格式引用动画名。

---

### 📄 `config.yml`（`tablist-name-formatting` 部分）

删除无效的 `default` 键，补上 `disable-condition` 字段即可：

```yaml
tablist-name-formatting:
  enabled: true
  disable-condition: '%world%=disabledworld'
```

> **说明**：`disable-condition` 用于指定在哪些世界/条件下禁用 TAB 列表名称格式化。如果你不需要禁用任何世界，可以将其设为空字符串 `""`。

---

### 📄 `groups.yml`（`Admin` 组部分）

将无效的 `header` 属性替换为有效属性（`tagprefix`、`tagsuffix`、`tabprefix`、`customtabname`、`tabsuffix`）：

```yaml
Admin:
  tabprefix: '&4[Admin] &f'
  tagsuffix: ''
  customtabname: '%player%'
  tabsuffix: ''
```

> **说明**：
>
> - `tabprefix`：TAB 列表中玩家名字前面的前缀
> - `tagsuffix`：TAB 列表中玩家名字后面的后缀
> - `customtabname`：TAB 列表中显示的名称（默认 `%player%` 即玩家名）
> - `tabsuffix`：TAB 列表后缀
> - 如果你使用 LuckPerms 管理权限组，前缀后缀也可以直接在 LuckPerms 中设置，TAB 会自动读取。
