### config.yml 完整示例

```yaml
# ================================ #
#       TAB 插件主配置文件          #
# ================================ #

# -------- 头部（Header）--------
header:
  - ''
  - '&6&l✦ 我的服务器 ✦'
  - '&7欢迎回来, &f%player%&7!'
  - ''

# -------- 底部（Footer）--------
footer:
  - ''
  - '&7在线人数: &a%online%&7/&6%max% &8| &7TPS: %tps%'
  - '&7你的在线时长: &b%playertime_time%'
  - '&7余额: &e$%vault_eco_balance%'
  - ''

# -------- 玩家名称格式 --------
tablist-name-formatting:
  # 按权限组显示不同前缀和后缀
  # 需要与 LuckPerms 等权限插件联动

  # 默认玩家组
  default:
    tabprefix: '&7[&f玩家&7] '
    tabsuffix: ' &8| &7%ping%ms'
    tagprefix: '&7[&f玩家&7] '
    tagsuffix: ''

  # VIP 组
  vip:
    tabprefix: '&6[&eVIP&6] '
    tabsuffix: ' &8| &7%ping%ms'
    tagprefix: '&6[&eVIP&6] '
    tagsuffix: ''

  # 管理员组
  admin:
    tabprefix: '&4[&c管理员&4] '
    tabsuffix: ' &4✦'
    tagprefix: '&4[&c管理员&4] '
    tagsuffix: ''

# -------- 排序设置 --------
sorting:
  type: 'GROUPS'
  # 按权限组排序，权重高的排在前面
  # 需要在 groups.yml 中设置每组的排序权重

# -------- 动态效果 --------
# 刷新间隔（单位：tick，20tick = 1秒）
refresh-interval:
  header: 20
  footer: 20
  tablist: 20

# -------- 其他设置 --------
# 是否显示 Ping 值
ping:
  enabled: true

# 是否启用 Tab 列表中的玩家头像
playerhead:
  enabled: true
```

### groups.yml 分组配置示例

```yaml
# ================================ #
#       权限组配置                  #
# ================================ #

admin:
  tabprefix: '&4[&c管理员&4] '
  tabsuffix: ' &4✦'
  tagprefix: '&4[&c管理员&4] '
  tagsuffix: ''
  # 排序权重，数值越大越靠前
  sorting: 100
  # 该组对应的权限节点（与 LuckPerms 联动）
  permission: 'group.admin'

vip:
  tabprefix: '&6[&eVIP&6] '
  tabsuffix: ' &e★'
  tagprefix: '&6[&eVIP&6] '
  tagsuffix: ''
  sorting: 50
  permission: 'group.vip'

default:
  tabprefix: '&7[&f玩家&7] '
  tabsuffix: ''
  tagprefix: '&7[&f玩家&7] '
  tagsuffix: ''
  sorting: 10
  permission: 'group.default'
```

### 前置插件安装清单

使用以上配置需要安装以下前置插件：

| 插件                           | 用途                      | 安装后操作                                  |
| ------------------------------ | ------------------------- | ------------------------------------------- |
| **PlaceholderAPI**             | 占位符核心桥梁            | 安装后执行 `/papi ecloud download <扩展名>` |
| **LuckPerms**                  | 权限管理，与 TAB 分组联动 | 创建对应权限组并分配玩家                    |
| **PlaytimeStats / PlayerTime** | 提供在线时长占位符        | 执行 `/papi ecloud download PlayTime`       |
| **Vault**                      | 经济系统桥接              | 搭配经济插件（如 EssentialsX）使用          |

---

### 部署步骤

1. 将以上配置文件分别保存到 `plugins/TAB/` 目录下
2. 确保已安装所有前置插件
3. 在 LuckPerms 中创建对应的权限组：
   ```
   /lp creategroup admin
   /lp creategroup vip
   /lp creategroup default
   ```
4. 下载所需的 PAPI 扩展：
   ```
   /papi ecloud download PlayerTime
   /papi ecloud download Vault
   ```
5. 执行 `/tab reload` 重载配置
6. 让玩家重新登录，即可看到效果

> **提示**：修改配置后建议先用 `/tab parse <文本>` 命令测试占位符是否能正确解析，确认无误后再 `/tab reload`。
