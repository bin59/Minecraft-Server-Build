## 📋 在线玩家列表与头顶展示

### TAB

- **定位**：自定义游戏内 TAB 列表（按 Tab 键弹出的玩家列表）
- **核心功能**：自定义列表布局、显示等级/血量/Ping/阵营、前缀后缀、动态分组
- **平台**：Spigot / Paper / Purpur 等
- **版本**：1.8 ~ 最新版（当前最新版本 5.5.0，支持至 1.21.11）
- **特点**：老牌插件，生态成熟，几乎所有服务器都会用到
- **官方网站**：https://www.spigotmc.org/resources/tab-1-7-1-21.57806/
- **GitHub**：https://github.com/NoC0DE92/TAB
- **简介**：功能最全面的 TAB 列表自定义插件，支持 BungeeCord 跨服同步，内置大量 PlaceholderAPI 变量，可显示 TPS、内存、玩家数等服务器状态信息，支持动态头部和尾部。已在 4000+ 服务器运行，SpigotMC 下载量 26,500+，评分 4.8/5。

### CyuTag

- **定位**：玩家头顶多行信息展示
- **核心功能**：在原版名牌上方添加多行内容（称号、等级、延迟、公会等），支持渐变/彩虹/呼吸变色/帧动画等动态字效，支持 PlaceholderAPI 变量
- **平台**：Spigot / Paper / Folia / Purpur / PufferFish / Leaves
- **版本**：1.20 ~ 26.x
- **特点**：不替换原版名牌、不接管 TAB，专注头顶视觉展示，支持权限组和单玩家独立配置，免费
- **官方网站**：https://www.spigotmc.org/resources/cyutag.111535/
- **简介**：国产优质插件（作者 HansOffice），专注于玩家头顶名牌上方的多行信息展示。支持静态渐变、流动渐变、动态彩虹、呼吸变色、文字帧动画及浮动/缩放关键帧动画。可按照权限组为不同玩家显示不同内容，也支持单玩家独立配置。完全免费，交流群：331910315。

## 📊 数据统计与分析

### Plan (Player Analytics)

- **定位**：服务器级数据分析平台
- **核心功能**：自动采集玩家活动（登录/登出/在线时长/会话）、服务器性能（TPS/CPU/内存）、地理分布、留存率等，内置 Web 服务器生成可视化仪表盘
- **平台**：Spigot / Paper / Sponge / BungeeCord / Velocity / Folia / Fabric
- **版本**：1.7.x ~ 最新版，全版本通用（当前最新版本 5.6 build 2965）
- **特点**：功能最全面的数据分析工具，支持跨服数据聚合，SQLite/MySQL 双存储
- **Modrinth 下载**：https://modrinth.com/plugin/plan
- **SpigotMC 下载**：https://www.spigotmc.org/resources/player-analytics-plan.32536/
- **GitHub**：https://github.com/Rsl1122/Plan-PlayerAnalytics
- **简介**：最强大的 Minecraft 服务器玩家行为分析工具，内置 Web 服务器自动生成可视化仪表盘，可展示在线活动、玩家基数变化趋势、留存率、地理分布等深度数据。支持 Paper、Spigot、Sponge、BungeeCord、Velocity 等多平台，运行在 4000+ 服务器上，SpigotMC 累计下载 93,900+，评分 4.8/5。支持多服务器数据聚合，适合中大型服务器网络。

### PlayerLeaderBoards

- **定位**：全息排行榜插件
- **核心功能**：在服务器世界中生成全息投影排行榜，实时展示击杀数、在线时长、聊天次数等排名
- **平台**：Paper 1.20+
- **版本**：1.20+（当前最新版本 1.3-2）
- **特点**：无需外部依赖，放入插件文件夹即可自动开始追踪，适合生存服/竞技服
- **官方网站**：https://www.spigotmc.org/resources/playerleaderboards.111111/
- **简介**：轻量级全息排行榜插件，可在游戏世界中以全息投影形式展示实时排名，支持自定义排名维度（击杀、死亡、在线时长、聊天次数等）。无需额外依赖，自动追踪数据，适合生存服和竞技服快速部署。

## 👤 玩家个人资料与统计 GUI

### BetterStats

- **定位**：轻量级统计 GUI 插件
- **核心功能**：通过 `/stats` 命令查看玩家统计（余额、击杀、死亡、在线时长、挖掘等），支持 PlaceholderAPI 和 Vault
- **平台**：Spigot / Paper
- **版本**1.21.8以下
- **特点**：完全免费，配置简洁，适合中小型服务器快速部署
- **官方网站**：https://modrinth.com/plugin/betterstats
- **简介**：由 Gerhart 开发的免费统计插件，提供美观的 GUI 界面展示玩家统计数据。支持查看自身或其他玩家的统计信息，兼容 PlaceholderAPI、Vault 和 EssentialsX。设计简洁现代，适合生存、RPG、SMP 等多种服务器类型，完全免费且质量堪比付费插件。

### Player Info

- **定位**：玩家登录信息 GUI
- **核心功能**：以 GUI 界面展示玩家首次登录、最后登录、登录次数、总在线时长、是否被封禁等信息，支持自定义描述和备注
- **平台**：Spigot / Bukkit
- **版本**：1.8 ~ 1.17
- **特点**：侧重登录行为追踪，适合管理员审核玩家活跃度
- **官方网站**：建议在 SpigotMC 搜索 "Player Info" 查找对应资源（该插件较老，页面可能已变更）
- **简介**：以 GUI 形式展示玩家的登录行为信息，包括首次/最后登录时间、登录次数、总在线时长、封禁状态等，便于管理员审核玩家活跃度。由于插件版本较老，建议在 SpigotMC 官网搜索确认最新版本和下载链接。

## 🔧 管理员深度监控

### Watcher

- **定位**：深度玩家分析与行为画像插件
- **核心功能**：54 槽 GUI 深度资料面板（基础信息、血量、坐标、物理运动、实时状态、游戏模式、经验、在线时长），实时背包窥视（45 槽只读），敏感客户端数据（IP/Ping/语言/视距/主机名），AI 行为分析器（追踪方块破坏、战斗模式、聊天速度，异常标记"可疑度"）
- **平台**：Spigot
- **版本**：1.21
- **特点**：功能极其强大，侧重安全监控与反作弊辅助，适合需要深度运维的服务器
- **官方网站**：https://www.spigotmc.org/resources/watcher.112233/
- **简介**：专为 Spigot 1.21 打造的高级玩家分析插件，提供 54 槽 GUI 深度资料面板，可查看玩家所有可获取的详细信息。内置实时背包窥视功能（45 槽只读），支持敏感客户端数据查看（IP、Ping、语言、视距等，需 watcher.sensitive 权限）。AI 行为分析器自动追踪方块破坏、战斗模式和聊天速度，对异常行为标记"可疑度"，是安全监控与反作弊辅助的强力工具。

### InfoPlayer

- **定位**：管理员快速查看玩家信息
- **核心功能**：查看 UUID、IP地址与端口、是否OP、飞行状态、血量、手持物品、经验等级、游戏模式、位置与距离
- **平台**：Spigot / Bukkit
- **版本**：1.8 ~ 1.9
- **特点**：纯管理工具，功能直接，适合运维排查
- **官方网站**：https://www.spigotmc.org/resources/infoplayer.41040/
- **简介**：经典的管理员指令工具，通过 `/infoplayer <用户名>` 快速查看玩家的 UUID、IP 地址与端口、OP 状态、飞行状态、血量、手持物品、经验等级、游戏模式、位置与距离等基本信息。插件小巧轻便，适合快速排查问题。注意该插件版本较老，仅支持 1.8~1.9 版本。

## 🌐 外部集成与地图展示

### External Server Ping

- **定位**：外部服务器状态查询
- **核心功能**：Ping 任意 MC 服务器，获取在线人数、最大人数、服务器状态、MOTD，通过 PlaceholderAPI 集成到记分板/TAB/聊天
- **平台**：Paper / Purpur / Spigot（1.21+）
- **版本**：1.21+
- **特点**：轻量级，适合跨服网络展示其他子服状态
- **官方网站**：https://modrinth.com/plugin/external-server-ping
- **简介**：轻量级插件，允许服务器通过 PlaceholderAPI 查询任意外部 Minecraft 服务器的在线状态和玩家数量。提供 `%externalserver_online%`、`%externalserver_max%`、`%externalserver_status%`、`%externalserver_motd%` 等占位符，可集成到记分板、TAB 列表、聊天或 Discord 机器人中。完全免费开源，采用 CC BY 4.0 协议。

### BlueMap

- **定位**：3D 网页地图
- **核心功能**：生成服务器世界的 3D 网页地图，支持实时更新，可选玩家定位功能（显示在线玩家位置和头像）
- **平台**：Spigot / Paper / Forge / Fabric
- **版本**：多版本支持
- **特点**：通过浏览器即可查看世界和玩家位置，适合大型生存服/城镇服
- **官方网站**：https://bluemap.bluecolored.de/
- **GitHub**：https://github.com/BlueMap-Minecraft/BlueMap
- **简介**：强大的 Minecraft 地图可视化工具，将服务器世界生成为精美的 3D 网页地图，可通过浏览器实时查看。支持自定义 POI（兴趣点）标记、动态数据展示和实时玩家定位（显示玩家位置、朝向和头像）。适用于 Spigot、Paper、Forge、Fabric 等多平台，是大型生存服和城镇服的理想选择。

## 💡 插件服推荐组合

- **日常运营标配**：TAB + Plan + BetterStats（玩家端展示 + 后台分析 + 玩家自查统计）
- **增强视觉效果**：加 CyuTag 做头顶称号/等级展示 + PlayerLeaderBoards 做全息排行榜
- **安全运维加强**：加 Watcher 做深度行为监控，替代老版的 InfoPlayer
- **跨服网络**：加 External Server Ping 展示子服状态 + BlueMap 做 3D 网页地图
