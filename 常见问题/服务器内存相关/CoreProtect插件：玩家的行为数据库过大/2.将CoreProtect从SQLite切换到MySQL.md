将 CoreProtect 从 SQLite 切换到 MySQL 主要分为四步：**创建数据库、修改配置、迁移数据、验证清理**。

> **请注意**：数据库迁移涉及数据安全，操作前**请务必备份**你的整个服务器文件，特别是 `plugins/CoreProtect/database.db` 文件。

### 📝 第一步：创建 MySQL 数据库和用户

首先，你需要为 CoreProtect 创建一个专用的数据库和用户。

1.  **登录 MySQL**：使用 root 用户登录到你的 MySQL 服务器。

    ```bash
    mysql -u root -p
    ```

2.  **创建数据库**：执行以下命令创建一个数据库（数据库名可自定义，例如 `coreprotect`）。

    ```sql
    CREATE DATABASE coreprotect CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
    ```

3.  **创建用户并授权**：创建一个专用用户，并赋予其对 `coreprotect` 数据库的全部权限。请务必将 `'strong_password_here'` 替换为一个强密码。

    ```sql
    CREATE USER 'coreprotect'@'localhost' IDENTIFIED BY 'strong_password_here';
    GRANT ALL PRIVILEGES ON coreprotect.* TO 'coreprotect'@'localhost';
    FLUSH PRIVILEGES;
    ```

    - **注意**：如果你的 Minecraft 服务器和 MySQL 数据库不在同一台机器上，需要将 `'localhost'` 替换为 Minecraft 服务器的 IP 地址。

### ⚙️ 第二步：修改 CoreProtect 配置文件

接下来，需要修改 CoreProtect 的配置文件，让它知道要去连接 MySQL。

1.  **停止服务器**：在修改任何配置文件前，**请务必先停止你的 Minecraft 服务器**。
2.  **编辑配置文件**：用文本编辑器打开 `plugins/CoreProtect/config.yml` 文件。
3.  **修改数据库设置**：将配置修改为如下所示，填入你刚才创建的数据库信息。
    ```yaml
    # 数据库类型: 设置为 true 以使用 MySQL
    use-mysql: true
    # 表前缀: 如果多个插件共用数据库，用于区分，保持默认即可
    table-prefix: co_
    # MySQL 连接信息
    mysql-host: localhost
    mysql-port: 3306
    mysql-database: coreprotect
    mysql-username: coreprotect
    mysql-password: strong_password_here
    ```

### 🚚 第三步：迁移现有数据（关键步骤）

配置文件修改好后，需要将原有 SQLite 数据库（`database.db`）中的数据迁移到新的 MySQL 数据库中。根据你的 CoreProtect 版本，有两种方法：

#### 方法一：使用插件内置命令（推荐，仅限 Patreon 版本）

此方法最为简单和安全，但**仅限 CoreProtect 23.0+ 的 Patreon 版本**使用。

1.  **启动服务器**：确保服务器已启动并加载了 CoreProtect。
2.  **在控制台执行命令**：在服务器**控制台**（不是游戏内聊天框）中输入以下命令：
    ```bash
    co migrate-db mysql
    ```
3.  **等待完成**：迁移过程可能需要一些时间，请不要中断服务器。完成后，CoreProtect 会自动开始使用新的 MySQL 数据库。

#### 方法二：使用第三方工具手动迁移（适用于所有版本）

如果你的 CoreProtect 不是 Patreon 版本，可以使用此方法。

1.  **导出 SQLite 数据**：在服务器命令行中，导航到服务器根目录，执行以下命令将数据导出为 SQL 文件。

    ```bash
    sqlite3 plugins/CoreProtect/database.db .dump > coreprotect_dump.sql
    ```

2.  **清理导出的 SQL 文件**：SQLite 和 MySQL 的语法有细微差别，需要对导出的文件进行清理，使其兼容 MySQL。

    ```bash
    # 替换自增主键语法
    sed -i 's/INTEGER PRIMARY KEY AUTOINCREMENT/INT AUTO_INCREMENT PRIMARY KEY/g' coreprotect_dump.sql
    # 删除 SQLite 特有的 PRAGMA 命令
    sed -i 's/PRAGMA.*;//g' coreprotect_dump.sql
    # 删除事务相关的命令
    sed -i '/^BEGIN TRANSACTION/d; /^COMMIT/d' coreprotect_dump.sql
    ```

3.  **导入到 MySQL**：将清理好的 SQL 文件导入到新创建的 MySQL 数据库中。
    ```bash
    mysql -u coreprotect -p coreprotect < coreprotect_dump.sql
    ```
    执行后，系统会提示你输入之前设置的 MySQL 用户密码。

### ✅ 第四步：验证与清理

1.  **启动服务器**：完成以上步骤后，启动你的 Minecraft 服务器。
2.  **验证数据**：进入游戏，使用 `/co lookup` 等命令查询一下历史记录，确认旧数据是否完整，新数据是否在正常记录。
3.  **清理旧文件（可选）**：确认一切正常后，为了释放硬盘空间，可以安全地删除旧的 SQLite 数据库文件 `plugins/CoreProtect/database.db`。

### 💎 总结与注意事项

- **性能提升**：对于中型及以上服务器，切换到 MySQL 能显著提升 CoreProtect 的查询和回滚速度。
- **操作不可逆**：迁移操作具有一定风险，**请务必提前备份**。
- **耐心等待**：如果你的 `database.db` 文件非常大（例如几十GB），迁移过程（尤其是方法二）可能会非常漫长，请预留足够的时间并保持服务器稳定。
- **Patreon 版本优势**：如果条件允许，使用 Patreon 版本并利用其内置的 `/co migrate-db` 命令是最省心、最安全的选择。
