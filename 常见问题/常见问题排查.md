# 附录 B: 常见问题排查

## Q1: 基岩版玩家无法连接？

1. 检查 UDP 端口 19132 是否在防火墙中放行
2. 检查 `Geyser-Spigot/config.yml` 中 `bedrock.port` 和 `clone-remote-port`
3. 确保 `plugins/floodgate/key.pem` 存在且与 Geyser 的 `floodgate-key-file` 指向一致
4. 重启服务器后尝试

## Q2: QQ 机器人消息无法同步？

**同机部署：**

1. 确认 EasyBot 主程序正在运行
2. 检查 WebSocket 连接地址 `ws://127.0.0.1:26990/bridge`
3. 核对 `token` 是否与主程序一致

**跨机部署（EasyBot 与 MC 服务器在不同电脑）：**

1. 确认 EasyBot 主程序（电脑 A）已启动，Bridge 端口就绪
2. 检查 `config.yml` 中 `service.url` 是否已改为电脑 A 的 IP（不是 `127.0.0.1`）
3. 从电脑 B ping 电脑 A 的 IP，确认网络可达
4. 检查电脑 A 的防火墙是否放行 **TCP 26990** 端口
5. 如果是公网，检查路由器端口映射是否正确
6. 核对两边的 Token 是否一致
7. 在 MC 服务器执行 `/ebot reload` 尝试重连

## Q3: 服务器卡顿？

1. 运行 `/spark profiler start --timeout 300` 进行 5 分钟分析
2. 运行 `/spark health` 查看健康报告
3. 检查 `view-distance` 和 `simulation-distance` 是否过高
4. 检查 Java 内存分配是否充足（当前 4GB）

## Q4: CoreProtect 数据文件过大？

1. 定期执行 `/co purge t:30d` 清理 30 天前数据
2. 考虑迁移到 MySQL 存储
