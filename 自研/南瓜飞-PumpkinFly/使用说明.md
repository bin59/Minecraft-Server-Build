# 南瓜飞 PumpkinFly 使用说明

按飞行时长扣秒的付费飞行插件。玩家用南瓜币买**永久飞行**或**限时飞行**，也能领取按天 / 小时 / 分钟设置的**限时体验奖励**；管理员可做**全服或单人**的飞行管理（总开关、全服免费飞行、全服体验、单人发放与禁用）。飞行权限由插件直接控制 `setAllowFlight`，不依赖 `essentials.fly` 权限；区域由 Residence 领地归属与主城白名单决定，离开允许区域会自动安全落地。

---

## 一、它解决什么问题

| 需求                    | 纯配置方案的问题                                                                                         | PumpkinFly 的做法                                                                           |
| ----------------------- | -------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------- |
| 10 万买永久飞行         | 商店执行 `lp ... permission set essentials.fly true` 后是**全局**可飞，野外照样飞                        | 永久标记只免扣时，**仍受区域规则限制**                                                      |
| 1 分钟 100 南瓜币        | `settemp essentials.fly true 1m` 按现实时间走，站着/离线也扣；到期只撤权限，人从半空掉下去               | 默认 `FLYING_ONLY`，**只有 `isFlying()` 为真才扣秒**；到期向下找落脚点 + 免摔保护           |
| 只在自己领地 + 主城能飞 | Residence 的 `fly` / `nofly` flag 没有「允许区域列表」概念，`FlyLandLocation` 是固定坐标会把人传回出生点 | 每秒按 `getByLoc()` 判定归属；`OWN_AND_MAIN` 默认自己领地 + `zhucheng`，另有 3 种可切换模式 |
| 数据可查                | 权限临时节点无历史                                                                                       | 四份本地 YAML 保存余额、体验、购买记录、每次起飞/落地时间与全局状态                        |
| 几天/几小时的体验奖励   | 临时权限按现实时间走、离线也扣，续费会覆盖到期时间，且无法「体验期不扣余额」                           | `trial-expire-at` 独立时间戳：体验期内不扣余额、到期自动恢复个人凭证；可配进服赠送 / 菜单领取 / 全服活动 |
| 全服或单人管理          | 改权限组影响所有人，单独改一个玩家要手动拼命令                                                           | `/pfly global` 管全服、`/pfly player` 管单人；QuickMenu 管理子菜单点选玩家即可执行       |

**开飞本身不需要命令**：插件判定通过后自动 `setAllowFlight(true)`，玩家双击空格即可起飞。命令只用于购买、领奖、开关、查询与管理。

## 二、部署

1. 停服，把 `PumpkinFly-1.0.0.jar` 放入 `plugins/`，**完整重启**，不要用 `/reload`。
2. 前提：`server.properties` 的 `allow-flight=true`；已装 `Vault` + 经济提供器（EssentialsX）；区域判定依赖 `Residence`。
3. 首次启动会生成 `plugins/PumpkinFly/config.yml` 和 `plugins/PumpkinFly/data/`（含 `players.yml` / `purchases.yml` / `sessions.yml` / `global.yml`）。
4. QuickMenu 配置已按服务器实跑版本更新（含按钮与管理子菜单），部署方式见第六节。
5. 验证：`/pfly status` 显示凭证与区域；`/pfly claim` 能领到体验；买 1 分钟后飞出领地，应在 1 秒内落地且不扣血。

> 替换 jar **不会覆盖**已有的 `config.yml`（Bukkit `saveDefaultConfig()` 行为）。新增配置键在代码里都有默认值，不改配置文件也能跑；但**缺 `messages` 新键时相关命令会回显 `[缺少消息: xxx]`**，所以升级必须手动同步配置。
> 2026-11-10 已把服务器实跑 `config.yml` 与项目源码配置对齐：业务参数逐键比对 0 差异，仅补齐 `global` / `rewards` / `display` 三段、29 条消息键与 6 条旧版提示文案（6687 → 12278 字节）。从更旧备份还原配置时，请重新执行同样的合并。
> ⚠️ 不打算开放领取的话，把 `rewards.claim-trial` 设为 `''`（留空）；旧配置缺 `rewards` 段时代码默认会启用「每人领取一次 30 分钟体验」。

插件元数据：`api-version: '26.3'`，class major 65（Java 21），13 个源文件 / 17 个 class，jar 63881 字节（r6）。

## 三、命令与权限

主命令 `/pfly`，别名 `/pumpkinfly`、`/pf`。

**时长格式**（购买、发放、体验统一管理）：`30m` / `2h` / `3d` / `45s` / `1d2h30m` / `1天2小时30分`；纯数字沿用旧口径按**分钟**（`/pfly buy 5` 仍是 5 分钟）。单次发放上限为 `rewards.max-trial-days`（默认 30 天）；付费购买受 `prices.max-minutes-per-buy` 约束——**普通玩家单次最多 120 分钟（2 小时），管理员（`pumpkinfly.admin`）不受此限，可随意购买任意时长**。

### 3.1 玩家命令

| 命令                                  | 说明                                                                 | 权限                                            |
| ------------------------------------- | -------------------------------------------------------------------- | ----------------------------------------------- |
| `/pfly buy <时长\|perm>`              | 购买时长或永久，时长累加到余额；`perm` 一次买断                     | `pumpkinfly.buy`                                |
| `/pfly claim`                         | 领取限时体验奖励（时长与领取模式由 `rewards` 配置）                 | `pumpkinfly.use`                                |
| `/pfly on` / `off` / `toggle`         | 手动开关飞行能力（不消耗余额）                                       | `pumpkinfly.use`                                |
| `/pfly hud [on\|off\|toggle]`         | 开关自己的飞行界面显示（不影响飞行能力）                             | `pumpkinfly.use`                                |
| `/pfly status [玩家]`                 | 凭证来源、体验/余额剩余、累计与本次已飞、区域、全局状态、飞行状态等 | `pumpkinfly.use` / `pumpkinfly.admin`（查他人） |
| `/pfly records [玩家] [buy\|session]` | 最近 10 条购买 / 发放记录或飞行会话记录                              | `pumpkinfly.records`                            |
| `/pfly help`                          | 命令提示                                                             | —                                               |

### 3.2 管理员命令

| 命令                                                                              | 说明                                                                                   | 权限              |
| --------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------- | ----------------- |
| `/pfly trial <玩家\|online\|all> <时长\|clear\|status>`                            | 发放限时体验：`online` 全体在线、`all` 所有已有账户（含离线）；`clear` 清除、`status` 查询 | `pumpkinfly.admin` |
| `/pfly global <on\|off\|toggle\|status>`                                           | 全服总开关；`off` 时所有人立即安全落地且无法起飞                                      | `pumpkinfly.admin` |
| `/pfly global free <on\|off\|toggle>`                                              | 全服免费飞行（无需凭证，仍受区域规则限制）                                             | `pumpkinfly.admin` |
| `/pfly global trial <时长\|clear>`                                                 | 全服限时体验，**含之后才上线的玩家**，无需逐个发放                                    | `pumpkinfly.admin` |
| `/pfly player <玩家> <status\|on\|off\|ban\|unban\|trial <时长>\|cleartrial\|give\|take\|setperm>` | 单人管理：查状态、开关、封禁/解禁、发/清体验、给/扣时长、设永久标记 | `pumpkinfly.admin` |
| `/pfly give <玩家> <时长\|perm>` / `take <玩家> <时长>` / `setperm <玩家> <true\|false>` | 旧管理命令，保留兼容；`give/take` 同样支持 `d/h/m` 格式，改的是**余额**不是体验 | `pumpkinfly.admin` |
| `/pfly reload`                                                                    | 重载配置并重建定时任务（不会重置 `data/global.yml` 里的运行时状态）                 | `pumpkinfly.admin` |

权限默认值：`pumpkinfly.use` / `pumpkinfly.buy` / `pumpkinfly.records` 为 `true`（全体玩家），`pumpkinfly.admin` / `pumpkinfly.bypass` 为 `op`。`pumpkinfly.bypass` 会**完全跳过**区域、余额与 Essentials 门禁判断，仅用于管理员调试；QuickMenu 的管理按钮都用 `pumpkinfly.admin` 控制显示。

常用示例：

```
/pfly buy 5                # 5 分钟 = 500 南瓜币
/pfly buy 2h               # 120 分钟 = 12000 南瓜币（玩家单次上限，正好 2 小时）
# 管理员不受 2 小时上限：/pfly buy 10h 也能成功
/pfly claim                # 领取一次 30 分钟体验（默认 ONCE）
/pfly status
/pfly trial Steve 1d2h30m  # 给某人 1 天 2 小时 30 分体验
/pfly trial online 2h      # 给全体在线 2 小时体验
/pfly global trial 1d      # 全服 1 天体验（含之后上线的玩家）
/pfly global status        # 查总开关、免费飞行、全服体验剩余
/pfly global off           # 活动结束：全部安全落地
/pfly player Steve ban     # 单独禁用某人飞行（不论凭证）
/pfly player Steve unban
lp user <玩家> permission set pumpkinfly.admin true
```

## 四、价格与计时

```yaml
prices:
  permanent: 100000 # 永久价格
  per-minute: 100 # 每分钟价格（2026-11-10 起：1 分钟 = 100 南瓜币）
  max-minutes-per-buy: 120 # 单次上限（分钟）= 2 小时，防误输入；仅普通玩家受限
  # 管理员（pumpkinfly.admin）不受 max-minutes-per-buy 与 max-balance-minutes 约束，可随意购买
  max-balance-minutes: 10080 # 余额上限（7 天），普通玩家受限，管理员免限
  allow-duplicate-permanent: false

timing:
  mode: FLYING_ONLY # 默认：仅飞行中扣秒
  tick-seconds: 1
  warn-seconds: [60, 30, 10] # 剩余秒数提醒
  track-permanent-sessions: true
```

| `timing.mode`             | 扣秒口径                                              | 站着 / 跑步 / 离线 |
| ------------------------- | ----------------------------------------------------- | ------------------ |
| `FLYING_ONLY`（本服采用） | 每秒 tick 检查 `isFlying()`，为真才 -1 秒             | **不扣**           |
| `REAL_TIME`               | 购买时设 `expire-at = now + 分钟数`，按现实时间倒计时 | **照扣**           |

`REAL_TIME` 下继续购买是**叠加到期时间**，不会覆盖；`FLYING_ONLY` 下继续购买是叠加秒数余额。永久飞行不消耗时长，但仍需满足区域条件。

### 4.1 已飞时长怎么算

「已飞时长」与「余额扣不扣」是两套独立统计，`/pfly status` 与界面显示都按这张表取值：

| 字段                           | 含义                                                        | 何时变化                                                                 |
| ------------------------------ | ----------------------------------------------------------- | ------------------------------------------------------------------------ |
| `remaining-seconds`            | 剩余可飞秒数                                                | 仅「余额凭证 + `FLYING_ONLY`」在 `isFlying()` 为真时每秒 -1；限时体验 / 全服体验 / 全服免费 / 永久期间都不扣 |
| `total-used-seconds`           | 累计已飞（status 的「已飞」、界面 `{total}`）               | **只要真正在飞就累加**，永久飞行、`REAL_TIME` 同样累计                    |
| `used-seconds`                 | 本次起飞到落地（status 的「本次已飞」、界面 `{session}`）   | 会话内累加；落地/关飞写盘后清零                                          |

会话在**主动落地时也会写盘**，所以 `sessions.yml` 与 `/pfly records session` 能看到每一次起飞的时间、秒数与结束原因。旧存档里 `total-used-seconds: 0` 是历史值，不会补记，从修复后的第一次飞行开始累计。

### 4.2 飞行界面显示（HUD）

不用敲 `/pfly status`：有凭证且在允许区域时，屏幕上实时显示飞行状态与剩余时长；离开允许区域、关飞、退出会自动清掉。

```yaml
display:
  mode: ACTION_BAR        # ACTION_BAR / BOSS_BAR / BOTH / OFF
  show-when: ENABLED      # ENABLED（含待起飞）/ FLYING（仅真正飞行中）
  update-seconds: 1
  warn-seconds: 60        # 剩余少于此秒数：剩余数字标红、BossBar 变红
  bar-color: GREEN
  bar-style: SOLID
  show-progress-bar: true # 模板里的 {bar} 显示 10 格进度条
  action-bar-flying: '&a&l[飞行中] &8| &7剩余 &e{remaining} &8| &7本次 &e{session} &8| &7累计 &e{total} &8| {bar}'
  action-bar-idle: '&e&l[飞行可用] &8| &7{source} &8| &7剩余 &e{remaining} &8| &7区域 &e{zone} &8| &e双击空格起飞'
  boss-bar-title: '&6南瓜飞 &8| &f{state} &8| &7剩余 &e{remaining} &8| &7本次 &e{session}'
```

| 占位符        | 内容                                                                        |
| ------------- | --------------------------------------------------------------------------- |
| `{remaining}` | 剩余时长；永久显示「永久」、全服免费显示「全服免费」，体验会带「体验 / 全服体验」前缀，临期自动标红 |
| `{session}`   | 本次已飞秒数                                                                |
| `{total}`     | 累计已飞秒数                                                                |
| `{state}`     | `飞行中` / `待起飞`                                                         |
| `{zone}`      | 当前区域标签                                                                |
| `{source}`    | 凭证来源：永久 / 全服免费 / 全服体验 / 限时体验 / 时长余额                  |
| `{bar}`       | 10 格文本进度条（体验按「剩余 / 本次发放总时长」，余额按「剩余 / 累计购买」，永久恒满） |

- `ACTION_BAR` 显示在快捷栏上方；`BOSS_BAR` 是顶部血条，限时飞行会随余额缩短，永久恒满并显示为蓝色。
- `show-when: ENABLED` 会让「已开飞、还没双击空格」的玩家也看到剩余时间；只想飞行中显示就改成 `FLYING`。
- **基岩端（Geyser/Floodgate）自动走原生 BossBar**：r5 起 `FlyDisplay` 检测到基岩玩家会把 ActionBar 自动升级为原生 BossBar（基岩端对 ActionBar 渲染不稳、且 `■` 文本进度条字形缺失），无需手动改配置；若想强制 Java 端也走 BossBar，把 `display.mode` 改成 `BOTH` 或 `BOSS_BAR` 后 `/pfly reload`。
- 玩家自己可用 `/pfly hud off` 关掉，状态存 `players.yml` 的 `hud-enabled`，重启保留；不影响飞行能力。快捷菜单「飞行界面显示」按钮动作已固定为 `[player] pfly hud on`（原 `toggle` 会被误关成 `false`，见第六节），避免玩家点一下把界面关掉。
- 与 TAB、公告类插件的 ActionBar 冲突时改用 `BOSS_BAR`，或设 `display.mode: OFF` 只保留 `/pfly status`。

扣款走 Vault 的 `withdrawPlayer(OfflinePlayer, double)`，南瓜币余额真源仍是 Essentials userdata；MoneyLedger 通过 Essentials `UserBalanceUpdateEvent` **实时**把这笔支出记入流水（1.1.0 起同步落盘，并有 `trade.log` 幂等回填兜底），插件不重复记账。

### 4.3 限时体验奖励（几天 / 几小时 / 几分钟）

「体验」是独立于余额的一张凭证：给玩家一个**现实时间到期时间戳**，有效期内可飞且**不扣时长余额**，到期自动恢复按自己的凭证判定。离线也计时，适合活动奖励、补偿、新手体验。

```yaml
rewards:
  # 首次进服自动赠送；留空 / 0 = 关闭
  join-trial: ''
  join-trial-once: true       # 每个 UUID 只送一次，标记写进 players.yml
  # /pfly claim 与快捷菜单「领取体验奖励」按钮的奖励，留空 / 0 = 关闭
  claim-trial: 30m
  claim-mode: ONCE            # ONCE 每人一次 / DAILY 每天一次 / ALWAYS 每次都发
  max-trial-days: 30          # 单次发放上限（天）
```

时长写法：`30m`、`2h`、`3d`、`45s`、`1d2h30m`、`1天2小时30分`，也可以写纯数字（按分钟，兼容旧命令）。所有发放命令与菜单按钮都用这套格式，菜单按钮改时长只需改按钮里的命令参数，例如 `[player] pfly global trial 7d`。

| 发放方式 | 命令 / 配置 | 作用范围 |
| -------- | ----------- | -------- |
| 进服赠送 | `rewards.join-trial: 2h` | 每个新 UUID 首次进服自动发一次 |
| 玩家自领 | `/pfly claim`、QuickMenu「领取体验奖励」 | 自己，按 `claim-mode` 限制次数 |
| 单人发放 | `/pfly trial Steve 1d2h30m`、`/pfly player Steve trial 1h` | 指定玩家（可离线） |
| 批量发放 | `/pfly trial online 6h`、`/pfly trial all 3d` | 全体在线 / 所有已有账户 |
| 全服活动 | `/pfly global trial 1d` | 所有人，**含之后才上线的玩家**，无需逐个发 |

凭证判定优先级（是否能飞）：

| 顺序 | 判定 | 结果 |
| ---- | ---- | ---- |
| 1 | `global.enabled: false` 或玩家被 `ban` | 一律禁飞并安全落地 |
| 2 | 全服免费飞行 / 全服限时体验生效 | 可飞，不扣余额 |
| 3 | 永久飞行 | 可飞，不扣余额 |
| 4 | 个人限时体验未到期 | 可飞，不扣余额 |
| 5 | 余额 `remaining-seconds > 0` | 可飞，按 `timing.mode` 扣秒 |

界面与 `/pfly status` 的「凭证来源」按 永久 → 全服免费 → 全服体验 → 个人体验 → 时长余额 显示；`{remaining}` 会带上「体验 / 全服体验」前缀，临期同样标红。体验期间 `REAL_TIME` 模式的余额到期时间会冻结，恢复扣费时按剩余余额重算，不会一到期就被清零。

> 多次发体验是**叠加到期时间**（`max(now, 到期) + 时长`），不会互相覆盖；`/pfly trial <玩家> clear` 与 `/pfly global trial clear` 可提前结束。每一笔发放都会写进 `purchases.yml`（`type` 为 `TRIAL` / `TRIAL_ONLINE` / `GLOBAL_TRIAL` / `CLAIM` / `JOIN_TRIAL`）。

### 4.4 全局与单人飞行管理

全局状态由 `/pfly global` 维护，单独存在 `data/global.yml`，**重启不丢**；`config.yml` 里的 `global.enabled` / `global.free-fly` 只在该文件不存在时作初值，`/pfly reload` 不会覆盖管理员的实时操作。

```yaml
# plugins/PumpkinFly/data/global.yml（由命令维护，勿在运行中手改）
enabled: true
free-fly: false
trial-expire-at: 0
trial-total-seconds: 0
trial-granted-by: ''
```

| 场景 | 操作 |
| ---- | ---- |
| 活动/维护期间全服禁飞 | `/pfly global off` → 所有人立即安全落地；结束再 `/pfly global on` |
| 开放全服免费飞行 | `/pfly global free on`（无需凭证，仍受 `zones` 限制） |
| 全服周末体验 | `/pfly global trial 2d`；`status` 可看到期时间 |
| 提前结束活动 | `/pfly global trial clear` |
| 单独禁用某玩家 | `/pfly player Steve ban`（不论其凭证）；`unban` 解除 |
| 单独发体验 / 查状态 | `/pfly player Steve trial 1h`、`/pfly player Steve status` |

单人状态存在 `players.yml`：`banned`（管理员禁用）、`manual-off`（玩家自己 `/pfly off`）、`trial-expire-at`（个人体验）、`permanent`、`remaining-seconds`。管理员查离线玩家也能看到完整账户状态，`/pfly status Steve` 不再要求对方在线。

快捷菜单里的「飞行管理」子菜单把上述全局操作做成按钮，单人管理用 `[player-selector]` 点选在线玩家，见第六节。

## 五、飞行区域（可配置「在哪些地方能飞」）

### 5.1 四种模式

| `zones.mode`           | 允许范围                                                                                    |
| ---------------------- | ------------------------------------------------------------------------------------------- |
| `OWN_AND_MAIN`（默认） | 自己的领地 + `main-residences` 列出的主城领地；可用细分开关再加被信任领地 / 其它领地 / 野外 |
| `ALL_RESIDENCES`       | 任意 Residence 领地内（含他人领地）                                                         |
| `WHITELIST`            | 仅 `residence-whitelist` 列出的领地                                                         |
| `EVERYWHERE`           | 不限制区域（仍需有有效凭证）                                                                |

### 5.2 完整配置项

```yaml
zones:
  mode: OWN_AND_MAIN
  main-residences: [zhucheng] # 本服主城领地实名
  allow-own-residences: true
  allow-trusted-residences: false
  allow-other-residences: false
  allow-wilderness: false
  wilderness-worlds: [] # 单独放行某些世界的野外
  residence-whitelist: []
  residence-blacklist: [] # 对所有模式生效
  world-whitelist: [] # 非空时只允许这些世界
  world-blacklist: [world_nether, world_the_end]
  when-residence-missing: WILDERNESS # Residence 未装时：WILDERNESS / ALLOW / DENY
```

判定顺序：**世界黑名单 → 世界白名单 → Residence `getByLoc()` → 领地黑名单 → 模式匹配 → 野外规则**。领地名比较忽略大小写。属主用 `ClaimedResidence.getOwnerUUID()` 与玩家 UUID 比对；`allow-trusted-residences` 会遍历 `getTrustedPlayers()`。

改配置的三个例子：

```yaml
# ① 主城 + 所有领地 + 主世界野外（最宽松但仍禁止下界/末地）
zones:
  mode: ALL_RESIDENCES
  allow-wilderness: true
  wilderness-worlds: [world]

# ② 只允许主城、活动场、矿区三个指定领地
zones:
  mode: WHITELIST
  residence-whitelist: [zhucheng, huodongchang, kuangqu]

# ③ 买了就能在任何地方飞（只保留余额约束）
zones:
  mode: EVERYWHERE
```

改完 `/pfly reload` 立即生效，不用重启。

## 七、本地数据存储

数据在 `plugins/PumpkinFly/data/`，四个文件各司其职，避免状态文件被历史记录撑大：

| 文件            | 内容                                                                                                      |
| --------------- | --------------------------------------------------------------------------------------------------------- |
| `players.yml`   | 账户真源：永久标记、余额、体验到期、领取/进服赠送标记、管理员禁用、累计购买/已飞、手动关闭、界面显示开关 |
| `purchases.yml` | 每一笔购买 / 管理员发放 / 体验发放 / 扣除的时间、类型、金额、到期时间、操作者                            |
| `sessions.yml`  | 每次起飞时间、结束时间、飞行秒数、结束原因、起始区域与世界坐标                                            |
| `global.yml`    | 全服总开关、全服免费飞行、全服体验到期时间（`global.enabled` 与 `global.free-fly` 的运行时真源）         |

`players.yml` 示例：

```yaml
version: 1
players:
  00000000-0000-0000-0009-01f66567385a:
    name: '.PumpkinVeget'
    permanent: false
    remaining-seconds: 300
    total-purchased-seconds: 600
    total-used-seconds: 300
    expire-at: 0
    manual-off: false
    hud-enabled: true
    trial-expire-at: 1794153600000     # 体验到期（毫秒），0 = 无
    trial-total-seconds: 7200          # 本次体验总时长，HUD 进度条用
    trial-granted-at: '2026-11-09 20:00:00'
    trial-granted-by: 'Console'
    claim-date: '2026-11-09'           # ONCE 只看是否为空；DAILY 按日期比对
    join-trial-given: false
    banned: false
    first-purchase: '2026-11-09 14:30:00'
    last-active: '2026-11-09 14:36:12'
```

购买记录字段：`time` / `uuid` / `name` / `type` / `minutes` / `cost` / `balance-before` / `balance-after` / `remaining-after` / `operator` / `detail`；体验类记录额外带 `seconds` / `expire-at`，全服记录的 `uuid` 为 `ALL`。
`type` 取值：`TIME`（付费买时长）、`PERMANENT`、`GIVE` / `GIVE_PERM`（管理员发放余额/永久）、`TAKE`、`SETPERM`，以及新增的 `TRIAL` / `TRIAL_ONLINE`（单人/批量体验）、`GLOBAL_TRIAL` / `GLOBAL_TRIAL_CLEAR`、`TRIAL_CLEAR`、`CLAIM`（菜单自领）、`JOIN_TRIAL`（进服赠送）。

会话记录字段：`start` / `end` / `used-seconds` / `end-reason` / `start-zone` / `start-world` / `start-xyz`。**主动落地即写盘**，双击空格短暂起飞再落地也会留下一条；`timing.track-permanent-sessions: false` 时永久飞行只累计 `total-used-seconds`、不产生会话记录。
`end-reason` 取值：`离开允许区域`、`时长用完`、`手动关闭`、`退出游戏`、`主动落地`、`切换世界`、`切换游戏模式`、`凭证失效`、`全服飞行关闭`、`管理员禁用`、`体验到期`、`插件重载`、`未起飞`。

落盘策略：购买、领奖、管理员操作、玩家退出、关服**立即写**；批量发放内部只标脏、循环结束统一写一次，不会每人写一遍全量 YAML。此外每 `storage.save-interval-seconds`（默认 60 秒）定时写一次。每个记录文件最多保留 `storage.max-records-per-file`（默认 5000）条，超出裁剪最旧的，`record-purchases` / `record-sessions` 可分别关掉。

> 别在服务器运行时手改这四个文件，会被内存里的状态覆盖。先停服再改。旧 `players.yml` 缺新字段时按默认值载入（体验为空、`banned: false`），不影响已有余额。

## 八、与其它插件的协作

| 插件                | 关系                                                                    | 注意                                                                                                                       |
| ------------------- | ----------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| Vault + EssentialsX | `depend: [Vault]`，扣款走 Economy 提供器                                | 没找到提供器时购买功能不可用，插件仍会启动                                                                                 |
| Residence           | `softdepend`，用 `ResidenceApi.getResidenceManager().getByLoc()` 判区域 | 未装时按 `when-residence-missing` 处理                                                                                     |
| Essentials          | `softdepend`，监听 `FlyStatusChangeEvent`                               | 拦截 `/fly`、`/efly`、`/essentials:fly`、控制台 `/fly <玩家>` 绕过区域限制；`integration.block-essentials-fly: false` 可关 |
| QuickMenu           | `softdepend`，按钮走 `[player] pfly ...`                                | 见第六节                                                                                                                   |
| MoneyLedger         | 无直接依赖                                                              | 余额变动事件实时记录（1.1.0 同步落盘 + `trade.log` 回填）                                                                    |

**关于 Residence 的 fly / nofly flag**（查 6.0.4.2 字节码确认）：

- 本服 `flags.yml` 默认 `fly: false`、`nofly: false`，此时 Residence **不会主动开关玩家飞行**，插件可全权控制。
- **不要把 `fly` 默认改成 `true`**：Residence 会在进入领地时给所有人 `setAllowFlight(true)`，等于绕过付费；插件每秒 tick 会纠正，但会明显抖动。
- 若某个领地被手动设了 `nofly: true`，Residence 会 `setFlying(false)` + `setAllowFlight(false)` 并把玩家传送到落脚点。解决：取消该领地的 `nofly` flag，或给默认组加 `residence.bypass_fly`、`residence.bypass_nofly`。
- Residence 的 `fly()` 内部对持有 `essentials.fly` / `cmi.command.fly` 的玩家直接跳过干预。**不要**把 `essentials.fly` 当作本插件的「购买凭证」发给玩家。

**关于 Essentials 的自动飞行**：`send-fly-enable-on-join`、`world-change-fly-reset` 若为 true，会在进服/换世界时抢写飞行状态。插件启动时检测到会打一条 WARNING，每秒 tick 会纠正，但建议在 Essentials 的 `config.yml` 里关掉。

## 九、安全与边界

- **离开区域 / 时长归零**：`safe-land: true` 时从玩家当前位置向下最多 `search-depth`（32）格找实心方块，要求头顶两格可通行，找到后传送到该方块上方；同时 `setFallDistance(0)` 并在 `no-fall-damage-seconds`（5 秒）内免疫摔落伤害。找不到落脚点时仍有免摔保护。
- **创造 / 旁观模式**：完全跳过，不干预原版飞行。
- **切换世界 / 游戏模式**：结束当前会话并立即重新判定（可分别用 `disable-on-world-change`、`disable-on-gamemode-change` 关闭）。
- **移动判定**：`PlayerMoveEvent` 跨方块时提前判定（250ms 节流），主循环每秒兜底，不会等满 1 秒才落地。
- **基岩端**：Geyser/Floodgate 玩家同样走 `setAllowFlight`，双击跳跃起飞；UUID 用玩家实际 UUID，与领地属主比对逻辑一致。
- **全局总开关 / 单人禁用**：`global.enabled: false` 或 `banned: true` 优先级高于一切凭证，`/pfly global off` 会遍历在线玩家先停飞、再找落脚点、最后关 `allowFlight`，同样带 5 秒免摔保护。
- **体验到期**：按现实时间判定，主循环每秒检查；到期只清体验标记，若还有余额会自动接着用，无凭证则安全落地。`REAL_TIME` 模式下会按剩余余额重算 `expire-at`，不会一次性扣光。
- **批量发放**：`trial all/online` 循环内不重复全量写盘，循环结束统一 `save()`，避免账户多时卡主线程。

## 十、常见问题

| 现象                     | 原因 / 处理                                                                                                                           |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------- |
| 买了时长但双击空格没反应 | `/pfly status` 看「当前区域」是不是允许区域；没凭证或不在允许区域时 `allowFlight` 会被关掉                                            |
| 一进领地就被强制落地     | 该领地设了 `nofly: true`，见第八节；也可能是 Essentials 自动飞行配置抢写                                                              |
| 每秒都在抖（开了又关）   | 检查 `send-fly-enable-on-join` / `world-change-fly-reset`；或有人给玩家发了 `essentials.fly` 后 Residence/Essentials 反复改写         |
| 玩家用 `/fly` 绕过       | 确认 Essentials 已启用且 `integration.block-essentials-fly: true`；`/essentials:fly` 命名空间命令同样会被 `FlyStatusChangeEvent` 拦下 |
| 站着不动余额也在掉       | `timing.mode` 被改成了 `REAL_TIME`，改回 `FLYING_ONLY` 后 `/pfly reload`                                                              |
| 已飞时长一直是 0 秒      | 旧逻辑只在「限时 + `FLYING_ONLY`」累计，永久 / `REAL_TIME` 不累加、落地也不写会话；现按 4.1 全模式累计，**旧值不补记**            |
| 屏幕上看不到飞行状态     | `/pfly status` 看「界面显示」是否被 `/pfly hud off` 关掉，`/pfly hud on` 打开；基岩端把 `display.mode` 改成 `BOTH` / `BOSS_BAR` |
| 扣款成功但没到账         | 看 `purchases.yml` 有没有记录；有记录说明到账，用 `/pfly status` 复核；没有记录查 Vault 提供器与经济日志                              |
| 提示「这个奖励已经领过了」 | `rewards.claim-mode: ONCE` 每位玩家只领一次（记在 `claim-date`）；改 `DAILY` 每天一次、`ALWAYS` 每次都发，或管理员直接 `/pfly trial <玩家> 1h` |
| 体验期间余额一直不减     | 设计如此：体验凭证有效期内不扣余额，到期后才恢复按余额扣秒；HUD 的 `{remaining}` 会带「体验」前缀区分                        |
| 全服体验结束后还有人在飞 | 主循环每秒会重新判定并安全落地；要立即结束用 `/pfly global trial clear`，要全部禁飞用 `/pfly global off`                       |
| 玩家被 ban 后怎么恢复     | `/pfly player <玩家> unban`（或管理菜单「解除指定玩家禁用」）；`/pfly status <玩家>` 可查离线账户的禁用标记                   |
| 飞行管理按钮不显示       | 需要 `pumpkinfly.admin` 权限；服务器 `plugins/QuickMenu/config.yml` 还是旧配置时也要按第六节合并新菜单段                       |
| 按钮不显示               | 权限节点没生效或服务器 `plugins/QuickMenu/config.yml` 还是旧配置，见第六节部署注意                                                    |
| 服重启后玩家要重新买     | 数据是本地 YAML，重启不丢；若真丢了，检查 `plugins/PumpkinFly/data/players.yml` 是否被外部清理                                        |
| 提示「经济系统未就绪」   | Vault 装了但没有 Economy 提供器，检查 EssentialsX 是否启用、是否禁用了经济模块                                                        |
