# 离线奖励 OfflineReward（自研插件）

> **定位**：按玩家**离线时长**计奖，下次上线把南瓜币写进**南瓜邮箱（PumpkinMail）**，玩家 `/mailbox` 领取。
> 复用现有南瓜邮箱与 Vault（南瓜币）体系，**零新增外部依赖**，纯后端、高性能、低占用。
> 适用：Leaf / Paper 1.21.11。

## 一、原理（30 秒看懂）

```
玩家退出 ──▶ 记录 last_logout 时间戳（offline.db / SQLite）
玩家上线 ──▶ 离线时长 = 现在 − last_logout
        ──▶ 奖励 = 离线小时 × coins-per-hour（带保底/每日封顶/总封顶/冷却）
        ──▶ 写入南瓜邮箱（可变金额），desc 记"离线 X 小时 → Y 南瓜币"
        ──▶ 玩家 /mailbox 点领取 → eco give（南瓜币，来源记入账本）
```

南瓜邮箱缺失或写入失败时，自动回退为直接 `eco give`（控制台命令）。

## 二、安装

1. 把 **`OfflineReward.jar`** 拷到运行服 `plugins/` 目录。
2. **完全重启服务端**（首次加载需重启，`/reload` 不可靠）。
3. 启动后自动生成 `plugins/OfflineReward/config.yml` 与 `plugins/OfflineReward/offline.db`。

> 依赖：软依赖 **PumpkinMail**（发邮箱）与 **Vault**（发钱）。南瓜邮箱必须已在运行，否则回退直发（仍能用，但不进邮箱）。

## 三、配置（plugins/OfflineReward/config.yml）

| 键                         | 默认                   | 说明                                                        |
| -------------------------- | ---------------------- | ----------------------------------------------------------- |
| `reward.coins-per-hour`    | `50`                   | 每离线 1 小时奖励的南瓜币数                                 |
| `reward.min-hours`         | `1`                    | 离线不足该小时数不发                                        |
| `reward.max-hours-per-day` | `24`                   | 单次最多计入的离线小时（防长时间不上线刷爆）                |
| `reward.max-reward`        | `0`                    | 单次奖励总封顶（0 = 不封顶）                                |
| `reward.cooldown-hours`    | `0`                    | 两次发放最小间隔（小时，0 = 不限），防反复上下线刷          |
| `reward.floor-minutes`     | `true`                 | true = 不足整小时的分钟舍去；false = 按精确小数计           |
| `exempt-permission`        | `offlinereward.exempt` | 拥有该权限节点的玩家不上线发放（管理员/测试号）             |
| `announce`                 | `true`                 | 上线发放后发一条聊天提示（南瓜邮箱另有 ActionBar 待领提示） |
| `db`                       | `offline.db`           | 数据文件（plugins/OfflineReward/ 下）                       |

改完 `config.yml` 执行 `/offlinereward reload`（或重启）生效。

## 四、命令与权限

| 命令                          | 作用                                            | 权限                                 |
| ----------------------------- | ----------------------------------------------- | ------------------------------------ |
| `/offlinereward reload`       | 重载配置                                        | `offlinereward.admin`（默认 op）     |
| `/offlinereward check <玩家>` | 查看某玩家最后退出/上次发放时间戳（仅在线玩家） | `offlinereward.admin`                |
| （alias `/offr`）             | 同上                                            | —                                    |
| 豁免                          | —                                               | `offlinereward.exempt`（默认 false） |

示例给测试号豁免：`/lp user <玩家> permission set offlinereward.exempt true`。

## 五、部署步骤

1. 确认 **PumpkinMail** 已装并在运行（发邮箱依赖）。
2. 拷 `OfflineReward.jar` → `plugins/`，完整重启。
3. 按需改 `config.yml`（币数/封顶/豁免）。
4. 验证：
   - `/offlinereward reload` 无报错；
   - 下线 1 小时+ 再上线 → 聊天提示"已发放 X 南瓜币到邮箱"；
   - `/mailbox` 能看到"离线奖励"条目 → 点击领取 → 余额增加，账本来源显示"离线奖励"。

## 六、防滥用设计（重要）

1. **停机也算离线**：`last_logout` 是真实退出时间，服务器停机几十小时后上线会算很久 → 靠 `max-hours-per-day` 封顶（默认单次最多计入 24 小时）。
2. **首次上线不发**：无 `last_logout` 记录视为离线 0。
3. **防重入账**：邮箱奖励 id 用 `uuid + 时间戳` 生成，`INSERT OR IGNORE` 天然防重复。
4. **反复上下线刷**：`cooldown-hours` 设置两次发放最小间隔；配合 `min-hours` 保底。
5. **管理/测试号**：`offlinereward.exempt` 权限直接豁免。

## 七、与现有插件衔接

- **PumpkinMail**：核心渠道——`OfflineReward` 直接调用其 `Storage.addReward()` 写入可变金额的 money 奖励，玩家 `/mailbox` 领取时由其 `RewardApplier` 执行 `eco give` 并写入南瓜账本来源（"离线奖励"）。
- **Vault / EssentialsX**：南瓜币经济来源。
- **LuckPerms**：给玩家设 `offlinereward.exempt` 豁免（或 `offlinereward.admin` 管理）。

## 八、构建（可选，本仓库已含 jar）

源码在 `src/`，依赖在 `lib/`（paper-api、adventure、bungee-stub、sqlite-jdbc，取自南瓜邮箱 lib）。重新编译：

```powershell
# 需传南瓜邮箱 jar 路径（含中文路径，作为参数避免脚本编码问题）
& "build.ps1" -pmm "F:\game\pc\MC\开服\Minecraft-Server-Build\自研\南瓜邮箱-PumpkinMail\PumpkinMail.jar"
```

产物 `OfflineReward.jar`（内嵌 sqlite-jdbc，仿南瓜邮箱打包方式）。

## 九、数据位置

- `plugins/OfflineReward/offline.db`（玩家最后退出 / 上次发放时间戳），备份/迁移直接拷这个文件即可。
