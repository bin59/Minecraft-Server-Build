# 快捷菜单系统（QuickMenu）与通用菜单插件的不可替代性对比

> 定位：回答"为什么本服不用现成的 DeluxeMenus 等通用菜单插件，而要自研 QuickMenu"。
> 结论先行：**只要服务器跑 Geyser 互通，QuickMenu 的基岩原生表单、两端分流、动态选择器就是不可替代的**；它本质是"为这台服务器定制的整合系统"，不是"又一个做菜单的插件"。

## 一、能力对比矩阵

| 能力维度 | QuickMenu（本服自研） | DeluxeMenus（通用标杆） | Geyser 翻译箱子（基岩端视角） |
|---|---|---|---|
| 基岩端原生表单（SimpleForm） | ✅ 原生表单，基岩客户端渲染，点击/滚动/按钮反馈正常 | ❌ 仅 Java 箱子 GUI | ⚠️ 能显示，但物品可拖出、移动端高亮异常、部分环境打不开、只能左键 |
| 同一按钮按客户端类型分流指令 | ✅ 内置 `[bedrock-player]` / `[java-player]` / `[bedrock-console]` / `[java-console]` 四种平台动作 | ⚠️ 无平台判断，需条件表达式硬凑 | —（无此能力） |
| 动态列出在线玩家选择（免输入玩家名） | ✅ `[player-selector]`，点击列出在线玩家，`{target}` 自动填命令 | ❌ 需手输玩家名或另装插件拼占位符 | —（无此能力） |
| 动态列出背包物品选择 | ✅ `[item-selector]`，自动排除触发物品、同材质合并，`{item}` 填命令 | ❌ 无内置选择器 | —（无此能力） |
| 基岩端无权限按钮自动重排序号 | ✅ `visibleItems` 按序重映射，不留空位、不会点 A 执行 B | ⚠️ 基岩翻译界面留空洞位，序号错位风险 | ❌ 无权限过滤逻辑 |
| 为整台服务器打包的整合体系 | ✅ 23 套菜单 + 每按钮 LuckPerms 权限清单 + 两端指令差异 + 构建校验（槽位冲突/覆盖缺口告警） | ⚠️ 通用工具，全部要自己重新配置 | —（无此能力） |

读法：✅=开箱即有　⚠️=能实现但复杂/有缺陷　❌=没有

## 二、三个不可替代点

### ① 基岩端原生 SimpleForm（不是 Geyser 翻译的箱子）

- DeluxeMenus 只做 Java 箱子 GUI。基岩玩家看到的是 Geyser 翻译后的箱子界面，存在**功能性缺陷**：物品可被拖出、移动端高亮异常、特定环境打不开、只能左键交互。
- QuickMenu 对 Floodgate 玩家直接发原生表单（Cumulus API），由基岩客户端自己渲染，点击/滚动/按钮反馈全部正常。
- 对应配置：`config.yml` → `platform.bedrock-native-form: true`（默认，勿关）。

### ② 动作级两端分流 + 动态选择器

- **平台动作**：`[bedrock-player]` / `[java-player]` / `[bedrock-console]` / `[java-console]`——同一个按钮，Java 玩家执行 `/warp`、基岩玩家执行 `/warpgui`，配置写两行即可；DeluxeMenus 只能靠条件表达式硬凑，且无法判断客户端类型。
- **玩家/物品选择器**：`[player-selector]`、`[item-selector]`——点按钮 → 动态列出在线玩家/背包物品 → 自动填命令。DeluxeMenus 里"选玩家"要么手输名字，要么额外装插件拼占位符。
- **覆盖缺口校验**：构建脚本自动检查——某按钮只配了 `[bedrock-*]` 而 Java 端连 `[message]` 都没有会告警（`[close]` 不算有效反馈）。

### ③ 为这台服务器定制的完整体系（不是通用工具）

- 23 套菜单（玩家 11 + 管理 12）把本服所有插件功能收编：EssentialsX / BPS / Residence / SkinsRestorer / EasyBot / SimplePets / 语音 / 传送阵 / 拍卖 / 玩家商店 / 每日收购 / 管理线。
- 每按钮对应 LuckPerms 权限清单（文档第 8 章），两端指令差异（BPS `warpgui` vs EssentialsX `warp`）、已知坑（"菜单只是前端，真正干活的是后端插件"）全部绑定在配置与文档里。
- 换通用插件 = 全部重新配置，且丢双端特性。

## 三、边界：什么时候可以被替代

| 场景 | 是否可替代 |
|---|---|
| 服务器继续跑 Geyser 互通 | ❌ 不可替代（基岩原生表单是硬差异） |
| 不再跑互通、纯 Java 服 | ✅ DeluxeMenus 可承担大部分功能 |
| 接受基岩玩家体验打折（看翻译箱子） | ⚠️ 可替代但基岩端体验明显下降 |
| 只想要"能打开菜单" | ✅ 任何通用插件都行 |

## 四、事实来源

- 本服 QuickMenu 文档 `快捷菜单系统-QuickMenu.md`（两端界面策略、动作类型、权限过滤行为、菜单结构）
- 本服互通层：Geyser + Floodgate（Floodgate 自带 Cumulus 表单 API，普通 Bukkit 插件即可调用，无需写 Geyser 扩展）
