# 建筑评分 BuildRate · 使用说明

> 自研活动制打分评审插件。一场活动里多座建筑，任意玩家给每座建筑打 1~10 分；**可反复改分记最新、打分公开可见、统计去掉最高/最低分、玩家自主报名**。Java / 基岩双端可用（箱子面板，基岩经 Geyser 自动转表单）。

## 一、管理员面板（推荐）

直接打开管理箱子菜单：

```
/br admin
```

面板内点按钮即可完成全部管理操作，不再依赖聊天栏文字：

| 按钮 | 作用 |
|---|---|
| 创建活动 | 关闭面板后在聊天栏输入活动名，自动创建并设为进行中 |
| 开启评分 | 把当前活动切到进行中，玩家可打分 |
| 截止并结算 | 结束当前活动，按名次把奖励发到获奖玩家邮箱 |
| 查看排名 | 箱子里按均分排名展示参评建筑（金锭图标） |
| 参与度 | 箱子里展示每位评委投了几票（玩家头图标） |
| 活动历史 | 箱子里列出历史活动（书本图标） |

列表面板点「返回管理面板」（箭头）回到主面板。

## 二、管理员：办一场评分活动

除面板外，也可用命令完成同样的事：

1. 创建活动（自动截止上一场进行中的活动）：
   ```
   /br create 2026国庆建筑大赛
   ```
   创建成功后会**全服聊天栏公告**该活动开启，引导玩家 `/br open` 打分、`/br join` 报名（管理面板里聊天创建同样会公告）。
2. 玩家自主报名，或管理员代报名：
   ```
   /br add 南瓜 南瓜城堡
   ```
3. 活动开始：`/br start`
4. 活动结束（**自动按名次结算发奖**）：`/br stop`
   `stop` 会按 config.yml 的 `rewards.ranks` 自动给前 N 名发奖，随后用管理面板「查看排名」或 `/br result` 核对。

> 已移除 `/br settle`：`/br stop` 即截止并自动结算，无需再单独手动结算。

## 三、玩家：报名 & 打分

| 指令 | 作用 |
|---|---|
| `/br join <建筑名>` | 报名参评（再报名=改名） |
| `/br open` | 打开打分面板：点建筑 → 选 1~10 分 |
| `/br score <编号> <分数>` | 命令直接打分（基岩兜底） |
| `/br list` | 参评列表（含当前均分/票数） |
| `/br result` | 排名（均分降序，去最高最低后） |

打分规则：
- 每人可给**每座建筑**打分一次，**可反复改分**，记录最新一次。
- **不能给自己的建筑打分**（可在 config.yml 开启 `allow-self-vote`）。
- 打分**公开可见**（`/br list` 显示每座建筑均分与票数，管理面板「参与度」看每个评分人投了几票）。

## 四、统计口径

- 默认**去掉最高分与最低分**再算平均（票数 ≥ 3 时生效；≤2 时按全部票平均），防刷分。
- 排名按均分降序、票数降序。
- 数据存 `plugins/BuildRate/data.db`（SQLite）。

## 五、结算奖励（全部发到邮箱，含南瓜币）

`/br stop` 截止活动时自动按 `config.yml` 的 `rewards.ranks` 结算。**所有奖励（南瓜币、物品）一律入队到玩家南瓜邮箱，由玩家 `/mailbox` 领取**。**只有真正获奖（配置了名次奖励）的在线玩家才会收到"请到邮箱领取"的私聊提示，未获奖玩家不打扰。** 第 N 名对应一份奖励列表，`type` 三种：

| type | 效果 | 说明 |
|---|---|---|
| `money` | 入队南瓜邮箱 | 玩家领取时由邮箱执行 `eco give` 加南瓜币，**南瓜账本来源记为该奖励描述（含活动名）** |
| `item` | 入队南瓜邮箱 | `data` 格式 `材质:数量`（如 `DIAMOND:1`） |
| `command` | 执行自定义命令 | `{player}` 替换为玩家名，仍直接控制台执行 |

邮箱里每条奖励的说明形如：`「活动名」第N名 · 第N名：500 南瓜币`。

示例：
```yaml
rewards:
  enabled: true
  announce: true
  ranks:
    "1":
      - { type: money, data: "500", desc: "第1名：500 南瓜币" }
      - { type: item, data: "DIAMOND:1", desc: "第1名：钻石 ×1" }
    "2":
      - { type: money, data: "300", desc: "第2名：300 南瓜币" }
    "3":
      - { type: money, data: "200", desc: "第3名：200 南瓜币" }
```

`announce` 为 true 时结算会广播前 3 名。

**账本联动**：需要南瓜账本 MoneyLedger 在服上运行。玩家在 `/mailbox` 领取南瓜币后，南瓜账本里这笔记录的**来源名就是含活动名的奖励描述**（如「2026国庆建筑大赛」第1名 · 第1名：500 南瓜币），便于在 `/moneyledger` 里按活动名追溯每一笔发币。

## 六、命令与权限

| 命令 | 权限 | 说明 |
|---|---|---|
| `/br admin` | buildrate.admin | 打开管理箱子菜单 |
| `/br create <名称>` | buildrate.admin | 创建活动并设为进行中 |
| `/br add <玩家> <建筑名>` | buildrate.admin | 代报名 |
| `/br remove <编号>` | buildrate.admin | 移除参评（含其评分） |
| `/br start` / `/br stop` | buildrate.admin | 开启 / 截止评分（stop 自动结算发奖） |
| `/br result` | 所有人 | 排名（箱子/聊天均可看） |
| `/br history` | 所有人 | 活动历史列表 |
| `/br join / open / score / list` | 所有人 | 玩家操作 |

`buildrate.admin` 默认给 op。

## 七、配置（config.yml）

```yaml
scoring:
  min-score: 1
  max-score: 10
  drop-highest-lowest: true   # 去最高最低分
  allow-self-vote: false      # 禁止自评
  one-build-per-player: true  # 每人一场一座建筑
```

改完配置重启服务端生效。

## 八、部署

`BuildRate.jar` 放入服务端 `plugins\` 目录，重启服务端即可。依赖：内置 sqlite-jdbc（已打进 jar）；发奖联动南瓜邮箱 PumpkinMail、南瓜账本 MoneyLedger（同服运行即可）。
