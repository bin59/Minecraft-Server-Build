# 建筑评分 BuildRate · 使用说明

> 自研活动制打分评审插件。一场活动里多座建筑，任意玩家给每座建筑打 1~10 分；**可反复改分记最新、打分公开可见、统计去掉最高/最低分、玩家自主报名**。Java / 基岩双端可用（箱子面板，基岩经 Geyser 自动转表单）。

## 一、管理员：办一场评分活动

1. 创建活动（自动截止上一场进行中的活动）：
   ```
   /br create 2026国庆建筑大赛
   ```
2. 玩家自主报名，或管理员代报名：
   ```
   /br add 南瓜 南瓜城堡
   ```
3. 活动开始时：
   ```
   /br start
   ```
4. 活动结束（**自动按名次结算发奖**）：
   ```
   /br stop
   /br result
   ```
   `/br stop` 会按 config.yml 的 `rewards.ranks` 自动给前 N 名发奖：**南瓜币**直接到账（在线玩家记入南瓜账本「活动参与」），**物品**发到玩家南瓜邮箱（`/mailbox` 领取）。也可用 `/br settle` 手动结算。

## 二、玩家：报名 & 打分

| 指令 | 作用 |
|---|---|
| `/br join <建筑名>` | 报名参评（再报名=改名） |
| `/br open` | 打开打分面板：点建筑 → 选 1~10 分 |
| `/br score <编号> <分数>` | 命令直接打分（基岩兜底） |
| `/br list` | 参评列表（含当前均分/票数） |
| `/br result` | 排名（均分降序，去最高最低后） |

打分规则：
- 每人可给**每座建筑**打分一次，**可反复改分**，记录最新一次。
- **不能给自己的建筑打分**（可在 config.yml 开启 `allow-self-vote`）。
- 打分**公开可见**（`/br list` 显示每座建筑均分与票数，管理员 `/br stats` 看每个评分人投了几票）。

## 三、统计口径

- 默认**去掉最高分与最低分**再算平均（票数 ≥ 3 时生效；≤2 时按全部票平均），防刷分。
- 排名按均分降序、票数降序。
- 数据存 `plugins/BuildRate/data.db`（SQLite），可 `export` 备份。

## 四、结算奖励（按名次自动发）

`/br stop` 截止活动时自动按 `config.yml` 的 `rewards.ranks` 结算，第 N 名对应一份奖励列表，`type` 三种：

| type | 效果 | 说明 |
|---|---|---|
| `money` | 直接发南瓜币 | 在线玩家经 Essentials API，**记入南瓜账本「活动参与」**；离线回退 `eco give` |
| `item` | 发到南瓜邮箱 | 玩家用 `/mailbox` 领取，`data` 格式 `材质:数量`（如 `DIAMOND:1`） |
| `command` | 执行自定义命令 | `{player}` 替换为玩家名 |

示例：
```yaml
rewards:
  enabled: true
  announce: true
  ranks:
    "1":
      - { type: money, data: "500", desc: "第1名：500 南瓜币" }
      - { type: item, data: "DIAMOND:1", desc: "第1名：钻石 ×1" }
    "2":
      - { type: money, data: "300", desc: "第2名：300 南瓜币" }
    "3":
      - { type: money, data: "200", desc: "第3名：200 南瓜币" }
```

手动补发：`/br settle`。`announce` 为 true 时结算会广播前 3 名。

**账本联动**：需要南瓜账本 MoneyLedger 在服上运行；BuildRate 发放的南瓜币会在 `/moneyledger` 里记为 **「活动参与」** 类别。

## 五、命令与权限

| 命令 | 权限 | 说明 |
|---|---|---|
| `/br create <名称>` | buildrate.admin | 创建活动并设为进行中 |
| `/br add <玩家> <建筑名>` | buildrate.admin | 代报名 |
| `/br remove <编号>` | buildrate.admin | 移除参评（含其评分） |
| `/br start` / `/br stop` | buildrate.admin | 开启 / 截止评分（stop 自动结算发奖） |
| `/br settle` | buildrate.admin | 手动按名次结算发奖 |
| `/br stats` | buildrate.admin | 投票参与度统计 |
| `/br history` | 所有人 | 活动历史列表 |
| `/br join / open / score / list / result` | 所有人 | 玩家操作 |

`buildrate.admin` 默认给 op。

## 五、配置（config.yml）

```yaml
scoring:
  min-score: 1
  max-score: 10
  drop-highest-lowest: true   # 去最高最低分
  allow-self-vote: false      # 禁止自评
  one-build-per-player: true  # 每人一场一座建筑
```

改完配置 `/br` 重启插件或重载服务端生效。

## 六、部署

`BuildRate.jar` 放入服务端 `plugins\` 目录，重启服务端即可。依赖：仅需服务端内置 sqlite-jdbc（已打进 jar），无其他前置。
