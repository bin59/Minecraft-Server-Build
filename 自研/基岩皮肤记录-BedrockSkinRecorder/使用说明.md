# 基岩皮肤记录器（BedrockSkinRecorder）

自研插件：**基岩玩家每次上线时，自动把其 Xbox 皮肤纹理保存为 PNG 到服务器磁盘**。

## 为什么需要它

基岩玩家（Floodgate 进服）的皮肤存在 **基岩账号（Xbox）** 上，服务器本地没有任何数据——Geyser 只在玩家**在线期间**临时持有皮肤，重启即失，离线后无法拉取（此前的"全服皮肤拉取"对基岩 126 人全部落空，原因即在此）。

本插件把「在线时的皮肤」**固化到磁盘**：玩家一上线，插件就从 Geyser 的皮肤缓存中取出纹理 PNG（Geyser 已在玩家加入时从基岩客户端获取），直接落盘。**无需联网、无需玩家操作、静默记录**。玩家换肤后再上线，PNG 会被覆盖更新。

## 工作原理

```
基岩玩家上线
  → PlayerJoinEvent（Floodgate UUID 判定）
  → 延迟 4 秒（等 Geyser 拉取皮肤）
  → 反射读 SkinProvider.CACHED_BEDROCK_SKINS（Geyser 基岩皮肤缓存）
  → key = SkinProvider.shorthandUUID(玩家UUID)
  → Skin.skinData()（PNG byte[]，Geyser 已从客户端获取）
  → 写入 plugins/BedrockSkinRecorder/skins/<玩家名>.png + <玩家名>.json（meta）
  → 缓存未命中自动重试，最多 5 次（每次间隔 4 秒）
```

- 皮肤数据**不经过网络**：Geyser 从基岩客户端拿到纹理后直接缓存，插件从内存缓存取 byte[] 落盘。
- 与 SkinsRestorer 互补：SkinsRestorer 管「换肤记录」，本插件管「基岩原生皮肤固化」。

## 数据位置

```
plugins/BedrockSkinRecorder/
├── skins/
│   ├── .PumpkinVeget.png      # 皮肤纹理（64×64 PNG）
│   ├── .PumpkinVeget.json     # meta：玩家名 / UUID / 抓取时间 / 纹理URL / 大小
│   └── ...
└── (无配置文件，零配置)
```

## 皮肤来源一览（本插件在全服皮肤来源中的定位）

全服玩家皮肤的来源共 4 类，本插件解决的是第 ③ 类「服务器原本拿不到数据」的问题：

| # | 来源 | 例子 | 服务器有无数据 | 由谁落地 |
| --- | --- | --- | --- | --- |
| ① | 皮肤库（服务器内置 `sr-recommendation-*`） | `sr-recommendation-herobrine` | ✅ 有（SkinsRestorer `skins/*.customskin`） | SkinsRestorer |
| ② | 皮肤网站（MineSkin `minesk.in`） | `https://minesk.in/265ad77148fa490eae1f1e5362189557` | ✅ 有（SkinsRestorer `skins/*.urlskin`） | SkinsRestorer |
| ③ | 基岩原生（客户端自带，126 人未换肤） | `.PinchHydra4690` | ❌ 原本无（在基岩账号） | **本插件（上线固化到 `skins/<玩家名>.png`）** |
| ④ | 正版 Mojang（账号自带，仅 18 人真正版） | `KAPIAN_` | ❌ 原本无（在 Mojang，可联网拉取） | 拉取脚本（Mojang session API） |

- ①② 产生 SkinsRestorer 记录（`.player` / `.customskin` / `.urlskin`）；③④ 不经过 SkinsRestorer。
- 本插件固化后，③的 PNG 与「皮肤拉取」流程兼容，可直接并入全服皮肤汇总。
- ④中 77 名 Java 未换肤玩家，18 人为真 Mojang 正版（联网可拉），其余为外置登录（LittleSkin）账号未设皮肤，显示默认 Steve/Alex。

## 命令与权限

| 命令 | 作用 | 权限 |
| --- | --- | --- |
| `/bsr` | 查看已记录玩家数与目录路径 | `bsr.admin`（默认 OP） |
| `/bsr list` | 列出最近记录的 30 名玩家 | `bsr.admin` |
| `/bsr reload` | 重载（核对目录） | `bsr.admin` |

无权限要求：记录行为对玩家完全透明，无需任何权限。

## 部署

1. 把 `BedrockSkinRecorder-1.0.0.jar` 放入 `plugins/`
2. 重启服务器（或 `/reload confirm`）
3. 启动日志：`基岩皮肤记录器已启用 | 皮肤目录: ...`

依赖：`floodgate`（判定基岩玩家）、`Geyser-Spigot`（皮肤缓存）——均为软依赖，缺 Floodgate 时插件只报错不崩。

## 构建

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```

产物：`_build/out/BedrockSkinRecorder-1.0.0.jar`。构建依赖（spigot-api / floodgate-api / guava / gson）自动下载，Geyser-Spigot.jar 从运行服务器 `plugins/` 复制（保证 API 版本与运行服一致）。

## 备注

- 已记录的 PNG 与「皮肤拉取」流程兼容：`plugins/BedrockSkinRecorder/skins/` 可直接并入皮肤拉取脚本的输入源。
- 玩家离线期间的换肤无法记录（皮肤在基岩账号，服务器不可见）；只有玩家**上线后**才会抓取。
