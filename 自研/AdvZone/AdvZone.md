# AdvZone — 不规则多边形区域强制冒险模式

自研插件：玩家进入指定多边形区域强制切换冒险模式，离开自动恢复，管理员豁免。不依赖 Residence / WorldGuard，纯 Paper API。

| 项目 | 内容 |
|---|---|
| 插件名 | AdvZone |
| 版本 | 1.1.0 |
| 类型 | 区域行为控制插件 |
| 依赖 | 无（仅 Paper/Leaf API） |
| 适用版本 | MC 1.21+（`api-version: 1.21`） |
| Java | 21 |
| 产物 | `dist/AdvZone.jar`（或 Maven 构建 `target/AdvZone.jar`） |
| 源码 | `src/main/java/com/hh/advzone/AdvZone.java` |

---

## 一、功能说明

- 玩家**进入**配置好的多边形区域 → 强制切换为**冒险模式**（不能破坏/放置方块）；
- 玩家**离开**区域 → **自动恢复进区前的模式**（生存/创造等）；
- 区域支持**不规则多边形**（任意顶点数 ≥3）、**垂直范围**（Y 轴可限定，超出不触发）；
- 区域在**游戏内用箭选点创建**，自动写回 `config.yml`，无需手动编辑文件；
- `advzone.bypass` 权限或 OP **豁免**，进区不改变模式；
- 不依赖任何领地插件，纯 Paper API 实现。

## 二、工作原理

```
PlayerMoveEvent / Teleport / Join
        │  （仅跨方块时触发真判定，见「性能设计」）
        ▼
check(player) ── 有 advzone.bypass / OP？ ──是──► 直接返回
        │ 否
        ▼
zoneAt(location) ── 遍历全部区域做点判定
        │
   ┌────┴─────────────────────────────┐
   │ 在区域内                          │ 不在任何区域
   │ 且当前非冒险模式                    │ 且曾被强制（forced 缓存里有）
   ▼                                  ▼
记下进区前模式 → 切冒险模式      恢复进区前模式 → 移除缓存
```

- 被强制的玩家记录在 `forced`（UUID → 进区前模式）内存表；
- **关服/卸载时**自动把仍在线且被强制的玩家还原，避免玩家卡在冒险模式；
- **玩家退出**时清空其 `forced` / 选点缓存。

### 多边形判定（Zone.contains）

两层判定，性能优先：

1. **包围盒快筛**：先比较 `x/z` 是否在区域最小外接矩形内、`y` 是否在 `y-min~y-max` 内——**框外零循环直接返回 false**；
2. **射线法（Ray Casting）**：点在多边形内判断，支持任意凹凸多边形，顶点按顺序自动闭合。

## 三、命令一览

主命令 `/az`（别名 `/advzone`），需权限 `advzone.admin`（默认 OP）。

| 命令 | 说明 |
|---|---|
| `/az wand` | 给一把选点魔棒（默认箭） |
| `/az add` | 在脚下当前位置加一个顶点 |
| `/az undo` | 撤销上一个顶点 |
| `/az clear` | 清空当前选点缓冲 |
| `/az points` | 查看当前选点列表 |
| `/az create <区域名> [yMin] [yMax]` | 用当前选点创建/覆盖区域（至少 3 个顶点） |
| `/az edit <区域名>` | 载入已有区域的顶点进行修改 |
| `/az delete <区域名>` | 删除区域 |
| `/az list` | 列出全部区域（顶点数、Y 范围） |
| `/az info <区域名>` | 查看区域详情（Y 范围 + 全部顶点坐标） |
| `/az reload` | 重载配置；重载后对所有在线玩家重跑判定（被删区域的玩家自动还原） |
| `/az check` | 查看自己当前所在区域与模式 |

子命令均支持 Tab 补全（含区域名补全）。

## 五、配置（`plugins/AdvZone/config.yml`）

```yaml
# 选点魔棒：手持该物品，站在拐角处 左键=加一个顶点，右键=撤销上一个顶点
# 顶点会显示粒子柱方便对位。也可用命令 /az add、/az undo、/az points 管理。
wand-material: ARROW

# 区域在游戏内用 /az create <名字> 创建并自动写回，无需手动编辑。
# 不规则形状 = 多边形顶点按顺序连线，自动闭合；
# 不连片的形状分多个区域（regions 下多个键）。
# y-min / y-max：区域垂直范围，超出不触发（-64 是 1.18+ 世界最低层）。
regions:
  safezone:
    y-min: -64
    y-max: 320
    points:
      - "100,200"
      - "300,210"
      - "320,400"
      - "90,380"
```

- `wand-material`：魔棒物品，默认 `ARROW`；
- `regions.<名>.points`：顶点坐标列表 `"x,z"`，按顺序连线自动闭合；
- `regions.<名>.y-min` / `y-max`：垂直范围，默认 `-64` ~ `320`。

## 六、选点建区流程（游戏内）

1. `/az wand` 拿魔棒（默认箭）；
2. 走到区域拐角处，**左键**加顶点（脚下位置），**右键**撤销上一个顶点；
3. 沿不规则边缘逐个拐角加点，每个顶点会有**粒子柱**可视化（玩家脚下 1 格起、向上延伸约 6 格，每 0.5 格一颗 END_ROD 粒子），方便对位；
4. 顶点 ≥3 个后 `/az create <区域名>` 保存，自动写回 `config.yml`；
5. 修改已有区域：`/az edit <区域名>` 载入顶点 → 右键删点、左键加点 → `/az create <区域名>` 覆盖保存。

> 提示：`/az add` 可代替魔棒加点；粒子预览每 0.5 秒刷新一次，仅对**有选点的玩家**绘制。

## 七、性能设计

| 手段 | 说明 |
|---|---|
| 跨方块才判定 | `PlayerMoveEvent` 仅当 `from`/`to` 的方块坐标（x/y/z）任一变化时才调用 `check()`，同方块内的微移动零开销 |
| 包围盒快筛 | 多边形判定前先过最小外接矩形 + Y 范围，框外直接返回，不进入射线法 |
| 粒子按需绘制 | 预览定时任务仅遍历有选点的玩家，不空转 |
| 内存状态最小化 | `forced` / `selection` 均以 UUID 为键，玩家退出即清理 |

## 八、构建与部署

```bash
# Maven 构建（pom.xml，finalName=AdvZone）
mvn clean package        # 产物 target/AdvZone.jar

# 或直接运行一键打包.bat（Windows）
```

1. 将 `dist/AdvZone.jar`（或构建产物）放入服务端 `plugins/` 目录；
2. 重启服务器（首次启动生成默认 `config.yml`）；
3. 用 `/az list` / `/az check` 验证加载。

## 九、常见问题

| 问题 | 说明 |
|---|---|
| 区域创建后没生效 | 检查顶点是否 ≥3、Y 范围是否覆盖目标高度；`/az list` 看是否已加载，`/az check` 验证自己所在区域 |
| 玩家进区后模式没变 | 玩家是否有 `advzone.bypass` 权限（默认 OP 豁免）；区域是否真的包含该坐标 |
| 离开后没有恢复原模式 | 需通过"进区强制→离开恢复"同一路径；若玩家是在插件重载/关服期间离开，`/az reload` 会对在线玩家重跑判定自动还原 |
| 多边形不连片 | 一个区域 = 一个多边形；不连片形状拆成多个区域（`regions` 下多个键） |
| 粒子预览方向 | 粒子柱为**竖直**（脚下到 +6 格），非水平扩散；顶点过多时粒子较密集属正常 |
