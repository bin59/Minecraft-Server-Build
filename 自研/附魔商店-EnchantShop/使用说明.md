# EnchantShop —— 附魔商店（自研）

> 让玩家（尤其基岩版）用经验等级在箱子 GUI 里给手持装备买 ExcellentEnchants 自定义附魔，绕过物理铁砧。

## 为什么做这个

Geyser 把 Java 铁砧翻译成基岩铁砧后有两个老大难：

- **结果槽取物不可靠**：基岩玩家点铁砧结果槽经常取不到成品；
- **改名框映射错乱**：基岩端文字输入和 Java 铁砧改名框对不齐，搞乱整个交互。

Java 玩家蹲物理铁砧正常，基岩玩家附魔不顺。本插件用箱子 GUI（Geyser 对箱子菜单翻译很稳）替代物理铁砧。

## 基本信息

| 项       | 值                                                         |
| -------- | ---------------------------------------------------------- |
| 包名     | `com.nangua.enchshop`                                      |
| 命令     | `/eshop`                                                   |
| 依赖     | ExcellentEnchants（`depend`，EE 未加载则本插件不开）       |
| 入口     | 快捷菜单主菜单 slot 15「附魔商店」（附魔书图标，发微光）   |

## 玩家用法

1. 点快捷菜单 →「附魔商店」（或输入 `/eshop`）；
2. 把要附魔的装备**放进上方中间格子**（输入格）；
3. 下方列出全部已启用的自定义附魔，每个标注类型和价格（经验等级）；
4. 点一个附魔：
   - 输入格没放装备 → 提示先放装备；
   - 装备类型不符（比如给剑买头盔附魔）→ 提示不能用在该物品上；
   - 经验等级不够 → 提示需要几级；
   - 装备已有该附魔 → 提示不重复扣；
   - 通过 → 扣等级，把附魔打在输入格的装备上；
5. 关闭菜单时输入格的装备自动回到背包。

## 扣费与施加逻辑

- **价格来源**：读该附魔在 `plugins/ExcellentEnchants/enchants/<id>.yml` 里的 `AnvilCost`；
- **扣的是经验等级条**：`player.giveExpLevels(-cost)`，和铁砧手感一致；
- **施加**：从运行时注册表取 `excellentenchants` 命名空间附魔，`ItemMeta.addEnchant(enchant, 1, true)` 打到输入格装备上；
- **装备类型校验**：读各附魔 `SupportedItems`（helmet / swords_axes / bow_crossbow / boots 等），按物品材质类别判断能否施加，不符则拒绝；
- **不依赖主手**：用独立输入格，避免快捷菜单触发物（时钟）占着手时误把时钟当装备；
- **价格兜底**：某附魔没配 `AnvilCost` 时，用本插件配置 `default-cost`（默认 3 级）。

## 配置

`plugins/EnchantShop/config.yml`：

```yaml
# 当某附魔配置里没有 AnvilCost 时的默认价格（经验等级）
default-cost: 3
```

## 显示名与附魔列表

- 列表来自**运行时注册表**：遍历 Bukkit 附魔注册表，筛 `excellentenchants` 命名空间——线上 EE 启用几个就列几个，不看磁盘目录；
- 显示名读各附魔 yml 的 `Definition.DisplayName`（自动剥掉 MiniMessage 颜色标签）；
- 配置文件查找顺序：先 `plugins/ExcellentEnchants/enchants/<id>.yml`，找不到再找 `_disabled_/<id>.yml`。

**新增附魔**：在 EE 里启用（把 `_disabled_/` 下对应 yml 移回 `enchants/`），重启后自动出现在商店，价格自动读 `AnvilCost`，无需改本插件。

## 文件

| 路径                                              | 作用                          |
| ------------------------------------------------- | ----------------------------- |
| `src/main/java/com/nangua/enchshop/EnchantShop.java` | 主类：加载附魔、开 GUI、点击扣费施加 |
| `src/main/resources/plugin.yml`                   | 插件描述（命令、依赖 EE）     |
| `src/main/resources/config.yml`                  | 默认价格                      |
| `EnchantShop.jar`                                 | 构建产物，部署到运行服 `plugins/` |

## 构建

classpath = 服务端 `libraries/` 全部 jar + `ExcellentEnchants-*.jar`，用 JDK 21 编译后打 jar。
