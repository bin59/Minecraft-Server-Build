## windows环境配置MCSM实例

在 Windows 环境下配置 MCSM 比 Linux 更简单，因为它提供了无需额外安装 Node.js 的“绿色版”程序。

### ⚙️ 第一步：下载与安装

1.  **下载程序**：访问 MCSManager 官网 [https://mcsmanager.com/](https://mcsmanager.com/)，找到并下载 Windows 版本的安装包（一个 `.zip` 压缩包）。
2.  **解压运行**：将下载的压缩包解压到任意目录（建议路径不要包含中文）。然后，**以管理员身份**运行解压文件夹里的启动器程序（通常是 `MCSManager.exe` 或 `start.bat`）。
3.  **访问面板**：程序启动后，它会自动在浏览器中打开面板页面。如果没有自动跳转，可以手动在浏览器输入 `http://localhost:23333` 访问。

### 🚀 第二步：创建你的第一个服务器实例

1.  **注册账号**：首次访问 `http://localhost:23333` 时，页面会提示你创建一个管理员账号，按提示填写信息即可。
2.  **新建实例**：登录后，在面板主界面点击 **“快速开始”**，然后选择 **“创建 Minecraft 服务器”**。
3.  **选择安装方式**：
    - **快速部署（推荐新手）**：在弹出的界面中，选择 **“一键开服”** 或 **“Minecraft 快速部署”**。然后，从列表中选择你想要安装的 Minecraft 版本（例如 1.19.2），点击 **“安装”** 即可。面板会自动下载并配置好服务端。
    - **手动上传（高级用户）**：如果你有自己的服务端整合包（如模组服），可以选择 **“引导创建”** 或 **“上传服务端”** 模式，然后根据提示上传你的服务端文件。

### 🛠️ 第三步：实例的核心配置

实例创建完成后，在启动前，有几个关键步骤必须完成：

1.  **同意 EULA 协议**：这是启动 Minecraft 服务器的前提。
    - 在面板中找到你刚创建的实例，进入其 **“文件管理”** 或 **“终端”** 页面。
    - 找到服务端目录下的 `eula.txt` 文件。
    - 用记事本打开它，将里面的 `eula=false` 改为 `eula=true`，然后保存。
2.  **配置服务器参数（可选）**：
    - 在 **“文件管理”** 中找到 `server.properties` 文件并编辑。
    - 一个常见的修改是将 **`online-mode`** 的值改为 `false`，这样非正版玩家也能进入你的服务器。
3.  **检查 Java 环境**：MCSM 需要正确的 Java 环境才能启动服务器。
    - **确认 Java 已安装**：在命令提示符（CMD）中输入 `java -version`，如果能显示版本信息，则说明已安装。
    - **设置 Java 路径（如需要）**：如果面板无法自动找到 Java，你需要在实例的 **“参数设置”** 中，手动指定 `java.exe` 的路径，例如 `C:\Program Files\Java\jdk-17.0.2\bin\java.exe`。
    - **调整内存分配**：在同样的“参数设置”或“启动命令”中，可以修改 `-Xms`（初始内存）和 `-Xmx`（最大内存）的值，例如 `-Xms1024M -Xmx2048M` 表示分配 1G 到 2G 的内存。

### ▶️ 第四步：启动与验证

完成上述配置后，回到实例的 **“终端”** 或 **“控制台”** 页面，点击 **“开启实例”** 或 **“启动”** 按钮。

面板会开始启动服务器，你可以在控制台实时查看启动日志。如果看到类似 `Done (x.xxxs)! For help, type "help"` 的信息，就表示服务器已成功启动。

### 📌 补充说明与常见问题

- **端口占用**：如果面板无法启动，或提示 `23333` 端口被占用，可以修改面板配置文件中的端口号。
- **防火墙拦截**：如果其他设备无法访问你的服务器，请确保 Windows 防火墙已放行 `23333`（面板端口）和 `25565`（游戏默认端口）。
- **开机自启**：如果需要将 MCSM 设置为 Windows 系统服务，可以参考社区提供的方案。
- **系统要求**：MCSM 建议在 **Windows 10** 或更高版本的系统上运行。

## 分布式部署：B电脑面板远程管理A电脑服务器

### 架构说明

MCSM 由两个独立组件组成：

| 组件 | 作用 | 默认端口 |
|------|------|----------|
| **Panel (Web 面板)** | 提供 Web 管理界面，接收用户操作 | `23333` |
| **Daemon (守护进程)** | 真正管理游戏服务器的进程（启动/停止/文件管理） | `24444` |

分布式部署模型：

```
┌─────────────────────────┐        ┌──────────────────────────────┐
│      电脑 B (管理端)     │        │      电脑 A (服务器端)         │
│                         │  API   │                              │
│  MCSM Panel (Web 面板)  │◄──────►│  MCSM Daemon (守护进程)       │
│  端口: 23333            │ 24444  │  端口: 24444                 │
│                         │        │  管理 MC 服务端 (端口: 55551) │
└─────────────────────────┘        └──────────────────────────────┘
```

> 电脑 A 上已有完整的 MC 服务端和配置文件，只需额外安装 MCSM **Daemon** 即可。

---

### ⚙️ 电脑 A（服务器端）：安装 MCSM Daemon

MCSM Windows 安装包**同时包含 Panel 和 Daemon**。电脑 A 只需要 Daemon。

#### 1. 下载与安装

1. 访问 [MCSManager 官网](https://mcsmanager.com/) 下载 Windows 版安装包（.zip）
2. 解压到不含中文的目录，例如 `D:\mcsm`
3. 解压后可看到 `daemon` 文件夹

#### 2. 启动 Daemon

进入 `daemon` 目录，以**管理员身份**运行 `start-daemon.bat`。

首次启动会自动生成 `daemon/data/Config/global.json` 配置文件。看到类似以下输出即启动成功：

```
[INFO] MCSManager Daemon is running on port 24444
```

> **注意**：Daemon 默认绑定 `0.0.0.0:24444`，监听所有网卡，允许远程连接。

#### 3. 配置 Daemon 密钥（重要）

打开 `daemon/data/Config/global.json`，找到 `key` 字段（或 `apiKey`）：

```json
{
  "port": 24444,
  "key": "默认生成的密钥",
  ...
}
```

记下这个 **key**，它是电脑 B 连接电脑 A 的凭证。你也可以把它改成自己好记的字符串。

#### 4. 防火墙放行 Daemon 端口

在电脑 A 上，确保 Windows 防火墙放行 TCP `24444` 端口：

```powershell
# 以管理员身份在 PowerShell 中执行
New-NetFirewallRule -DisplayName "MCSM Daemon" -Direction Inbound -Protocol TCP -LocalPort 24444 -Action Allow
```

---

### ⚙️ 电脑 B（管理端）：安装 MCSM Panel 并连接远端节点

#### 1. 下载与安装

同电脑 A，下载 Windows 安装包，解压到电脑 B。电脑 B 只需要 Panel。

#### 2. 启动 Panel

进入解压目录，以管理员身份运行 `start-panel.bat`（或 `MCSManager.exe`）。

启动后浏览器访问 `http://localhost:23333`，注册管理员账号。

#### 3. 添加远端节点（电脑 A 的 Daemon）

登录面板后：

1. 点击左侧菜单 **"节点管理"**（或 "Nodes"）
2. 点击 **"新建节点"** 或 **"+ 添加"**
3. 填写以下信息：

| 设置项 | 值 |
|--------|-----|
| 节点名称 | 随便填，如 "电脑A-南瓜服" |
| 节点地址 | 电脑 A 的 **局域网 IP**，如 `192.168.1.100` |
| 节点端口 | `24444`（Daemon 端口） |
| API 密钥 | 电脑 A 上 `global.json` 中的 `key` 值 |

4. 点击 **"连接"** 或 **"保存"**。如果连接成功，节点状态会显示为 **"已连接"**（绿色）。

> **如何获取电脑 A 的局域网 IP？** 在电脑 A 的 CMD 中执行 `ipconfig`，找到 IPv4 地址，如 `192.168.1.100`。

#### 4. 在远端节点上导入已有 MC 服务端

1. 在面板中切换到电脑 A 的节点
2. 点击 **"新建实例"** → **"引导创建"** 或 **"无需文件/选择已存在文件"**
3. **实例目录**：填入电脑 A 上MC服务端的绝对路径，如 `c:\mc_serve\1.21.11-test`
4. **启动命令**：填入电脑 A 上已有的启动命令，如：
   ```
   java -Xms1G -Xmx4G -jar leaf-1.21.11-174.jar nogui
   ```
5. 填写实例名称后保存

这样 MCSM 就会直接接管电脑 A 上**已有的服务端目录**，无需复制文件。

### 🔑 连接验证清单

| 检查项 | 电脑 A | 电脑 B |
|--------|--------|--------|
| Daemon 已启动 | ✅ `netstat -an | findstr 24444` | — |
| Panel 已启动 | — | ✅ 浏览器打开 `localhost:23333` |
| 防火墙放行 | ✅ TCP 24444 | — |
| 网络互通 | ✅ `ping 电脑B的IP` | ✅ `ping 电脑A的IP` |
| 密钥一致 | ✅ `global.json` 中 key | ✅ 节点设置中填写的 key |

---

### 🛡️ 安全建议

- **绑定内网**：如果 Panel 和 Daemon 都在局域网内，Daemon 无需暴露到公网
- **修改默认密钥**：首次安装务必修改 `global.json` 中的默认 key
- **公网穿透**：如果电脑 B 在外网需要管理电脑 A，建议用 VPN（Tailscale/ZeroTier）组虚拟局域网，或 Nginx 反向代理 + SSL，**不要直接暴露 24444 到公网**
- **Windows 防火墙**：只放行必要端口（24444），游戏端口（55551/19132）如果不需要远程玩家连接可以不放行
