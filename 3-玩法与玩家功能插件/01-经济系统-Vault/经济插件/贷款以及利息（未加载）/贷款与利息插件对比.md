→ **要实现贷款+利息，必须另装插件**。下表列出的 **BankSystem+ / OmniBank / Credits / LoanMC / PlayerCredit** 均兼容 1.21.x，可直接加装。

## 功能速览

- **BankSystem+**：分级账户（Basic/Silver/Gold/Platinum），贷款带息 2–5%、存款自动利息、自动分期还款、GUI、审计日志。
- **OmniBank**：存钱/物品/XP、贷款（信用额度随还款记录增长）、按小时利息、分级、玩家互转（含离线）。
- **Credits**：完整经济系统 + 贷款 + 利息 + 储蓄 + 税收，多数据库（YAML/MySQL/SQLite/MongoDB），支持到 26.1。
- **LoanMC**：轻量，贷款+自定义利息、储蓄、投资、物品抵押、财务声望排行。
- **PlayerCredit**：玩家驱动贷款，自定义利率+期限+抵押，Staff 审批工作流，适合 RPG 服。
- **PlayerLoans**：玩家间借贷，仅 1.19 官方验证，需实测 1.21.11。

---

## 推荐排序（结合本服现状）

1. **BankSystem+ / OmniBank**：功能最全（分级、贷款带息、存款利息、自动还款、GUI），1.21 原生支持，适合做玩家/公会银行。
3. **Credits**：版本覆盖最广（到 26.1），含贷款+利息+储蓄+税收，适合想要完整经济替代。
4. **LoanMC**：轻量纯贷款+储蓄+抵押，但下载量低、较新，适合小服试水。
5. **PlayerLoans**：仅在你能接受「未官方确认 1.21.11」风险时考虑，务必先在测试服验证。
