# 领地插件使用指南（玩家篇）

> 本指南基于 Residence 插件编写，帮助你在服务器中圈地、保护家园、管理权限。

---

## 第一步：认识领地插件

领地插件可以让玩家自己圈出一块地，用来保护房子、箱子和农田。

圈地之后：

- 别人不能随便破坏你的建筑
- 别人不能随便打开你的箱子
- 你可以决定谁能进入、谁能建造
- 你的家不再怕熊孩子

---

## 第二步：准备圈地工具

圈地前，你需要一把**圈地工具**。

本服使用：**木锄**（默认）

使用方法：

| 操作 | 作用 |
|---|---|
| 左键方块 | 设置第一个点 |
| 右键方块 | 设置第二个点 |

这两个点会形成一个长方体区域，也就是你的领地范围。

---

## 第三步：选择领地范围

站在你想圈地的位置，按下面步骤操作：

1. 拿着木锄
2. 对准一个角落的方块，**左键点击**
3. 走到对角线位置，对准另一个方块，**右键点击**
4. 系统会显示你选择的区域大小

你可以想象成：

```
A点
┌──────────────┐
│              │
│   你的领地   │
│              │
└──────────────┘
              B点
```

A 和 B 是长方体的两个对角点。

### 纵向扩展到天空和基岩

如果你想领地从天空到基岩全部覆盖：

```text
/res select vert
```

---

## 第四步：创建领地

选好区域后，输入创建指令：

```text
/res create 领地名
```

例如：

```text
/res create myhome
```

创建成功后，这块区域就会变成你的领地。

注意：

- 领地名不要和别人的重复
- 建议用英文、数字或简单名称
- 不要使用特殊符号

---

## 第五步：查看领地信息

站在领地内，输入：

```text
/res info
```

可以看到：

- 领地名称
- 领地主人
- 领地大小
- 当前权限设置
- 领地成员列表

如果想看自己有哪些领地，输入：

```text
/res list
```

---

## 第六步：设置领地权限

创建领地后，你可以设置别人能做什么、不能做什么。

常用权限：

| 权限 | 作用 |
|---|---|
| `build` | 建造 |
| `destroy` | 破坏方块 |
| `use` | 使用门、按钮、工作台等 |
| `container` | 打开箱子、熔炉等容器 |
| `pvp` | 是否允许玩家互相攻击 |
| `move` | 是否允许进入领地 |
| `tp` | 是否允许传送到领地 |
| `damage` | 是否允许受到伤害（怪物/掉落等） |
| `firespread` | 火焰是否蔓延 |
| `flow` | 水/岩浆是否流动 |

权限只有两种状态：

- `true`：开启
- `false`：关闭

例如：

```text
/res set myhome build true
```

表示允许建造。

```text
/res set myhome pvp false
```

表示关闭玩家对战。

---

## 第七步：给玩家单独设置权限

如果你只想让某个朋友进入你的领地，可以使用：

```text
/res pset 领地名 玩家名 权限 true
```

例如：

```text
/res pset myhome Steve build true
```

表示给 `Steve` 在 `myhome` 领地里的建造权限。

常用权限示例：

```text
/res pset myhome Steve build true
/res pset myhome Steve destroy true
/res pset myhome Steve use true
/res pset myhome Steve container true
```

如果想取消权限：

```text
/res pset myhome Steve build false
```

---

## 第八步：给玩家管理员权限

如果你想让信任的朋友帮你管理领地的权限设置，可以赋予 admin 权限：

```text
/res pset myhome Steve admin true
```

这样 Steve 就可以帮你：
- 添加/移除领地成员
- 修改领地权限
- 设置传送点
- 管理子领地

如果想收回管理员权限：

```text
/res pset myhome Steve admin false
```

---

## 第九步：传送与退出

传送到自己的领地：

```text
/res tp 领地名
```

设置当前站立位置为传送点：

```text
/res tpset
```

设置默认主领地（每次传送默认去这里）：

```text
/res setmain 领地名
```

如果你不小心卡在领地里，可以尝试：

```text
/res unstuck
```

---

## 第十步：删除领地

如果不需要这个领地了，可以删除：

```text
/res remove 领地名
```

例如：

```text
/res remove myhome
```

注意：删除领地后，保护会消失，别人可能就可以破坏或进入。

---

## 第十一步：子领地

如果你在大领地里面想再划分一块小区域，可以创建子领地。

步骤：

1. 站在父领地内
2. 用木锄选择新区域
3. 输入：

```text
/res subzone 父领地名 子领地名
```

例如：

```text
/res subzone myhome shop
```

这样就在 `myhome` 里面创建了一个叫 `shop` 的子领地。

### 子领地隔离：大领地授权的人，子领地怎么单独 deny

**问题**：大领地 `/res padd` 或 `/res pset` 给了某人建造/使用/容器权限，这个权限**默认延伸到所有子领地**。你在子领地里只想让自己能动、别人不能动，但子领地怎么设置都不生效——别人还是能在子领地里建造/开门/开箱。

**解决**：在子领地里把那个人的权限显式 deny 掉：

```text
# 假设大领地叫 home，子领地叫 home.cave，朋友叫 bob
/res pset home.cave bob build false
/res pset home.cave bob destroy false
/res pset home.cave bob use false
/res pset home.cave bob container false
/res pset home.cave bob move false      # 连进都进不来（私密房间）
```

**关键点**：子领地权限**不会**自动从大领地"隔离"出来，必须反向写 `false`。只在子领地 `/res pset home.cave 自己 build true` 是不够的，大领地给别人的 allow 仍然会穿透到子领地。

---

## 第十二步：设置进入和离开提示

你可以设置别人进入或离开领地时看到的提示。

进入提示：

```text
/res message 领地名 enter 欢迎进入我的家
```

离开提示：

```text
/res message 领地名 leave 你已经离开我的家
```

例如：

```text
/res message myhome enter 欢迎来到 %player 的家
```

---

## 第十三步：扩展和缩小领地

如果你创建领地后想扩大范围：

```text
/res expand 数量
```

向你面对的方向扩展。

如果想缩小：

```text
/res contract 数量
```

---

## 第十四步：领地聊天

如果你和领地成员想私下聊天，可以加入领地频道：

```text
/res rc join
```

然后在领地频道发消息：

```text
/res rc 大家快来我家吃饭
```

离开领地频道：

```text
/res rc leave
```

---

## 基岩玩家注意事项

本服支持基岩版玩家通过 Geyser/Floodgate 连接。

**基岩玩家名带 `.` 前缀**（如 `.shangxin2179`）。

当你给基岩玩家设置领地权限时，**必须手打全名（含点）**：

```text
/res pset myhome .shangxin2179 build true
```

否则会报"找不到玩家"。

## 常见问题

### 1. 为什么我圈不了地？

可能原因：

- 没有木锄（圈地工具）
- 选区太小或太大
- 领地数量达到上限
- 没有创建领地权限
- 服务器限制了某些世界

可以先输入：

```text
/res select size
```

查看当前选区大小。

---

### 2. 为什么别人还能进我的领地？

可能是因为 `move` 权限没有关闭。

你可以输入：

```text
/res set myhome move false
```

但要注意，这样可能会影响你自己进出，需要根据服务器实际规则调整。

---

### 3. 为什么别人还能破坏我的方块？

检查 `build` 和 `destroy` 权限：

```text
/res set myhome build false
/res set myhome destroy false
```

如果别人有单独权限，还需要取消：

```text
/res pset myhome 玩家名 build false
/res pset myhome 玩家名 destroy false
```

---

### 4. 为什么我打不开箱子？

可能是你没有 `container` 权限。

如果你是领地主人，可以设置：

```text
/res set myhome container true
```

如果你想让朋友打开箱子：

```text
/res pset myhome 玩家名 container true
```

---

### 5. 我把自己权限删了，现在没法管理领地怎么办？

如果你不小心把自己的权限删了，导致自己都不能管理领地，可以找管理员帮忙：

管理员会用 `/resadmin pset 领地名 你的名字 admin true` 给你恢复权限。

**为什么会这样？**

Residence 把"领地所有权"和"操作权限"分成两层：

| 层级 | 说明 | 怎么改 |
|---|---|---|
| **Owner（所有权）** | 领地的"主人"字段 | 只有 `/res remove`（删除领地）或 `/resadmin setowner`（转移所有权）才会改变 |
| **权限（Flags/Perms）** | 谁能建造、谁能开门、谁能管理领地 | `/res pset`、`/res set`、`/res padd`、`/res pdel` 都能改 |

**为什么自己能踢自己？**

`/res pset`、`/res padd`、`/res pdel` 这些命令对**任何人**都生效，包括 owner 自己。Residence 没有"owner 不能修改自己权限"的保护机制。

如果你执行了：
- `/res pset myhome 你自己 build false` —— 把自己的建造权限关掉
- `/res pdel myhome 你自己` —— 把自己从成员列表里移除
- `/res pset myhome 你自己 admin false` —— 把自己的管理员权限关掉

你就会"锁在自己家门外"：领地还是你的（`/res list` 还显示），但你不能建造、不能开门、不能管理。

**解决方法：**

1. **管理员恢复**：`/resadmin pset 领地名 你的名字 admin true`
2. **自己恢复**（如果你还能进领地）：`/res setdefaultflags`
3. **删了重建**：`/res remove 领地名`，然后重新圈地创建

**注意**：不要对自己用 `/res pset 领地名 你自己 权限 false`，否则你会把自己锁在门外。

---

### 6. 子领地怎么设置都不生效？

**问题**：大领地给了别人权限，子领地怎么 deny 都没用。

**原因**：Residence 权限是**叠加继承**，不是自动隔离。大领地 `build: allow` → 子领地没显式设置 = 继承 allow。

**解决**：在子领地里把那个人的权限显式反向声明 `false`：

```text
/res pset 子领地名 玩家名 build false
/res pset 子领地名 玩家名 destroy false
/res pset 子领地名 玩家名 use false
/res pset 子领地名 玩家名 container false
```

## 新手推荐流程

1. 拿到木锄（圈地工具）
2. 左键第一个点
3. 右键第二个点
4. 输入 `/res create 领地名`
5. 输入 `/res info` 查看领地
6. 设置 `build`、`destroy`、`container` 等权限
7. 需要时给朋友单独权限
8. 需要时给朋友 admin 管理员权限
9. 使用 `/res tp 领地名` 传送回家

---

## 简单记忆版

```text
左键点A
右键点B
/res create 领地名
/res set 领地名 build false
/res pset 领地名 玩家名 build true
/res tp 领地名
```

掌握这几步，基本就能在服务器里安全建房、保护箱子、和朋友一起玩了。
