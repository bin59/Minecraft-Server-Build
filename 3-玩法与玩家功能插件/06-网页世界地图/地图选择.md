# 网页地图选型：Dynmap / BlueMap

两款网页地图插件对比，按"渲染风格 × 性能 × 生态"取舍。

## 在线 Demo（配图）

| 插件    | 官方 Demo                       | 备注                                       |
| ------- | ------------------------------- | ------------------------------------------ |
| BlueMap | https://bluecolored.de/bluemap/ | 官方 demo 地图，3D 旋转查看                |
| Dynmap  | 无官方 demo 页                  | 装好后浏览器开 `http://IP:8123` 看真实效果 |

## 详细功能

### Dynmap —— 功能最全的经典 2D 地图

- 渲染：Google Maps 风格 2D 俯视，多渲染器（性能版 / 高清 HD）；可选俯视、洞穴（cave）、扁平（flat）视图
- 实时：网页实时同步世界、白天/夜晚循环可视化、显示游戏时间与天气
- 玩家：玩家头像 + 实时位置标记
- 网页聊天（独有）：网页访客可直接与游戏内玩家聊天（聊天泡泡/聊天框）
- 标记系统：管理员命令或 API 放点/区域/文字标签；生态最全（WorldGuard/Towny/Residence 集成）
- 每世界独立标签页；内置 WebServer（8123）/ 可挂到现有 Apache 网站
- 平台：Bukkit/Spigot/Paper/Forge/Fabric；组件系统可加/删功能

### BlueMap —— 3D 沉浸式地图

- 渲染：Three.js/WebGL 3D 立体模型，鼠标自由旋转/缩放/平移；5.5+ 新增 2D flat 视图
- 增量渲染：只重渲变化区块，日常开销小
- 玩家标记：在线玩家位置（可关，隐私友好）
- 标记系统：marker API 可画多边形区域 + 文字标签（Residence 领地图层集成思路见 `BlueMap.md`）
- 资源包方块：自定义方块也能正确显示
- CLI 离线渲染（独有）：不跑服务端直接读存档烘焙静态站点
- 多服网络：BungeeCord/Velocity 多服地图合并到一张图
- 平台：Paper/Spigot/Purpur/Folia/Sponge/Fabric/Forge；内置 WebServer（8100）
- 版本：5.16-paper 已在本服测试服验证 ✅

## 对比表

| 维度         | Dynmap                                          | BlueMap                                 |
| ------------ | ----------------------------------------------- | --------------------------------------- |
| 渲染风格     | 2D 俯视（谷歌地图风）+ 可选等距                 | **3D 立体，可自由旋转/缩放**            |
| 视觉冲击力   | 中                                              | **高**（地形起伏、建筑立体感）          |
| 首次渲染     | 慢，需手动命令启动全量                          | 中（首渲几十分钟~数小时）               |
| 性能开销     | **最重**（组件多、持续渲染）                    | 中（3D 渲染吃 CPU，增量更新日常开销小） |
| 更新机制     | 实时瓦片更新                                    | **增量**（只重渲变化区块）              |
| 玩家标记     | ✅（含头像）                                    | ✅（可关，隐私友好）                    |
| 网页聊天     | ✅ 网页访客可与游戏内聊天                       | ❌                                      |
| 标记生态     | **最成熟**（WorldGuard/Towny/Residence 集成多） | 有 marker API，可自行集成 Residence     |
| 离线渲染     | ❌                                              | ✅ **CLI 离线烘焙静态站点**             |
| 配置复杂度   | 复杂                                            | 中等                                    |
| 磁盘占用     | 大                                              | 大（meshes 随探索增长）                 |

| 开发活跃度   | 老牌、更新慢                                    | 活跃                                    |

## 各自定位

### Dynmap：功能全面的经典之选

- 实时交互（网页可聊天）、信息丰富（游戏时间/天气）、高度可配置、平台支持广泛。
- 适合大型社区服，想要"谷歌地图"式全景 + 最全插件生态。
- 代价：最重、首渲慢（需手动 `/dynmap fullrender`）、配置复杂。

### BlueMap：3D 沉浸之选（本服采用）

- 浏览器 Three.js 渲染 3D 世界，鼠标旋转/缩放/平移；增量渲染只更新变化区块。
- 多世界标签、marker API（可叠加 Residence 领地图层）、CLI 离线烘焙静态站点。
- 支持 1.21.11 与 Folia；本服测试服已用 5.16-paper 验证通过（详见 `BlueMap.md`）。
- 代价：首渲吃 CPU/盘（建议配合 Chunky 预生成）、无网页聊天、Residence 集成需自研/找社区插件。

## 选型结论

- **功能全面 + 网页聊天 + 最大生态** → Dynmap（最重、渲染慢）
- **3D 冲击力 + 增量省资源 + 可离线出图** → **BlueMap** ✅

本服为生存社交服，目标给玩家/访客"看世界"的沉浸入口，3D 展示冲击力最强、性能适中、活跃维护、支持 1.21.x 与 Folia；**最终采用 BlueMap**。生产部署走"云端渲染 + 反代对外"，隐私上默认关 `player-markers`（见 `BlueMap.md`）。
