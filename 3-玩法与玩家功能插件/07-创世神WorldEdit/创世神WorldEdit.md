## 官方下载渠道

- **Modrinth**（推荐）：https://modrinth.com/plugin/worldedit
- **Bukkit / CurseForge**：https://dev.bukkit.org/projects/worldedit

这两个都是官方认可的发布平台，下载安全可靠。

---

## 下载安装步骤

1. 打开上面的链接
2. 在版本列表中选择**对应你服务器 Minecraft 版本**的文件
3. 注意选择**插件版（Plugin）**，不要选成模组版（Mod）
4. 下载后会得到一个 `.jar` 文件
5. 将该文件放入服务器的 `plugins` 文件夹
6. 重启服务器即可

## 安装后验证

重启服务器后，在游戏内输入以下指令确认安装成功：

- `/pl` 或 `/plugins` — 查看插件列表，确认 WorldEdit 已加载
- `//version` — 查看 WorldEdit 版本信息

---

## 配置文件位置

安装成功后，服务器会自动生成配置文件夹：

| 服务端类型 | 配置文件夹路径       |
| ---------- | -------------------- |
| 插件服     | `plugins/WorldEdit/` |
| 模组服     | `config/worldedit/`  |

其中 `schematics` 子文件夹用于存放建筑方案文件（`.schem` / `.schematic`）。

---

## 本服实际配置要点（2026-09-16 校准，对照 plugins/WorldEdit/config.yml）

| 配置项 | 实际值 | config.yml 行号 |
| --- | --- | --- |
| `wand-item`（`//wand` 给的选区工具） | `minecraft:wooden_axe`（木斧） | 第 147 行 |
| `navigation-wand.item`（导航杖，用于 `/jumpto` `/thru` `/unstuck` 等） | `minecraft:compass`（指南针） | 第 124 行 |
| `navigation-wand.max-distance` | `100` | 第 125 行 |
| 单次最大改动方块 `limits.max-blocks-changed` | `default: -1` / `maximum: -1`（无上限） | 第 20–22 行 |
| 垂直高度上限 `vertical-height` | `256` | 第 23–24 行 |
| 历史记录 `history` | `size: 15` / `expiration: 10` | 第 137–139 行 |
| 快照 `snapshots.directory` | 空（未配置快照目录，`//restore` 类功能不可用） | 第 120–121 行 |
| 方案保存目录 `saving.dir` | `schematics` | 第 131–132 行 |
| 不允许操作的方块 `disallowed-blocks` | 树苗/床/铁轨/草/花/作物/红石元件等一长串（见 config 第 34–94 行） | 第 34–94 行 |

> **刻意错开说明（重要）**：本服 WorldEdit 的导航杖 `navigation-wand` 是 **指南针 `minecraft:compass`**（第 124 行），而快捷菜单 QuickMenu 的触发物品是 **时钟 CLOCK**——两者刻意不同，避免冲突。`//wand` 给的是**木斧**（选区），别把导航杖当成 `//wand`。

以下是创世神（WorldEdit）的常用使用方法，按操作流程整理：

---

## 第一步：获取选区工具

输入 `//wand` 获得一把**木斧**，用它来框选你要操作的区域：

- **左键**点击方块 → 设定**第一点**（pos1）
- **右键**点击方块 → 设定**第二点**（pos2）

两个点之间构成的立方体就是你的操作选区。

> 也可以用指令代替：站在目标位置输入 `//pos1` 和 `//pos2`

---

## 第二步：常用编辑指令

#### 填充与替换

| 指令                          | 功能                     | 示例                         |
| ----------------------------- | ------------------------ | ---------------------------- |
| `//set <方块>`                | 将选区全部填充为指定方块 | `//set stone`                |
| `//replace <原方块> <新方块>` | 替换选区内的特定方块     | `//replace dirt grass_block` |
| `//walls <方块>`              | 只生成围墙（无顶无底）   | `//walls cobblestone`        |
| `//hollow`                    | 将选区内部挖空           | `//hollow`                   |

#### 复制粘贴与移动

| 指令             | 功能                 | 示例         |
| ---------------- | -------------------- | ------------ |
| `//copy`         | 复制选区内容         | `//copy`     |
| `//paste`        | 在当前站位粘贴       | `//paste`    |
| `//paste -a`     | 粘贴时忽略空气方块   | `//paste -a` |
| `//move <距离>`  | 将选区向面朝方向移动 | `//move 10`  |
| `//stack <次数>` | 向面朝方向连续复制   | `//stack 5`  |

#### 旋转与镜像

| 指令              | 功能                     | 示例          |
| ----------------- | ------------------------ | ------------- |
| `//rotate <角度>` | 顺时针旋转（90/180/270） | `//rotate 90` |
| `//flip <方向>`   | 镜像翻转                 | `//flip east` |

#### 生成几何体（无需选区）

| 指令                          | 功能         | 示例                      |
| ----------------------------- | ------------ | ------------------------- |
| `//sphere <方块> <半径>`      | 生成实心球体 | `//sphere glass 5`        |
| `//hsphere <方块> <半径>`     | 生成空心球体 | `//hsphere stone 10`      |
| `//cyl <方块> <半径> <高度>`  | 生成实心圆柱 | `//cyl oak_planks 5 10`   |
| `//hcyl <方块> <半径> <高度>` | 生成空心圆柱 | `//hcyl cobblestone 8 12` |

---

## 第三步：撤销与重做

操作失误时非常实用：

- `//undo` — 撤销上一步操作
- `//redo` — 恢复被撤销的操作

---

## 第四步：选区调整

| 指令                       | 功能                 |
| -------------------------- | -------------------- |
| `//expand <数量> [方向]`   | 扩大选区             |
| `//contract <数量> [方向]` | 缩小选区             |
| `//expand vert`            | 垂直扩展到基岩到天空 |
| `//size`                   | 查看选区大小         |
| `//desel`                  | 取消选区             |

---

## 第五步：保存与加载建筑（schematic）

可以把建好的建筑保存为文件，以后随时加载使用：

- **保存**：选好区域 → `//copy` → `//schem save 文件名`
- **加载**：`//schem load 文件名` → `//paste`

> 文件存放位置：`plugins/WorldEdit/schematics/`

---

## 新手快速上手流程

> 1. `//wand` 获取木斧
> 2. 左键点一个角，右键点对角 → 框选区域
> 3. `//set stone` 填充石头
> 4. 不满意就 `//undo` 撤销
