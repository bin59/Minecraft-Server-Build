## 自定义资源

> 提示
>
> 如果你想专门切换到 `emerald`、`diamond`、`iron` 和 `gold`，可能还希望在服务器上加入 Hypixel 的其他特性，比如升级系统。在这种情况下，我们建议你查看 [SBA](https://www.spigotmc.org/resources/sba-screaming-bedwars-addon-1-8-8-1-20-1.99149/)。

打开配置文件（`plugins/BedWars/config.yml`）并向下滚动，直到找到名为 `resources` 的部分。使用 `Ctrl+F` 可以帮你快速搜索到它。

下面是一个如何添加 `emerald`、`diamond`、`iron` 和 `gold` 的示例。


## 数据库连接

在 config.yml 中可以找到一个名为 `database` 的部分。在该部分下，你可以配置数据库连接。目前官方仅支持 MySQL 和 MariaDB，但配置也允许你为更新版本的数据库系统提供自定义驱动，或为其他类 SQL 数据库系统（如 PostgreSQL）提供驱动。欢迎提交 Pull Request 来完善对不同数据库系统的支持 :)

要启用数据库连接，你需要指定将某些内容保存到数据库中。目前只有统计数据可以保存到数据库。要启用此功能，请找到 `statistics` 部分，并将 `type` 从 `yaml` 切换为 `database`。

database 部分包含以下字段：

* `host` 是数据库服务器的主机名或 IP 地址，默认为 `localhost`。
* `port` 是数据库服务器的端口，默认为 `3306`，即 MySQL/MariaDB 的默认端口。
* `db` 是数据库的名称，默认为 `database`
* `user` 是数据库系统中拥有指定 `db` 访问权限的用户。该用户需要能够修改数据库的结构。默认为 `root`，不过应用程序不应拥有 root 权限。
* `password` 是数据库用户的密码。默认为 `secret`，不过你应该选择更安全的密码（最好是随机生成的）。
* `table-prefix` 是一个字符串，会被添加到表名之前，默认为 `bw_`。
* `type` 是数据库系统的类型，默认为 `mysql`（使用 MySQL 驱动时对 MySQL 和 MariaDB 均有效）。
* `driver` 是将要使用的驱动。有两种可选方式：
  * 可以将其设置为 `default`。驱动会根据 type 自动选择。Spigot 和 Paper 服务器都为 `mysql` 类型提供了驱动。其他插件也可能向 classpath 提供其他驱动。
  * 要使用第三方驱动，请指定其路径，例如 `mysql-connector-j-8.0.0.jar`。该路径始终相对于 `plugins/BedWars` 文件夹，因此我们建议将 jar 放入此文件夹。驱动需要兼容 JDBC 4。该驱动对其他插件不可见，也不会以任何方式影响它们。
* `params` 是一个映射，包含驱动的特定选项。在修改之前，你应该查阅所选数据库系统的文档。默认设置了以下参数：
  ```yaml
  params:
    useSSL: false  # change this to true if your database server requires SSL or runs on a different machine and has SSL enabled
    serverTimezone: Europe/Prague  # default value is based on your system
    autoReconnect: true
    cachePrepStmts: true
    prepStmtCacheSize: 250
    prepStmtCacheSqlLimit: 2048
  ```

> 警告：驱动版本
>
> 如果你使用的是古老的 Minecraft 版本（如 1.8.8），但 MySQL/MariaDB 是较新版本，Spigot 1.8.8 内置的驱动可能不兼容。请在[这里](https://dev.mysql.com/downloads/connector/j/)获取新版 MySQL Connector J：选择 Platform Independent，下载压缩包并从中解压出 mysql-connector-j-8.x.x.jar 文件（压缩包中的其他文件无关紧要）。将该 JAR 文件放入 `plugins/BedWars` 文件夹，并将 `driver` 从 `default` 改为该文件名，例如 `mysql-connector-j-8.4.0.jar`。

> 信息：stats_players 表结构
>
> 在某些特定情况下，数据库表的自动创建可能会失败。此时你可能需要手动创建它，使用以下代码或其变体。
>
> ```sql
> CREATE TABLE IF NOT EXISTS `bw_stats_players` (
>   `kills` int(11) NOT NULL DEFAULT '0',
>   `wins` int(11) NOT NULL DEFAULT '0',
>   `score` int(11) NOT NULL DEFAULT '0',
>   `loses` int(11) NOT NULL DEFAULT '0',
>   `name` varchar(255) NOT NULL,
>   `destroyedBeds` int(11) NOT NULL DEFAULT '0',
>   `uuid` varchar(255) NOT NULL,
>   `deaths` int(11) NOT NULL DEFAULT '0',
>   PRIMARY KEY (`uuid`)
> );
> ```

## 游戏特效

在 config.yml 中可以找到一个名为 `game-effects` 的部分。在这里你可以设置一些视觉特效，以增强你的游戏体验。

### 事件

* `end` — 游戏结束时触发此特效。
* `start` — 游戏开始时触发此特效。
* `kill` — 有人击杀他人时触发此特效。
* `teamkill` — 有人击杀他人且床或其他目标方块被摧毁时触发此特效。
* `lobbyjoin` — 有人进入大厅时触发此特效。
* `lobbyleave` — 有人离开大厅时触发此特效。
* `respawn` — 有人重生时触发此特效。
* `beddestroy` — 有人摧毁床或其他目标方块时触发此特效。
* `warppowdertick` — 有人被 Warp Powder 传送时触发此特效。

### 特效类型

* `Particle` — [粒子特效（点击此处查看列表）](https://hub.spigotmc.org/javadocs/bukkit/org/bukkit/Particle.html)
* `Effect` — [特效（点击此处查看列表）](https://hub.spigotmc.org/javadocs/bukkit/org/bukkit/Effect.html)
* `Firework` — 发射烟花
* `List` — 在一个事件上叠加多种特效

#### Particle

```yaml
game-effects:
  start:
    type: Particle
    value: LAVA # uppercase key from the list
    # options below are optional
    count: 2 # how many particles will be spawned (default - 1)
    offsetX: 1 # offset from the event location (default - 0 for each coordinate)
    offsetY: 1
    offsetZ: 1
    extra: 1 # extra data, depends on each particle (default - 1)
```

#### Effect

```yaml
game-effects:
  start:
    type: Effect
    value: DOOR_CLOSE # uppercase key from the list
```
