猫薄荷
Catnip是一款专为PaperMC设计的插件，旨在优化猫咪的行为表现，并在玩家与他们驯养的猫咪之间建立完善的互动关系。

特点
🐾 亲密关系系统
猫薄荷为被驯服的猫咪带来了持续的亲密关系机制。这种亲密关系的程度会影响猫咪的行为，玩家也可以随时查看这一数值。

增进亲密关系
玩家可以通过喂食或与猫咪玩耍等积极的互动方式，来加深与它们之间的亲密关系。

亲密度下降
：如果攻击了一只已被驯服的猫，那么与它的亲密度将会大幅降低。

键合衰减
：如果长时间不照顾猫咪，其键合能级会自然下降。

🧠 更强大的人工智能与行为能力
猫薄荷为被驯服的猫咪设计了多种自定义目标与行为：

亲密度较高的猫咪（亲密度达到85%或以上）偶尔会主动靠近主人并拥抱它们，同时还会发出呼噜声，还有爱心图案出现。

进行“打斗”游戏
。那些与主人之间的亲密程度较低（低于35%）的猫，可能会与主人玩打斗的游戏，过程中会有轻微的伤害，同时还会发出嘶嘶声。

物品互动
猫会主动玩弄掉在地上的物品，具体来说：

字符串
鱼类（鳕鱼和三文鱼）
与环境互动
猫咪可能会选择坐在温暖的物体上，比如：

炉子
高炉
吸烟者
他们也可能躺在红毯上。

偷鱼行为
：当附近的箱子被打开时，猫就有机会偷走箱子里的鱼，然后带着那些鱼逃走。

命令
命令 描述
/catbond [player] 显示指定玩家所拥有的所有猫咪的绑定等级、名称以及项圈颜色。如果未指定玩家，则会显示发送者自己的猫咪信息。
权限
许可 描述 违约
catnip.bond 允许玩家查看自己的与猫咪的亲密程度。 true
catnip.admin 可以查看其他玩家猫咪的亲密度，并在有新成员加入时收到通知。 op
技术要求
平台：PaperMC
API版本：1.21
依赖项：使用bStats来收集匿名指标数据。
