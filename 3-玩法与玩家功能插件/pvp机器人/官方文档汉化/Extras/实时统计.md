# 实时统计（Live stats）

> 原文：[Live stats](https://mods.icondice.org/vexbot/wiki/live-stats)

> 公开统计页面：它展示什么、发送什么，以及如何关闭。

mods.icondice.org/vexbot/stats 展示当前各服务器上 VexBot 机器人正在做什么，数据来自每一台运行 VexBot 3.0 或更新版本的服务器。在顶部选择一个版本，可以只看某一个版本。

## 展示内容

- 当前在线的机器人和服务器数量，每秒更新。
- 机器人上线图表：1H、1D、1W、1M 或 ALL，折线图或股市 K 线图样式，并显示涨跌幅度。
- 机器人击杀数（点击可切换查看玩家、怪物和机器人）、机器人死亡数、以半心为单位计算的伤害、生成的机器人数量、创建的队伍数量和同时在线机器人峰值。
- 使用最多的命令、最常见的机器人名字、已安装和已下载的扩展。
- 更多统计：放置和挖掘的方块、机器人击破和穿透的盔甲套装、机器人和玩家触发的图腾、放置的蜘蛛网。

## 发送什么

只发送计数，每 5 秒一次（在有变化时）：上述数字、命令名、附加组件 ID、VexBot 和 Minecraft 版本、Fabric 或 Paper，以及一个随机的安装 ID。最常见的机器人名字以小写形式发送；一个名字只有在 3 台服务器使用后才会出现在页面上。绝不发送玩家名字、UUID、IP、坐标或聊天内容。只有玩家或控制台输入的命令会计数——命令方块不算。

## 关闭它

```
/vexbot settings stats off
```

默认开启。关闭会立即停止所有计数和发送。当统计服务器无法访问时，VexBot 会停止尝试并安静地定期重试，所以离线服务器永远不会变慢。
