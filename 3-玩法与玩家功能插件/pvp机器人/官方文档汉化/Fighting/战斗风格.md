# 战斗风格（Playstyles）

> 原文：[Playstyles](https://mods.icondice.org/vexbot/wiki/playstyles)

> 每台机器人的性情：它投入到什么程度、什么时候逃跑、如何使用安全网。

战斗风格位于难度和技巧之上，改变的是机器人“想做什么”，而不是“做得有多好”。它按机器人名字存储，因此重生后依然保留。

| 战斗风格 | 行为 |
| --- | --- |
| default | 默认平衡 |
| aggressive | 投入更猛、脱战更晚，为了伤害冒更多险 |
| safe | 重视存活：更早回血、蛛网封箱绝境翻盘、被连招时扔珍珠脱身 |
| defensive | 守住阵地打反击，而不是追击 |
| balanced | 介于 default 与 safe 之间 |
| adaptive | 随战局变化而调整 |

```
/vexbot playstyle <style> <targets|all>
/vexbot team <team> playstyle <style>
/vexbot randomplaystyle <targets|all>
/vexbot randomplaystylechances <style> <weight>
```

randomplaystyle 为每台机器人独立随机，所以一队人出来时风格各异，而不是六个一模一样的战士。权重是相对值——不必加起来等于 100——randomplaystylechances list 会显示每个风格实际占比多少。
