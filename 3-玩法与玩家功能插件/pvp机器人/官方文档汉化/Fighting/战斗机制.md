# 战斗机制（How a fight works）

> 原文：[How a fight works](https://mods.icondice.org/vexbot/wiki/combat)

> 选目标、近战、盾牌、图腾、回血与补给。

## 选择目标

开启 autotarget 后，机器人会在 targetplayers、targetbots 和 targetmobs 开关允许的范围内猎杀目标。来自 /vexbot attack 或 teamtargets 的队伍指令会覆盖这一切。revengemode 让机器人被打后反击；在一个开启了复仇的队伍里，打其中一台机器人就会引来全队围攻你。

## 开场

机器人一旦选中你，并不会沿直线朝你冲刺。它走向你身旁一个左右漂移的点位，不时停下来观察你的动作，最后几格绕着弧线靠近而不是直冲正中——全程都在盯着你。长距离接近时它步行，只在接近终点时才开始冲刺。

> 这只是开场。从双方任意一方命中第一击起，机器人在这场战斗剩余时间里的移动和战斗方式就和它一贯的打法完全一样，即使你俩分开又重新汇合。重锤、长矛重锤、鞘翅重锤、无烟花和三叉戟套装完全跳过开场——它们的开场就是俯冲或冲刺——以及一个白送的惩罚窗口，比如抓住你咬食物的硬直。

它游走的幅度随难度缩放，用的是同一个控制绕圈步宽的旋钮：PERFECT 难度的机器人漂移很小，大约十格外就开始冲刺；easy 难度的机器人游走明显，五格内才开始投入。

## 近战

> 战斗打到墙角时，机器人不再一头撞进墙里。任何会把它推进实体墙面的动作都会被放弃，贴着墙走的动作则保留，于是它会绕墙滑过去——包括命中后的后撤步，以前那一步会直接倒着撞进身后的东西里。

机器人遵守原版攻击距离——默认 3 格，和你一样，可用 attackrange 调整。它会等冷却、瞄准暴击、跳跃重置以减少承受的击退，并按难度设定的角度横移。

## 盾牌

举着盾的机器人会像玩家一样承受剩余伤害、护甲损耗和击退。它看到你的盾牌就会用斧子劈，破盾速度和等待的蓄力程度都是难度旋钮。在 SMP 上，副手先放图腾——只有图腾用光了才掏出盾牌。

## 存活

- 低于你用心数设定的阈值时撤退进食，关闭 retreat 则原地进食
- 开启 enderpearl 时用珍珠传送脱身，而不是逃跑
- 战斗中修补护甲，而不是让某一件坏掉
- 用水桶 MLG 接住坠落，成功率由 clutch 旋钮控制
- 吃下紫颂果，从挖不出去的蛛网里传送脱身
- **在饥饿值只剩三格时停下进食**，不管它刚才在做什么——包括重锤连招中途。它会拿背包里饱和值最高的普通食物（牛排优先于金苹果，因为金苹果是战斗资源），一口就够

被连招也有应对：机器人跳跃重置来扛过连招链，用暴击还击而不是平换，一旦交换明显落败就扔珍珠脱身。它能做到这些的频率跟随 accuracy 旋钮，所以弱的机器人也会像弱的玩家一样被连死。

## 补给

物资不足时，机器人会走到潜影盒旁补充。它只拿自己缺的那部分——四个图腾、十六颗珍珠、八个金苹果、每种武器各备一把——这样盒子能用很久，也不会塞满。建筑方块或经验瓶用完了也算不足。

机器人还会从地上捡有用的东西：击杀掉落物，或者附近更好的一件护甲。`/vexbot pickuploot off` 会阻止它捡地上任何东西，包括你丢的物品。

## 从末影箱重整装备

开启 `/vexbot settings enderchestregear`（自 2.2.10 起**默认开启**）后，机器人会像 SMP 上的人那样重整装备：用珍珠脱离战斗，把末影箱放在自己身旁，拿出一个潜影盒、从里面补货、把潜影盒放回去，再带着箱子走。不会留下任何东西站在那里——跑路的每一种结局都会把箱子收走，包括放置失败或你在它重整途中追上它。

它需要背包里有一个末影箱，箱里有一个有用的潜影盒。用 `/vexbot view enderchest <bot>` 给它备货，这个界面正是因为这个原因可编辑。

它不会在你面前开箱子——开一个箱子要站着不动将近十秒——所以它需要先和你拉开真实距离或隔着一堵墙，在那之前它会继续战斗。它会趁你走开、视线被挡或停下进食时抓住窗口。重整装备在装备还剩大约一场战斗的耐久时就开始，而不是等耐久打光。

## 查看机器人的背包

```
/vexbot view inventory <player>     # read-only: hotbar, armour, offhand
/vexbot view enderchest <player>   # EDITABLE — drop a shulker or a spare set in
```
