# 入门指南（Getting started）

> 原文：[Getting started](https://mods.icondice.org/vexbot/wiki/getting-started)

> VexBot 是什么、需要什么，以及让一台机器人开打所需的五条命令。

VexBot 会在你的服务器上生成假玩家，像真人一样战斗。它们不是披着皮肤的怪物：它们手持物品、穿戴护甲、承受击退、吃东西、格挡、暴击、扔末影珍珠，并且像任何普通玩家一样死亡。下面的一切都发生在服务端，因此任何人用原版客户端都能加入并与它们对战。

## 需求

- Minecraft 1.21.11、26.1.2 或 26.2 —— 运行在 Fabric 上，或运行在 Paper 服务端上（3.0 新增）。每个版本各有一个 jar；参见 Which build do I install?
- Fabric API（仅 Fabric —— Paper 插件不需要任何额外东西）
- 1.21.11 用 Java 21，26.x 构建用 Java 25 —— 游戏本身要求如此
- 仅服务端 —— 加入的玩家不需要安装这个 mod

## 你的第一台机器人

```
/vexbot spawn Steve
```

如果不写名字，它会用一个默认名字在你脚下生成一台机器人。给它一个对手：

```
/vexbot attack Steve @p
```

然后清理掉：

```
/vexbot kill Steve
```

## 你真正会用到的五条命令

| 命令 | 作用 |
| --- | --- |
| /vexbot spawn <name> | 在这里生成一台机器人 |
| /vexbot mass_spawn <count> | 一大群机器人 |
| /vexbot givekit <kit> <target> | 用保存好的 kit 给它们换装 |
| /vexbot team <name> | 打开某个队伍的设置界面 |
| /vexbot settings | 打开设置宝箱 |

> 几乎每条命令在需要填名字的地方都接受 @ 选择器，所以一条命令可以同时作用于所有机器人。参见 Targets and selectors。

## 接下来去哪

- Commands —— 完整命令列表
- Settings —— 每一个开关及其作用
- Difficulty —— 它们有多难打
- Kits —— 保存和发放装备

> VexBot 会向公开的 Live stats 页面发送匿名使用统计（在线机器人数、击杀数、命令名 —— 绝不包含玩家名或 IP）。默认开启；`/vexbot settings stats off` 可关闭。
