# 设置（Settings）

> 原文：[Settings](https://mods.icondice.org/vexbot/wiki/settings)

> 全部 70 项设置：每一项的作用，以及如何修改。技巧（Techniques）本身也是一种设置。

设置默认是全局的，作用于所有未加入队伍的机器人。队伍可以覆盖其中任意一项，该队伍中的机器人使用队伍自己的那份设置。

```
/vexbot settings                       # open the chest
/vexbot settings list                  # print everything
/vexbot settings <setting> <value>     # set one
/vexbot team <team> settings <setting> <value>
```

这个箱子界面有六行，并分页。左键切换或选下一个值，右键回退，按住 Shift 时数字和百分比会以更大的步长变化。它是根据与命令相同的列表生成的，因此永远包含全部设置。
