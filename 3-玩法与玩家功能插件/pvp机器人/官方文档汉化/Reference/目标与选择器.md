# 目标与选择器（Targets and selectors）

> 原文：[Targets and selectors](https://mods.icondice.org/vexbot/wiki/selectors)

> @b、@a、@e、@p、@r 与 @s —— 如何让一条命令同时指向多台机器人。

任何命令在需要填写机器人或玩家名字的位置，都可以用一个选择器代替名字。这正是 VexBot 能用于命令方块的原因：一条命令，作用于所有机器人。

| 选择器 | 指向的对象 |
| --- | --- |
| @b | 服务器上的每一台 VexBot 机器人 |
| @a | 每一位真实玩家 |
| @e | 所有人——机器人和玩家 |
| @p | 距离执行命令者最近的玩家 |
| @r | 随机一台 |
| @s | 执行命令者本人 |
| <name> | 按名字指定一台机器人或玩家 |

```
/vexbot randomplaystyle @b
/vexbot givekitid @b VBK3-XXXX
/vexbot attack @b @p
```

> 选择器是 VexBot 自己的参数，不是原版选择器，因此不支持 `[distance=..]` 这类过滤器。机器人按名字匹配，玩家按真实账号名匹配。
