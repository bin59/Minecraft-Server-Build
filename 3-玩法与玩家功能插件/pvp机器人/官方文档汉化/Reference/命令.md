# 命令（Commands）

> 原文：[Commands](https://mods.icondice.org/vexbot/wiki/commands)

> 3.0 版本里的每一条 /vexbot 命令，全部取自命令树。

所有命令都以 /vexbot 开头。每一级都支持 Tab 补全，凡是需要填机器人名字的位置，也都接受 @ 选择器。除非服务器另行设置，命令需要权限等级 2（gamemaster）才能执行。`[ ]` 表示可选，`( | )` 表示从中选一个。

## 机器人

```
/vexbot spawn [<name>] [<pos>] [<kit>]
/vexbot mass_spawn <count> [<pos>]
/vexbot kill [<name>]
/vexbot list
/vexbot view (inventory|enderchest) <name>
/vexbot tag [on|off]
/vexbot nick <player> (stop|<nickname> [<skin>])
/vexbot movement (freeze|unfreeze)
/vexbot look <bot> (stop|pitch|yaw|<pos>|<target>)
/vexbot lookat <bot> (stop|pitch|yaw|<pos>|<target>)
/vexbot playstyle (list|<style> (all|<targets>))
/vexbot randomplaystyle (all|<targets>)
/vexbot randomplaystylechances [list|reset|<style> <weight>]
/vexbot spawnarea [show|clear|off|here <radius>|set <from> <to>]
/vexbot namepool (list|none|<pool>)
/vexbot pickuploot [<value>]
/vexbot goto <bot> (stop|<pos>|<target>) [then attack <target>|then hold]
/vexbot path (list|create|add|info|show|delete|removepoint|mode|walk|assign|spread|stop) …
```
