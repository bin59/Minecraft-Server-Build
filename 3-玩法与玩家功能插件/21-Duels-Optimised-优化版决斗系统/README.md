# Duels Optimised — 优化版决斗系统

> 玩家之间约架 1v1 的决斗插件：选定装备 kit、自动传送到竞技场、打完恢复状态，支持多种 PvP 规则模式。

## 基本信息

| 项目     | 内容                                         |
| -------- | -------------------------------------------- |
| 插件名   | Duels Optimised（Modrinth）                  |
| 命令前缀 | `/duels`（玩家常用 `/duel <玩家>` 发起挑战） |
| 数据目录 | `plugins/Duels/`                             |
| 语言文件 | `lang.yml`（游戏内消息全可改）               |
| 扩展机制 | 自带 extension 系统，按需加装额外功能模块    |

如何将扩展程序上传到服务器？
借助扩展系统，你可以轻松为对决功能添加各种额外特性，比如自动重置的战斗场地、全息排行榜以及占位符等。只需下载相应的扩展插件，将其放入plugins/Duels/extensions/文件夹中，然后启动服务器即可。

## 玩法流程

1. 玩家 `/duel <玩家名>` 向对方发起决斗邀请；
2. 对方接受后，双方选/自动分配一个 kit（装备预设）；
3. 插件把两人传送到一个空置竞技场；
4. 战斗结束（一方死亡/投降/超时），胜利者判定，双方恢复血量、物品、位置；
5. 旁观者可观战，可 rematch（再来一局）。

## 支持的规则模式

通过 `/duels options` 给 kit 一键开启：

- **SOUP**：喝药水碗回血（经典 SoupPvP）
- **SUMO**：把对方推下平台摔死（无装备）
- **UHC**：不开自然回血，只能吃金苹果/药水
- **COMBO**：极限连击（NoDebuff 类）
- **PERMISSION**：按权限决定谁能用哪个 kit
- **ARENASPECIFIC**：把竞技场和 kit 绑定，某些图只能打特定模式

## 管理员命令

| 命令              | 作用                                                                  |
| ----------------- | --------------------------------------------------------------------- |
| `/duels options`  | 配置 kit 规则模式（SOUP/SUMO/UHC/COMBO 等）                           |
| `/duels bind`     | 把竞技场绑定到指定 kit（限定某图只能打某模式）                        |
| `/duels setlobby` | 在你当前站位设置决斗大厅（等候/结束落点），不设则临时用世界出生点     |
| `/duels reload`   | 重载配置与 lang.yml                                                   |
| 建场              | 设置竞技场出生点 1/2、边界、图图标（一般在 `/duels` 管理 GUI 内完成） |
| 建 kit            | 穿好装备后保存为 kit，在编辑器里调整格子                              |

## 配置要点

- **`lang.yml`**：所有提示文案汉化在这做，改完 `/duels reload`。
- **竞技场**：先建场、设两个出生点和边界，再绑 kit；没绑的场所有 kit 都能用。
- **Kit**：穿好想要的装备 → 保存为 kit → 在 options 里开对应规则。想做"无装备推人"就建空 kit 开 SUMO。
- **扩展**：需要战绩统计、ELO、下注（bet）之类时，看它的 extension 列表加装。

## 社区 kit 资源与自建

Duels Optimised **没有公开的 `kits.json` 可直接导入**。它的 kit 不是开放格式，必须在游戏内穿好装备后 `/duels savekit <名字>` 保存，或用 `/customkits` GUI 摆。
