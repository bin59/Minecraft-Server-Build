ScreamingBedWars 插件使用我们自研的库 **SimpleInventories** 来创建并渲染基于背包的 GUI（包括商店）。本文介绍商店物品格式的基础用法。更多高级特性请参阅 [SimpleInventories Wiki](https://github.com/ScreamingSandals/SimpleInventories/wiki)。

## 创建新物品

要创建新物品，你需要知道物品的内部名称。可以在 [Minecraft Wiki](https://minecraft.wiki) 上查询。名称通常以 `minecraft:` 开头，但此前缀可以省略。

在旧版环境（1.8.8–1.12.2）中，你也可以使用新版名称。如果不生效，请参阅[此页面](https://helpch.at/docs/1.12.2/org/bukkit/Material.html)查找旧的材料名称。请注意，旧名称已被弃用，未来的 BedWars 版本可能不再支持。

定义物品支持两种格式：`short stack` 和 `long stack`。

### 使用 short stack

short stack 格式仅支持材料名称、数量、显示名称和 lore。除材料外，其余各部分均为可选，并用分号（`;`）分隔。

```yaml
items:
- stone
- dirt;2
- diamond_pickaxe;;Super Sword
- tnt;3;Trinitrotoluene;Does explode
```

要让物品可购买，添加 `for <amount> <resource>`：

```yaml
items:
- stone for 1 bronze
- dirt;2 for 3 iron
- diamond_pickaxe;;Super Sword for 5 gold
- tnt;3;Trinitrotoluene;Does explode for 9 iron
```

要使用额外属性（例如[特殊物品](specials.md)中用到的 `properties`），只需将字符串格式转换为带 `stack` 和 `price` 键的映射：

```yaml
items:
- stack: stone
  price: 1 bronze
- stack: dirt;2
  price: 3 iron
- stack: diamond_pickaxe;;Super Pickaxe
  price: 5 gold
- stack: tnt;3;Trinitrotoluene;Does explode
  price: 9 iron
```

### 使用 long stack

long stack 格式允许对物品进行完全控制——附魔、lore、显示名称等。

下面看看上一个例子用 long stack 重写后的样子：

```yaml
items:
- stack: 
    type: stone
  price: 1 bronze
- stack: 
    type: dirt
    amount: 2
  price: 3 iron
- stack: 
    type: diamond_pickaxe
    display-name: Super Pickaxe
  price: 5 gold
- stack: 
    type: tnt
    amount: 3
    display-name: Trinitrotoluene
    lore:
    - Does explode
  price: 9 iron
```

现在，给我们的 Super Pickaxe 附上 Fortune III（时运 III）。

```yaml
- stack: 
    type: diamond_pickaxe
    display-name: Super Pickaxe
    enchants:
      fortune: 3
  price: 5 gold
```

附魔名称请参阅[此列表](https://www.digminecraft.com/lists/enchantment_list_pc.php)。

可用选项的完整列表请参阅[此页面](https://github.com/ScreamingSandals/SimpleInventories/wiki/Variable:-stack)。

## 将物品用作分类

你可以把任意物品用作分类入口（即使该物品本身已在另一个分类中）。当玩家点击该物品时，会打开对应的子分类。实现方式很简单：在物品中添加一个名为 `items` 的新列表。分类内 `items` 的格式与基础 `data` 列表相同。

```yaml
- stack: 
    type: diamond_pickaxe
    display-name: Super Pickaxes
    lore:
     - You will never mine with anything else!
  items:
    - wooden_pickaxe for 10 gold
    - golden_pickaxe for 20 gold
```

## 自定义物品

有时你可能想出售仅靠 long stack 选项无法表达的物品。此时可使用 `tag` 字段，以 SNBT（字符串化 NBT）格式定义额外的物品数据。

示例：

```yaml
- stack:
    type: diamond_pickaxe
    tag: '{Enchantments:[{lvl:3,id:fortune}]}'
```

这会创建一把带有 Fortune III 的钻石镐。请注意，tag 格式取决于 Minecraft 版本。

### 新版中的 tag

自 Minecraft 1.20.5 起，物品数据采用新的 data components 格式。下面是同一把镐在 Minecraft 1.21.4 中的定义方式：

```yaml
- stack:
    type: diamond_pickaxe
    tag: '{enchantments:{levels:{fortune:3}}}'
```

请注意，`tag` 要求的这种 SNBT 格式与游戏内现今使用的命令格式略有不同：

```
/give @a diamond_pickaxe[enchantments={levels:{fortune:3}}]
```

将此类命令转换为有效的 tag 格式：

1. 提取方括号部分：
    ```
    [enchantments={levels:{fortune:3}}]
    ```
2. 将开头的 `[` 替换为 `{`，结尾的 `]` 替换为 `}`：
    ```
    {enchantments={levels:{fortune:3}}}
    ```
3. 将所有顶层的 `=` 替换为 `:`：
    ```snbt
    {enchantments:{levels:{fortune:3}}}
    ```

现在你就得到了 `tag` 键的合法值。

### 用 tag 升级物品

由于 tag 与版本相关，升级服务器可能导致旧 tag 失效。自 ScreamingBedWars 0.2.37 起，你可以添加 `DataVersion` 字段，让游戏自动升级 tag：

```yaml
- stack:
    type: diamond_pickaxe
    DataVersion: 1343
    tag: '{Enchantments:[{lvl:3,id:fortune}]}'
```

这里的 `1343` 是 Minecraft `1.12.2` 的数据版本。每当服务器在更新版本上加载时，tag 都会被升级，而文件本身保持不变。

Minecraft 数据版本可在[此 Wiki 页面](https://minecraft.wiki/w/Data_version)上查询。

## 物品定位

默认情况下，物品按从左到右、从上到下的顺序渲染。不过 SimpleInventories（以及 ScreamingBedWars）允许你通过定位指令控制布局。这些指令有助于对齐、调整间距，以及将物品组织成行、列，甚至多个页面。

### `skip`

在下一个物品放置前跳过若干格子。

```yaml
- stack: chest for 1 bronze
  skip: 3
```

![skip 效果演示](assets/positioning/skip-1.png)

### `column` 与 `row`

用这些指令把物品放到指定的列或行。`column` 从 `0` 开始计数，而 `row` 从 `1` 开始。
对于 `column`，你还可以使用特殊值：`left`、`center` 和 `right`，以代替数字。

```yaml
- stack: iron_block for 10 gold
  column: 1
- stack: glowstone for 5 iron
  row: 4
  column: center
```

![column 效果演示](assets/positioning/column-1.png)

![row 效果演示](assets/positioning/row-1.png)

### `linebreak`

强制下一个物品放到新的一行。可以把它想象成在某个物品后按下“回车”。

`linebreak` 有三个合法取值：

* `before` - 在物品渲染前换行
* `after` - 在物品渲染后换行
* `both` - 同时应用 `before` 和 `after`

```yaml
- stack: ender_chest for 5 iron
  linebreak: before
```

![linebreak 效果演示](assets/positioning/linebreak-1.png)

### `pagebreak`

强制下一个物品放到新的一页。

与 `linebreak` 类似，`pagebreak` 接受三个取值：

* `before` - 在物品渲染前换页
* `after` - 在物品渲染后换页
* `both` - 同时应用 `before` 和 `after`

```yaml
- stack: ender_chest for 5 iron
  pagebreak: after
- stack: gunpowder for 5 iron
  row: 3
```

![pagebreak 效果演示](assets/positioning/pagebreak-1.png)

### `absolute`（不推荐）

把物品放到确切的格子索引处（从 `0` 开始）。这会绕过所有自动定位逻辑，仅在你需要完全手动控制时使用。

```yaml
- stack: obsidian for 20 gold
  absolute: 13
```

这会使布局更难维护，除非确有必要，否则**不推荐**使用。
