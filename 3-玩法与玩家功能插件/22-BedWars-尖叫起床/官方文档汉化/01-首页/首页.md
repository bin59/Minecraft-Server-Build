## 功能特性

- 完整的 BedWars 游戏基础玩法（床、队伍等）
- 其他 BedWars 变体：CakeWars / EggWars / AnchorWars / 以及你想创建的任何玩法
- 高度可自定义的商店，且每个竞技场可配置多个不同的商店
- 简单的 BungeeCord 与 Velocity 集成
- Vault 奖励与奖励命令
- 旁观者模式（旁观者也可加入进行中的游戏）
- 竞技场重建（非常快）
- 大厅和/或游戏内显示剩余时间的 BossBar 或 XP 进度条
- 可破坏方块（竞技场重建后刷新）/ 忽略的方块
- 特殊物品（RescuePlatform、TNTSheep 等），支持在商店中进行全局与本地配置
- 高度可配置，且支持按竞技场进行配置
- 以及更多……

## 安装

你可以从以下官方渠道之一下载 ScreamingBedWars。只需将 jar 放入 `plugins` 文件夹并启动服务器即可。

- [**Hangar**](https://hangar.papermc.io/ScreamingSandals/ScreamingBedWars)
- [**Modrinth**](https://modrinth.com/plugin/screamingbedwars)
- [**SpigotMC Forums**](https://www.spigotmc.org/resources/screaming-bedwars.63714/)
- [**Bukkit Dev (CurseForge)**](https://dev.bukkit.org/projects/screamingbedwars)
- [GitHub Actions](https://github.com/ScreamingSandals/BedWars/actions/workflows/build-0-2-x.yml) – 包含开发版快照，需要 GitHub 账号
- [Discord 服务器](https://screamingsandals.org/discord) – 在专属频道获取稳定版与快照版
