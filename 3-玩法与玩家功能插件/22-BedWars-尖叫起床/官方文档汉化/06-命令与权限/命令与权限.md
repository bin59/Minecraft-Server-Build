## 权限

* `bw.admin` - 允许你创建/编辑竞技场、重载插件，以及在启用时使用作弊命令。
* `bw.vip.startitem` - 允许你使用物品开始游戏。所有玩家将被自动分配到队伍。
* `bw.vip.forcejoin` - 允许你在游戏已满时仍加入（没有此权限的玩家将被踢出）。
* `bw.otherstats` - 允许你查看其他玩家的统计数据。
* `bw.admin.alljoin` - 允许你使用 /bw alljoin 命令。
* `bw.disable.joinall` - 保护你不受 /bw alljoin 命令效果影响。
* `bw.cmd.join` - 允许你使用 /bw join 命令。
* `bw.cmd.leave` - 允许你使用 /bw leave 命令。
* `bw.cmd.stats` - 允许你使用 /bw stats 命令。
* `bw.cmd.rejoin` - 允许你使用 /bw rejoin 命令。
* `bw.cmd.autojoin` - 允许你使用 /bw autojoin 命令。
* `bw.cmd.list` - 允许你使用 /bw list 命令。
* `bw.cmd.leaderboard` - 允许你使用 /bw leaderboard 命令。

每个权限都可以加上 `misat11.` 前缀。请注意，这种自我中心的做法已弃用，并将在未来版本中移除。

所有以 `bw.cmd.` 开头的权限默认即为允许，即使未显式授予该权限。这可以在 `config.yml` 的 `default-permissions` 小节中更改。

```yaml
default-permissions:
  join: true
  leave: true
  stats: true
  list: true
  rejoin: true
  autojoin: true
  leaderboard: true
```

## 命令

每条命令在括号中都标明了其对应的权限。

`<argument>` 为必填参数。
`[argument]` 为可选参数，未指定该参数时命令仍可执行。但是，位于该可选参数之前的每个可选参数都必须先指定，才能使用该参数。

### 玩家命令

* `/bw help` - 显示命令列表（无需权限）
* `/bw join [arena]` - 加入竞技场（权限：`bw.cmd.join`）
* `/bw leave` - 离开竞技场（权限：`bw.cmd.leave`）
* `/bw list` - 列出所有可用竞技场（权限：`bw.cmd.list`）
* `/bw stats` - 显示你的统计数据（权限：`bw.cmd.stats`）
* `/bw stats <player>` - 显示该玩家的统计数据（权限：`bw.cmd.stats` 并搭配 `bw.otherstats` 或 `bw.admin`）
* `/bw leaderboard` - 显示本服务器上的顶尖玩家（权限：`bw.cmd.leaderboard`）
* `/bw rejoin` - 加入你最近玩过的一局游戏，方便你快速重赛。请注意，尽管名字不太理想，该命令并不能让你在网络故障时重新连接到正在进行的对局。（权限：`bw.cmd.rejoin`）
* `/bw autojoin` - 加入随机游戏（权限：`bw.cmd.autojoin`）
* `/bw party warp` - 将你队伍中的所有玩家传送到你的游戏或传送到你身边（权限：`bw.cmd.party`，需要 [Parties](https://alessiodp.com/parties) 插件，并在 config.yml 中启用 `party` 小节）

### 管理员命令

除非另有说明，所有这些命令都需要 `bw.admin` 权限。

#### 竞技场编辑

* `/bw admin <arena> info [section]` - 显示关于竞技场的全部信息
* `/bw admin <arena> add` - 创建新竞技场
* `/bw admin <arena> lobby` - 将大厅位置设为你的当前位置
* `/bw admin <arena> spec` - 将旁观者出生点设为你的当前位置
* `/bw admin <arena> pos1` - 将竞技场的一个极点设为你的当前位置
* `/bw admin <arena> pos2` - 将竞技场的另一个极点设为你的当前位置
* `/bw admin <arena> lobbypos1` - 将大厅的一个极点设为你的当前位置（此项为可选；若与 `invisible-lobby-on-game-start` 配置选项一同设置，则可在游戏开始时移除大厅）
* `/bw admin <arena> lobbypos2` - 将大厅的另一个极点设为你的当前位置
* `/bw admin <arena> pausecountdown <seconds> [players:seconds,players:seconds,...]` - 设置游戏开始前的暂停时长。可为多个玩家人数阈值设置更短的时限，以便在大厅满员时加快游戏开始。
* `/bw admin <arena> minplayers <minimum>` - 设置开始游戏所需的最少玩家数
* `/bw admin <arena> time <seconds>` - 设置游戏时长
* `/bw admin <arena> team add <team> <color> <max players>` - 向游戏添加一个队伍
* `/bw admin <arena> team color <team> <color>` - 更改队伍颜色
* `/bw admin <arena> team maxplayers <team> <max players>` - 更改队伍最大玩家数
* `/bw admin <arena> team spawn <team>` - 将队伍出生点设为你的当前位置
* `/bw admin <arena> team bed <team> [looking_at|standing_on]` - 将队伍目标方块设为你准星所指的位置（可以是任意方块，而不仅限于床）
* `/bw admin <arena> jointeam <team>` - 设置使用实体加入队伍的功能
* `/bw admin <arena> spawner add <bronze|gold|iron|...> [hologram] [first level] [name] [team] [max spawned resources]` - 在你的当前位置添加物品刷怪点（或者你也可以在不指定队伍的情况下指定最大已生成资源数）
* `/bw admin <arena> spawner reset` - 移除所有刷怪点
* `/bw admin <arena> spawner remove` - 移除当前位置的所有刷怪点
* `/bw admin <arena> store add [name above dealer head] [file with shop] [team name] [use main shop]` - 在你的当前位置添加交易村民（或者你也可以在不指定 `team name` 的情况下指定 `use main shop`）
* `/bw admin <arena> store remove` - 从你的当前位置移除交易村民
* `/bw admin <arena> store type <living entity>` - 设置商店的实体类型（Villager、Horse、Cow、Pig 等）
* `/bw admin <arena> store child` - 将此店主标记为幼年
* `/bw admin <arena> store adult` - 将此店主标记为成年
* `/bw admin <arena> config <constant> <value>` - 为游戏设置常量变量的值
* `/bw admin <arena> arenatime <type>` - 设置竞技场中的时间（DAY、NIGHT 等）
* `/bw admin <arena> arenaweather <type>` - 设置竞技场中的天气（default、CLEAN、DOWNFALL）
* `/bw admin <arena> postgamewaiting <seconds>` - 设置玩家被传送出竞技场前的等待时间。
* `/bw admin <arena> customprefix <name|off>` - 为竞技场启用自定义前缀
* `/bw admin <arena> save` - 保存游戏并激活它！
* `/bw admin <arena> edit` - 关闭游戏并将竞技场切换到编辑模式
* `/bw admin <arena> remove` - 移除竞技场

#### 作弊命令

这些命令必须使用配置选项 `enable-cheat-command-for-admins` 手动启用。管理员必须身处游戏中（正在运行或在等待大厅中）才能执行作弊命令。

* `/bw cheat give <resource> [amount] [player]` - 给予玩家指定数量的资源
* `/bw cheat kill [player]` - 击杀指定玩家
* `/bw cheat startemptygame` - 启动一个仅有一个队伍的游戏（便于测试）
* `/bw cheat destroybed <team>` - 摧毁指定队伍的床
* `/bw cheat destroyallbeds` - 摧毁游戏中的所有床
* `/bw cheat jointeam [team]` - 将管理员加入指定队伍或当前队伍（无视队伍人数限制；也可在游戏运行中使用，但该队伍必须已有一些玩家）

除 `/bw cheat` 命令外，还有 `/bw cheatIn <game> <cheat> [params...]` 命令。该命令允许管理员在其未加入的游戏中或从控制台执行作弊。目前支持以下作弊：`give`、`kill`、`destroybed` 和 `destroyallbeds`。

#### 杂项

* `/bw alljoin [arena]` - 将所有没有 `bw.disable.alljoin` 权限的玩家加入竞技场（权限：`bw.admin.alljoin`）
* `/bw reload` - 重载插件
* `/bw mainlobby [enable|set]` - 启用主大厅或设置主大厅位置
* `/bw dump [paste.gg|pastes.dev]` - 转储服务器信息并给你转储链接。此链接在寻求支持时可能有用。
* `/bw dumplogs` - 使用 [mclo.gs](https://mclo.gs) 转储 latest.log 文件并提供转储链接。
* `/bw addholo [leaderboard|stats]` - 在你的当前位置添加新的全息投影
* `/bw removeholo` - 执行此命令后，玩家可以右键点击全息统计投影将其移除
