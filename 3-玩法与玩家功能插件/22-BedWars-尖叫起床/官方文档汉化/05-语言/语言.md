## 使用内置语言

要使用某种内置语言，请将 `config.yml` 文件中的 `locale` 值更新为你想要的语言代码。可用的语言代码列表如下：

locale: cs

> 注意：使用挪威语
>
> YAML 会把字面量 `no` 当作 `false` 处理。要把 `no` 用作挪威语语言代码，必须像这样将其强制转换为字符串：  
>
> ```yaml
> locale: "no"
> ```

> 注意：空的语言文件夹
>
> `languages` 文件夹通常是空的，因为内置语言存储在插件 jar 内部。除非你打算自定义翻译，否则无需下载任何文件。

## 自定义语言文件

如果你想修改语言文件，请按以下步骤操作：

1. **下载基础语言文件**  
   你可以从我们的 [GitHub 仓库](https://github.com/ScreamingSandals/BedWars/tree/ver/0.2.x/plugin/src/main/resources/languages) 下载基础语言文件。
2. **将文件放入 languages 文件夹**  
   把修改后的语言文件放到 `BedWars` 文件夹（位于默认的 `plugins` 文件夹中）下的 `languages` 文件夹内。例如，要修改捷克语，创建一个名为 `language_cs.yml` 的文件。
3. **更新 `config.yml`**  
   将 `config.yml` 中的 `locale` 变量更新为与你文件的语言代码一致。  
   ```yaml
   # Example for Czech:
   locale: cs
   ```

> 提示
>
> 虽然你可以下载并修改整个语言文件，但更好的做法是创建一个空的语言文件，只写入你想要覆盖的行。
> 这样，任何未翻译的行仍会使用更新后的内置版本。如果你把未改动的行也粘贴进自定义文件，它们会覆盖内置翻译，即使插件之后更新了这些行。

## 创建新语言

要创建一种全新的语言，请按以下步骤操作：  

1. 从 [GitHub 仓库](https://github.com/ScreamingSandals/BedWars/tree/ver/0.2.x/plugin/src/main/resources/languages) 下载英语语言文件。  
2. 将文件保存为 `language_myCode.yml`，其中 `myCode` 是你想要的语言代码。  
3. 将各行翻译成你的新语言。  
4. 将 `config.yml` 中的 `locale` 变量更新为你的新语言代码：  
   ```yaml
   locale: myCode
   ```  

> 提示
>
> 如果你创建了一种新语言，不妨通过我们的 Weblate 实例为插件贡献该语言，让它被收录！这样，你的语言会在未来的插件更新中面向所有人可用。访问我们的 [Weblate 实例](https://weblate.screamingsandals.org/projects/bedwars/0-2-x/) 即可开始。
