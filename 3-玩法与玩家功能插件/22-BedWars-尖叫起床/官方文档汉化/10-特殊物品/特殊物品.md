# 特殊物品
ScreamingBedWars 官方文档简体中文翻译 — 特殊物品
> 原文：[Special items](https://docs.screamingsandals.org/BedWars/latest/specials/)

> 翻译说明：本译文为官方文档的简体中文翻译，命令、权限节点、配置项/键名、占位符、物品/升级 ID、API 名称、版本号、URL 及代码块一律保留英文原文。

特殊物品可以在商店中出售，并在使用时拥有独特的行为。例如，它们可以生成实体、降低击退抗性、给予药水效果等等。

附加插件（Addon）也可以引入新的特殊物品。

商店中的每一件特殊物品都是通过 `properties` 进行配置的。

## Arrow Blocker

Arrow Blocker 是一件物品，使用后可以在一段时间内阻挡箭矢。

Arrow Blocker 有两个可配置选项：

* `protection-time` - 玩家在该持续时间（秒）内不会被投射物伤害。
* `delay` - 使用后的冷却时间（秒），在此期间玩家无法再使用另一个 Arrow Blocker。

以下是在商店中配置 Arrow Blocker 的示例：

```yaml
- price: 5 of gold
  properties:
  - name: "ArrowBlocker"
    protection-time: 10
    delay: 5
  stack:
    type: ender_eye
    display-name: "Arrow Blocker"
    lore:
      - "Block arrows that are coming"
      - "for you with black magic."
      - "I mean, with this item."
```

也可以使用 `config.yml` 中的全局配置来替代本地配置。`config.yml` 中的全局配置如下所示：

```yaml
specials:
  # ...
  arrow-blocker:
    protection-time: 10
    delay: 5
  # ...
```

要使用全局配置，只需在商店配置中省略你不想覆盖的选项即可。如果只有一个仅含名称、没有任何覆盖项的属性，可以使用以下写法：

```yaml
- price: 5 of gold
  properties: "ArrowBlocker"
  stack:
    type: ender_eye
    display-name: "Arrow Blocker"
    lore:
      - "Block arrows that are coming"
      - "for you with black magic."
      - "I mean, with this item."
```

## Auto Ignitable TNT

Auto Ignitable TNT 是一件特殊物品，放置时会生成已点燃的 TNT。

Auto Ignitable TNT 有三个可配置选项：

* `explosion-time` - 生成的 TNT 经过该时间（秒）后爆炸。
* `damage-placer` - 放置 TNT 的玩家是否也会受到伤害。
* `damage` - TNT 造成的伤害。

> 注意：TNT 跳跃
>
> 像 SBA 这样的附加插件会为这件物品提供与跳跃相关的额外自定义选项。详情请参阅它们的文档。

以下是在商店中配置 Auto Ignitable TNT 的示例：

```yaml
- price: 3 of iron
  properties:
  - name: "AutoIgniteableTnt"
    explosion-time: 5
    damage-placer: false
    damage: 4.0
  stack:
    type: tnt
    display-name: "Autoigniteable TNT"
```

也可以使用 `config.yml` 中的全局配置来替代本地配置。`config.yml` 中的全局配置如下所示：

```yaml
specials:
  # ...
  auto-igniteable-tnt:
    explosion-time: 5
    damage-placer: false
    damage: 4.0
  # ...
```

要使用全局配置，只需在商店配置中省略你不想覆盖的选项即可。如果只有一个仅含名称、没有任何覆盖项的属性，可以使用以下写法：

```yaml
- price: 3 of iron
  properties: "AutoIgniteableTnt"
  stack:
    type: tnt
    display-name: "Autoigniteable TNT"
```

## Golem

Golem 是一件特殊物品，使用后会生成一个铁傀儡来攻击敌方队伍。

这件特殊物品有多个可配置选项：

* `speed` - 铁傀儡的移动速度。
* `follow-range` - 铁傀儡追击敌人的范围。
* `health` - 铁傀儡的生命值。
* `show-name` - 是否在铁傀儡头顶显示名称。
* `delay` - 生成下一个铁傀儡之前的冷却时间。
* `collidable` - 玩家是否会与铁傀儡发生碰撞。
* `name-format` - 铁傀儡头顶名称的格式。有两个占位符：`%teamcolor%` 代表队伍颜色，`%team%` 代表队伍名称。

以下是在商店中配置 Golem 的示例：

```yaml
- price: 24 of iron
  properties:
  - name: "Golem"
    speed: 0.25
    follow-range: 16.0
    health: 20
    show-name: true
    delay: 0
    collidable: true
    name-format: "%teamcolor%%team% Golem"
  stack:
    type: ghast_spawn_egg
    display-name: "Golem"
    lore:
      - "An iron golem that will protect"
      - "your team from the enemies."
```

也可以使用 `config.yml` 中的全局配置来替代本地配置。`config.yml` 中的全局配置如下所示：

```yaml
specials:
  golem:
    speed: 0.25
    follow-range: 16.0
    health: 20
    show-name: true
    delay: 0
    collidable: true
    name-format: "%teamcolor%%team% Golem"
```

要使用全局配置，只需在商店配置中省略你不想覆盖的选项即可。如果只有一个仅含名称、没有任何覆盖项的属性，可以使用以下写法：

```yaml
- price: 24 of iron
  properties: "Golem"
  stack:
    type: ghast_spawn_egg
    display-name: "Golem"
    lore:
      - "An iron golem that will protect"
      - "your team from the enemies."
```

## Lucky Block

Lucky Block 是一件受 [LuckyBlock Addon for BedWarsRel](https://www.spigotmc.org/resources/bedwarsrel-luckyblock-addon.8268/) 启发而设计的特殊物品。
该方块可以放置在任意位置，被破坏时会触发一个随机配置的事件。Lucky Block 默认不会出现在商店中，因此你必须手动将其添加到商店里。

与其他特殊物品一样，Lucky Block 也使用 `properties` 进行配置。这类方块对应的属性名为 `LuckyBlock`，其中包含一个 `data` 段。该段是一个可能触发的事件列表。

共有 5 种事件类型：

* `nothing` - 顾名思义，什么也不发生。
* `teleport` - 该事件沿 Y 轴方向传送玩家。变量 `height` 用于配置这种相对传送。例如，如果玩家位于高度 60，而配置的高度为 50，他们就会被传送到 Y 110。
* `tnt` - 该事件发生时会生成一个已点燃的 TNT 实体，并立即爆炸。
* `potion` - 该事件给予玩家一种药水效果。效果通过变量 `effect` 进行配置。
* `item` - 该事件给予玩家一件物品。该物品通过变量 `stack` 进行配置。

下面是一个包含上述所有事件、完整配置的 Lucky Block 示例。此外，每个事件都可以有一个变量 `message`。这条消息会发送给破坏该方块的玩家。

```yaml
- price: 7 of iron
  properties:
  - name: "LuckyBlock"
    data:
    - type: tnt
    - type: nothing
    - type: teleport
      height: 50
    - type: item
      stack: dirt
      message: "This sends you message. You can add it to any event type."
    - type: potion
      effect:
        effect: blindness
        amplifier: 2
        duration: 100
        ambient: true
        particles: true
        icon: true
  stack:
    type: sponge
    amount: 1
    display-name: "Lucky Block"
```

与其他特殊物品不同，Lucky Block 没有全局配置。

## Protection Wall

Protection Wall 是一件特殊物品，使用后会建起一面墙。

这件物品有若干可配置选项：

* `is-breakable` - 是否可以破坏这面墙的方块。
* `delay` - 建起下一面 Protection Wall 之前的冷却时间。
* `break-time` - 墙经过该时间（秒）后消失。可设为 `0` 以禁用墙的自动破坏。
* `width` - 墙的宽度（以格为单位）。必须为奇数；若为偶数，插件会打印警告并额外增加一格。
* `height` - 墙的高度（以格为单位）。
* `distance` - 从使用该物品的玩家到墙出现位置的距离（以格为单位），方向为玩家所面朝的方向。
* `material` - 用于建墙的材料。如果该材料可染色，它会自动转换为队伍颜色。

以下是在商店中配置 Protection Wall 的示例：

```yaml
- price: 64 of bronze
  properties:
  - name: "protectionwall"
    is-breakable: false
    delay: 20
    break-time: 0
    width: 5
    height: 3
    distance: 2
    material: cut_sandstone
  stack:
    type: bricks
    display-name: "Protection Wall"
    lore:
      - "Instantly builds a wall that"
      - "can save your life!"
```

也可以使用 `config.yml` 中的全局配置来替代本地配置。`config.yml` 中的全局配置如下所示：

```yaml
specials:
  # ...
  protection-wall:
    is-breakable: false
    delay: 20
    break-time: 0
    width: 5
    height: 3
    distance: 2
    material: cut_sandstone
  # ...
```

要使用全局配置，只需在商店配置中省略你不想覆盖的选项即可。如果只有一个仅含名称、没有任何覆盖项的属性，可以使用以下写法：

```yaml
- price: 64 of bronze
  properties: "protectionwall"
  stack:
    type: bricks
    display-name: "Protection Wall"
    lore:
      - "Instantly builds a wall that"
      - "can save your life!"
```

## Rescue Platform

Rescue Platform 与 Protection Wall 类似，但它建造的不是墙，而是一个平台；玩家在坠落时可以使用它来防止跌落伤害或掉出地图。

这件物品有若干可配置选项：

* `is-breakable` - 是否可以破坏平台的方块。
* `delay` - 建造下一个 Rescue Platform 之前的冷却时间。
* `break-time` - 平台经过该时间（秒）后消失。可设为 `0` 以禁用平台的自动破坏。
* `distance` - 平台出现在使用该物品的玩家下方多少格处（以格为单位）。
* `material` - 用于建造平台的材料名称。如果该材料可染色，它会自动转换为队伍颜色。

以下是在商店中配置 Rescue Platform 的示例：

```yaml
- price: 64 of bronze

    is-breakable: false
    delay: 0
    break-time: 10
    distance: 1
    material: glass
  stack:
    type: blaze_rod
    display-name: "Rescue Platform"
    lore:
      - "Protect yourself from falling into"
```

## Team Chest

放置这件物品会生成一个只有放置队伍才能访问的箱子。所有这些箱子共享同一个物品栏，类似于末影箱。

出于历史原因，商店中的任何末影箱都会被转换为 Team Chest，无论给定的 properties 是什么。要禁用此行为，你需要在 `config.yml` 中将 `specials.teamchest.turn-all-enderchests-to-teamchests` 设为 `false`。

在商店中显式创建 Team Chest 的方式如下：

```yaml
- price: 1 of gold
  properties: "teamchest"
  stack: ender_chest
```

> 警告
>
> 物品的 type 必须为 `ender_chest` 才能正常工作！

## TNT Sheep

TNT Sheep 是一件特殊物品，使用后会召唤一只爆炸羊，并追击敌方玩家。召唤时，它会锁定最近的敌人作为目标。

这件特殊物品有若干可配置选项：

* `speed` - 羊的移动速度。
* `follow-range` - 羊追击敌人的范围。
* `max-target-distance` - 初始目标可以存在的最远距离（以格为单位）。如果此距离内没有目标，羊就不会生成。
* `explosion-time` - TNT 经过该时间（秒）后爆炸，羊随之消失。
* `damage` - TNT Sheep 爆炸时造成的伤害。

以下是在商店中配置 TNT Sheep 的示例：

```yaml
- price: 10 of gold

    speed: 0.25
    follow-range: 10.0
    max-target-distance: 32
    explosion-time: 8
    damage: 4.0
  stack:
    type: sheep_spawn_egg
    display-name: "TNT Sheep"
    lore:
      - "Use the TNT-Sheep! It will"
      - "walk towards your closest enemy"
      - "and explode within 8 seconds!"
```

也可以使用 `config.yml` 中的全局配置来替代本地配置。`config.yml` 中的全局配置如下所示：

要使用全局配置，只需在商店配置中省略你不想覆盖的选项即可。如果只有一个仅含名称、没有任何覆盖项的属性，可以使用以下写法：

## Tracker

Tracker 是一件简单的特殊物品，用于显示最近敌人的距离和方向。建议将 Tracker 设为指南针，因为该物品会为使用者设置指南针的目标点。与其他特殊物品不同，这件物品是永久的，可以反复使用。

以下是在商店中配置 Tracker 的示例：

```yaml
- price: 5 of iron
  properties: "Tracker"
  stack:
    type: compass
    display-name: "Tracker"
    lore:
      - "Wanna know where your closest target is?"
      - "Let's try this out!"
```

## Trap

Trap 是一件可放置的特殊物品。当敌人踩上陷阱时，所有配置的事件都会触发。此外，队伍会收到通知，告知有人触发了他们的陷阱。

与其他特殊物品不同，陷阱没有全局配置。这里唯一的选项是 `data`，它是一个包含所有事件的列表。

共有 3 种事件类型：

* `sound` - 播放指定的声音。
* `effect` - 对受害者施加一种药水效果。效果通过变量 `effect` 进行配置。
* `damage` - 对玩家造成指定量的伤害。

以下是一个完整配置的 Trap 示例：

```yaml
- price: 3 of iron
  properties:
   - name: "Trap"
     data:
      - damage: 2.0
      - sound: ENTITY_SHEEP_AMBIENT
      - effect:
          effect: blindness
          amplifier: 2
          duration: 100
          ambient: true
          particles: true
          icon: true
      - effect:
          effect: weakness
          amplifier: 2
          duration: 100
          ambient: true
          particles: true
          icon: true
      - effect:
          effect: slowness
          amplifier: 2
          duration: 100
          ambient: true
          particles: true
          icon: true
  stack:
    type: string
    display-name: "Trap"
    lore:
      - "Get informed if an enemy steps on your trap"
      - "and your enemy won't be able to move properly."
```

## Warp Powder

Warp Powder 是一件特殊物品，使用后会将你传送回队伍出生点。但是，你必须保持静止等待几秒，否则传送会被取消。

* `teleport-time` - 玩家被传送前的等待时间（秒）。
