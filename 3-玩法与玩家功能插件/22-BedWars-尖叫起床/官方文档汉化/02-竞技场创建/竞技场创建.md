# 竞技场创建
ScreamingBedWars 官方文档简体中文翻译 — 竞技场创建
> 原文：[Arena creation](https://docs.screamingsandals.org/BedWars/latest/arena/)

> 翻译说明：本译文为官方文档的简体中文翻译，命令、权限节点、配置项/键名、占位符、物品/升级 ID、API 名称、版本号、URL 及代码块一律保留英文原文。

> 警告
>
> 本指南假设你已经拥有一个存放 BedWars 地图的世界。
> 你应使用 Multiverse 或 SlimeWorldManager 之类的插件加载该世界，并且你应当已经身处该世界之中。

## 创建竞技场

要创建竞技场，运行此命令：
`/bw admin <arena name> add`

将 `<arena name>` 替换为你想给竞技场取的名称。每个竞技场必须拥有唯一的名称。

## 设置竞技场位置

首先，走到地图的一个角落并运行：`/bw admin <arena name> pos1`
然后走到对角的另一个角落并运行：`/bw admin <arena name> pos2`

> 注意
>
> 这两个点定义了环绕你竞技场的一个长方体区域。
> 这类似于用 WorldEdit 设置选区。

### 设置队伍出生点

走到队伍玩家出生时应出现的位置。
朝向你希望玩家出生时面对的方向，然后运行：
`/bw admin <arena name> team spawn <team name>`

为每个队伍重复此操作。

### 设置队伍床

看向队伍床的**床头**（带枕头的一侧），然后运行：
`/bw admin <arena name> team bed <team name>`

为每个队伍重复此操作。

> 提示
>
> 床只是多种目标方块选项之一。你也可以使用 **Dragon Egg**、**Cake** 或 **Respawn Anchor** 等方块来创建其他玩法模式（EggWars、CakeWars、AnchorWars）。大多数原版方块都受支持，但容器类方块和复杂方块实体除外。

## 添加刷怪点（资源生成器）

站在你希望刷怪点（也称资源生成器）所在的位置，然后运行：
`/bw admin <arena name> spawner add <resource> <true/false>`

默认支持的资源：`bronze`、`iron` 和 `gold`。对于 `diamond` 或 `emerald` 等额外资源，你需要在[配置文件](config.md)中手动配置。

`true/false` 参数控制是否在刷怪点上方显示全息投影。

## 添加商人

要添加商店实体，站在你希望商店出现的位置，面向你希望店主看向的方向，然后运行：
`/bw admin <arena name> store add [name above shopkeeper's head] [file with shop]`

示例：
`/bw admin <arena name> store add &aStore shop.yml`
`/bw admin <arena name> store add &aStore`
`/bw admin <arena name> store add`

> 信息
>
> 要更改商店实体类型，使用：
>
> `/bw admin <arena name> store type <entity type>`
>
> 示例：
>
> `/bw admin <arena name> store type Villager`
>
> 要使用玩家皮肤：
>
> `/bw admin <arena name> store type Player:skinname`
>
> 必须安装 Citizens 插件才能使用玩家皮肤。

## 最后步骤

设置大厅和旁观者位置：

* `/bw admin <arena name> lobby`
* `/bw admin <arena name> spec`

**最后，别忘了保存竞技场：**
`/bw admin <arena name> save`

> 注意
>
> 保存竞技场后，你可以切换到**编辑模式**进行修改，运行：
>
> `/bw admin <arena> edit`
>
> 编辑完竞技场后，保存它。

## 加入告示牌

要创建加入告示牌，放置一块写有以下内容的告示牌：

- **第 1 行**：`[BedWars]` 或 `[BWGame]`
- **第 2 行**：竞技场名称

放置后，插件会自动更新该告示牌。

要创建**离开告示牌**，只需写入 `leave` 而不是竞技场名称。

### 队伍实体

队伍实体允许玩家通过右键点击特定实体来选择自己的队伍。

有两种设置方式：

### 使用 `jointeam` 命令

1. 走到你的 BedWars 大厅并放置实体（例如 Armor Stand）。
2. 将竞技场切换到编辑模式。
3. 运行：
   `/bw admin <arena name> jointeam <team name>`
4. 右键点击该实体，将其绑定到队伍。
    * Armor Stand 会自动获得该队伍颜色的皮革护甲。
    * 该实体会自动设置为持久化。

之后保存竞技场。

### 手动创建

在你的大厅中放置任意**生物实体**，并给它起一个**与队伍名称一致的自定义名称**（例如 `Red`），插件就会将其识别为队伍选择器。
