# CarryOnPaper — 搬运方块与实体插件使用文档

> 官方来源：[Modrinth - CarryOnPaper](https://modrinth.com/plugin/carryonpaper)（Paper 版）
> 适用本服版本：**Java 1.21.8–1.21.11**（本服 1.21.11 适用）；加载器 Paper（兼容 Bukkit / Folia / Purpur / Spigot）

---

## 一、插件简介

**CarryOnPaper** 是一个专为 Paper 服务器打造的**搬运（Carry On）系统**——玩家通过 **潜行 + 右键** 即可捡起并搬走**已配置的方块**和**生物**，全程**服务端实现，客户端无需装任何 Mod**。

适合生存服 / SMP / 角色扮演服 / 建筑服 / 公共服务器，尤其适合需要"干净、可配置、安全"的搬运体验的开服环境。

**设计目标**：捡方块、抱生物、安全移动容器，全部可控、可自定义、现代消息与音效、权限化。

---

## 二、核心玩法

**潜行（Sneak）+ 右键点击** 目标：

| 目标 | 效果 |
| --- | --- |
| 已配置的**方块** | 捡起并顶在头上搬运 |
| 已配置的**生物** | 举起并搬运 |

搬运后再次右键（或按放置）即可放下。

---

## 三、功能详解

### 1. 搬运方块 📦

可搬运**已配置的方块**，典型用途是移动以下类型：

- ✅ 箱子 Chest
- ✅ 桶 Barrel
- ✅ 熔炉 Furnace
- ✅ 漏斗 Hopper
- ✅ 酿造台 Brewing Stand
- ✅ 实用类方块 Utility blocks
- ✅ 其他可配置方块

**容器库存安全保留**：开启后，搬运箱子/桶等容器时**能安全保留其内部物品**，移动存储方块平滑可靠，不会丢东西。

### 2. 搬运生物 🐄

支持搬运生物，自带**大型实体白名单/黑名单**，服主可完全控制哪些生物能/不能搬运。

可搬运示例：

- 🐄 牛 Cows
- 🐑 羊 Sheep
- 🐝 蜜蜂 Bees
- 🐺 狼 Wolves
- 🐴 马 Horses
- 🧑‍🌾 村民 Villagers
- 🐢 乌龟 Turtles
- 🐸 青蛙 Frogs
- 🦙 羊驼 Llamas
- 以及其他更多

**危险或过大的生物**可通过配置直接屏蔽（如守卫者、末影龙等）。

### 3. 现实感搬运物品 🎒

搬运物有逼真的物品外观：

- **方块** → 显示为该方块的**真实方块物品**
- **生物** → 尽可能显示为该生物的**刷怪蛋**

比用统一通用物品更干净自然。

### 4. 多语言支持 🌍

内置多语言文件：

| 语言文件 | 语言 |
| --- | --- |
| `en_us` | 🇺🇸 English 英语 |
| `de-eu` | 🇩🇪 German 德语 |
| `es_es` | 🇪🇸 Spanish 西班牙语 |
| `fr_fr` | 🇫🇷 French 法语 |

可在 **config 直接指定**，也可用 **语言命令** 切换。中文可通过修改/新增语言文件实现（见七·扩展）。

### 5. 消息格式 💬

支持两种消息格式：

- **MiniMessage**（默认，现代格式）
- **Legacy 颜色代码**（传统 `&` 格式）

按服务器喜好切换。

### 6. 可配置音效 🔊

完整 `sounds.yml`，每个关键动作可独立设置/调整/关闭音效：

- 📦 捡起方块 / 放置方块
- 🐾 捡起生物 / 放置生物
- ❌ 无权限提示
- 🔁 重载提示
- 🌍 语言切换提示
- ⚠️ 无法搬运提示

## 四、命令

| 命令 | 说明 |
| --- | --- |
| `/carryon help` | 显示 CarryOnPaper 帮助信息 |
| `/carryon reload` | 重载配置文件、语言文件、音效文件 |
| `/carryon language <语言>` | 切换当前插件语言（如 `/carryon language en_us`） |

**别名**：`/carry`（⚠️ 原 `/co` 别名已移除——与服务器另一插件命令冲突，已重打包 jar 只保留 `/carry`；见下方"命令冲突"备注）

---

## 五、权限

| 权限节点 | 作用 |
| --- | --- |
| `carryon.use` | 允许玩家使用捡起与放置动作 |
| `carryon.carry.blocks` | 允许搬运已配置的**方块** |
| `carryon.carry.entities` | 允许搬运已配置的**生物** |
| `carryon.reload` | 允许 `/carryon reload` |
| `carryon.language` | 允许切换插件语言 |
| `carryon.bypass.limit` | 绕过设置的搬运数量上限 |
| `carryon.admin` | 授予所有管理权限 |

## 六、配置要点（config.yml）

服主可在配置中控制以下全部内容（字段以实际生成的 `config.yml` 为准）：

| 配置项 | 说明 |
| --- | --- |
| 是否要求**潜行** | 决定搬运是否需要潜行触发 |
| 是否要求**空手** | 决定搬运是否需要空手状态 |
| 方块**白名单 / 黑名单** | 控制可/不可搬运的方块 |
| 实体**白名单 / 黑名单** | 控制可/不可搬运的生物 |
| 库存保留 | 搬运容器时是否保留内部物品 |
| 容器存储保护 | 容器类方块的存储安全保护 |
| 搬运速度修正 | 搬运时的移速调整 |
| 生物大小检查 | 可选的生物体积校验，过大拒搬 |
| 多物品搬运 | 每个玩家可同时搬运多个物品 |
| 玩家搬运 | 可选是否允许搬运玩家 |
| 权限访问 | 按权限控制搬运能力 |

---

## 七、常用配置与扩展

### 语言
- 默认语言在 config 中设置，或用 `/carryon language` 命令切换。
- 如需**中文**：在插件语言目录复制一个语言文件改中文文本，并在 config 指定（或新增语言键）。

### 消息格式
- 默认 MiniMessage；可用传统 `&` 颜色代码（Legacy）替换。

### 音效
- 编辑 `sounds.yml` 逐项调整。

---

## 八、安装步骤

1. 下载 Paper 版 `CarryOnPaper.jar`（对应 1.21.11，来源 Modrinth：`https://modrinth.com/plugin/carryonpaper`）。
2. 放入服务器 `plugins/` 目录。
3. 重启服务器（或热加载）。
4. 首次生成 `plugins/CarryOnPaper/` 下的 config.yml / 语言文件 / sounds.yml，按需修改后 `/carryon reload` 生效。

---

## 九、注意事项

- **服务端 only**：无需客户端 Mod，基岩版（Geyser）玩家同样可使用。
- 危险/过大生物建议在黑名单中屏蔽，避免破坏平衡。
- 容器库存保留需在 config 开启后才生效。
- 权限建议用权限插件（LuckPerms）统一分配 `carryon.use` + `carryon.carry.blocks` / `carryon.carry.entities` 给普通玩家，`carryon.admin` 给管理员。
