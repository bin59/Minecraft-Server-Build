# 南瓜服自定义模型资源包 · 玩家自行安装

> 版本：2026-11-13 制作 / **2026-11-14 修订**（`pack.mcmeta` 已适配 MC 26.3） | 装了才能看到家具、法杖、宠物等自定义模型；不装只是看不到模型，游戏照常玩。

## 选哪个文件

| 你玩的端 | 下载文件 | 后缀 |
|---|---|---|
| Java 版（PC 启动器） | `南瓜服模型资源包-Java-20261113.zip` | `.zip` |
| 基岩版（Win10 / 手机 / 主机） | `南瓜服模型资源包-基岩-20261113.mcpack` | `.mcpack` |

**两个包不能混用，不要解压，不要改后缀。**

## Java 版安装

1. 下载 `...-Java-20261113.zip`，保持压缩包原样。
2. 打开资源包文件夹：启动器 → 安装 → 打开游戏目录 → `resourcepacks`；或 Win+R 输入 `%appdata%\.minecraft\resourcepacks`。
3. 把 zip 整个拖进去。
4. 游戏内：**选项 → 资源包…** → 左侧选中 → 点中间箭头移到右侧 → 点「完成」。
5. 列表里应正常显示，**没有红色「不兼容」提示**（包内 `pack_format: 97` + `min_format: 69` / `max_format: 999`）。
6. 进服，能看到模型即成功。

## 基岩版安装

1. 下载 `...-基岩-20261113.mcpack`，保持后缀。
2. 双击文件（Windows）或点「用 Minecraft 打开」（手机），等提示「导入成功」。
3. 游戏内：**设置 → 全局资源包 → 我的包** → 找到 `ResourcePackManager Bedrock Pack` → 激活。
4. 放在**全局资源包**，不要只放单个世界的资源包。
5. 进服看模型。若之前装过旧包，先在「我的包」里删掉旧版再导入。

## 常见问题

| 现象 | 处理 |
|---|---|
| 看不到模型 | 确认包已移到右侧「已选」/ 已激活；重进一次服 |
| 显示红色「不兼容」/「为旧版本制作」 | 手上还是 2026-11-14 之前的旧包（旧包 `pack_format: 34`，只到 1.21.1）。重新下载同名文件覆盖，游戏内按 **F3 + T** 重载资源包 |
| 基岩双击没反应 | 保持 `.mcpack` 后缀，别用压缩软件打开；改回后缀后重试 |
| 服里更新模型后看不到新家具 | 重新下载最新版文件，覆盖旧包并重新激活 |

> 2026-11-14 修订：包名未变、内容已更新（md5 `a2c3fe7a`）。已装过旧包的玩家重新下载覆盖即可，不用改文件名、不用重新选中。
> 模型更新（新增模型、`/fmm reload`）后必须重新下载安装；以文件修改时间和 md5 作为实际版本标识。
> 服务器当前也会在进服时自动推送同一个包，手动装的是备用/离线方案，两者不冲突。
