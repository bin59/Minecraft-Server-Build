# 南瓜生存服经济系统设计方案

> 副标题：基于 Vault 的成熟玩家兑换 / 购买 / 定价体系，目标——长期稳定运行、抗通胀、与领地·签到·Velocity 架构融合

---

## 0. 设计目标

1. **长期抗通胀**：货币总量可控，物价不随时间失控。
2. **玩家体验顺滑**：兑换、购买、定价逻辑清晰，玩家一眼看懂。
3. **架构融合**：经济系统复用现有 Vault + MySQL + Redis 能力，并与领地系统、签到计分板、Velocity 跨服代理对接。
4. **风险隔离**：可交易货币与不可交易积分物理分离，阻断 RMT（真实货币交易）冲击游戏内经济。

---

## 1. 通胀从哪来（根因分析）

货币总量只增不减，而商品（方块 / 装备）能被无限刷出来，两边失衡即通胀。

- **水龙头 Faucet（发钱）**：任务奖励、签到、每日礼包、投票奖励等——凡是"可 farm / 可无上限"的发钱口都是通胀源头，必须严控或取消。
- **排水口 Sink（花钱）**：不足或被忽略。
- **致命坑**：`/sell` 无脑回收一切 + 任务无上限发钱 = 钱比货涨得快 → 经济崩溃。

> 核心原则：**让 Sink 永远 ≥ Faucet，并用"不可量产的资源"给货币定底价——绝不锚定任何可被农场量产的实物。**

**为什么不能锚定可 farm 的实物（关键修正）**：
- **矿物有限 → 少数人垄断**：钻石等限量资源"先到先得"，早期玩家囤积即掌握货币锚，后入者被收割，经济从一开始就分配畸形。
- **掉落物可无限量产**：生电 / 科技农场能海量刷怪掉、农作物乃至部分材料，任何"商品本位"都会被农场冲垮。
- 结论：货币供应**只由服务器可控的水龙头决定**，购买力锚定在"不可量产之物"（见 §4），而非任何可刷物品。

---

## 2. 货币双轨设计

| 货币 | 名称 | 形态 | 是否可交易 | 后端 | 用途 |
|---|---|---|---|---|---|
| 游戏币 | **南瓜币 (PC)** | 虚拟币 | ✅ 可交易 | Vault + MySQL | 拍卖行、玩家商店、领地扩张、传送等一切市场行为 |
| 积分 | **领地积分 / 签到积分** | 数值 | ❌ 不可交易 | 自存（Lua / Scoreboard） | 领地权限、签到奖励、排行榜，绝不进入交易市场 |

**为什么双轨**：积分若可交易，会被工作室刷后倾销，直接冲击南瓜币。把"努力产出"和"可花钱"分开，既保活性又防刷分。

---

## 3. 玩家兑换体系（成熟形态）

| 体系 | 运作方式 | 为什么成熟 |
|---|---|---|
| **拍卖行 /ah** | 服务器做中介，玩家挂单 + 一口价 / 竞拍 | 防骗、去除点对点纠纷；**上架费 + 成交税是纯 Sink** |
| **玩家商店**（ChestShop / Shopkeepers） | 玩家自定价，市场自发调节 | 价格由供需决定，不靠 Admin 拍脑袋 |
| **点对点 /trade** | 直接交易 GUI，防骗 | 大服更推 AH 减少纠纷，小服可用 |

**结论：拍卖行是黄金标准**，主交易渠道定为拍卖行，玩家商店为辅。

拍卖行关键参数（示例）：
- 上架费：`100` 南瓜币（沉没成本，抑制囤积与垃圾挂单）
- 成交税：`8%`（纯销毁货币，最好的抗通胀武器）

---

## 3.5 玩家获取南瓜币的方式（合规水龙头）

> 核心区分：**系统发放 = 印钱（Faucet，必须 ≤ Sink）**；**玩家间交易 = 转账（不新增货币，只是转移）**。健康经济里，大部分玩家收入应来自"向市场提供货 / 服务"，而非系统白送。

### A. 合规水龙头（系统可控发放，均不可自动化 + 封顶）

| 获取方式 | 单账号上限 | 是否可刷 | 说明 |
|---|---|---|---|
| 投票奖励 | 1 次/日，~80 PC | ❌ 需真人启动 | VoteReward，最稳的日常保底 |
| 每日任务 | 3 选 2，合计 ≤200 PC/日 | ❌ 硬封顶 | 引导玩法，非挂机可完成 |
| 一次性成就 | 一次性，~50–500 PC | ❌ 不可重复 | 探索 / 建造 / 击杀类 |
| BOSS 击杀 | 每账号冷却 7 天，~500 PC | ❌ 冷却限制 | 末影龙 / 凋灵等 |
| 资源世界首批探索 | 重置后限时加成 | ❌ 限时 | 配合资源世界重置 |
| 赛季 / 活动奖励 | 限时限量 | ❌ 限时 | 拉动活跃，不发日常量 |

### B. 市场赚取（玩家间，主收入来源，零通胀）
- **拍卖行卖货 / 服务**：把农场产物、成品装备、建筑 / 附魔代工挂 AH，钱从买家流向卖家——**不新增货币总量**，是经济健康度核心指标。
- **玩家商店**：ChestShop / Shopkeepers 玩家间自由交易。
- 玩家越能提供稀缺货 / 服务，收入越高；farm 过剩物则价格自然下跌，自动平衡。

### C. 设计红线
- 系统发放总量（周 Faucet）**必须 ≤** 同期 Sink 总量，否则净印钱 → 通胀。
- 绝不开放"击杀掉落卖店""挂机产出"类无人值守发钱口。
- 监控"系统发放占比"：占比越高越危险，理想是市场赚取占玩家总收入大头。

## 3.6 水龙头配比测算（按在线规模反推发放额度）

**核心公式**
```
周 Faucet（系统总发放）  ≤  周 Sink（系统总回收）
人均日发放  =  周 Faucet  /  活跃人数  /  7
```
**方法**：先按玩法体验定"人均日发放目标"，再验证对应 Sink 能否覆盖；覆盖不了就降发放或加 Sink。本节的"实际"数字是一个**自洽可运行的示例**，上线前用你自己的在线规模替换 `N` 重算即可。

### A. 实例（中型服：活跃 300 人，DAU≈150）

**人均周 Faucet（系统发放，按可完成上限）**
| 来源 | 额度 | 周计 (PC) |
|---|---|---|
| 投票 | 30 PC / 日 | 210 |
| 每日任务（假设活跃 5/7 天） | 100 PC / 日 | 500 |
| 成就 / BOSS 摊销 | — | 200 |
| 赛季活动摊销 | — | 100 |
| **合计** | | **≈ 1010 / 周·活跃玩家** |

→ 周总 Faucet ≈ 1010 × 300 = **303,000 PC / 周**

### B. 对应需要的 Sink（必须 ≥ 303,000）
人均周 Sink 目标 ≥ 1010 PC，分解验证：
| Sink 项 | 人均周 (PC) | 备注 |
|---|---|---|
| 拍卖行税（个人成交额 8%，需周成交 ~1875） | 150 | 靠玩家交易量，非系统强控 |
| 上架费（50 × 4 单） | 200 | 沉没成本，抑制垃圾挂单 |
| /tpa 传送（20 × 10 次） | 200 | |
| 领地扩张 | 300 | land 系统主 Sink |
| 修理 / 附魔 | 100 | |
| /home 扩位 | 60 | |
| 周持有税 | 50 | 逼货币流动 |
| **合计** | **≈ 1060** | **≥ 1010 ✓ 有安全边际** |

### C. 调参杠杆
- **周 Faucet > 周 Sink（印钱）**：① 降投票 / 任务额度；② 提上架费 / 税率 / 领地单价；③ 收紧活动发放。
- **周 Sink ≫ 周 Faucet（偏紧）**：玩家缺钱、交易萎缩 → 适度提发放或降部分 Sink（如降上架费促活）。
- **上线后每周跑一次**：实测 Faucet 总量、Sink 总量、货币净增量，超阈值报警。

### D. 通用速算（替换 N = 活跃人数）
```
周 Faucet 上限  =  N × 人均周 Sink 目标（≈1000~1100 PC）
人均日发放上限  =  周 Faucet 上限 / N / 7  ≈  143~157 PC / 日
```
把上面"人均日发放上限"当作**发放红线**，在 §3.5 的各水龙头额度内分配，总和切勿超过它。

## 4. 定价模型（防通胀核心，给具体数）

### A. 货币 = 法币，不锚定任何可 farm 物品（核心修正）
南瓜币是服务器发行的纯数字货币，背后**不绑定任何可被量产实物**（钻石、掉落物均排除）。购买力不来自"能换多少矿"，而来自"能买到什么稀缺物"（见 §5 Sink）。供应只由服务器可控水龙头决定。

### B. 价值锚 = 不可量产的资源（稀缺来自设计，非自然）
把购买力锚定在机器无法批量复制的东西上：
- **玩家时间 / 注意力**：投票（每账号每日 1 次，需真人启动）、每日任务（硬封顶）。
- **唯一性内容**：每个存档独有的已探索结构，消费即消失，直至资源世界重置。
- **服务器特权 / 外观**：称号、粒子、领地格、传送位——完全由服务器增发，可控。
- **玩家服务**：建筑、附魔代工、PVP 保护——稀缺来自人力，不可自动化。

### C. 水龙头必须"不可自动化 + 封顶"（防量产）
合格发钱口必须同时满足：**真人动作 + 硬上限 + 不可红石 / 脚本批量跑**。
- ✅ 投票、每日任务（封顶）、一次性成就、BOSS 击杀（每账号冷却）、资源世界重置后首批探索。
- ❌ 击杀掉落卖店、挂机产出、无上限任务——会被农场无限刷，一律不做主水龙头或严格限流。

### D. 系统商店只卖"不可量产物"，绝不回收 farm 物（关键）
系统商店的定位是**可控 Sink + 价格锚**，不是印钞机：
- 对可量产物品（铁、金、合金、农作物…）：**系统不收购**，让它们在玩家拍卖行由市场自由定价；农场过剩时价格自然下跌，不会变印钞机。
- 对半稀缺 / 不可量产物（图腾、鞘翅、成品附魔装备、领地格、外观）：设定买卖价差作为价格地板。

### E. 买卖价差 Spread（系统商店必做）
```
系统买价 50  <  系统卖价 65   （价差 ~30%）
```
玩家只能"亏着"回售给系统，系统不无限发钱；价差同时是 Sink + 价格地板。**无价差 = 印钞机。**

### F. 动态中位价（大型服）
以 AH 近期成交中位价作参考，系统 / 商店定价跟随，自动抗波动。

### G. 货币分层（阻断 RMT 冲击）
真钱购买的"点券 / 代币"设为**不可交易**，只能换外观 / 特权；可交易南瓜币靠玩法产出。两者物理隔离，土豪砸钱也冲不垮游戏经济。

## 5. 排水口 Sink 清单（必须有，越多越稳）

- 拍卖行税 + 上架费（核心）
- 传送费（`/tpa` 单次、`/home` 扩位）
- 修理 / 附魔 / 重铸费
- **领地扩张 / 维护费**（现有 land 系统天然可接，是最佳 Sink）
- 死亡复活税、彩票 / 赌池（零和）
- 周 / 月持有税（对账户或领地征税，逼货币流动）

## 7. 货币流向图（Faucet → Sink）

```
                 ┌──────────── 水龙头 FAUCET（发钱）────────────┐
                 │  投票 · 每日任务(封顶) · 成就 · BOSS冷却(均不可自动化)    │
                 └──────────────────────┬──────────────────────┘
                                        │ 南瓜币 流入
                                        ▼
        ┌──────────────────── 玩家持有 南瓜币 (PC) ────────────────────┐
        │   Vault + MySQL 统一账本（Velocity 各服共享同一表）            │
        └──────────────────────┬──────────────────────────────────────┘
                               │ 南瓜币 流出
        ┌──────────────────────┴─────────────────── 排水口 SINK（花钱）─┐
        │  拍卖行税/上架费 · 传送费 · 领地扩张 · 修理费 · 周持有税 · 外观  │
        └──────────────────────────────────────────────────────────────┘
                                        │
                                        ▼
                            货币净存量 ↑ 受控 → 物价稳定
```

**判定标准**：监控「周新增货币（Faucet 合计）」与「周销毁货币（Sink 合计）」，前者持续 > 后者即预警通胀。

## 8. 跨服（Velocity）与经济一致性

- 各后端服（NeoForge / Paper）**共用同一 MySQL 经济表**，避免每服各自发钱叠加通胀。
- Redis 做余额缓存（复用现有 RedisUtils 经验），降低 MySQL 读压力。
- 跨服转账 / 购买走统一服务层，禁止各服本地写账本。

---

## 9. 风险与监控

1. **没有绝对免疫通胀的体系**——"法币 + 不可量产锚 + 系统商店价差 + 拍卖行税 + 领地消耗"是被验证的稳配方，但需持续监控。
2. **Admin 定价漂移**：系统买 / 卖价长期偏离 AH 中位价会制造套利漏洞，需定期回标。
3. **工作室刷分**：积分不可交易是底线，签到 / 领地产出设每日封顶。
4. **发钱上限**：任务、签到每日封顶，杜绝无脑撒钱。
5. **监控面板**： weekly 输出 Faucet 总量、Sink 总量、货币存量曲线、AH 中位价，异常即调参。
6. **反垄断 / 防有限资源集中**：货币不锚定矿物，从源头消除"早期玩家垄断货币锚"。若仍保留矿物玩家间交易，配"资源世界定期重置 + 世界边界渐进扩张"，让有限资源持续再注入、旧囤货被稀释，而非永久集中。
