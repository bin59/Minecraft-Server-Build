### 领地插件使用指南

> 本指南基于 Residence 插件编写，帮助你在服务器中圈地、保护家园、管理权限。
> 不同服务器的指令前缀可能不同，请以游戏内实际可用指令为准。

---

### 第一步：认识领地插件

领地插件可以让玩家自己圈出一块地，用来保护房子、箱子和农田。

圈地之后：

- ️ 别人不能随便破坏你的建筑
- 别人不能随便打开你的箱子
- 你可以决定谁能进入、谁能建造
- 你的家不再怕熊孩子

---

### 🪓 第二步：准备圈地工具

圈地前，你需要一把**圈地工具**。

常见工具是：

- 🪓 **木斧**
- 或服务器指定的圈地物品

使用方法：

| 操作     | 作用         |
| -------- | ------------ |
| 左键方块 | 设置第一个点 |
| 右键方块 | 设置第二个点 |

这两个点会形成一个长方体区域，也就是你的领地范围。

---

### 第三步：选择领地范围

站在你想圈地的位置，按下面步骤操作：

1. 拿着圈地工具
2. 对准一个角落的方块，**左键点击**
3. 走到对角线位置，对准另一个方块，**右键点击**
4. 系统会显示你选择的区域大小

你可以想象成：

```text
A点
┌──────────────┐
│              │
│   你的领地   │
│              │
└──────────────┘
              B点
```

A 和 B 是长方体的两个对角点。

---

### 第四步：创建领地

选好区域后，输入创建指令：

```text
/res create 领地名
```

例如：

```text
/res create myhome
```

创建成功后，这块区域就会变成你的领地。

注意：

- 领地名不要和别人的重复
- 建议用英文、数字或简单名称
- 不要使用特殊符号

---

### 第五步：查看领地信息

站在领地内，输入：

```text
/res info
```

可以看到：

- 领地名称
- 领地主人
- 领地大小
- 当前权限设置

如果想看自己有哪些领地，输入：

```text
/res list
```

---

### 第六步：设置领地权限

创建领地后，你可以设置别人能做什么、不能做什么。

常用权限：

| 权限        | 作用                   |
| ----------- | ---------------------- |
| `build`     | 建造                   |
| `destroy`   | 破坏方块               |
| `use`       | 使用门、按钮、工作台等 |
| `container` | 打开箱子、熔炉等容器   |
| `pvp`       | 是否允许玩家互相攻击   |
| `move`      | 是否允许进入领地       |
| `tp`        | 是否允许传送到领地     |

权限只有两种状态：

- `true`：开启
- `false`：关闭

例如：

```text
/res set 领地名 build true
```

表示允许建造。

```text
/res set 领地名 pvp false
```

表示关闭玩家对战。

---

### 第七步：给玩家单独设置权限

如果你只想让某个朋友进入你的领地，可以使用：

```text
/res pset 领地名 玩家名 权限 true
```

例如：

```text
/res pset myhome Steve build true
```

表示给 `Steve` 在 `myhome` 领地里的建造权限。

常用权限示例：

```text
/res pset myhome Steve build true
/res pset myhome Steve destroy true
/res pset myhome Steve use true
/res pset myhome Steve container true
```

如果想取消权限：

```text
/res pset myhome Steve build false
```

---

### 第八步：传送与退出

传送到自己的领地：

```text
/res tp 领地名
```

设置当前站立位置为传送点：

```text
/res tpset
```

如果你不小心卡在领地里，可以尝试：

```text
/res unstuck
```

---

### ️ 第九步：删除领地

如果不需要这个领地了，可以删除：

```text
/res remove 领地名
```

例如：

```text
/res remove myhome
```

注意：删除领地后，保护会消失，别人可能就可以破坏或进入。

---

### 第十步：子领地

如果你在大领地里面想再划分一块小区域，可以创建子领地。

步骤：

1. 站在父领地内
2. 用圈地工具选择新区域
3. 输入：

```text
/res subzone 父领地名 子领地名
```

例如：

```text
/res subzone myhome shop
```

这样就在 `myhome` 里面创建了一个叫 `shop` 的子领地。

---

### 第十一步：设置进入和离开提示

你可以设置别人进入或离开领地时看到的提示。

进入提示：

```text
/res message 领地名 enter 欢迎进入我的家
```

离开提示：

```text
/res message 领地名 leave 你已经离开我的家
```

例如：

```text
/res message myhome enter 欢迎来到 %player 的家
```

---

### 第十二步：出租和出售

如果服务器开启了经济系统，你可能还可以出租或出售领地。

出租领地：

```text
/res rent 领地名
```

出售领地：

```text
/res sell 领地名 价格
```

购买领地：

```text
/res buy 领地名
```

### 第十三步：给成员管理权限

如果你想让信任的朋友帮你管理领地的权限设置，可以赋予 admin 权限：

```text
/res pset 领地名 玩家名 admin true
```

---

具体是否可用，取决于服务器设置。

| 删除领地       | `/res remove 领地名`                |

### ️ 常见问题

### 1. 为什么我圈不了地？

可能原因：

- 没有圈地工具
- 选区太小或太大
- 领地数量达到上限
- 没有创建领地权限
- 服务器限制了某些世界

可以先输入：

```text
/res select size
```

查看当前选区大小。

---

### 2. 为什么别人还能进我的领地？

可能是因为 `move` 权限没有关闭。

你可以输入：

```text
/res set 领地名 move false
```

但要注意，这样可能会影响你自己进出，需要根据服务器实际规则调整。

---

### 3. 为什么别人还能破坏我的方块？

检查 `build` 和 `destroy` 权限：

```text
/res set 领地名 build false
/res set 领地名 destroy false
```

如果别人有单独权限，还需要取消：

```text
/res pset 领地名 玩家名 build false
/res pset 领地名 玩家名 destroy false
```

---

### 4. 为什么我打不开箱子？

可能是你没有 `container` 权限。

如果你是领地主人，可以设置：

```text
/res set 领地名 container true
```

如果你想让朋友打开箱子：

```text
/res pset 领地名 玩家名 container true
```

---

### 5. 指令提示没有权限怎么办？

说明服务器限制了该指令。

你可以：

- 询问管理员
- 查看服务器规则
- 输入 `/res ?` 查看可用指令

不同服务器的权限设置可能不同，所以有些指令不一定都能使用。

---

### 新手推荐流程

1. 拿到圈地工具
2. 左键第一个点
3. 右键第二个点
4. 输入 `/res create 领地名`
5. 输入 `/res info` 查看领地
6. 设置 `build`、`destroy`、`container` 等权限
7. 需要时给朋友单独权限
8. 使用 `/res tp 领地名` 传送回家

---

### 简单记忆版

```text
左键点A
右键点B
/res create 领地名
/res set 领地名 build false
/res pset 领地名 玩家名 build true
/res tp 领地名
```

掌握这几步，基本就能在服务器里安全建房、保护箱子、和朋友一起玩了。
