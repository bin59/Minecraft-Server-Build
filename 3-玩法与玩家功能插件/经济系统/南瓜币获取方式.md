# 南瓜币获取方式（每日收入总览）

> 本服货币为「南瓜币」，统一存于 EssentialsX 单账本（经 Vault 桥接，见 [Vault.md](Vault.md)）。
> 本文档汇总玩家**每天能稳定拿到的南瓜币**来源、数量与入口，作为「收入侧」总览，与 [服务器扣费点清单.md](服务器扣费点清单.md)（支出侧）对应。
>
> 数据为 2026-11-10 实跑/既定配置核对结果；在线奖励随 OfflineReward 1.1.0 上线生效（见末节部署状态）。

---

## 一、总览表

| 途径 | 入口 | 获取方式 | 数量（每天） | 频率 / 上限 |
| --- | --- | --- | --- | --- |
| **每日任务** | `/quests` 或 菜单 → 每日任务 | 完成当日轮换的 6 个任务（14 个任务按星期轮换，相邻日零重叠） | **约 250~260 币**（周五、周日 250，其余 260） | 每任务 24h 冷却（`redo-delay: 86400`） |
| **每日随机收购** | `/ds choose` → `/ds sell`（`/ds sellall` 卖满） | 从 8 种候选自选 5 种，出售自己采集 / farming 的物品 | **单人每日上限 900 币** | 每天 0 点刷新清单，选择按日期持久化 |
| **每日工具包** | `/kit daily` | 领取每日包（含 南瓜币×5） | **5 币/次 × 最多 4 次 = 20 币/天** | 每 6 小时可领 1 次 |
| **离线奖励** | 上线自动发放（进南瓜邮箱） | 按**离线时长**结算 | **15 币/小时**（单次最多计 24h） | 上线自动到账，离线与在线互斥 |
| **在线奖励**（OfflineReward 1.1.0 新增） | 在线自动结算（进南瓜邮箱） | 按**在线时长**定期结算 | **25 币/小时**（高于离线，无每日封顶） | 每 5 分钟结算一段，鼓励在线 |
| **南瓜邮箱活动奖励** | `/mailbox` | 管理发放活动 / 补偿 | 不定期、金额不固定 | 上线有 ActionBar「有待领取奖励」提示 |

> 💡 **收入结构小结**：离线 15 / 在线 25（在线更高，刻意拉开差距鼓励在线）；每日任务 + 每日收购是「干活换币」的主动收入大头；每日工具包是稳定零碎补给；活动邮件为额外补充。
> 一个全勤玩家（做满每日任务 + 卖满每日收购 + 领满 4 次工具包 + 长期在线）自动化 faucet 合计约 **250 + 900 + 20 + 在线时长×25** 币/天（不含活动邮件）。

## 二、各途径明细

### 2.1 每日任务（Quests）

- **插件**：Quests Classic 5.3.2（PikaMug），奖励经 Vault 发放南瓜币。
- **机制**：14 个每日任务按星期轮换，**每天恰好 6 个可选、相邻两天零重叠**；每日组合全天合计约 250~260 币（周五、周日 250，其余 260）。
- **冷却**：每个任务 `redo-delay: 86400`（秒，即 24 小时，完成后计时，非每日 0 点统一重置）。
- **轮换入口**：由 QuickMenu 的 `days:` 星期条件在 Java 箱子界面与基岩原生表单同步过滤；跨天后重新打开菜单即更新，无需 reload。
- **详细任务清单与配置**：[经济插件/Quests每日任务.md](经济插件/Quests每日任务.md)。

### 2.2 每日随机收购（DailySell，自研）

- **机制**：每天 0 点从 110 种物品池随机抽 **8 种**作为全服共享候选；每位玩家用 `/ds choose` 从 8 种里**自选 5 种**作为当天唯一可卖清单（选择按日期持久化，跨天失效需重选）。
- **上限**：`daily-budget: 900` 既是清单总价上限，也是**每人每日总收益上限**（按「玩家 + 日期」独立累计，重选不重置）。
- **出售**：`/ds sell`（卖 1 个）/ `/ds sellall`（卖满额度）；单价当日浮动、每种额度随机。
- **详细文档**：[自研/每日随机收购-DailySell/使用说明.md](../../自研/每日随机收购-DailySell/使用说明.md)。

### 2.3 每日工具包（Kit `daily`）

- **入口**：`/kit daily`（基岩端 `/kitgui`）。
- **内容**：面包×2 + **南瓜币×5**。
- **频率**：每 6 小时可领 1 次，**一天最多 4 次** → 上限 20 币/天。
- **说明**：另有一次性的 `starter` 新手包（不含每日币），与 `daily` 无关。命令与冷却见主文档「🎁 工具包」章节（[../../README.md](../../README.md)）。

### 2.4 离线奖励（OfflineReward，自研）

- **机制**：玩家离线期间按**时长**累计，下次上线自动结算并发到**南瓜邮箱**（PumpkinMail），上线有 ActionBar 待领提示。
- **单价**：`coins-per-hour: 15`；`min-hours: 1`（不足 1 小时不发）；单次最多计 `max-hours-per-day: 24`（防长时间不上线刷爆）；`floor-minutes: true`（不足整小时舍去）。
- **边界**：离线与在线互斥——上线后开始计在线、停止计离线。

### 2.5 在线奖励（OfflineReward 1.1.0 新增，自研）

- **机制**：玩家在线期间由定时任务**每 `interval-minutes`（默认 5）分钟**遍历在线玩家，按整段结算并发到南瓜邮箱；鼓励玩家在线游玩。
- **单价**：`coins-per-hour: 25`（**高于离线 15**，刻意拉开差距）；`min-minutes: 5`（单段不足不发）；`max-per-day: 0`（不封顶）；`floor-minutes: true`（按 interval 整段取整）。
- **配置段**（`config.yml` 的 `online-reward:`）：`enabled` / `coins-per-hour` / `min-minutes` / `interval-minutes` / `max-per-day` / `floor-minutes`。

### 2.6 南瓜邮箱活动奖励（PumpkinMail，自研）

- **机制**：管理通过 `/mailbox admin` 发放面板或 `/mailbox give <奖品ID> <名单>` 批量发放活动 / 补偿奖励；玩家 `/mailbox` 一键领取。
- **性质**：**不定期、金额不固定**，不计入「每日稳定收入」，属额外补充。
- **说明文档**：[../../自研/南瓜邮箱-PumpkinMail/](../../自研/南瓜邮箱-PumpkinMail/)。

## 三、部署状态与口径说明

- **在线奖励** 随 **OfflineReward 1.1.0** 上线生效。截至本文撰写，编译产物 `OfflineReward-1.1.0.jar` 已就绪，但仍需由运维**删旧 1.0.0 → 放 1.1.0 → 覆盖 `config.yml`（补 `online-reward` 段）→ 完整停服重启**后，线上才会真正开始发放在线奖励。本文按「既定/将生效」状态记录并标注「1.1.0 新增」。
- **到账路径统一**：每日任务（Quests）、每日收购（DailySell）、工具包（Essentials Kit）走 Vault / EssentialsX 直接入账；离线 / 在线奖励与活动邮件走 **南瓜邮箱（PumpkinMail）** 待领。
- **防刷设计**：每日任务 `redo-delay: 86400` + `prevent-exploit`；每日收购按「玩家+日期」独立累计上限；离线奖励 `max-hours-per-day` 与 `cooldown` 限制；均为合规 Faucet 设计。
