# 扩展（Extensions）

> 原文：[Extensions](https://mods.icondice.org/vexbot/wiki/extensions)

> 四款 V3 附加组件、如何安装它们，以及它们所基于的 API。

VexBot 在 vexbot.api 上暴露了一个公开 API，独立的 mod 在它之上构建。它们就是普通的 Fabric mod，和 VexBot 一起丢进服务器即可——一台服务器可以运行其中任意几款、全部，或者一款都不运行。四款全部基于 V3（3.0.0），每个 Minecraft 版本对应一个 jar。

| 附加组件 | Id | 作用 |
| --- | --- | --- |
| VexSim | bounty-sim | 悬赏契约、操作员 NPC 与 AI 猎人——参见 VexSim |
| VexTrial | vextrial | 波次生存：一圈圈机器人逼近，一波接一波——参见 VexTrial |
| VexShop | vexshop | 把任意机器人变成店主，右键即可与之交易；`/vexbot shop <bot>` 打开编辑器 |
| VexPull | vexpull | 让一台机器人值守陷阱门岗：任何人在聊天框输入 "pull"，它就把最近的陷阱门拽开；`/vexbot vexpull set-puller <bot>` |

```
/vexbot extensions list
/vexbot extensions pull <id>
/vexbot extensions update
/vexbot extensions unload <id>
```

`extensions pull` 会从扩展托管站下载对应你 Minecraft 版本的构建，因此你永远不需要手动搬运 jar；之后重启服务器即可。`extensions update` 会把每一个已安装的附加组件更新到最新。

> 附加组件是 Fabric mod，因此需要 Fabric 版的 VexBot——而不是 Paper 插件。
