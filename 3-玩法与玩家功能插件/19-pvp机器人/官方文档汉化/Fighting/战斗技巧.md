# 战斗技巧（Techniques）

> 原文：[Techniques](https://mods.icondice.org/vexbot/wiki/techniques)

> 二十七种长矛、重锤与珍珠技巧——在 3.0 里每一个都是普通设置。

难度决定机器人玩得有多好。技巧决定它究竟被允许使用哪些招式。关掉一个，机器人就打得像从没学过它一样。

```
/vexbot settings <technique> on|off
/vexbot settings <technique> <variant>
/vexbot team <team> settings <technique> on|off
/vexbot team <team> settings search <word>
```

> `/vexbot settings` 在 3.0 中已被移除。技巧现在和其他设置放在一起：设置箱里、`/vexbot settings list` 里，以及每个队伍的设置界面里。

## 分组

| 分组 | 涵盖 |
| --- | --- |
| 核心切换 | mace-swap, spear-mace-swap, sword-windburst-swap, breach-swap, spear-reach-swap |
| 基础功底 | windcharge-mace and its crouch boost, cooldown discipline, hit preference, hotbar shield tracking, elytra wc boost |
| 位移 | spear-dash, dash-chain, spear-macing, wc-reset and wc self-reset |
| 珍珠 | pearl-catch and its variant, pearl-catch glide, pearl-grapple |
| 鞘翅 | dive-bomb, elytra-stun-slam, elytra-preservation |
| 反盾牌 | ground-backstab, elytra-backstab, stun-slam and its variant, spear-stun-slam, shield-drain |
| 终结技 | detap-spear-mace, detap-breach, spear-double-pop, wc-cancel |
| 烟花重锤 | rocket-mace and four variants of the climb-and-drop |

有些技巧不是简单的开/关，而是有变体——stun-slam 可以是 optimal、easy 或旧的单 tick 写法，rocket-mace 则有四种不同的飞行模式。珍珠抓取已完全移出技巧列表：它放在 `/vexbot settings pearlcatchtype`，这样只有一个地方可以设置。

## 背刺还是眩晕猛击，二者不可兼得

`/vexbot settings backstab` 是应对举起盾牌的另一种答案：从目标身边冲刺掠过、转身 180°、用重锤砸它的后背，而不是用斧子把盾牌劈碎。它与眩晕猛击互斥——开了其中一个就会关掉另一个。它们要求相反的站位（一个在背后，一个在头顶），想两个都要的机器人哪个都做不好。

> 与机器人原本打法相符的技巧默认开启。真正全新的技巧默认关闭，直到你手动打开。
