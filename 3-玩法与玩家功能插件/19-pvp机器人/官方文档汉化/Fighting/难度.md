# 难度（Difficulty）

> 原文：[Difficulty](https://mods.icondice.org/vexbot/wiki/difficulty)

> 十九个独立的旋钮，而不是一条从易到难的滑条。

难度没有一个统一的数字。机器人技艺的每一部分都是独立的旋钮，因此你可以造出一个瞄准完美但反应迟缓的机器人，或者一个从不暴击落空、却打不出绝境翻盘的机器人。

```
/vexbot difficulty list
/vexbot difficulty <knob> <value>
/vexbot difficulty preset <easy|medium|hard|expert|professional|perfect>
/vexbot team <team> difficulty <knob> <value>
/vexbot difficulty player <bot> <knob> <value>   # one bot only
```

`difficulty player <bot>` 为单台机器人单独设置自己的旋钮，其优先级高于它所在队伍和全局设置——顺序是机器人、然后队伍、然后全局。它也接受 `list`、`preset <level>` 和 `clear`（后者把该机器人交还给队伍/全局旋钮）。设置某个旋钮时会先复制该机器人当前正在使用的全部数值，所以改动一项不会悄悄重置其他十三项。

预设只是一次性写入所有旋钮的快捷方式。执行之后，每个旋钮仍由你自由调整。

## 旋钮

| 参数 | 单位 | 作用 |
| --- | --- | --- |
| misschance | % | 挥击故意偏离头部的频率 |
| accuracy | % | 机器人成功打出高阶技巧的频率 |
| clutch | % | 水桶 MLG 落地成功率 |
| reaction | ms | 对任何新情况作出反应前的延迟 |
| shielddisablespeed | ms | 它发现你的盾牌后用斧子破盾的速度 |
| shieldcharge | % | 尝试破盾前等待的斧子蓄力程度 |
| strafe | degrees | 它绕你转圈的半径 |
| crittiming | % | 它为暴击把握下落时机的精准度 |
| anchorspeed | ticks | 两次重生锚充能之间的间隔 |
| stunslam | % | 它打出“先斧后锤”眩晕猛击的概率 |
| potspeed | seconds | 两次投掷药水之间的间隔 |
| webdrainspeed | seconds | 它舀走你脱身用水的速度 |
| webescapespeed | seconds | 它开始挣脱蛛网所需的时间 |
| reachflips | 0–10 | 挥击放弃满射程的频率。0 表示始终满射程 |
| cartskip | % | 它放弃的 TNT 矿车机会占比 |
| cartspeed | ticks | 两辆 TNT 矿车之间的 tick 数 |
| crystalspeed | ticks | 两个末地水晶之间的 tick 数 |
| anchorgap | ticks | 两个重生锚之间的 tick 数 |
| elytramace | 1–5 | 鞘翅重锤技巧等级，从 easy 到 professional |

> elytramace 值得单独一提：在较低等级时，机器人不只是动作变慢，它还会像真人一样失手——爬得太高、卸装太晚而从你头顶滑过、手忙脚乱地点错烟花、偏离瞄准点、停止连续俯冲。
