# 模式与附加功能（Modes and extras）

> 原文：[Modes and extras](https://mods.icondice.org/vexbot/wiki/gamemodes)

> FFA、护送、练习、POV 录制、昵称与空门。

## 自由混战（FFA）

`/vexbot ffa start` 把整个服务器变成一场自由混战，带有"搜刮—战斗"循环：机器人用斧子劈开箱子、捡起击杀掉落，然后继续下一轮。

## 护送（Escort）

`/vexbot follow` 是保镖模式，不是宠物——跟随的机器人会反击任何攻击你或它的人，然后回去继续跟随。拴绳范围 32 格，队伍可以保持一个阵型。

## 眩晕重锤练习（Stun-slam practice）

`/vexbot stunslampractice` 生成一个扎根的假人，带有不可破坏的盾牌和无限抗性提升（Resistance），让你可以练习用重锤和长矛下坠攻击时的举盾时机。

## POV 录制（POV recording）

`/vexbot recordpov` 在屏幕外把机器人的第一人称视角渲染成无声 MP4，并画上原版 HUD。仅客户端、仅整合服务器。

> 仅限 1.21.11。Minecraft 26.x 替换了该 HUD 覆盖层所依赖的 GUI 绘制机制，所以在 26.x 构建版上该命令会给出提示并拒绝执行，而不是出错。其余功能在所有三个版本上完全相同。

## 昵称（Nicknames）

`/vexbot nick` 可以实时重命名并重设一台机器人或一位真实玩家的皮肤。把一个 PNG 放进 `vexbot_skins/`，它会被签名并缓存给你。`nick <name> stop` 恢复原样。

## 空门（Null portal）

`/vexbot nullportalspawn` 建造并点亮一个下界传送门，然后放出装备齐全、名字带乱码下划线的机器人。用 `nullportalconfig` 配置。

传送门有等级。每一台穿过传送门的机器人都有小概率成为指挥官（Commander，每个传送门至多一台，名字由十五个下划线组成）或特种兵（Special，至多七台，名字由八个下划线、一个随机字符和另外五个组成）。用 `commanderchance`、`specialchance` 和 `jamatopchance` 调整概率，并用 `commanderkit` 和 `specialkit` 给每个等级分配各自的 Kit（通过分享码）——`clear` 恢复标准的空门 Kit。

## 生成区域（Spawn area）

机器人通常出现在命令执行的位置——你的脚下，或从控制台/命令方块执行时的世界出生点。`/vexbot spawnarea` 改用一个区域盒。它适用于 `spawn`、`mass_spawn` 和 `team <team> massspawn`；显式指定地点仍然优先，批量生成会在区域盒内散开而不是排成一列。

```
/vexbot spawnarea here <radius>
/vexbot spawnarea set <x y z> <x y z>
/vexbot spawnarea show
/vexbot spawnarea clear
```

## 名字池（Name pools）

把一个 `.json` 文件放进 `vexbot_namepools/` 文件夹，机器人就会用你的名字生成，而不是内置名字。内置列表会在世界首次加载时写出为 `vexbot-standard-names.json`，作为格式示例。格式很宽容：JSON 列表、带 `names` 列表的对象、或者直接用逗号分隔的名字都可以。

```
/vexbot namepool <pool>
/vexbot namepool list
/vexbot namepool none
/vexbot teamnamepool <team> <pool>
```

## 注视（Look）

`/vexbot look` 让机器人的头朝向某个目标并保持：一个玩家或机器人（它会持续跟踪）、世界中的某个位置，或固定的俯仰角（pitch）或偏航角（yaw）——设置其中一个会保留另一个。注视的机器人站在原地不动、不战斗，直到收到新的攻击或跟随指令，或 `stop`。`/vexbot teamlook` 对整支队伍做同样的事，每台机器人各自转向。

```
/vexbot look <bot> <player>
/vexbot look <bot> <x y z>
/vexbot look <bot> pitch -45
/vexbot look <bot> yaw 90
/vexbot look <bot> stop
```
