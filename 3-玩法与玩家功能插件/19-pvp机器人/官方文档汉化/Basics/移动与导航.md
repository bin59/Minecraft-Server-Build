# 移动与导航（Movement and navigation）

> 原文：[Movement and navigation](https://mods.icondice.org/vexbot/wiki/movement)

> 寻路、搭路、垫高、船、隧道与游泳。

导航分三个层级运行：有开阔通道时沿直线射线前进；没有时使用带预算上限的 A* 寻路；再以八格光束作为兜底，保证它绝不会在战斗中途僵住。

## 接近你

- 跨越缺口搭路——ninja（蹲着后退）、god（向前冲刺）或 moonwalk（横着走），用 bridgemode 设置。
- 向在自己上方建造或飞行的目标垫高上去，再搭路过去。
- 乘船渡水：放下船、划过去、下船、把船拆了带走。
- 有合适工具时会挖穿一切实心方块——两格宽、两格高；你偏在一侧时斜着挖；上下都能挖——直到真正能够到你。
- 游泳，包括朝视线方向游动的标准游泳姿势。
- 不会从自己摔不死的悬崖上走下去——不过战斗寻路会刻意更大胆一些。

## 闲站

开启 wander 后，闲站的机器人会在生成点十格范围内晃悠，而不是一动不动地站着。当有玩家在 90 格以内时，闲站的机器人会保持激活状态。

## 派单台机器人去某处

```
/vexbot goto <bot> <x y z|player>
/vexbot goto <bot> <x y z> then attack <target>
/vexbot goto <bot> <x y z> then hold
/vexbot goto <bot> stop
```

这是 `/vexbot team <team> goto` 的单机器人版本：机器人自己走过去，挖穿挡路的一切。

## 巡逻路线

路径就是你自己走一遍来标出的路线。`create` 在你站的位置放下第一个点，`add` 依次放下后面的每个点；`show` 用粒子把路线画出来。`assign` 让机器人从第 1 个点开始出发，`spread` 把他们均匀分散到整条路线上——这正是巡逻想要的效果。两者都接受 @ 选择器。

```
/vexbot path create <name>
/vexbot path add <name>
/vexbot path show <name>
/vexbot path mode <name> once|loop|pingpong
/vexbot path walk <name> walk|sprint|bunnyhop
/vexbot path spread <name> <bots>
/vexbot path stop <bots>
```

巡逻属于闲站行为：在路线上的机器人遇到什么都会打，打完再回到路线上。
