# 选择构建版本（Which build do I install?）

> 原文：[Which build do I install?](https://mods.icondice.org/vexbot/wiki/which-build)

> 每个 Minecraft 版本一个 jar，分 Fabric 和 Paper 两种。如何挑选你的版本，以及哪些东西必须互相对上。

VexBot 为三个 Minecraft 版本构建，并且自 3.0 起支持两种服务端类型：Fabric mod 和 Paper 插件。它们是同一个 VexBot —— 相同的 AI、命令、kit、队伍和 GUI。安装与你的游戏和服务端相匹配的那一个。

## 三种构建

| 你的服务端 | jar | Java |
| --- | --- | --- |
| Fabric 1.21.11 | vexbot-3.0.4+mc1.21.11.jar | 21 |
| Fabric 26.1.2 | vexbot-3.0.4+mc26.1.2.jar | 25 |
| Fabric 26.2 | vexbot-3.0.4+mc26.2.jar | 25 |
| Paper 1.21.11 | vexbot-paper-3.0.4+paper-mc1.21.11.jar | 21 |
| Paper 26.1.2 | vexbot-paper-3.0.4+paper-mc26.1.2.jar | 25 |
| Paper 26.2 | vexbot-paper-3.0.4+paper-mc26.2.jar | 25 |

`+` 后面的部分是 Minecraft 版本，前面的部分是 VexBot 版本。在 changelog 页面顶部可以按 Minecraft 版本筛选，只看为你的游戏构建的发布。

## 扩展插件也必须匹配

附加组件（VexSim、VexTrial、VexShop、VexPull）是以同样方式构建的 Fabric mod：每个 Minecraft 版本一个 jar，为某一版本构建的 jar 无法在另一个版本上加载。让你的游戏版本、VexBot jar 和附加组件 jar 三者对上。`/vexbot extensions pull` 会替你选好正确的那一个。

```
vexbot-3.0.4+mc26.2.jar
vexsim-3.0.0+mc26.2.jar
vextrial-3.0.0+mc26.2.jar
```

## 为什么有三个

Minecraft 在 1.21.11 之后发生了变化。26.x 版本附带真实的类名而不是混淆后的类名，并且运行在 Java 25 上 —— 因此为其中一个编译的 mod 无法在另一个上加载。除了 Mojang 改名的那几个调用之外，VexBot 本身在它们之间没有任何区别。

> 一个例外：`/vexbot recordpov` 只在 1.21.11 构建上可用，因为 26.x 替换了它的 HUD 覆盖层所依赖的绘制路径。在 26.x 上该命令会带一条消息拒绝执行，而不是行为异常。

## 如果你装错了

Fabric（或 Paper）会拒绝加载它，并在日志中说明原因 —— 它会检查 jar 声明的 Minecraft 版本。什么都不会损坏；把 jar 换成正确的再重新启动即可。Paper jar 放进 `plugins/`，Fabric jar 放进 `mods/`。
