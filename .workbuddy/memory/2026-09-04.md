## 关键发现：Floodgate 不注册 LuckPerms context

- 经 Web 检索确认：Floodgate **默认不在 LuckPerms 注册 `floodgate` context**，旧文档/教程中「`/lp group bedrock permission set ...` 用 context」的说法站不住
- 采用方案：独立 `bedrock` 附加组 + BedrockPlayerManager 插件自动分配（或手动 `lp user <x> parent add bedrock`），而非依赖 context 区分
- 此结论已写入 `权限组设计方案.md` §5 与 `LuckPerms.md`
