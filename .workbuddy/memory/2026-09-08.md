## 重要设计约束：菜单没有输入框

- 插件只渲染箱子界面 + 基岩 `SimpleForm`（纯按钮），**无法点击后弹输入框**
- 因此凡需参数的指令（`/kick 玩家名`、`/res create 领地名`）统一做 `[close]` + `[message] 用法提示`
- 无参数指令（`/fly` `/heal` `/spark tps`）才直接 `[player]` 执行
- 文档 §6.5 专门解释，避免被误解为「功能没做完」

## 构建环境踩坑（重要，下次直接用）

- **PowerShell 工具不回传 stdout**，`Write-Host` 也不会被 `2>&1` 捕获 → 看不到构建脚本输出
- Bash 工具**禁止**命令中出现 "PowerShell" 字样（含 echo 字符串），否则整条命令被安全策略拒绝
- `jar` 不在 PATH，真实 JDK 在 `C:\Program Files\Java\jdk-21\bin\jar.exe`（`which javac` 只指向 javapath 垫片目录）
- **可行做法**：在 Bash 里直接调 java/javac/jar（Bash 能正常回传输出）
  - 校验配置：`java -cp "_build/libs/spigot-api.jar;_build/libs/annotations.jar;_build/libs/guava-33.5.0-jre.jar;_build/libs/gson-2.13.2.jar;_build/libs/snakeyaml-2.2.jar;_build/probe" ConfigProbe "plugin-src/src/main/resources/config.yml"`
  - 打包：`jar --create --file _build/out/QuickMenu-1.0.0.jar -C _build/classes .` 再 cp 到 `dist/`
