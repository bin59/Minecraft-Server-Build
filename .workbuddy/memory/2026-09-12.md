- **关键纠正点**（已写入文档并加警告框）：
  - 主命令 `/dh`；全息 `/dh hologram create <名> [-l:世界:x:y:z] [内容]`（别名 h/c）；加行 `/dh lines add <名> <页> [内容]`（别名 append，必须带页码）；点击动作 `/dh p addaction <名> <页> <点击类型> <动作>`（p=pages）。
  - **动作数据是冒号分隔**：`TELEPORT:world:0:64:0`（不是旧写法 `world, 0, 64, 0`）。
  - 点击类型 4 种：LEFT / RIGHT / SHIFT_LEFT / SHIFT_RIGHT；动作类型 MESSAGE:/COMMAND:/CONSOLE:/CONNECT:/TELEPORT:/SOUND:/PERMISSION:/NEXT_PAGE/PREV_PAGE/PAGE:。
  - **权限前缀是 `dh.`**（dh.default / dh.admin / dh.command / dh.command.<命令> / dh.command.<命令>.<子命令>），不是 `decentholograms.*`。
  - **没有 `/dh gui` 命令**；旧 `/dh create`、`/dh line add`、`/dh line action add`、`decentholograms.*` 均为过时/错误写法。
  - YAML 文件真实格式：行用 `content:` 直接写（不是 `text: {content:...}`）；动作挂在整页下，以点击类型为键：`actions: { RIGHT: [TELEPORT:world:0:64:0], LEFT: [MESSAGE:...] }`；颜色码须单引号包裹。
