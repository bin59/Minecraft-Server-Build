# MC Java版 刀剑神域SAO界面模组汇总

> 注意：**UI类模组大多是客户端模组**，服务器（Leaf/Paper）不需要装，仅玩家客户端安装即可；只有带技能/属性系统的才需要服务端同步。

## 1. SAOMenu（UncannyOVO，国内最火SAO圆形菜单模组）

- 加载器：**Architectury（同时支持 Fabric / Forge）**
- 推荐版本：1.20.1
- 核心功能
  1. 默认按 **O键** 调出SAO悬浮环形主菜单（人物属性、装备栏、背包、地图、队伍、好友面板）
  2. HUD改造：左上角SAO风格血条/经验条，怪物头上环形血条
  3. 击杀怪物：数据碎片碎裂消失特效、右上角获得经验弹窗
  4. 适配 **史诗战斗EpicFight、拔刀剑**，可在面板绑定剑技
  5. 进入游戏弹出「Welcome to Sword Art Online」开场提示
- 特点：纯UI为主，轻量化；**客户端模组，服务器不用装**
- 下载：Modrinth / CurseForge 搜 `SAOMenu`

## 2. SAO HUD（SirDrake2，1.21.11可用，优先推荐新版）

- 加载器：NeoForge
- 支持版本：**1.21 / 1.21.1 / 1.21.11**（正好适配你现在服务器版本）
- 核心功能
  1. 全覆盖SAO动漫风格HUD，玩家状态栏+生物血环
  2. 配置文件 `saohud-common.toml`，可自由调整血条大小、颜色、显示开关
  3. 轻量，只改界面，**无额外RPG技能**，性能压力很小
- 特点：1.21.11原生支持，适合你的南瓜生存服；仅客户端安装

## 3. DASAO UI（DASWORDARTONMINE，完整大型SAO整合模组）

- 加载器：Forge 1.20.1
- 核心：不止UI，完整SAO RPG大模组
  - SAO全套HUD、装备面板、公会、好友、组队决斗
  - 剑技系统、等级、经济、层数副本、动态怪物难度
- 注意：**客户端+服务器都要装**，属于大改造模组，插件服不推荐，适合纯模组服

## 4. 旧款：SAO UI（Bluexino）

- 仅1.12.2 Forge，版本老旧，不推荐新项目使用

# 选型建议（针对你的Paper/Leaf插件服）

✅ 首选 **SAO HUD（NeoForge 1.21.11）**：只美化界面、不用改服务端，玩家客户端单独装，和插件兼容性最好。
✅ 想要SAO标志性环形O键菜单：选 **SAOMenu（1.20.1）**，但版本要降到1.20.1。
❌ DASAO UI 不要上你的插件服，RPG系统会和插件大量冲突。

# 部署要点（插件服重要）

1. UI模组**只放玩家客户端mods文件夹**，你的Leaf服务器plugins文件夹**不要放**
2. 客户端必须和服务器版本一致、加载器匹配（NeoForge/Fabric不能混用）
3. 搭配推荐：SAO HUD + EpicFight史诗战斗，完美还原SAO剑技打斗
