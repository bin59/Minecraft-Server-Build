南瓜生存服待选玩法插件选型清单：按粒子特效、宠物系统、全息文字、称号头衔、头颅装扮、聊天消息、趣味互动、RPG 养成、菜单面板分类整理候选插件，附兼容性、亮点、适合场景与指令冲突提醒。

## 一、粒子特效（玩家最爱的装扮系统）

### 1. KillEffects —— 击杀特效（1.21 原生 TextDisplay，无卡顿）

- **链接**：[Modrinth](https://modrinth.com/plugin/killeffects)

- **兼容性**：Paper 1.21+，基于原生 TextDisplay 实体，不依赖 ProtocolLib/NMS

- **亮点**：
  - `/ke` 打开 GUI 预览 / 选择击杀特效，击杀敌人时**全服可见**炫酷效果（如 "EZ" 悬浮字）

  - 特效类型丰富，支持颜色 / 大小 / 动画自定义

- **适合场景**：**活动奖励 / 装扮商城**—— 普通玩家基础特效，特殊特效作活动奖励或商城出售

- **权限思路**：`killeffects.use` 给全体，具体特效按权限拆分给活动奖励组（以官方页为准）

### 2. XNMagicBRL —— 粒子特效（极简中文指令，国人插件）

- **链接**：[GitHub](https://github.com/MC-xiaonan/XNMagicBRL-Plugin)

- **兼容性**：Spigot/Paper 1.16.5 - 1.21+（含 LeaveMC 1.21.10）

- **亮点**：
  - **50+ 种粒子效果预设**，支持 SIMPLE / MULTI / COMPOSITE / RAINBOW / RAIN 等多种效果类型

  - 粒子效果跟随玩家移动，配置支持热重载

- **常用指令**：

```
/XNM <效果>       # 开启指定粒子

/XNM list         # 查看全部效果

/XNM stop         # 关闭
```

- **适合场景**：轻量，适合**给全体玩家开放**，零门槛玩粒子

### 3. Zenavia Cosmetics —— 帽子 / 背包 / 粒子 / 称号 / 击杀特效全家桶

- **链接**：[SpigotMC](https://www.spigotmc.org/resources/zenavia-cosmetics.133540/)

- **兼容性**：1.20.4+ / 1.21，全 YAML 配置

- **亮点**：
  - 帽子、背包、粒子、称号、击杀特效**五合一**，一个插件覆盖大部分装扮需求

  - 服主可自定义无限量装扮，玩家自管资源包（无需强制下载）

- **适合场景**：长期运营服做**完整装扮商城**，搭配经济插件出售装扮

- **注意**：功能全意味着配置量大，建议上线前花 1-2 天专门调 YAML

### 4. PlayerParticles —— 老牌经典粒子插件（2016 年至今持续更新）

- **链接**：[SpigotMC](https://www.spigotmc.org/resources/playerparticles.40261/)

- **兼容性**：支持 1.8 - 1.21.10 全版本（2026-05 更新），Java 17+

- **亮点**：
  - 老牌稳定、文档 / 教程最多，100+ 粒子效果（含 1.21.9 新增 `copper_fire_flame`）

  - GUI 选择 + 指令切换双通道，逐玩家独立生效

  - 与 PAPI 联动可做 "活动自动解锁特效"

- **适合场景**：想给全体玩家开放又怕新插件出问题的**保守之选**

- **注意**：与 KillEffects 等击杀特效插件**功能有重叠**，别叠 2 个以上同类型

### 5. sParticles —— 脚步粒子 + 光环（装扮神器）

- **链接**：[SpigotMC](https://www.spigotmc.org/resources/sparticles-add-particles.125449/)

- **兼容性**：1.21.x，轻量

- **亮点**：
  - 独特的**脚步足迹粒子**（走过留痕）+ 持续光环粒子，视觉辨识度高

  - 玩家可解锁、选择、展示，天然适合做成**活动奖励 / 装扮商城特权**

- **适合场景**：配合活动奖励发放特效使用权

## 二、宠物系统（伙伴跟随，生存服人气王）

### 1. FarPets —— 功能最全宠物插件（2026-09 仍在更新）

- **链接**：[SpigotMC](https://www.spigotmc.org/resources/farpets.138745/)

- **兼容性**：1.20.4+ / 1.21，性能优化过，几十人服无压力

- **亮点**：
  - **22 种被动加成**：海豚加速钓鱼、狼加近战伤害等

  - 70+ 粒子轨迹、支持骑乘、宠物改名

- **常用指令**：

```
/pets               # 打开宠物菜单

/pets summon <种类> # 召唤宠物
```

- **适合场景**：**全服开放**宠物养成，配合经济插件做 "买宠物蛋"

### 2. RZXPets —— 浮空肩宠，升级到 100 级

- **链接**：[SpigotMC](https://www.spigotmc.org/resources/rzxpets.137426/)

- **兼容性**：1.21.x

- **亮点**：
  - 宠物**悬浮肩膀跟随**，外观可爱、存在感强

  - 独立经验升级至 **100 级**，等级越高加成越多

- **适合场景**：主打**养成玩法**，适合长期在线玩家；等级加成可做 "宠物排行榜"

### 3. SimplePets —— 最流行的宠物插件（生态最完善）

- **链接**：[GitHub](https://github.com/brainsynder-Dev/SimplePets)

- **兼容性**：Spigot 1.21.6 - 1.21.11；Java 21（1.20.5+/1.21.11）/ Java 17（1.19-1.20.4）

- **亮点**：
  - 纯服务端、GUI 管理，召唤 / 隐藏 / 改名 / 换皮肤一条龙

  - **生态最好**：有 GemsEconomy 经济联动、扩展 addon，可做 "花钱买宠物"

  - 开源（GPL-3.0），API 完善，遇到问题好排查

- **适合场景**：宠物玩法的**主力选择**，与 FarPets 二选一即可，别两个都装

- **注意**：文档在官方 GitHub Wiki，配置项多，但社区资料全

## 三、全息文字（服务器装饰 / 公告整活）

### 1. dHolograms —— 1.21 原生 TextDisplay，支持动画（高性能）

- **链接**：[SpigotMC](https://www.spigotmc.org/resources/dholograms-minimessage-support-animations-scale-billboard.134742/) ｜ [Wiki](https://github.com/DogeTennant/dHolograms/wiki)

- **兼容性**：**仅 Paper 1.21+**（不支持 Spigot，需 Paper API），Java 21+，PlaceholderAPI 可选

- **亮点**：
  - 基于原生 TextDisplay/ItemDisplay，**无盔甲架、无发包 hack**，任意渲染距离都清晰

  - MiniMessage 彩色 / 渐变格式、5 种文本动画、多页导航、**点击执行指令**、逐玩家 placeholder

  - 存储支持 YML 或 MySQL

- **常用指令**：

```
/dh create <名字>   # 创建（例：/dh create welcome \<gradient:gold:yellow>欢迎回家\</gradient>）

/dh edit            # GUI 编辑
```

- **适合场景**：主城装饰、公告牌、"南瓜雕像" 悬浮称号、点击领礼包

### 3. AxoHologram —— 最新纯 Display Entity 实现

- **链接**：[Modrinth](https://modrinth.com/plugin/axohologram)

- **兼容性**：Paper 1.21+（2026-09 更新）

- **亮点**：
  - 纯 Display Entity，性能好、支持**逐玩家可见性控制**（只让指定玩家看到）

- **适合场景**：想要 "只对指定玩家可见的隐藏称号 / 彩蛋" 时用

### 4. Death Holograms —— 死亡地点全息（整活向）

- **链接**：[SpigotMC](https://www.spigotmc.org/resources/death-holograms-1-16-26-1-2.133766/)

- **兼容性**：1.16 - 26.1

- **亮点**：玩家死亡时在死亡点生成全息，可自定义文案（如 "XX 在此阵亡"），复活点捡尸之路整活拉满

- **适合场景**：配死亡消息一起用，欢乐加倍；记得设置自动清理时长防堆积

## 四、称号头衔（聊天 / 榜单存在感）

### DeluxeTags —— 权限称号插件（无限量自定义）

- **链接**：[SpigotMC](https://www.spigotmc.org/resources/deluxetags.4390/)

- **兼容性**：1.8 - 26.1（2026-09 更新）；依赖 **PlaceholderAPI**

- **亮点**：
  - 无限量**权限绑定称号**：给权限即解锁，玩家在 GUI 自由切换

  - 称号支持分类展示、彩色 / 渐变、悬停说明

  - 占位符 `%deluxetags_identifier%` 可接入聊天 / 计分板 / Tab 列表（EssentialsX 等均兼容）

  - 有社区 294 个现成称号扩展包可直接抄（[DeluxeTags-Extension](https://www.spigotmc.org/resources/deluxetags-extension-294-pre-designed-tags-fully-automatic.58222/)）

- **常用指令**：

```
/tags       # 打开称号 GUI

/dt admin   # 管理员管理
```

- **适合场景**：活动限定称号、排行榜称号、管理组专属称号

- **权限思路**：`deluxetags.tag.<名称>` 分发给对应组；示例配置：

```
deluxetags:

&#x20; ADMIN:

&#x20;   order: 1

&#x20;   tag: '&7\[\&c管理&7]'

&#x20;   description: '管理组专属称号'
```

## 五、头颅装扮（装饰 / 收藏）

### HeadDB（原 HeadDatabase）—— 数千自定义头颅数据库

- **链接**：[SpigotMC](https://www.spigotmc.org/resources/headdb.84967/) ｜ [Modrinth](https://modrinth.com/plugin/hdb)

- **兼容性**：Paper 1.21+（2026-09-12 更新）；1.20.6 及以下用 legacy 版

- **亮点**：
  - 数千个现成自定义皮肤头颅，GUI 浏览即取

  - 支持**服务端自定义头颅**（本地存储）：活动奖励、节日限定、员工头

  - 头颅可分类 / 打标签 / 收藏，API 完善，可被商店 / 菜单插件调用

- **常用指令**：`/hdb` 打开头颅浏览器

- **适合场景**：南瓜主题装饰（南瓜头换肤）、活动掉落、建筑美化

- **注意**：仅头颅本体，不包含掉落逻辑；想 "怪物掉头颅" 可另配 DropHeads / MoreMobHeads

## 八、RPG 养成（长期在线动力）

### 1. mcMMO —— 老牌 RPG 技能插件（经典中的经典）

- **链接**：[官网](https://mcmmo.org/)

- **兼容性**：1.20.5 - 26.2 全兼容（2026 持续更新），**24 种技能** + 超级技能 + 排行榜 + 队伍系统

- **亮点**：
  - 挖掘 / 砍树 / 钓鱼 / 战斗等日常行为自动获得技能经验，解锁被动加成与主动大招

  - 数百项配置，可关掉不想用的技能，防反作弊联动成熟

- **常用指令**：`/mcmmo help`（帮助）、`/mcstats`（个人面板）、`/mctop`（排行榜）

- **适合场景**：想给生存服加 "肝" 的深度，长线留存神器

- **注意**：技能过多可能改变原版平衡，建议先只开 5-8 个核心技能试水

### 2. ExcellentEnchants —— 80+ 原版风格自定义附魔

- **链接**：[SpigotMC](https://www.spigotmc.org/resources/61693/)（原 80+ Vanilla-like Enchantments）

- **兼容性**：**1.21.8+**，Java 21+，依赖 nightcore 引擎；Spigot/Paper 均可

- **亮点**：
  - 80+ 全新附魔（吸血红、连锁挖矿、爆炸箭等），风格与原版高度统一

  - 附魔带**粒子与音效**，还有独特的 "充能" 机制，附魔玩法更深

  - 不改战利品表 / 村民交易 / 附魔台，原版体验无缝接入

- **适合场景**：挖矿 / 战斗深度增强，配合经济插件卖 "附魔书"

- **注意**：与自定义附魔类插件只能装一个（同类冲突）

### 3. Jobs Reborn —— 职业经济系统

- **链接**：[SpigotMC](https://www.spigotmc.org/resources/jobs-reborn.4216/)

- **兼容性**：1.8 - 26.x 长期维护（2026-09 更新），依赖 **Vault** 经济

- **亮点**：
  - 12 个默认职业：猎人 / 农夫 / 附魔师 / 探险家 / 伐木工 / 矿工 / 建筑师 / 挖掘者 / 工匠 / 渔夫 / 武器匠 / 酿酒师

  - 做对应行为赚金币 + 经验，职业等级越高收入越高；可自定义职业与计费规则

  - GUI 查看 / 加入职业，奖励上限防刷

- **常用指令**：`/jobs`（职业 GUI）

- **适合场景**：给经济系统定 "来钱路子"，配合地皮 / 商店插件形成经济闭环

## 九、PVP 比赛（活动 PK / 锦标赛 / 常驻 PVP 规则）

> 适配环境：Leaf（Paper 分支）1.21.11、Java 21、基岩互通（Geyser）。以下插件均为服务端逻辑，基岩端可直接参与。

### 1. PvPManager —— 生存服常驻 PVP 规则（自愿开关 + 区域强制）

- **链接**：[CurseForge](https://www.curseforge.com/minecraft/bukkit-plugins/pvpmanager) ｜ [SpigotMC](https://www.spigotmc.org/resources/pvpmanager.27415/)

- **兼容性**：**1.21.11 已出专门版本**（v4.0.1.21.11，2026-03 更新），免费开源

- **亮点**：
  - **PVP 自愿开关**（`/pvp`）：玩家自己决定是否开 PVP，默认关，开的人互相才能打
  - **新手保护**（新人进服一段时间免伤）、**防战斗逃跑**（combat log 惩罚）、**防边界跳**（战斗中不能跑进安全区）
  - **指定区域强制 PVP**：把竞技场区域圈成强制开 PVP，平时主城 / 领地默认关

- **常用指令**：

```
/pvp [玩家]    # 开关 PVP
/pvpstatus     # 查看自己的 PVP 状态
```

- **适合场景**：解决"领地里能不能打人"的规则问题，是生存服 PVP 活动的**底层规则件**

- **注意**：与 Residence 领地的 `pvp` flag 功能有重叠，**两者选一个主导**（本服已有 Residence，可用它做区域控制，PvPManager 负责全服开关 / 新手保护 / 防逃跑）

### 2. CxDuels —— 1v1 决斗（带下注，活动 PK 主力）

- **链接**：[SpigotMC](https://www.spigotmc.org/resources/cxduels-1-21-x.134768/)（2026-05 更新，含中文 Wiki）

- **兼容性**：**明确支持 1.21.11**，Spigot/Paper

- **亮点**：
  - `/duel <玩家>` 发起挑战，菜单式接受 / 拒绝
  - **下注系统**：南瓜币 / 经验 / 物品对赌，赢家通吃
  - 可编辑 Kit、地图配置**免 WorldEdit**（工具选点）、自带背包模式（用匹配前的装备打）

- **常用指令**：

```
/duel <玩家>     # 发起 1v1 挑战
/duels editor    # 地图 / 竞技场管理 GUI
```

- **适合场景**：周末 PK 活动、赌注赛（配经济系统形成"赛事经济"）

- **权限思路**：`cxduels.use` 给全体（以官方页为准），下注额度可设上限防刷

### 3. UltimateDuels —— 专业决斗 / 竞技场（排位、FFA、小队战）

- **链接**：[Modrinth](https://modrinth.com/plugin/ultimateduels)（2026-09 更新）

- **兼容性**：1.21.1 – 1.21.x，**仅 Paper**，Java 21

- **亮点**：
  - **排位匹配 + 天梯**、**FFA 竞技场**、小队战（Party）
  - 1 – 20 回合制（Best of / Play All）、比分板实时更新、赛后 Title
  - 完整 Kit 管理（比赛用固定装备，公平竞技）

- **适合场景**：想长期做 PVP 竞技氛围、天梯排行，比 CxDuels 更"电竞化"

- **注意**：功能全 = 配置多；与 CxDuels **二选一**，别同时装两个决斗插件

### 4. dTournaments —— 限时目标赛（击杀榜 / 活动赛）

- **链接**：[SpigotMC](https://www.spigotmc.org/resources/dtournaments-gui-rewards-randomized-pool-20-objectives.134632/)（2026-09 更新）

- **兼容性**：Paper 1.21\* – 26.1.2

- **亮点**：
  - **20+ 目标**：击杀数、连杀、死亡、距离等，**限时赛自动结算排名**
  - GUI 奖励发放、随机奖池、活动全程可自定义

- **适合场景**："今晚 19 点，1 小时击杀王，冠军拿南瓜币 ×1000" 这类**限时目标活动**

- **权限思路**：`dtournaments.participate` 给全体，管理员权限单独给 admin（以官方页为准）

### 5. Manual Tournaments —— 正规淘汰赛网格

### 6. BKCTF —— 夺旗团队对抗（整活向）

## 十二、⚠️ 安装与注意事项

### 1. 基础环境

- 服务端：**Paper 1.21+**（dHolograms 等部分插件强制要求 Paper，Spigot 跑不了）

- Java：**21+**（老插件最低 Java 17，统一装 21 最省心）

- 核心前置：**PlaceholderAPI**（DeluxeTags / DeluxeMenus / DecentHolograms 等常用）、**Vault**（Jobs Reborn / DeluxeMenus 经济）、**nightcore**（ExcellentEnchants）

### 2. 指令冲突（重点检查）

- **dHolograms 与 DecentHolograms 共用&#x20;**`/dh`**&#x20;前缀，只能二选一**（本清单已默认选 dHolograms）

- 多个粒子插件并存时，**保留 1 个主力 + 1 个脚步特效**即可，别 5 个同类叠一起

### 3. 性能建议

- 粒子 / 宠物类插件吃一点性能：FarPets、Zenavia 都是 1.21 优化过的，几十人服没问题；但**宠物数量与粒子效果都设上限**（如每玩家 1 只宠物、粒子距离 32 格）

- 全息不要在主城无脑堆几百行，TextDisplay 虽快也不是无限

- BetterRTP 建议开异步加载，避免多人同时传送卡 TPS

### 4. 权限分组思路（LuckPerms）

- **default 组**：装扮基础（PlayerParticles 常用特效）、宠物 1 只、聊天 / 死亡整活、RTP 基础、`/pvp` 开关、`/duel` 挑战、参加限时赛（`dtournaments.participate`）

- **admin 组**：全部粒子特效 + 击杀特效 + 称号 + 宠物 2 只 + 隐藏全息可见权 + 全息管理 `/dh`、DeluxeMenus 配置、HeadDB 管理，其余全给；**PVP 活动管理**（CxDuels / dTournaments / Manual Tournaments 的管理节点、强制 PVP 区域）

### 5. PVP 活动注意事项

- **反作弊联动**：NovaAC / Grim 等对 PVP 场景容易误判（格挡、连跳、击退位移、鞘翅），**活动前把竞技场区域加入反作弊白名单 / 临时关掉 Speed / Fight / KillAura 检测**，赛后再开

- **决斗与下注**：CxDuels 等赌注功能建议设**单次下注上限**，防止玩家拿经济系统刷对赌；对赌双方需先开启 PvPManager 的 `/pvp`（或竞技场区域强制 PVP）

- **基岩玩家**：决斗 / 锦标赛均为服务端逻辑，基岩端可参与；聊天栏指令 `/duel` 基岩端可用，表单类交互以插件是否走 Floodgate API 为准（多数未适配时用聊天栏操作）

- **比赛禁用命令**：开赛前确认竞技场区域内 `/spawn`、`/home`（已禁用）、`/warp` 等逃出类指令被限制，多数决斗插件内置命令锁

### 6. 版本更新习惯

- 插件每 1-2 周检查一次官方页更新；MC 大版本升级（如 1.21 → 26.x）**先查各插件兼容表再升**

- 每次加新插件先在测试服跑 30 分钟，重点看控制台报错与 TPS

### 7. 下载安全

- 只认官方源：Modrinth / SpigotMC / Hangar / 作者 GitHub Release

- 警惕 "免费整合包" 里的 jar（可能带后门 / 挖矿脚本）；下载后对比文件大小与官方发布页
