# 服务器音乐方案：常驻 BGM + 现场放歌

> 适用：Leaf 1.21.11 双端互通服（Java + 基岩）。
> 本目录已备好**资源包骨架**和**循环播放数据包**，只差两样东西就能上线：
> ① 音乐 OGG 文件　② 一个可 HTTP 访问的资源包下载地址。

---

## 一、两条路径总览

| 需求 | 方案 | 谁能听到 | 本目录产物 |
|---|---|---|---|
| 主城/矿区/出生点**常驻 BGM**（进圈自动响） | 服务器资源包 + 自定义音效 + 数据包循环播放 | Java + 基岩（Geyser 转译） | `BGM资源包源文件/`、`循环BGM数据包/` |
| 管理员/DJ **现场点歌放歌** | Simple Voice Chat 客户端 Soundboard | 装了 SVC 模组的 Java 玩家（基岩走网页语音） | 无需改服务端，见 §四 |

> 为什么常驻 BGM 必须用资源包：原版 MC 客户端只能播放**资源包里注册的音效事件**，服务端无法直接把外部音频流推给原版客户端。所以自定义音乐必须打进资源包，再用 `/playsound <自定义事件>` 触发。

---

## 二、常驻 BGM 部署步骤

### 第 1 步：放入音乐文件
把无版权 OGG 放进 `BGM资源包源文件/assets/minecraft/sounds/music/`，文件名：

| 文件名 | 对应音效事件 | 用途 |
|---|---|---|
| `lobby.ogg` | `bgm.lobby` | 主城/大厅 |
| `mines.ogg` | `bgm.mines` | 矿区 |
| `spawn.ogg` | `bgm.spawn` | 出生点 |

> 要求：OGG Vorbis、44100Hz、立体声、无版权。每首 2~4 分钟。
> 不想要某段就不放对应文件、并删掉 `sounds.json` 里对应段。

### 第 2 步：打包资源包
把 `BGM资源包源文件/` 目录**里面的内容**（pack.mcmeta、assets/）压成一个 zip：
- zip 根目录直接是 `pack.mcmeta` 和 `assets/`（不要多套一层文件夹）。
- 命名如 `pumpkin-bgm.zip`。

### 第 3 步：托管到 HTTP
资源包必须通过 **URL** 下发，玩家进服时自动下载。任选其一：
- 本服已有的 Caddy/静态站点：把 zip 丢到站点目录，得到 `https://你的域名/pumpkin-bgm.zip`。
- 或任意静态托管（GitHub Release / OSS / CDN）。
- ⚠️ 必须是 **HTTPS**（或内网 HTTP 也行，但外网玩家要 HTTPS）。

### 第 4 步：算 SHA1
在 zip 所在目录算哈希（PowerShell）：
```powershell
Get-FileHash .\pumpkin-bgm.zip -Algorithm SHA1
```
复制那串 40 位十六进制。

### 第 5 步：写 server.properties
编辑 `C:\mc_serve\1.21.11-test\server.properties`：
```properties
resource-pack=https://你的域名/pumpkin-bgm.zip
resource-pack-sha1=第4步的40位哈希
require-resource-pack=false
resource-pack-prompt={"text":"下载音乐包以收听主城 BGM","color":"gold"}
```
> `require-resource-pack=false`：不强制，玩家拒绝也能玩（只是听不到 BGM）。
> 改完重启服务器。

### 第 6 步：装数据包并填坐标
1. 把 `循环BGM数据包/` 整个文件夹复制到：
   `C:\mc_serve\1.21.11-test\world\datapacks\pumpkin-bgm\`
   （即 datapack 根目录里要有 pack.mcmeta）
2. 改三个 `data/bgm/function/*_play.mcfunction` 里的坐标：
   - `lobby_play` → 主城中心 X Y Z
   - `spawn_play` → 出生点中心
   - `mines_play` → 矿区中心（若在别的世界，把 `in minecraft:overworld` 改成对应世界）
   - 把 `schedule function ... 2400` 的 2400 改成「曲目秒数 × 20」（如 3 分钟 = 3600）。
3. 游戏内控制台执行：
   ```
   /reload
   /function bgm:start
   ```
   之后玩家进对应区域就能听到 BGM，重启服务器也会自动播（load 标签已配）。
4. 停止：`/function bgm:stop`。

### 权限
- 玩家侧**无需任何权限**：`/playsound` 是服务端对玩家播，玩家被动听。
- 只有 OP/控制台能执行 `/function bgm:start|stop`。
- 基岩版玩家：Geyser 会把资源包音效转译，能听到；若听不到，确认基岩客户端已加载服务器资源包。

## 三、排错

| 现象 | 排查 |
|---|---|
| 玩家听不到 BGM | ① 确认资源包已加载（Esc → 选项 → 资源包里有）；② `/playsound bgm.lobby music @a ~ ~ ~ 1 1` 手动测；③ 看 F3 是否报 `Missing sound` |
| 资源包下载失败 | URL 是否 HTTPS、SHA1 是否和 zip 一致、防火墙/CDN 是否放行 |
| BGM 卡顿/重叠 | `schedule` 的 tick 数要 ≥ 曲目长度，否则上一首没播完又重播 |
| 客户端报资源包版本不符 | 改 `pack.mcmeta` 的 `pack_format` 为客户端提示的值 |

## 四、现场放歌（SVC Soundboard）

本服已装 Simple Voice Chat（2.6.21）。Soundboard 是**客户端模组功能**，服务端无需改配置：

1. 管理员/主持人在**自己的游戏客户端**（装了 SVC 模组）打开 SVC 设置 → Soundboard。
2. 添加音频条目（指向本地音频文件或 URL）。
3. 游戏内按 Soundboard 快捷键/点击，音频会通过语音通道广播给附近装了 SVC 的玩家。
4. 基岩版玩家通过 Geyser-SVC 网页语音端也能听到。

> 适用场景：活动、聚会、DJ 现场。想让所有人随时听到同一首歌、无人操作 → 还是走 §二 的常驻 BGM。

## 五、免费音乐素材来源（OGG）

> 选曲原则：**可商用**（服务器是公开的）、**最好直接给 OGG**、适合循环。
> 下表按"省事程度"排序。注意区分 **CC0（无需署名）** 和 **CC-BY（必须署名）**——CC-BY 要在服务器简介/公告里写明原作者。

| 站点 | 许可 | 格式 | 适合 | 备注 |
|---|---|---|---|---|
| [OpenGameArt.org](https://opengameart.org) | 多为 CC0 / CC-BY / OGA-BY | **OGG / WAV / MP3** | 游戏 BGM 首选 | 数万条游戏音乐与音效，按许可筛 CC0 可免署名；搜 "music" + "loop" |
| [SoundImage.org](https://soundimage.org) | CC-BY（需署名） | **直接给 OGG（循环版）** | 奇幻/冒险/解谜风格 BGM | 有专门的 OGG 打包页（如 Fantasy Ogg），专为游戏循环设计 |
| [Incompetech（Kevin MacLeod）](https://incompetech.com/music) | CC-BY 4.0（可付费免署名） | OGG / MP3 | 各种氛围 BGM | 量大、经典；CC-BY 必须署名作者与站 |
| [itch.io 免费音乐包](https://itch.io/game-assets/free/tag-music/tag-ogg) | 多为 CC0，看单包 | **OGG / WAV / MP3** | 8-bit、电子、奇幻整包 | 筛 "Free" + "OGG" + "Loopable"，CC0 包可商用免署名 |
| [Pixabay Music](https://pixabay.com/music/) | Pixabay 许可（免费商用、免署名） | 多为 MP3 | 通用氛围/轻快 BGM | 需转 OGG（见下） |
| [Mixkit Music](https://mixkit.co/free-stock-music/) | Mixkit 许可（免费商用） | MP3 | 轻快/氛围 | 需转 OGG |
| [Freesound.org](https://freesound.org) | 逐文件 CC0/CC-BY | OGG / WAV | 音效为主，BGM 为辅 | 找单段音效（门声、叮咚等），少用整曲 |

### MP3 → OGG 转码
很多站只给 MP3。MC 资源包要 OGG，用 ffmpeg 转：
```powershell
ffmpeg -i input.mp3 -c:a libvorbis -q:a 5 output.ogg
```
> `-q:a 5` 约 160kbps，BGM 够用；想更小用 `-q:a 4`。立体声保留即可。

### 选曲建议（对应本服三段）
- **lobby（主城）**：轻松/明亮，避免太吵——SoundImage 的 Fantasy / Puzzle 类，或 Incompetech 的 "Carefree" 类。
- **mines（矿区）**：低沉/氛围，不干扰挖矿——Incompetech 的 "Investigations" 类，或 OpenGameArt 搜 "ambient dark loop"。
- **spawn（出生点）**：温馨/新手引导感——Pixabay / Mixkit 的轻音乐。
