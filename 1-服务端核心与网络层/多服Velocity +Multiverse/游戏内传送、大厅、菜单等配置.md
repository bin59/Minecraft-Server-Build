## 1. 设计原则

| 原则                   | 说明                                                                         |
| ---------------------- | ---------------------------------------------------------------------------- |
| **每服独立菜单**       | 三个子服各有一套自己的 QuickMenu，右键时钟打开，只显示**本服该有的功能**     |
| **survival 全功能**    | 生存服是枢纽，加载完整菜单（40+：传送/领地/经济/任务/指南/管理面板等）       |
| **其他服只自己的功能** | minigames / skyblock 只保留本服世界切换 + 双向跨服返回，不加载 survival 那套 |
| **每服可立自己的 NPC** | 三个服各装一份 FancyNpcs，管理员在各自服里立本服的导航 NPC                   |
| **双向互通不断链**     | 任意节点都能回大厅、能去其他服；从任一服出发都能顺畅往返，不会"进得去出不来" |

**"大厅"的两个含义（本文统一）：**

1. **跨服大厅 / 主城** = survival 服的 `world`（玩家首登落点，所有服都能回）。
2. **本服大厅 / hub** = minigames 的 `mg_hub`、skyblock 的 `skyblock_hub`（各服自己的出生枢纽世界）。

### 1.1 三条跨服入口与各自前置

| 入口                    | 触发方式          | 实际链路                                      | 代理端前置                                    |
| ----------------------- | ----------------- | --------------------------------------------- | --------------------------------------------- |
| Advanced Portals 传送门 | 走进选区          | 后端 → `BungeeCord` 通道 `Connect` → Velocity | **仅** `bungee-plugin-message-channel = true` |
| FancyNpcs NPC           | 点击实体          | 后端执行 `/server <子服>` → 命令转发回代理    | 下面 §3 的三件套                              |
| QuickMenu `worldmenu`   | 点按钮 / 右键时钟 | 后端执行 `/server <子服>` → 命令转发回代理    | 下面 §3 的三件套                              |

> ⚠️ **别把两套权限混用**：传送门**不发** `/server` 命令，所以不受 `[commands]` / LuckPerms-Velocity /
> `velocity.command.server` 约束；那三件套只管点按钮、点 NPC 的入口。
> 传送门走进去没反应，先查 `bungee-plugin-message-channel` 与 `velocity.toml` 的 `[servers]` 名字；
> 菜单 / NPC 点了没反应，才查三件套。网络侧配置见 [多服网络与端口架构.md](./多服网络与端口架构.md) §4.1。
>
> 传送门的版本、命令、标签、配置文件与排错见 [传送门-Advanced Portals.md](./传送门-Advanced Portals.md)，本文不重复。

## 3. 跨服命令与前置（三服通用）

菜单里的跨服按钮本质是让**后端执行 `/server <子服名>` 再转发回代理**。必须满足三件套（缺一即"点击无反应"，与 OP 无关）：

1. `velocity/velocity.toml` 有 `[commands]` 段：
   ```toml
   [commands]
     server = "velocity.command.server"
     velocity = "velocity.command.velocity"
   ```
2. 代理端装 `LuckPerms-Velocity.jar`（独立 H2，不碰后端权限数据）。
3. 代理控制台授权：`lp group default permission set velocity.command.server true`。

> 改完 **重启 Velocity** 才生效（`/qm reload` 只重载后端菜单，不管代理）。
> 后端 OP 身份**不会**透传到代理，OP 也不能绕过这三件套；配置齐后用 `/qm open worldmenu` 逐服点验。

**与自研 SpacePortal 的分工**：SpacePortal 只做**单服内**坐标传送与传送阵，不能跨服。
命令上 `/portal` 专归 Advanced Portals，SpacePortal 用 `/csz` / `/spportal` / `/spaceportal`
（r1 曾抢注 `/portal`，r2 已移除）。两者都靠 `PlayerMoveEvent` 触发，**门的选区不要落在阵法激活半径内**
（默认 2.2 格，建门离阵法中心至少 5 格），否则会同时扣钻石充能与换服。
细节见 [SpacePortal 使用说明](../../自研/传送阵-SpacePortal/空间传送阵使用说明.md) §9。

**服内世界切换**（不跨服）：

- minigames 有 Multiverse → `[player] mvtp <世界>`（如 `mvtp map-jkpof`、`mvtp overworld`）。
  > ⚠️ **26.3 主世界名是 `overworld`，不是 `mg_hub`**：`mg_hub` 只是磁盘目录名（`level-name`）。`worlds.yml` 里主世界注册为 `minecraft:overworld`、`legacy-world-name: mg_hub`、`alias: ''`，所以 `mvtp mg_hub` 找不到世界、传送失败；必须写 `mvtp overworld`。
- skyblock 无 Multiverse，只有 BentoBox → 回自己岛用 `[player] island spawn`（需先 `/is create`）；回大厅用 `[player] server skyblock`（重进服落 `skyblock_hub`）。命令名以游戏内 Tab 补全为准（BSkyBlock/AOneBlock 提供 `/is`、`/island`、`/ob`）。

## 4. survival 菜单（完整版 · 全功能）

**配置**：`plugins/QuickMenu/config.yml`（`default-menu: main`）。

**主菜单（main）** 常用一级入口：世界切换（slot 22，原语音位已替换）、传送、领地、经济、工具包、皮肤、社交、信息、指南、南瓜飞等；管理线入口由 `quickmenu.admin` 门控。

**世界切换菜单（worldmenu）** —— 跨服四按钮：

```yaml
worldmenu:
  title: '&6&l世界切换 &8» &f选择你的去处'
  size: 27
  items:
    to-survival:
      {
        material: GRASS_BLOCK,
        slot: 11,
        actions: ['[close]', '[player] server survival'],
      }
    to-minigames:
      {
        material: DIAMOND_SWORD,
        slot: 13,
        actions: ['[close]', '[player] server minigames'],
      }
    to-skyblock:
      {
        material: END_STONE,
        slot: 15,
        actions: ['[close]', '[player] server skyblock'],
      }
    to-jkpof:
      {
        material: GOLDEN_CARROT,
        slot: 17,
        actions: ['[close]', '[player] server minigames'],
      }
```

- 打开：主菜单「世界切换」一级入口，或 `/qm open worldmenu`。
- 主菜单 `slot 22` 是**一级入口 `worldswitch`**（`END_PORTAL_FRAME`，动作 `[menu] worldmenu`），由原「语音」按钮位替换而来；`voice` 菜单定义本身保留在配置里，未删除。
- `to-jkpof` 先跨服到 minigames，到服后再右键时钟开 minigames 菜单进幸运之柱（两步，见 §5）。
- 改完 `/qm reload` 生效。

## 5. minigames 菜单（精简版 · 只自己的功能）

**配置**：`minigames/plugins/QuickMenu/config.yml`（`default-menu: worldmenu`）。已加载 Multiverse。

```yaml
worldmenu: # 标题：世界切换 » 小游戏服
  items:
    to-jkpof: { slot: 11, actions: ['[close]', '[player] mvtp map-jkpof'] } # 进幸运之柱
    to-mg-hub: { slot: 13, actions: ['[close]', '[player] mvtp overworld'] } # 回本服大厅（26.3 主世界 MV 名为 overworld，不是 mg_hub）
    to-survival: { slot: 15, actions: ['[close]', '[player] server survival'] } # 跨服回主城
    to-skyblock: { slot: 17, actions: ['[close]', '[player] server skyblock'] } # 跨服去空岛
```

**双向返回核对（不断链）** ✅：

- 本服内：`map-jkpof` ↔ `mg_hub`（都能 mvtp 回去）。
- 跨服：能回 survival 主城、能去 skyblock；反过来从 survival/skyblock 也都能来 minigames。

> `map-jkpof` 首次需管理员在 minigames 执行 `/mv import map-jkpof normal` 注册进 Multiverse，否则 `mvtp` 报未知世界。

### 5.1 幸运之柱地图 map-jkpof

**地图**：JK's Pillars of Fortune（幸运之柱）v1.4.1，MC 26.3。世界文件夹命名 `map-jkpof`，数据包 ID 仍为 `jkpof`（勿改）。归属 **minigames 后端**。

| 兼容性检查  | 结论                                                            |
| ----------- | --------------------------------------------------------------- |
| DataVersion | 地图 `5023` = 服务端 `5023` ✅                                  |
| 世界布局    | `dimensions/minecraft/overworld/region/`，无需挪文件 ✅         |
| 逻辑载体    | `datapacks/jkpof` 纯原版数据包，Leaf 原生运行，不依赖 Fabric ✅ |
| 基岩端      | 无 `resourcepacks/`，Geyser 直接翻译 ✅                         |

放进 minigames 前要做的清理（从客户端存档复制而来时）：

1. 删除客户端残留：`voxy/`、`serverconfig/`、`xaeromap.txt`、`LICENSE`、`README.md`、`icon.png`、`level.dat_old`、`session.lock`、`data/collective`、`data/fabric`、`data/mezz_config`（**`session.lock` 必须删**，否则服务端可能拒载）。
2. 保留：`dimensions/`、`datapacks/jkpof/`、`data/`（仅 `jk` + `minecraft`）、`level.dat`、`players/`。
3. `minigames/server.properties` 需 `spawn-protection=0`（地图 README 硬性要求）。
4. 执行 `/mv import map-jkpof normal` 注册进 Multiverse；`worlds.yml` 为空说明尚未注册，`mvtp` 会报未知世界。

**注意**：

- minigames 另有 `FortunePillars-4.6.0.jar`（同款插件版）。二选一：**A.** 纯 Multiverse + 数据包（本文采用，让插件不加载该图或卸掉插件）；**B.** 改用 FortunePillars 托管（不走 `/mv import`）。别让两者抢同一世界。
- 想干净开局，可删 `map-jkpof/data/scoreboard.dat` 与 `map-jkpof/data/jk/`，让数据包重新初始化。

> ⚠️ **26.3 实测坑（2026-11-22）**：`/mv import` 只搬地形不搬 `datapacks/jkpof`，导入后"只有地图没玩法"；spawn 默认在虚空（`0,1,0`）会被 `mvtp` 拦。**根因、修复步骤、`/mvsetspawn`（无参数）用法、原始文件夹别删等完整内容见 Multiverse 分册 [多世界-Multiverse/README.md](./多世界-Multiverse/README.md) §3–§4**（本处不再复制，避免两份漂移）。

**配置**：`skyblock/plugins/QuickMenu/config.yml`（`default-menu: worldmenu`，3 个菜单）。**无 Multiverse，只有 BentoBox（BSkyBlock + AOneBlock 两个 addon）**。用 QuickMenu 原生 `[menu] 菜单id` 跳转 + `back-menu` 返回按钮实现两级。

**一级 `worldmenu`（size 27）· 模式选择**

| 按钮（slot）   | 动作                        | 说明                  |

> 两个子菜单的 `back-menu: worldmenu` 会在右下角 slot 26 自动放返回按钮，Java / 基岩通用；该格不要再放物品。
> **新玩家进服自动创建岛**：`/is create` 按钮只作兜底，正常不用点。
> **重置岛**：BentoBox 自带二次确认 + 300 秒冷却，菜单只负责执行 `/is reset`。**背包 + 末地箱在重置时清空**：BSkyBlock 与 AOneBlock 的 `config.yml` → `on-join.inventory: true`、`on-join.ender-chest: true`（原为 false，导致旧物品被带进新岛）。这是"创建/重置岛"触发的重置；`on-leave` 未动。改完 `/bsb reload` 或重启生效。
> **邀请组队带参数**：走 `input-forms.is-invite`（`command: 'is invite {player}'`，字段 `type: player` 选在线玩家）——基岩弹原生选人表单，Java 端降级为 `/is invite 玩家名` 文本提示。这是配置层，不需要玩家打字。
> **查赛季**：本服未装 EzSeasons，菜单不放该入口。

**双向返回核对（不断链）** ✅：

- 本服内：子菜单 → 一级用右下角返回按钮；经典岛 → 大厅用 `server skyblock` 重进服、大厅 → 岛用 `island spawn`；单方块 → 大厅同理。
- 跨服：一级能回 survival 主城、能去 minigames；反过来也都能来 skyblock。

> `/island spawn` 需玩家已有岛（先 `/is create`）；`/ob` 需已有单方块岛。否则按钮提示无岛，属正常。命令名以游戏内 Tab 补全为准。
> 改完 `/qm reload` 生效；`input-forms` 段也在同一份配置里，重载即加载。

## 8. 各服 NPC 配置（FancyNpcs 2.12.1）

三服各装一份 `FancyNpcs-2.12.1+382.jar`（md5 一致：`41c5625603f2...`），**每 JVM 独立、配置各自生成**。管理员站在要放 NPC 的位置执行建 NPC 命令。

### 8.1 语法要点（2.x，与旧教程 1.x 不同）

| 旧（1.x，错）              | 新（2.12.1，对）                                 |
| -------------------------- | ------------------------------------------------ |
| `/npc movehere`            | `/npc move_here`                                 |
| `/npc displayName`         | `/npc displayname`                               |
| `any_click`                | `ANY_CLICK`（或 `LEFT_CLICK` / `RIGHT_CLICK`）   |
| `/npc playerCommand X ...` | `/npc action X ANY_CLICK add player_command ...` |

通用语法：

```
/npc create <英文id>
/npc skin <id> <玩家名|url|@mirror|@none>
/npc displayname <id> <MiniMessage文本>
/npc move_here <id>
/npc action <id> <ANY_CLICK|LEFT_CLICK|RIGHT_CLICK> add <type> [value]
/fancynpcs save
/npc list
```

- action 类型跨服推荐 `player_command`（值写命令，如 `server minigames`，走 §3 三件套）；也可用 `send_to_server`（值写子服名，走 BungeeCord 通道），两者都可用，本套 Velocity modern 环境下 `player_command` 更稳。
- 已废弃 `player_command_as_op`（临时给 OP，有安全风险），勿用。
- 数据落在各服 `plugins/FancyNpcs/npcs.yml`（空 = 未建）。改完 `/fancynpcs save` 落盘，config 另开有 15 分钟自动保存；`/npc list` 可核对。

### 8.5 把 `skyblock_hub` 建成真正的大厅（零新增插件）

**现状**：`skyblock_hub` 已是该服 `level-name`（玩家进服落点），但是 `minecraft:flat` 空世界、什么都没建。skyblock 只装了 BentoBox + FancyNpcs + QuickMenu + ServerConnector + Floodgate（**无 Multiverse**），所以「建大厅」= **在这个 flat 世界上盖建筑 + 立 NPC + 用现成菜单**，不需要装任何新插件、不需要多开世界。

**核心原则（避开主世界没有 `/ob` 的坑）**：`skyblock_hub` 不是 BentoBox 注册的模式世界（模式世界是 `oneblock_world` 和经典岛世界），所以 **在 hub 里 `/ob`、`/island spawn` 都不解析**——NPC 绝不能绑岛命令。正确做法是让 NPC **打开现成的两级菜单**，玩家在菜单里选模式、跳子菜单，命令由 BentoBox 在对应世界执行。菜单已经配好（见 §6），直接用即可。

#### 大厅布局（坐标由服主进服后自定， Below 仅示意）

| 区域       | 内容                               | 说明                                         |
| ---------- | ---------------------------------- | -------------------------------------------- |
| 出生点     | 大厅中心广场                       | 玩家 `/server skyblock` 落点；`spawn` 设在此 |
| 模式选择区 | 一个「空岛模式选择」NPC            | 绑 `qm open worldmenu`，弹出 §6 两级菜单     |
| 跨服返回区 | 回主城 / 去小游戏 NPC              | 绑 `server survival` / `server minigames`    |
| 装饰区     | 指示牌、地毯、灯笼、模式展示展品   | 纯原版方块，无功能，按审美摆                 |
| 岛入口提示 | 告示牌写「选好模式后点菜单创建岛」 | BentoBox 岛要从菜单/命令创建，不是走进传送门 |

> **不建传送门**：BentoBox 的岛是「每人一个动态生成的私有世界」，无法用固定坐标的 Advanced Portals 传送门直达；进岛统一靠菜单按钮执行 `/is create`、`/ob`。这也和 §6 一致。

#### 建造命令（管理员在 hub 里站位后执行，坐标即当时脚下）

```mcfunction

# ---------- 落盘 ----------
```

#### 出生点与防破坏

```bash
# 把大厅出生点设到当前站位（玩家进服/回大厅落这里）
/setworldspawn

# flat 世界建议保护出生广场，防止玩家破坏大厅建筑：
# 用 Residence 圈一块大厅保护区，关掉 build/destroy（见领地文档）
/res create skyblock_hub_lobby   # 站在广场用木锄圈地后执行
/res set skyblock_hub_lobby build false
/res set skyblock_hub_lobby destroy false
```

> ⚠️ 大厅若不加保护，玩家能拆 NPC 底座和装饰。用 Residence 圈区是最省事的办法（本服木锄圈地流程见领地文档）。`/setworldspawn` 是世界出生点；ServerConnector 进服落点若另行配置，以该插件为准（见下「待确认」）。

#### 玩家动线（建完后的完整闭环）

```
进服落 skyblock_hub → 点「空岛模式选择」NPC → 弹 §6 一级菜单
   ├─ 点「经典空岛」→ bskyblock 子菜单 → 创建岛/回自己岛
   └─ 点「单方块」  → oneblock 子菜单  → 创建单方块/回自己单方块
从岛回大厅 → §6 子菜单「空岛大厅」按钮 → /server skyblock 重进服落 hub
回主城/去小游戏 → 大厅对应 NPC → server survival / server minigames
```

#### 待确认（本鱼不越权，交给你进服核实）

- **ServerConnector 进服落点**：skyblock 装了 `ServerConnector-1.0.0.jar`，跨服 `/server skyblock` 的落点可能由它配置而非纯 `spawn`。若点「空岛大厅」没落到 hub，查它的 config。
- **`qm open worldmenu` 是否需要权限**：QuickMenu 的 `/qm open` 需 `quickmenu.use`（见 QuickMenu 文档 §命令）；确认玩家组有该权限，否则 NPC 点了没反应。
- **菜单触发物**：本服右键时钟也直接开 `worldmenu`（`default-menu: worldmenu`），所以即使不立 NPC，玩家在 hub 里右键时钟也能选模式——NPC 只是更直观。

## 9. 落地清单与生效方式

| 改动                          | 位置                                      | 生效方式                                   |
| ----------------------------- | ----------------------------------------- | ------------------------------------------ |
| survival 完整菜单 + worldmenu | `plugins/QuickMenu/config.yml`            | `/qm reload`                               |
| minigames 精简菜单            | `minigames/plugins/QuickMenu/config.yml`  | `/qm reload`                               |
| skyblock 精简菜单（本次新建） | `skyblock/plugins/QuickMenu/config.yml`   | 重启 skyblock（新 jar）/ 之后 `/qm reload` |
| 三服 FancyNpcs jar            | 各服 `plugins/FancyNpcs-2.12.1+382.jar`   | **重启对应服**才会加载                     |
| 各服 NPC 实体                 | 各服 `plugins/FancyNpcs/npcs.yml`         | 游戏内建完 `/fancynpcs save`               |
| `[commands]` + 代理权限       | `velocity/velocity.toml` + 代理 LuckPerms | **重启 Velocity** + `lp` 授权              |

**新装插件必须重启对应服务器**才会被扫描（先启动后放 jar 不生效——本次 Advanced Portals 就是踩这个坑）。菜单/NPC 配置改完各自 reload 或重启即可。

**启动顺序**：survival → minigames → skyblock → Velocity，各控制台 `Done (` 后再放玩家。

## 10. 排错速查

| 现象                         | 原因                                                                                                | 解决                                                                                               |
| ---------------------------- | --------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| `/portal`、`/npc` 报未知命令 | jar 放进 `plugins/` 后没重启                                                                        | 重启对应服；确认日志有 `Enabling`                                                                  |
| 走进传送门毫无反应           | `bungee-plugin-message-channel` 未开 / `bungee:` 名字与 `[servers]` 不一致 / 选区没包住脚下触发方块 | 见 [传送门-Advanced Portals.md](./传送门-Advanced Portals.md) §6；**不要**去查 `[commands]` 三件套 |
| 菜单跨服按钮点了没反应       | `[commands]` 段缺失 / 代理无 LuckPerms / 未授权                                                     | 见 §3 三件套，重启 Velocity + `lp` 授权                                                            |
| `/npc` 语法报错              | 用了 1.x 旧语法                                                                                     | 见 §8.1 换成 2.x 语法                                                                              |
| `mvtp map-jkpof` 未知世界    | 地图未注册进 Multiverse                                                                             | minigames 执行 `/mv import map-jkpof normal`                                                       |
| `map-jkpof` 有地形但没玩法   | 26.3 迁移只搬 region，没搬 `datapacks/jkpof`                                                        | 见 [多世界-Multiverse/README.md](./多世界-Multiverse/README.md) §3：放回 datapacks + 完整重启      |
| skyblock `mvtp` 不存在       | skyblock 无 Multiverse                                                                              | 回大厅用 `/server skyblock` 重进服，回岛用 `/island spawn`                                         |
| NPC 建了看不到               | 不在 NPC 所在服 / `npcs.yml` 空                                                                     | 确认所在服、`/npc list`、站对位置重建                                                              |
| 玩家进服没有时钟菜单         | 触发物品发放失败                                                                                    | 检查 `give-on-join: true`，或手动给时钟；/`qm` 开                                                  |
