## 口径纪律

1. **端口与配置只有一处真源**：`多服网络与端口架构.md`。迁移教程里的 `55551 / 19132 / 32217` 等是**教学示例**，不能当当前配置照抄。
2. 游戏内跨服的三种入口只在 `游戏内传送、大厅、菜单等配置.md` 写实现；插件分册只写插件本身，网络基准只写链路区别。
3. **Multiverse 命令/导入/spawn 的唯一真源是 `多世界-Multiverse/README.md`**；主文档 §11 只留定位概述，游戏内配置 §5.1 只留地图落地步骤，细节不再复制。
4. 新内容先判断属于哪一类再落笔；跨文档用链接，不复制整段。
