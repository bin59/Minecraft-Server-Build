# 3.3 基岩皮肤与皮肤头显示异常排查

本页记录本服「基岩版玩家皮肤 / 玩家头颅全部显示成史蒂夫（Steve）」这一类问题的定位方法与修复配置。适用插件：Geyser（Leaf 后端）、Floodgate、SkinsRestorer。记录日期：2026-09-24。

## 一句话结论

**Geyser 内置的皮肤支持是单向的**——它让 Java 端能看到基岩玩家的皮肤，但基岩客户端默认把 Java 版玩家全部显示为史蒂夫。要让两个方向都正常，必须：

1. Geyser 侧开 `skin-provider-mode`（管基岩端看 Java 皮肤 / 基岩玩家自己的 Xbox 皮肤）；
2. SkinsRestorer 侧认 Floodgate 前缀（管基岩玩家自己的皮肤生效）。

## 先分清是哪一种现象

| 编号 | 现象 | 根因 | 性质 |
|---|---|---|---|
| A | Java 玩家看到基岩玩家是史蒂夫 | Geyser 内置皮肤链路只支持「Java 看基岩」这一个方向 | **默认行为**，不算故障；要改就得上 SkinsRestorer |
| B | 基岩玩家看到 Java 玩家是史蒂夫 | Geyser 没代拉 Mojang 皮肤下发给基岩客户端 | 配置问题 |
| C | 基岩玩家设了皮肤，自己的头/皮肤库预览仍是史蒂夫 | SkinsRestorer 没覆盖到带 `.` 前缀的基岩玩家 | 配置/用法问题 |

## 修复：B — 基岩端看 Java 版玩家

```yaml
# plugins/Geyser/config.yml
settings:
  skin-provider-mode: default    # Geyser 代拉 Mojang 皮肤，下发给基岩客户端
                                 # proxied = 改用基岩玩家自己的 Xbox Live 皮肤
                                 # 本服用 default
```

- 改完执行 `/geyser reload`。
- 基岩客户端版本必须 **≥ 1.19.70**，player skins 是这一版起才在基岩端支持的。
- 若想让基岩玩家显示**自己开机自带 / Xbox Live 的皮肤**，改用 `proxied`。

## 修复：C — SkinsRestorer 不认基岩玩家

1. **版本**：SkinsRestorer 需 **≥ 10.0**，老版本不识别 Floodgate 的 `.` 前缀。
2. **设皮肤时名字必须带前缀**：
   ```
   /skin set .玩家名 皮肤名      ✔ 带点号
   /skin set 玩家名 皮肤名       ✘ SkinsRestorer 会当成不存在的 Java 玩家
   ```
3. **皮肤在进服时套用**：设置完必须让玩家**重新上线**才生效。
4. **交叉验证**：先在 Java 端 `/skin set 玩家名 皮肤名` 确认 Java 客户端能显示，能显示说明 SkinsRestorer 本身正常，问题只可能在基岩链路。

## 容易踩的坑

| 坑 | 说明 |
|---|---|
| `enable-custom-content` 关掉 | 关掉会导致 Geyser 的 skull（玩家头）映射失效，头颅一律变史蒂夫。本服为 `true`，不要动 |
| 换皮肤插件后没清旧皮肤 | 旧数据按原 UUID/名字存的基岩玩家皮肤不会自动迁移，需要重设一次 |
| 以为是 online-mode 问题 | 本服 `online-mode=true`，skin 拉取正常；不是这条链的问题就别往这查 |
| 基岩端 resource pack 压过皮肤 | 服务端强制资源包时基岩端可能只加载资源包，皮肤不刷新 |

## 排障顺序建议

1. `/geyser reload` + 让玩家重进一次（八成是缓存）。
2. 用 Java 客户端设皮肤，确认 SkinsRestorer 工作正常。
3. 用基岩客户端设皮肤，确认带 `.` 前缀。
4. 检查 Geyser `skin-provider-mode` 与 `enable-custom-content`。
5. 仍不行时 `/geyser dump` 导出上下文（含皮肤与 floodgate 状态）发到 Geyser Discord 或贴给维护者。
