# Minecraft Java 版 指令大全

本文件整理了 Minecraft Java 版 1.21.11 的常用指令，按实用、有趣、整蛊、场景专题等分类列出，并附带可直接复制的组合脚本与新旧语法排错对照表。服主和管理员可按分类索引快速查到所需指令，开服或日常运维时适合作为速查手册翻阅。

> **版本**：Java Edition **1.21.11**（Mounts of Mayhem / 群骑纷争，2025-12-09，协议 774，数据包 94.1）
> **适用**：绝大多数指令向下通用到 **1.20.5+**；🆕 标记 = 1.21 / 1.21.11 新增；⚠ 标记 = 有风险，先看注释
> **服务端**：本仓库用 Leaf（Paper 分支），语法与官方一致。命令方块需在 `server.properties` 设 `enable-command-block=true`
> **约定**：表中「注释」列写给人的话；代码块里 `#` 开头是注释，**复制时不要带上**

## 0. 基础必读

### 0.1 权限

| 项 | 值 | 注释 |
| --- | --- | --- |
| 单人 | 创建世界时开「允许作弊」，或 ESC → 开放局域网 → 允许作弊 | 仅本次会话有效 |
| 服务器 | 后台控制台 `/op 玩家名`；`server.properties` 的 `op-permission-level=4` | 聊天框里 `/op` 通常需要权限 3+ |
| 权限等级 | 1=防破坏，2=`/give`/`/tp`/`/effect` 等，3=`/ban`/`/kick`，4=`/stop`/`/save-off`/`/op` | 命令方块默认等级 2 |

### 0.2 选择器

| 选择器 | 含义 | 注释 |
| --- | --- | --- |
| `@s` | 执行者自己 | 命令方块里 `@s` 指方块自身，通常改用玩家名或 `@a` |
| `@p` | 最近玩家 | 单人图最常用 |
| `@a` | 全部玩家 | 服务器广播类 |
| `@r` | 随机玩家 | 抽奖、随机传送 |
| `@e` | 全部实体 | **务必加 `type=` 限定**，否则连掉落物、盔甲架一起处理 |
| `@a[limit=1,sort=random]` | 随机一人 | 比 `@r` 更可控 |

常用过滤器（写在方括号里，逗号分隔）：

| 过滤器 | 例 | 注释 |
| --- | --- | --- |
| `type=` | `@e[type=zombie]` / `@e[type=!player]` | `!` 表示排除 |
| `distance=` | `@e[distance=..10]` | `..10` = 10 格以内；`5..20` = 5 到 20 格 |
| `limit=` `sort=` | `@e[limit=3,sort=nearest]` | `nearest` / `furthest` / `random` / `arbitrary` |
| `tag=` | `@e[tag=temp]` | 配合 `/tag` 或 summon 的 `Tags` |
| `team=` `gamemode=` `name=` | `@a[team=red,gamemode=survival]` | 玩家常用 |
| `nbt=` | `@e[type=item,nbt={Item:{id:"minecraft:diamond"}}]` | 1.20.5+ 用小写 `count` |
| `scores=` | `@a[scores={deaths=1..}]` | 计分板条件 |
| `predicate=` | `@a[predicate=fun:inwater]` | 数据包谓词 |

### 0.3 坐标系

| 写法 | 含义 | 注释 |
| --- | --- | --- |
| `100 64 -200` | 绝对坐标 | 按 F3 查 |
| `~ ~ ~` | 相对执行者 | `~5` = 偏移 +5 |
| `^ ^ ^` | 相对视线 | `^ ^ ^5` = 眼前 5 格；左 `^-3` 右 `^3` 上 `^0 ^2 ^0` |
| `~ ~ ~ 90 0` | 坐标 + Y/X 旋转 | 用于强制转向 |

### 0.4 ⚠ 1.20.5 语法大改（最重要的一节）

| 场景 | ❌ 旧（≤1.20.4） | ✅ 新（1.20.5+ / 1.21） |
| --- | --- | --- |
| 物品附魔 | `{Enchantments:[{id:sharpness,lvl:5}]}` | `[minecraft:enchantments={levels:{minecraft:sharpness:5}}]` |
| 物品名 | `{display:{Name:'{"text":"A"}'}}` | `[minecraft:custom_name='{"text":"A"}']` |
| Lore | `{display:{Lore:[...]}}` | `[minecraft:lore=[...]]` |
| 染色 | `{display:{color:16711680}}` | `[minecraft:dyed_color={rgb:16711680}]` |
| 无法破坏 | `{Unbreakable:1}` | `[minecraft:unbreakable={}]` |
| 方块状态 | `{BlockStateTag:{level:15}}` | `[minecraft:block_state={level:15}]` |
| 药水 | `{Potion:"minecraft:poison"}` | `[minecraft:potion_contents={potion:"minecraft:poison"}]` |
| 实体里的物品 | `{id:"stone",Count:1}` | `{id:"minecraft:stone",count:1}`（**小写 count**） |
| 生物属性 | `{Attributes:[{Name:"generic.max_health",Base:100}]}` | `{Attributes:[{id:"minecraft:max_health",base:100}]}` |
| 找群系 | `/locatebiome` | `/locate biome` |

> **口诀**：物品用**方括号** `[组件]`，实体/方块用**花括号** `{NBT}`。两者不能混。

### 1.8 备份与运维

| 指令 | 效果与注释 |
| --- | --- |
| `/save-off` | 暂停自动存档（**备份前必做**） |
| `/save-all` | 立即保存一次 |
| `/save-all flush` | 强制写入磁盘 |
| `/save-on` | 恢复自动存档 |
| `/stop` | 关服（会先保存） |
| `/forceload remove all` | 取消常加载，降低内存占用 |
| `/kill @e[type=item]` | 清掉落物治卡顿 |

**标准热备份流程**（注释版）：

```mcfunction
# 1. 暂停写入，避免备份出一半的区块
/save-off
# 2. 强制落盘
/save-all flush
# >>> 此时用面板/MCSM/脚本复制 world 文件夹 <<<
# 3. 一定要记得恢复自动存档，否则崩服会丢数据
/save-on
# 4. 确认恢复
/gamerule doAutoSave      # 输出 true 即为自动存档开启
```

| `Too many blocks in the specified region` | `/fill` / `/clone` 超 32768 格，分块执行 |
| `/kill @e` 把盔甲架、展示框也杀了 | 加 `@e[type=!player,type=!armor_stand,type=!item_frame]` |
| 速度等级 5 以上穿墙失控 | `/effect` 速度用 2~3 即可 |
| 命令方块不执行 | `server.properties` 设 `enable-command-block=true` |
| 连锁方块只跑一次 | 第一格必须是「循环·保持开启」，且连锁方块**朝向**正确 |
| 组件里写中文报错 | JSON 文本用单引号包：`'{"text":"中文"}'` |
| `/tick rate` 太高卡崩 | 建议 ≤200，用完 `/tick rate 20` |
| `/reload` 后插件异常 | Paper/Leaf 上 `/reload` 有风险，**重启服务器更稳** |
| 1.21.11 客户端连不上旧服务端 | 协议 774，需同步升级服务端 |
