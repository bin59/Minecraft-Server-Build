# 🎃 南瓜生存服 · 玩家命令使用手册

本文档收录南瓜生存服玩家可用的各类命令，按传送、家园、领地、经济、工具包、皮肤、社交、语音等功能分类整理，并附基岩版专属表单命令与各身份能力对照。内容已按服务器实际配置逐条核对，面向进服玩家日常游戏查阅，管理类命令不在收录范围内。

> 本服大部分功能可以**右键指南针**打开快捷菜单完成，命令是为了让你更顺手。
> 遇到不会的，先点菜单；菜单没有的，再看下面的命令。
>
> 本手册已按服务器**实际配置**逐条核对（2026-09-19 更新）。

## 🌀 四、空间传送阵（本服特色）

服务器里有一种**地面法阵**，走进去自动充能，完成后传送到相连的法阵——这是长途移动最快的方式。

| 命令 | 作用 |
| --- | --- |
| `/csz` 或 `/csz list` | 查看所有传送阵（也可用别名 `/portal`、`/spaceportal`） |
| `/csz create 名字 [颜色]` | 在**脚下**创建一个传送阵 |

**怎么用**

1. 走到阵法中央，站着别动
2. 自动充能约 3 秒（中途移动会取消）
3. 充能完成 → 传送到相连阵法，落地有特效

**注意事项**

| 项目 | 说明 |
| --- | --- |
| 传送费用 | 每次消耗 **20 颗钻石**（背包里没有就传不了） |
| 冷却 | 落地后 5 秒内不能再次触发 |
| 阵法命名 | 只能用中英文、数字、下划线，最多 16 个字符 |
| 自建上限 | 服务器限制了每人可建数量，达到上限会提示 |
| 连线 | 阵法之间的连接需要**管理**操作，建好后找管理连线 |

> 💡 目前已公开的阵法：**主城 ↔ 矿区**（双向）。新阵法建好后联系管理接入网络。

## 🏠 五、领地系统（保护你的家）

**圈地三步**：

1. 拿**木锄**（本服圈地工具；若没有可向管理申请）
2. 左键点一个角 → 右键点对角，选中一块区域
3. 输入 `/res create 领地名` 完成圈地

| 命令 | 作用 |
| --- | --- |
| `/res create 领地名` | 创建领地 |
| `/res remove 领地名` | 删除自己的领地（不可恢复） |
| `/res list` | 查看自己的全部领地 |
| `/res info` | 查看**所在**领地的信息 |
| `/res tp 领地名` | 传送到自己的领地 |
| `/res tpset` | 把领地的传送点设在脚下 |
| `/res set 领地名 权限 true/false` | 设置领地内所有访客的权限 |
| `/res pset 玩家名 权限 true/false` | 单独设置某个玩家的权限 |
| `/res subzone 父领地 子领地` | 在领地内再划一块独立小区域 |
| `/res message 领地名 enter 欢迎语` | 设置进出领地的提示文字 |
| `/res unstuck` | 被领地边界卡住时脱困 |
| `/res ?` | 查看领地系统完整帮助 |

常用权限：`build`（建造）· `destroy`（破坏）· `use`（使用门/按钮）· `container`（开箱子）· `move`（移动）· `pvp`（PVP）· `tp`（传送）

> 💡 **小技巧**：手持**线**（STRING）右键方块/实体，可以直接查看它属于哪个领地。
>
> ⚠️ 圈地后别人就不能破坏你的建筑、开你的箱子了。权限设置以游戏内提示为准。
> 建议不要关闭 `move`，否则访客会走一步被拉回一步（体验很差）；防盗用 `build`+`container` 就够了。

## 💰 六、经济

**赚南瓜币**

| 命令 | 作用 |
| --- | --- |
| `/vote` | 为服务器投票，每票 30 南瓜币 |
| `/quests` | 每日任务（挖矿/打怪/钓鱼），完成后领南瓜币 |

**玩家间交易**

| 命令 | 作用 |
| --- | --- |
| `/ah` | 打开拍卖行：上架、竞拍、一口价购买（上架费 100，成交税 8%） |
| `/shop` | 打开玩家商店界面 |
| `/chestshop` | 创建木牌商店（开店费 100，成交税 5%） |

**消费与税务**

| 命令 | 作用 |
| --- | --- |
| `/homeshop` | 购买家园数量上限（5000 / 10000 / 15000 南瓜币） |
| `/eztax stats` | 查看周持有税统计（余额超 1 万部分按 1% 周征） |

> ⚠️ 量产物品（矿物、农作物等）**无法卖给系统**，请走玩家间交易（/ah /shop）；仅鞘翅、不死图腾等稀有物品有系统回收价。

## 🎙️ 十、语音聊天（Simple Voice Chat）

需要先在客户端安装 Simple Voice Chat 模组（版本需与服务器一致）。

| 按键 | 作用 |
| --- | --- |
| `Caps Lock` | **按住说话**（默认按键说话模式） |
| `V` | 打开语音设置界面（调音量、麦克风、语音距离） |
| `G` | 群组语音（无视距离，全图可听） |
| `M` | 静音麦克风 |
| `N` | 开关语音聊天 |
| `H` | 隐藏语音图标 |

> 📱 基岩版玩家需要配合网页端使用语音，详情看服务器公告或找管理。
>
> 🔧 听不到 / 说不了：检查模组是否安装且版本匹配 → 检查音频设备选择 → 服务器 UDP 端口 24454 需放行。

## 🏅 十二、不同身份能用什么（速览）

| 分组 | 聊天前缀 | 说明 |
| --- | --- | --- |

| 能力 | 玩家 | VIP |

| `/tpa` `/back` 传送 | ✅ | ✅ |
| `/skin` 换皮肤 | ✅ | ✅ |
| 语音聊天 | ✅ | ✅ |
| `/csz` 传送阵 | ✅ | ✅ |

> 具体能力由服主在权限系统中配置，以游戏内实际为准。想升级身份请联系管理。

## ❓ 十三、常见问题

| 问题 | 解决方法 |
| --- | --- |
| 命令没反应 | 先看是否拼写正确；部分命令有权限或身份要求 |
| 传送被取消 | 请求发出后对方需要 `/tpaccept`，且等待期间不能移动 |
| 领地被别人破坏 | 用 `/res pset 玩家名 build false` 禁止对方建造，或找管理用 CoreProtect 回滚 |
| 在别人领地里走不动、总被拉回 | 该领地关闭了 `move` 权限，找领主或管理开放 |
| 找不到指南针 | 输入 `/qm` 直接打开菜单即可，指南针只是个快捷方式 |
| 传送阵传不了 | 检查背包是否有 20 颗钻石；落地 5 秒内无法再次触发 |
| 还是不会 | 游戏里输入 `/help` 查看帮助，或找带 `[管理]` 前缀的玩家 |
