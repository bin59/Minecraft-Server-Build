| 节点 | 说明 | 分组 |

| `residence.select.basic` | 基础选区 | ✅ |
| `residence.select.area` | 选区工具选区 | ✅ |
| `residence.select.chunk` | 按区块选区 | ✅ |
| `residence.select.expand` | 纵向扩展选区 | ✅ |
| `residence.select.worldedit` | 用 WorldEdit 选区 | 🔧 |
| `residence.info` / `residence.info.others` | 查看领地信息 | ✅ |
| `residence.list` | 列出自己的领地 | ✅ |
| `residence.teleport` | 传送到自己的领地 | ✅ |
| `residence.subzone` | 创建子区域 | ✅ |
| `residence.message` | 设置进出提示语 | ✅ |
| `residence.unstuck` | 卡住时脱离 | ✅ |
| `residence.kick` | 把人踢出自己领地 | ✅ |

### 组映射（关键）

| 节点 | 说明 |
|---|---|
| `residence.group.<组名>` | 决定玩家使用 `plugins/Residence/groups.yml` 中的哪一组限制 |
| `residence.group.*` | 可使用任意组 🔧 |

> ⚠️ 组名要小写，且 `groups.yml` 中必须存在同名组，否则不生效。
> 详见 [权限组设计方案.md §4.2](权限组设计方案.md#42-residence-领地组residencegroupname)。

### Flags

| 节点 | 说明 |
|---|---|
| `residence.flags.<flag名>` | 允许设置某个 flag（如 `residence.flags.build`） |
| `residence.flags.*` | 所有 flags 🔧 |
| `residence.flags.bypass` | 无视他人领地的 flag 限制 🔧 |

常用 flag：`build` `destroy` `use` `container` `move` `tp` `pvp` `fire` `ignite` `flow` `tnt` `creeper` `damage` `trample` `mobkilling` `animalkilling` `wither`

### 管理 🔧

| 节点 | 说明 |
|---|---|
| `residence.admin` | 全部管理权限 ☠️ |
| `residence.admin.info` | 查看任意领地信息 |
| `residence.admin.remove` | 删除任意领地 ☠️ |
| `residence.admin.setowner` | 转移领地归属 ☠️ |
| `residence.admin.select` | 选取他人领地 |
| `residence.admin.tp` | 传送到任意领地 |
| `residence.lease` / `residence.rent` | 租赁 / 出租系统 |

| `luckperms.migration` | `/lp migration` 存储迁移 | ☠️ |
| `luckperms.import` / `luckperms.export` | 导入 / 导出 | ☠️ |
| `luckperms.reload` | `/lp reload` | — |
| `luckperms.*` | 全部 | ☠️☠️ 仅服主 |

> 更细粒度的形式：`luckperms.<命令>.<子命令>`，如 `luckperms.user.parent.add`。

## 原版与 Bukkit 命令

| 节点 | 说明 |
|---|---|
| `minecraft.command.<命令>` | 单个原版命令，如 `minecraft.command.gamemode` |
| `minecraft.command.*` | 全部原版命令 🔧 |
| `bukkit.command.*` | Bukkit 内置命令（`/pl` `/version` 等）🔧 |

常用原版命令节点：

```
minecraft.command.gamemode      minecraft.command.teleport
minecraft.command.give          minecraft.command.effect
minecraft.command.time          minecraft.command.weather
minecraft.command.summon        minecraft.command.kill
minecraft.command.setblock      minecraft.command.fill
minecraft.command.clone         minecraft.command.tp
minecraft.command.op            minecraft.command.deop        ☠️
minecraft.command.stop          ☠️
minecraft.command.datapack      ☠️
```

> ☠️ `minecraft.command.op` / `deop` / `stop` **绝不给任何玩家组**，包括 admin。

## 通用排错命令

```bash
# 检查某玩家是否拥有某权限
/lp user <玩家> permission check <节点>

# 查看某玩家的完整权限信息（含继承来源）
/lp user <玩家> info

# 查看某组的完整信息
/lp group <组名> info

# 实时追踪某权限的判定过程（排查神器）
/lp verbose on <玩家|me> <权限关键字>
/lp verbose off

# 查看权限树（某插件注册了哪些节点）
/lp tree <关键字>

# 列出所有组
/lp listgroups
```
