## 01-服务器核心-Leaf（生产 config\leaf-global.yml + paper-global.yml + paper-world-defaults.yml + spigot.yml + bukkit.yml + server.properties + start.bat）

### [高] 启动脚本无 Aikar GC 参数、Xms≠Xmx，4G 堆对 50 人偏紧
- 位置：生产 `start.bat`
- 问题：`java -Xmx4G -Xms1G -javaagent:... -jar leaf-1.21.11-174.jar nogui`。①没有任何 G1GC 调优（Aikar flags）；②`-Xms1G` 与 `-Xmx4G` 不等，堆会反复扩张/收缩触发 Full GC 抖动；③4G 上限对 50 人 + Geyser + Plan Web + ClearLag SQLite 历史记录偏紧。
- 建议：仅建议，改动前先备份 start.bat。改成 Xms=Xmx 并加 Aikar 参数，例如：
  ```
  java -Xmx6G -Xms6G -XX:+UseG1GC -XX:+ParallelRefProcEnabled -XX:MaxGCPauseMillis=200 -XX:+UnlockExperimentalVMOptions -XX:+DisableExplicitGC -XX:+AlwaysPreTouch -XX:G1NewSizePercent=30 -XX:G1MaxNewSizePercent=40 -XX:G1HeapRegionSize=8M -XX:G1ReservePercent=20 -XX:G1HeapWastePercent=5 -XX:G1MixedGCCountTarget=4 -XX:InitiatingHeapOccupancyPercent=15 -XX:G1MixedGCLiveThresholdPercent=90 -XX:G1RSetUpdatingPauseTimePercent=5 -XX:SurvivorRatio=32 -XX:+PerfDisableSharedMem -XX:MaxTenuringThreshold=1 -Dusing.aikars.flags=https://mcflags.emc.gs -Daikars.new.flags=true -javaagent:YggdrasilOfficialProxy-2.3.0-paperclip.jar -jar leaf-1.21.11-174.jar nogui
  ```
  前提是机器有 6G 以上空闲内存。
- 影响/收益：GC 抖动 / 卡顿（MSPT），这是小服最容易吃到的收益。
- 证据：生产 `start.bat` 全文仅一行 `-Xmx4G -Xms1G ...`。

### [中] server.properties：sync-chunk-writes 开着、网络压缩阈值过低
- 位置：生产 `server.properties`；键 `sync-chunk-writes` / `network-compression-threshold`
- 问题：①`sync-chunk-writes=true`（区块同步写盘，IO 卡顿源，Paper 官方建议 false 走异步写）；②`network-compression-threshold=64`（默认 256，64 意味着很小的包也压缩，CPU 白烧）；③`view-distance=12` 配合 `simulation-distance=4` 尚可，但 12 视距对小服偏高。
- 建议：仅建议，改动前先备份。`sync-chunk-writes=false`；`network-compression-threshold=256`；若玩家少于 30，`view-distance` 可降到 10。
- 影响/收益：IO（同步写盘卡顿）/ CPU（压缩）/ 内存（视距区块数）。
- 证据：`sync-chunk-writes=true`、`network-compression-threshold=64`、`view-distance=12`（生产 `server.properties` 第 45、67、71 行）。
